# 세계 주요 뉴스 | Daily news

[오늘의 뉴스 읽기](최신뉴스_latest.md)

해외·국내 언론의 공식 뉴스 피드에서 기사 제목과 원문 링크를 모읍니다. 매일 오전 9시 17분(한국 표준시)에 갱신하도록 설정되어 있으며, 실제 수집 시각은 뉴스 목록 위에 표시합니다. 뉴스 내용은 각 매체의 원문에서 읽으실 수 있습니다.

## 읽는 방법

- [오늘의 뉴스](최신뉴스_latest.md): 세계 뉴스와 한국 뉴스를 매체별로 읽습니다. 영어 기사는 원제 그대로, 한국어 기사는 한국어로 표시합니다.
- [매체와 수집 기준](매체와수집기준_sources.md): 사용하는 공식 피드, 기사 선택 기준과 출처를 확인합니다.
- [운영 안내](운영안내_operations.md): 실행 시간, 오류 확인, 수집 중지와 다시 실행하는 방법을 확인합니다.

서로 다른 매체의 기사도 같은 통신사 보도를 바탕으로 할 수 있습니다. 같은 사건을 여러 곳에서 다뤘다는 사실만으로 독립적으로 확인된 보도라고 판단하지 않습니다.
