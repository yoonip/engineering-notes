모의고사 1 · 빈도에서 구간과 탐색으로 · 가장 가까운 탈출구
[자체 창작 연습 · 실제 LIG 기출 아님]

0/1 격자와 K개 탈출구 위치를 받는다. 1만 통과해 상하좌우로 움직이며 시작은 (0,0)이다. 도달 가능한 탈출구 중 이동 횟수가 최소인 탈출구의 번호와 이동 횟수를 출력한다. 탈출구 번호는 입력 순서대로 1~K이며, 거리 동점이면 번호가 작은 것을 고른다. 모두 불가능하면 -1 -1.

입력: 첫 줄 N M K. 다음 N줄 0/1 문자열. 다음 K줄 탈출구 r c.
출력: 탈출구 번호와 최소 이동 횟수. 불가능하면 -1 -1.
제한: 1≤N,M≤100, 1≤K≤10,000. 각 탈출구 좌표는 0 기반이며 격자 내부. 중복 좌표 허용. 벽의 탈출구는 도달 불가능.

예제 입력
3 3 3
111
010
111
2 2
0 2
2 0
예제 출력
2 2
