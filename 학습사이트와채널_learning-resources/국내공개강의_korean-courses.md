# 국내 공개 강의 | Open courses in Korea

[학습 사이트와 채널](README.md) · [한국어 유튜브 채널](한국어유튜브_korean-youtube.md) · [해외 공개 강의](해외공개강의_global-courses.md)

한국어로 전공과 교양을 차례대로 공부할 수 있는 강의 플랫폼입니다. 대학의 대표 홈페이지보다 실제 강좌 목록과 수강 안내로 연결했습니다.

## 대학 강의와 기초 학습

| 사이트·운영 주체 | 주요 내용 | 시작 지점 | 이용 조건 |
| --- | --- | --- | --- |
| [KOCW 대학공개강의](https://www.kocw.net/home/index.do) · 한국교육학술정보원 | 여러 대학의 전공 강의와 강의자료를 과목·교수·대학별로 찾을 수 있습니다. | ‘선형대수학’, ‘전자회로’, ‘반도체 입문’처럼 과목명으로 검색 | 공개 강의 무료; 일부 외부 영상의 제공 여부는 강좌별 확인 |
| [K-MOOC](https://www.kmooc.kr/) · 국가평생교육진흥원 | 대학·기관의 온라인 강의를 주차별로 공부할 수 있습니다. 공학뿐 아니라 인문·사회·예술 강의도 있습니다. | 원하는 분야와 대학을 고른 뒤 선수지식·학습기간 확인 | 무료 강좌; 수강신청·진도 관리 등에 회원가입 필요 |
| [서울대학교 SNUON 안내](https://snu.ac.kr/about/sharing-snu/knowledge-sharing) · 서울대학교 | 일반인에게 공개하는 전공·교양 강좌와 지식나눔 서비스를 안내합니다. | [SNUON 바로가기](https://etl.snu.ac.kr/snuon)에서 강좌 검색 | 외부인 회원가입 제공; 수강신청·로그인 조건 확인 |
| [STAR-MOOC](https://www.starmooc.kr/) · 과학기술 특성화 대학 공동 플랫폼 | KAIST·UNIST·DGIST·GIST·POSTECH·UST가 공동으로 운영하는 과학기술 공개 강좌입니다. | [UNIST 공식 수강 안내](https://edu.unist.ac.kr/star-mooc_v2/)에서 가입·수강 절차 확인 | 공식 안내상 무료 회원가입 후 수강; 강좌별 제공 언어 확인 |
| [연세대학교 LearnUs](https://www.learnus.org/index.php?lang=ko) | 기초 수학·통계·물리부터 공학·철학·외국어까지 분야별 강의를 제공합니다. | [기초 물리학](https://www.learnus.org/local/ubonline/view.php?id=235693) 또는 무료 강좌에서 시작 | 무료·유료 과정 구분; 수강신청 조건은 강좌별 확인 |
| [고려대학교 K-CLASS](https://k-class.korea.ac.kr/) | 통계·데이터과학·AI 강의와 문학·인문학 공개 콘텐츠를 제공합니다. | [데이터과학의 수학 기초](https://k-class.korea.ac.kr/local/ubonline/view.php?group=&id=41) 또는 Open Courses 확인 | 공개·제한 강좌 구분; 강좌별 로그인·등록 조건 확인 |
| [부스트코스](https://www.boostcourse.org/opencourse) · 네이버 커넥트재단 | 소프트웨어·AI 학습에 사용할 수 있는 무료 강좌를 모아 제공합니다. | 무료 강의 목록에서 필요한 개발·AI 과목 선택 | 무료 강의; 학습 기능의 로그인 조건 확인 |
| [EBS 위대한 수업](https://home.ebs.co.kr/greatminds/index) | 연구자·작가·예술가가 자신의 분야를 주제별 짧은 강의로 설명합니다. | 과학·철학·경제·예술 중 관심 분야 선택 | EBS의 다시보기·구독 조건 확인; K-MOOC 제공 강좌는 별도 검색 |

SNUON은 서울대 공식 안내에서, STAR-MOOC는 UNIST의 [운영·수강 안내](https://edu.unist.ac.kr/star-mooc_v2/)에서 확인했습니다. K-CLASS의 공개교육 성격은 [고려대학교 안내](https://registrar.korea.ac.kr/eduinfo/program/open.do)에서도 확인할 수 있습니다. 대학 이름보다 강좌의 교수자·계획서·등록 조건을 먼저 살펴보시면 선택하기 쉽습니다.

확인일: 2026-10-22. 공식 소개와 공개 강의·자료 목록을 확인했습니다. 무료 열람, 계정 등록, 원문 구독과 별도 교육과정의 조건은 구분해서 확인하시면 됩니다.
