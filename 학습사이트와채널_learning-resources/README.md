## 선정과 이용 기준

운영 주체와 강사·작성자가 확인되고, 실제 강의·설명·원문 자료로 연결되는 곳을 우선했습니다. 대학 강의는 순서대로 공부할 때, 시각적 해설은 개념을 처음 이해할 때, 공식 기술 문서는 사양과 사용 조건을 확인할 때 적합합니다. 기업의 뉴스룸은 해당 기업의 발표를 읽는 곳이며, 경쟁 제품보다 우수하다는 독립 검증을 대신하지 않습니다.

개인 채널은 전공 강의와 교양·기술 동향 해설을 구분했습니다. 구독자 수나 기관의 명성만으로 모든 설명이 정확하다고 판단하지 않으며, AI 도구의 사용 여부도 일괄 보증하지 않습니다. 중요한 수치나 설계 조건은 영상에 연결된 원문·교재·데이터시트에서 함께 확인하시면 좋습니다.

확인일은 2026-10-22입니다. 소개 페이지, 강의·영상 목록과 공개 설명에서 운영 주체·주제·접근 조건을 확인했습니다. 모든 강의를 수강하거나 모든 영상을 끝까지 시청한 목록은 아닙니다. 한국어 더빙·제작 자막과 플랫폼의 자동 번역은 구분하며, 유료 과정·수료증·장비 비용이 있는 경우 해당 안내를 따릅니다.

이 폴더는 외부에서 공부할 곳을 찾는 안내입니다. 이 저장소의 글에 사용한 근거는 [출처와 참고 자료](../참고자료_references/README.md), 직접 작성한 해설은 [분야별 목차](../분야별목차_CATALOG.md)에서 찾으실 수 있습니다.
