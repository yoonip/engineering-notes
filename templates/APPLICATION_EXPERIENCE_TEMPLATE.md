# 지원 기록의 구성

지원 기록은 지원한 대상과 직무, 제출 문서, 전형 단계, 수행 내용, 결과를 연결한다. 같은 기업이라도 직무·시기·전형이 다르면 다른 경험이다.

| 항목 | 의미 |
|---|---|
| 대상·시기 | 학교·연구실·기업과 지원 시점 |
| 직무·관심 분야 | 지원 목적과 기술 범위 |
| 문서 | 이력서·CV·자기소개서·포트폴리오의 버전 |
| 평가 | 코딩테스트·직무시험·역량검사·과제·면접 |
| 결과·오퍼 | 전형 결과와 후속 진행 |
| 복기 | 준비 과정, 판단, 개선 내용 |
