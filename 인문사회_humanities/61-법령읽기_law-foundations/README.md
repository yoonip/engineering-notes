대한민국의 헌법·법률·명령·조례와 법령의 시행시점을 구분하고, 법적 요건과 효과를 원문에 근거해 읽습니다.

## 같은 문서 이름, 다른 적용 시점

가상의 규칙 v1이 2024-02-01에 시행되고, 이를 바꾸는 v2가 2024-11-01에 공포되어 2025-01-01에 시행된다고 가정하겠습니다. 2024-12-01에 시행 중인 버전을 조회하면 v1이고, 2025-01-01에는 v2입니다. “가장 최근에 공개된 문서”와 “그 날짜에 시행 중인 문서”는 같지 않을 수 있습니다. 이 예는 이력 조회를 설명하기 위한 가정이며 실제 법령의 적용 결론이 아닙니다.

읽는 순서는 문서의 제명·조문, 공포일·시행일, 적용례·경과조치, 해당 사실관계입니다. 시행일을 찾는 계산과 구체적인 사건에 어느 규정을 적용하는지는 다른 질문입니다. [법령의 출처와 해석](해설_notes/법령을읽는첫걸음_legal-sources-and-interpretation.md)은 공식 원문을 읽는 기준을, [법령 이력과 시간 구간](해설_notes/법령이력과시간구간_version-timelines-and-scope.md)은 날짜 경계와 이진 탐색을 설명합니다.

### Publication and effective dates

In a constructed timeline, v1 takes effect on 2024-02-01; v2 is published on 2024-11-01 and takes effect on 2025-01-01. An effective-version lookup on 2024-12-01 returns v1, while a lookup on 2025-01-01 returns v2. Finding the correct dated text and deciding its application to a real case remain separate questions. The linked articles cover official sources and an explicit date-boundary model.
