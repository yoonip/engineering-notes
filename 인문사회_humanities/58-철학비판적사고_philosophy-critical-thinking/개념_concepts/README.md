# 철학의 기본 개념 / Core concepts in philosophy

용어의 뜻을 익히고, 하나의 사례에 적용한 뒤, 다른 입장이 제기할 반론을 비교합니다. 철학사를 이름과 연도만 외우는 목록으로 읽기보다 ‘무엇을 묻는 개념이며 어떤 판단을 구분합니까’를 중심에 둡니다. 오래 정착한 용어와 논증을 배운다는 것이 모든 철학적 결론이 이미 하나로 확정되었다는 뜻은 아닙니다.

## 다섯 장을 읽는 순서

| 순서 | 본문 | 익힐 개념과 사례 |
|---|---|---|
| 1 | [질문과 시대](철학의질문과시대_questions-and-periods.md) | 존재·앎·행동의 질문, 고대·중세·근현대의 맥락, 주장과 반론을 적는 학습 카드 |
| 2 | [실재와 원인](실재와원인_reality-and-causation.md) | 사물과 성질, 보편자, 형상과 질료, 네 원인과 고장 경보 |
| 3 | [지식과 근거](지식과근거_knowledge-and-justification.md) | 믿음·참·정당화, 경험과 이성, 회의와 반례, 귀납과 인과 |
| 4 | [윤리와 정의](윤리와정의_ethics-and-justice.md) | 결과·의무·덕, 권리·자유·평등·분배, 원칙이 충돌하는 실제적 문제 |

각 장의 확인 문제는 답을 닫고 먼저 풀어 보시면 좋습니다. 정의를 다시 적는 데서 멈추지 않고, 다른 사례에서도 같은 기준을 적용할 수 있는지 확인합니다. 표에 있는 입장은 읽기 위한 출발점이며 해당 전통 전체를 짧은 문장 하나로 대체하지 않습니다.

## 한 사례를 여러 분야로 읽는 연습

다음은 직접 만든 사례입니다. 학습용 AI가 학생에게 맞춤 설명을 제공하지만, 일부 설명은 틀렸고 기록은 다른 서버로 옮겨졌다고 하겠습니다.

| 질문 | 이어 읽을 장 | 아직 결론에 넣지 않을 것 |
|---|---|---|
| 모델·기록·서비스 중 어느 대상을 같은 것이라고 합니까? | 실재와 원인, 마음·자유·동일성입니다. | 파일이 같으므로 같은 경험 주체라는 결론입니다. |
| 설명을 믿을 근거는 무엇입니까? | 지식과 근거입니다. | 유창하거나 우연히 맞았으므로 지식이라는 결론입니다. |
| 오류를 알렸을 때 출력이 바뀌는 까닭은 무엇입니까? | 실재와 원인, 마음·자유·동일성입니다. | 말로 이유를 출력했으므로 실제 원인도 같다는 결론입니다. |
| 운영자는 어떤 오류를 알리고 누구를 보호해야 합니까? | 윤리와 정의입니다. | 평균 성능이 높으므로 모든 운영 방식이 정당하다는 결론입니다. |

질문을 구분해도 서로의 근거가 무관해지는 것은 아닙니다. 실제 오류율은 윤리 판단에 중요하고, 무엇을 같은 서비스로 볼지에 따라 사용자에게 설명할 내용도 달라집니다. 다만 경험적 사실, 개념의 조건, 규범적 이유가 어떤 단계에서 결합되는지 드러냅니다.
