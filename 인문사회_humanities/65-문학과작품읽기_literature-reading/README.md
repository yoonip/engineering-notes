# 문학과 작품 읽기 / Literature and close reading

처음에는 예문을 읽은 느낌을 한 문장으로 적고, 그 느낌에 영향을 준 표현 두 곳을 표시해 보십시오. 그다음 다른 해석이 가능한 단서를 하나 찾습니다. 각 글의 확인 문제와 해설을 대조하면 근거를 넘어서 추측한 부분을 확인할 수 있습니다.

이 과정은 작품 분석의 출발점입니다. 한국·세계 문학사의 모든 시대와 작가를 포괄하는 과정으로 표시하지 않습니다. [언어이해](../../언어이해와추리논증_reading-reasoning/README.md)는 지문·선택지 판단을, [외국어 학습](../../외국어와기술영어_foreign-languages/README.md)은 언어 자체를 익히는 별도 경로입니다. [예술과 감상](../66-예술과감상_arts-aesthetics/README.md)에서는 매체·관객·평가를 이어서 다룹니다.

## English

These lessons use original prose, poetry and drama examples to study voice, information, rhythm, narrative order and staging. Each includes a worked analysis and three questions with explanations. This is an introduction to close reading rather than a complete literary history.
