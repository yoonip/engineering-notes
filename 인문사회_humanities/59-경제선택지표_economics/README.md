# 경제·선택·지표 | Economics, Choices and Indicators

희소성·기회비용·유인에서 출발해 경제적 선택을 분석하고, GDP와 물가를 정의·분모·기준시점에 맞게 읽습니다.

선택의 이유는 기회비용에서, 금액과 생산량의 차이는 GDP·물가에서, 산업 간 수요의 연결은 투입산출 모형에서 이어서 살펴보실 수 있습니다. 국어 지문의 구조와 선택지 판단 연습은 [언어이해](../../언어이해와추리논증_reading-reasoning/언어이해_reading/README.md)로 연결합니다.

## 명목 증가와 실제 증가를 계산해 보기

소득이 100에서 110으로 늘고 같은 소비 묶음의 가격이 100에서 105로 올랐다고 가정하겠습니다. 명목 소득 증가율은 10%지만, 그 묶음을 살 수 있는 양의 변화는 `1.10 / 1.05 - 1`, 약 4.76%입니다. 10%에서 5%를 뺀 5%는 근삿값이고 정확한 계산은 비율을 나눕니다. 이 수치는 설명용 가정이며 실제 국가의 소득·물가 통계가 아닙니다.

경제 지표는 무엇을 재고 어떤 가격을 고정했는지부터 읽으시면 됩니다. GDP는 생산의 범위를, 소비자물가는 정해진 소비 묶음의 가격을 다루므로 두 지표의 목적과 분모를 같게 놓을 수 없습니다. [GDP와 물가](해설_notes/GDP와물가읽기_gdp-inflation-real-values.md)는 명목·실질·증가율의 차이를 이어서 설명합니다.

선택 문제에서는 이미 지출한 비용과 지금 포기하는 대안을 나누어 보시면 됩니다. 이미 낸 환불 불가 비용은 지금 선택으로 되돌릴 수 없지만, 추가로 쓸 두 시간은 다른 일에 사용할 수 있습니다. [기회비용](해설_notes/희소성에서선택으로_scarcity-opportunity-cost-incentives.md)은 이 차이를, [투입산출 모형](해설_notes/산업연관과고정점_leontief-input-output.md)은 한 산업의 수요가 다른 산업에 이어지는 계산을 다룹니다.

## English

### Nominal and real changes

If income rises from 100 to 110 while a fixed consumption basket rises from 100 to 105, purchasing power changes by `1.10 / 1.05 - 1`, about 4.76%. Subtracting 5% from 10% is only an approximation. These are constructed values, not actual national statistics. The linked articles continue with indicator definitions, opportunity cost and inter-industry demand.
