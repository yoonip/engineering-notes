## 제출 코드와 보관 코드

일반 문제의 채점 기록은 해당 언어의 제출 내역에 근거합니다. 빈칸 채우기·한 줄 수정 형식의 C++ 16문제는 사이트에서 허용한 부분으로 채점받았으며, 전체 코드와 줄별 메모는 별도 보관본입니다.

주석을 정리한 보관본을 다시 제출한 기록으로 표시하지 않습니다. 채점 기록의 `archive_source_sha256`는 보관 파일 전체의 해시이며, `archive_execution_body_sha256`는 설명 구간 앞 실행 본문의 해시입니다. 문제별 확인 기록에는 실제 언어와 100점 제출 시각, 코드·README·채점 파일 경로를 남겼습니다.

제출 내역의 점수 확인과 보관 파일의 동일성 검사는 별도 근거입니다. 제출 ID와 사이트 제출 코드 원문을 새로 수집한 기록은 아니며, 해시 대조의 대상은 저장소의 보관 파일과 이전 게시본입니다.
