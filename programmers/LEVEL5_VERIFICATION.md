## 파일과 확인 근거

각 문제 폴더에는 제출한 실행 코드, 같은 코드의 모든 비어 있지 않은 줄에 붙인 문법·역할 설명, 풀이 요약, README, 사이트 채점 기록, 별도 로컬 검사 기록이 있습니다. 줄별 설명과 요약을 포함한 전체 코드를 채점에 제출했습니다.

채점 기록에는 제출 시각, 결과 확인 시각, 언어별 정답 내역, 제출본 SHA-256을 보관합니다. 최종 채점 화면을 보관한 30개 풀이에는 테스트별 통과 결과도 담았습니다. ‘눈사람 만들기’ 두 언어는 저장된 제출 내역의 정답 100/100을 최종 확인 근거로 기록합니다. 브라우저에 입력할 때 줄바꿈을 LF로 맞춘 사실도 구분해서 기록합니다. 로컬 전수·무작위·최대 크기 검사는 후보 작성 당시의 검사이며, 사이트 점수를 대신하지 않습니다.

기존 Python 파일 1732개는 작업 전 SHA-256과 모두 일치합니다. 이전 레벨 0~4 풀이와 채점 기록도 바꾸지 않았습니다. 기존 파일에서는 언어별 목록·전체 목차·검색용 카탈로그만 새 레벨 5 자료로 연결했습니다.
