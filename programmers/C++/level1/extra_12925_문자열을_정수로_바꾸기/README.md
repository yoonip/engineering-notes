# 문자열을 정수로 바꾸기

[레벨 1 목록](../README.md) · [C++ 전체 목록](../../README.md) · [프로그래머스](../../../README.md)

[공식 문제](https://school.programmers.co.kr/learn/courses/30/lessons/12925) · Level 1 · C++

## 풀이

stoi로 부호가 포함된 십진 문자열을 정수로 변환.

## 코드와 줄별 설명

#include <string>
#include <vector>
#include <algorithm>

#include <functional>
