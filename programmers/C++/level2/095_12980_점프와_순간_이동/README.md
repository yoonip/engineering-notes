## 풀이

목적지에서 거꾸로 짝수는 절반으로 줄이고 홀수에서만 점프 비용을 더해 이진수의 1 개수 세기

## 코드와 줄별 설명

[코드 파일](solution.cpp) · [채점 기록](grading.json)

```cpp
int solution(int n) {
    int answer = 0;
    while (n > 0) {
        answer += n % 2;
        n /= 2;
    }
    return answer;
}
```
