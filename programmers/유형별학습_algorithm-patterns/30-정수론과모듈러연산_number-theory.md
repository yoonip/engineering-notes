# 최대공약수·소수·모듈러 연산

[학습목차](README.md) · [연습문제](연습문제_problem-index.md)

## 핵심 원리와 중요성

정수론 문제에서는 나눗셈의 나머지와 약수 구조로 큰 수의 계산을 줄입니다.
a≡b mod m은 m이 a−b를 나눈다는 뜻입니다.
덧셈·뺄셈·곱셈은 중간에 나머지를 취해도 최종 나머지가 같습니다.
하지만 나눗셈은 역원이 존재하는지 확인해야 하므로 같은 규칙으로 처리하지 않습니다. [MIT 모듈러 연산 강의](https://courses.csail.mit.edu/6.857/2021/files/recitations/R01-notes.pdf)
반복 주기, 큰 경우의 수, 서로 다른 나머지 조건의 결합을 다룰 때 중요합니다.
아래 수치 예제는 직접 구성한 계산입니다.

## 최대공약수와 유클리드 알고리즘

gcd(a,b)=gcd(b,a mod b)는 두 수의 공약수 집합이 같다는 사실을 사용합니다.
a=qb+r이면 a와 b를 나누는 수는 r도 나누고, b와 r을 나누는 수는 a도 나눕니다.
나머지를 반복하면 두 번째 수가 0이 되었을 때 첫 번째 수가 최대공약수입니다.

| a | b | a mod b |
| ---: | ---: | ---: |
| 84 | 30 | 24 |
| 30 | 24 | 6 |
| 24 | 6 | 0 |

따라서 gcd(84,30)=6이며 lcm(84,30)=(84/6)×30=420입니다.
lcm을 a×b/gcd로 계산하면 최종 값은 작아도 중간 곱이 넘칠 수 있어 나눗셈을 먼저 합니다.
gcd(0,a)=|a|로 처리하며, 문제에 0이 포함되면 lcm 정의와 분모 0도 구분합니다.
유클리드 알고리즘은 O(log min(a,b)) 나머지 연산, 반복형의 보조 공간 O(1)입니다.
큰 정수의 비트 연산 비용까지 따지는 분석에서는 나눗셈 자체가 O(1)이 아닙니다.

## 확장 유클리드와 역원

확장 유클리드는 ax+my=gcd(a,m)을 만족하는 정수 x,y도 구합니다.
gcd(a,m)=1이면 ax≡1 mod m이므로 x mod m이 a의 역원입니다.
반대로 공약수 d>1이면 ax와 m의 배수의 차이가 1일 수 없어 역원이 없습니다.
3×4=12≡1 mod 11이므로 3의 역원은 4입니다.
8을 3으로 나눈 모듈러 값은 8×4 mod 11=10입니다.
보통 정수 나눗셈 8//3=2와 다른 연산입니다.
2 mod 6은 역원이 없으며, 소수 p에서도 0 mod p에는 역원이 없습니다. [ACL 역원 제약](https://atcoder.github.io/ac-library/production/document_en/math.html)

## 빠른 거듭제곱

a^e는 e의 이진수에서 1인 자리의 a^(2^k)만 곱해 계산합니다.
a^(2^(k+1))은 이전 값을 제곱해 구하므로 거듭제곱 수만큼 순회하지 않습니다.
3^13 mod 7에서 13=8+4+1입니다.
3^1,3^2,3^4,3^8의 나머지는 3,2,4,2이며 답은 2×4×3 mod 7=3입니다.

```python
def power_mod(base, exponent, modulus):  # exponent≥0, modulus≥1인 조건
    answer = 1 % modulus  # 지수 0의 값도 modulus=1 조건에 맞게 초기화
    base %= modulus  # 이후 제곱할 나머지
    while exponent:  # 지수의 남은 이진수 자리 처리
        if exponent & 1:  # 현재 자리에서 해당 거듭제곱을 선택
            answer = answer * base % modulus  # 선택한 인수의 곱을 누적
        base = base * base % modulus  # 다음 이진수 자리의 거듭제곱
        exponent >>= 1  # 처리한 최하위 비트를 제거
    return answer  # 최종 나머지 반환
```

시간 O(log e) 모듈러 곱셈, 보조 공간 O(1)입니다.
소수 p와 a가 p의 배수가 아닌 조건에서 a^(p−2)가 역원이지만, 합성수에 이 공식을 적용하지 않습니다.
Python은 pow(a,e,m), 역원이 존재하면 pow(a,-1,m)도 제공합니다. [Python pow 공식 문서](https://docs.python.org/3/library/functions.html#pow)

## 소수 판정·체·소인수분해의 구분

한 수의 단순 소수 판정은 2 이상 √n 이하의 약수를 확인하는 O(√n) 나눗셈 방법입니다.
약수가 짝으로 나타나므로 합성수에는 √n 이하인 약수가 적어도 하나 존재합니다.
N 이하를 반복 질의하면 에라토스테네스의 체로 소수의 배수를 지우는 방법을 검토합니다.
표준 체는 O(N log log N) 시간, O(N) 표 공간이며 p²부터 지우면 이미 처리한 배수를 건너뜁니다.
최소 소인수 표를 저장하면 여러 수의 분해에 재사용할 수 있지만 표의 상한 N만큼 메모리가 필요합니다.
큰 단일 정수에는 확률적 소수 판정·분해가 다른 선택이며, 작은 체의 복잡도를 그대로 적용하지 않습니다.

## 일반화된 중국인의 나머지 정리

x≡r1 mod m1과 x≡r2 mod m2는 gcd(m1,m2)가 r2−r1을 나눌 때에만 양립합니다.
직접 구성한 x≡2 mod 6, x≡5 mod 9는 차이 3이 gcd 3의 배수라서 가능합니다.
2,8,14를 대입하면 14가 두 조건을 만족하고 전체 해는 x≡14 mod 18입니다.
x≡1 mod 6, x≡2 mod 9는 차이 1이 3의 배수가 아니므로 해가 없습니다.
합친 주기는 곱이 아니라 lcm(m1,m2)이며, 모듈러가 서로소인 경우에만 곱과 같습니다. [ACL 일반 CRT 반환 규약](https://atcoder.github.io/ac-library/production/document_en/math.html)

## 구현·활용·한계

C·C++에서는 모듈러 전에 a*b가 넘치지 않는지 확인하고 필요하면 더 넓은 정수나 안전한 곱셈을 사용합니다.
음수의 % 결과가 언어마다 다르므로 ((x%m)+m)%m 같은 정규화의 필요 여부를 정합니다.
주기 일정의 교점과 정수 비율의 약분에 활용하며, 달력의 예외 규칙까지 단순 CRT가 해결하는 것은 아닙니다.
암호 프로토콜은 관련 정수 연산을 사용하지만 학습용 구현을 보안 구현으로 그대로 사용하지 않습니다.
[조합론](31-조합론과생성함수_combinatorics-generating-functions.md)의 나눗셈과 [행렬 거듭제곱](32-행렬거듭제곱과선형점화_matrix-recurrence.md)의 모듈러를 함께 확인합니다.

## 복습 질문과 답

- 질문: p가 소수면 모든 정수를 p로 나눌 수 있습니까? 답: p의 배수는 나머지가 0이라 역원이 없고, 나머지가 0이 아닌 정수만 역원이 있습니다.
- 질문: CRT의 모듈러가 서로소가 아니면 항상 실패합니까? 답: 나머지 차이가 최대공약수의 배수이면 해가 있고, 주기는 최소공배수입니다.
- 질문: 모듈러를 쓰면 곱셈 오버플로도 자동으로 사라집니까? 답: 나머지를 취하기 전에 곱셈이 수행되므로 중간 자료형의 범위를 따로 확인해야 합니다.
