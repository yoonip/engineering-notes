## 실행 환경과 비교 방법

C17·C++17은 Zig 0.16.0의 컴파일 드라이버를 사용했습니다. 옵션은 -O0 -Wall -Wextra -Werror이며, 경고도 오류로 처리했습니다. Python은 3.12.14에서 실행했습니다. Windows 출력의 CRLF만 LF로 정규화하고 값·공백·마지막 줄은 그대로 비교합니다.

소스의 각 실행 줄에 설명 주석이 있는지 확인했습니다. 주석은 짧은 복습 메모로 작성하며, 문자열 안의 주석 기호를 실제 주석으로 세지 않습니다. 본문에 넣은 전체 코드와 저장한 소스, 대표 입력·출력 파일이 같은지도 확인합니다.

## 실행 흐름과 언어 차이

각 유형에서 입력부터 초기 상태·주요 갱신·최종 결과까지 중간값을 표로 읽을 수 있습니다. 이 추적과 언어별 차이는 실제 코드와 별도로 대조했습니다. C·C++의 고정 배열과 정수 범위, Python의 입력 토큰·리스트 비용, 컨테이너·입출력 방식이 다른 부분을 예제에 맞춰 설명합니다.

확인한 입력 범위 밖의 모든 경우에 대한 증명이나 실행 시간 보장은 아닙니다. 본문의 정당성·비용 설명과 함께 읽으며, 예제에 구현한 기법은 각 문서의 범위에 적습니다. 같은 장에서 소개한 모든 세부 알고리즘을 하나의 프로그램이 구현한 것으로 표시하지 않습니다.
