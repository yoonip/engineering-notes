## 하나의 예제 실행

원하는 유형 폴더에서 실행합니다. C17·C++17을 지원하는 컴파일러와 Python 3을 사용합니다. 작은 유효 입력의 허용 범위는 각 유형 본문과 example.json에 적습니다.

```sh
cc -std=c17 example.c -o example_c
c++ -std=c++17 example.cpp -o example_cpp
./example_c < input.txt
./example_cpp < input.txt
python3 example.py < input.txt
```

Windows에서 Zig를 사용한다면 다음처럼 빌드하고 PowerShell 파이프로 입력할 수 있습니다. zig와 python의 실행 경로는 설치 환경에 맞게 지정합니다.

```powershell
zig cc -std=c17 example.c -o example_c.exe
zig c++ -std=c++17 example.cpp -o example_cpp.exe
Get-Content -Raw -Encoding utf8 input.txt | .\example_c.exe
Get-Content -Raw -Encoding utf8 input.txt | .\example_cpp.exe
Get-Content -Raw -Encoding utf8 input.txt | python .\example.py
```

## 예제 모음 확인

예제 전체 폴더에서 다음 도구를 실행하면 주석·Python 문법을 확인하고 C·C++을 컴파일한 뒤 저장한 기본·경계 입력을 세 언어에 전달합니다. 출력은 줄바꿈만 정규화하고 값과 공백을 그대로 비교합니다. 실행 파일과 결과 JSON은 지정한 경로에 저장하며 원본 코드는 바꾸지 않습니다.

```sh
python3 check_examples.py --cc cc --cxx c++ --build-dir /tmp/algorithm-example-build --report /tmp/algorithm-example-results.json
```

Zig를 쓰는 환경에서는 --zig 옵션에 실행 파일을 지정합니다. 일부 장만 확인하려면 --chapters 뒤에 장 번호를 나열합니다. --jobs로 동시 작업 수를 조절할 수 있습니다.

```powershell
python check_examples.py --zig zig --chapters 19 20 21 --build-dir .\build --report .\results.json
```

학습 예제의 로컬 결과는 프로그래머스 사이트의 새 채점 결과가 아닙니다. 예제마다 실제로 구현한 기법과 비용을 설명하며, 같은 장에서 소개한 모든 심화 알고리즘을 한 프로그램에 합쳤다는 뜻은 아닙니다.
