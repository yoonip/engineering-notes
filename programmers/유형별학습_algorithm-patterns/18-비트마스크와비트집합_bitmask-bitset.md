# 비트마스크 상태와 비트집합 연산

[학습목차](README.md) · [연습문제](연습문제_problem-index.md)

## 핵심 원리와 중요성

비트마스크는 정수의 각 비트에 원소의 포함 여부를 대응한 집합 표현입니다.
원소 0,2를 고른 집합은 이진수 101, 정수 5로 나타냅니다.
작은 원소 집합을 정수 하나로 저장하면 상태의 비교·복사·배열 인덱싱이 간단합니다.
비트집합은 더 많은 불리언 값을 기계어 단위로 묶어 여러 상태를 한 번에 처리하는 표현입니다.
집합 하나를 상태로 쓰는 비트마스크 DP와, 가능 여부 배열을 묶는 비트집합 DP는 구분합니다.

## 알아보는 단서와 한계

- 선택 대상 수 n이 작고 과거의 순서보다 선택된 집합이 중요한지 확인합니다.
- 합이 가능한지·서로 연결됐는지처럼 많은 불리언 상태를 함께 바꿀 수 있는지 확인합니다.
- 개별 원소가 중복 선택되는 횟수나 순서를 비트 하나만으로 표현하지 않습니다.
- 정수 하나에 들어간다고 해도 부분집합 수 2^n 자체가 작아지는 것은 아닙니다.

일반적인 집합 DP는 n=20 안팎에서도 전이 수와 메모리를 계산해야 합니다.
n=25에서 원소 하나당 전이를 수행하면 이미 약 8억 개 후보를 확인할 수 있습니다.
가능 여부를 OR로 합치는 연산은 경우의 수의 덧셈을 대신하지 못합니다.

## 집합의 기본 연산

| 목적 | 비트 식 | 의미 |
| --- | --- | --- |
| i 포함 검사 | mask & (1 << i) | 해당 자리만 남겨 0인지 확인 |
| i 추가 | mask \| (1 << i) | 기존 원소를 유지하고 i 포함 |
| i 제거 | mask & ~(1 << i) | i 자리만 0으로 변경 |
| i 뒤집기 | mask ^ (1 << i) | 포함·미포함을 반대로 변경 |
| 합집합·교집합 | a \| b, a & b | 자리별 OR, AND |
| 가장 낮은 1비트 | mask & -mask | 비어 있지 않은 집합의 한 원소 추출 |

Python 정수는 고정 32·64비트로 잘리지 않으며, 음수의 비트 연산은 무한 부호 확장을 가정합니다.
따라서 n개 원소에 대한 여집합은 (~mask) & ((1<<n)-1)처럼 범위를 제한합니다. [Python 정수 비트 연산](https://docs.python.org/3/library/stdtypes.html#bitwise-operations-on-integer-types)

## 직접 구성한 비트집합 배낭 예제

무게 [2,3,3]에서 합 6이 가능한지 구합니다. 각 물건은 한 번만 사용합니다.
정수 bits의 s번째 비트가 1이면 합 s가 가능하다고 정의합니다.
처음 bits=1은 합 0만 가능하다는 뜻입니다.

| 처리한 물건 | 새로 가능한 합 | 누적 가능한 합 |
| --- | --- | --- |
| 없음 | 0 | {0} |
| 2 | 2 | {0,2} |
| 3 | 3,5 | {0,2,3,5} |
| 두 번째 3 | 6,8 | {0,2,3,5,6,8} |

기존 정수를 w만큼 왼쪽으로 밀면 모든 가능한 합에 w를 더한 상태가 됩니다.
이 결과와 기존 정수를 OR하면 물건을 고르는 경우와 고르지 않는 경우를 함께 보관합니다.
오른쪽 식을 기존 bits에서 한 번 계산하므로 같은 물건을 연쇄적으로 다시 사용하지 않습니다.

```python
def subset_sum(weights, target):  # 음이 아닌 목표와 양의 정수 무게를 가정
    bits = 1  # 합 0이 가능한 초기 집합
    limit = (1 << (target + 1)) - 1  # 목표 이하 비트만 보관할 마스크
    for weight in weights:  # 서로 다른 물건을 한 번씩 반영
        if weight <= target:  # 양수이므로 목표보다 큰 물건은 제외
            bits = (bits | (bits << weight)) & limit  # 선택·미선택 상태를 합친 뒤 범위 제한
    return bool((bits >> target) & 1)  # 목표 합 비트의 존재 여부 반환
```

워드 크기를 w, 목표를 W, 물건 수를 n이라 하면 워드 배열 구현은 O(n⌈(W+1)/w⌉) 워드 연산과 O(⌈(W+1)/w⌉) 공간입니다.
Python 큰 정수도 비트 길이에 따라 연산 비용이 늘어나므로 전체 정수 연산을 O(1)로 세지 않습니다.
정확한 실행 시간은 구현의 내부 자리 크기와 메모리 할당에도 영향을 받습니다.

## 부분집합 DP와 부분마스크 순회

방문한 도시 집합 S와 마지막 도시 v를 dp[S][v]로 저장하면 경로의 순서는 최솟값에 압축합니다.
다음 도시 u를 추가하는 전이를 모두 보면 일반적인 방문 경로 DP는 O(n²2^n) 시간, O(n2^n) 공간입니다.
마지막 도시를 지우고 집합만 저장하면 다음 이동 비용을 판단하지 못하는 반례가 생깁니다.
S의 부분집합 T를 순회할 때 T=(T-1)&S를 반복하면 S에 없는 비트를 제거하면서 감소합니다.
T=0은 종료 조건으로 따로 처리하며, 0에서도 같은 식을 반복하면 S로 돌아갑니다.
모든 S에서 모든 T⊆S를 순회하는 총 횟수는 O(3^n)입니다.
각 원소가 S 밖·S 안이지만 T 밖·T 안의 세 상태 중 하나이기 때문입니다.

## 구현 차이와 실수

C·C++에서 단일 정수 시프트는 자료형의 비트 폭 이상 이동하거나 음수만큼 이동하면 안전하지 않습니다.
마스크가 64비트라면 상수도 1ULL처럼 충분한 폭의 부호 없는 값으로 시작합니다.
C++의 std::bitset<N>은 크기가 컴파일 시점에 정해지며, 이동과 비트 연산을 지원합니다. [Microsoft C++ bitset 문서](https://learn.microsoft.com/en-us/cpp/standard-library/bitset-class?view=msvc-170)
동적 워드 배열을 직접 이동할 때에는 워드 간 캐리와 마지막 워드의 범위 밖 비트를 처리합니다.
원래 배열을 덮어쓴다면 큰 인덱스부터 갱신해야 현재 물건의 새 상태를 다시 읽지 않습니다.

## 실전 연결과 연계 유형

서로 다른 집합의 원소 번호 체계가 같아야 하며, 희소하고 범위가 큰 ID는 압축이나 다른 집합 구조를 검토합니다.

## C·C++·Python으로 같은 예제 실행

가능한 합을 정수의 비트로 보관하고 이동·OR 연산으로 물건을 한 번씩 반영합니다.

이 예제에서 직접 구현하는 기법은 0-1 부분합 비트집합 · 왼쪽 시프트와 OR · 범위 마스크입니다. 같은 표준 입력에서 세 언어가 같은 결과를 출력합니다.

### 입력과 출력

n,T(0≤n≤20,0≤T≤60), 다음 n개의 양의 무게(1..60)입니다.

```text
3 6
2 3 3
```

목표 합을 만들 수 있으면 YES, 아니면 NO를 출력합니다.

```text
YES
```

### 입력부터 결과까지

| 단계 | 중간 상태 | 수행 이유 |
| --- | --- | --- |
| 1 | bits=1, 가능한 합 {0} | 빈 선택만 가능한 초기 상태입니다. |
| 2 | 무게 2 뒤 {0,2} | 기존 비트를 두 칸 이동하여 선택한 합을 추가합니다. |
| 3 | 첫 무게 3 뒤 {0,2,3,5} | 이번 물건을 고른 경우와 고르지 않은 경우를 합칩니다. |
| 4 | 둘째 무게 3 뒤 목표 이하 {0,2,3,5,6} | 새 합 6의 비트가 켜져 YES를 출력합니다. |

### C 예제

[실행 가능한 C 파일](<예제_examples/18-비트마스크와비트집합_bitmask-bitset/example.c>)

```c
#include <stdio.h>  // 표준 입력과 출력 함수

int main(void) {  // 비트집합 부분합 계산 시작
    int n, target;  // 물건 수와 목표 합
    scanf("%d %d", &n, &target);  // 목표는 60 이하로 제한
    unsigned long long bits = 1ULL;  // 합 0의 비트만 설정
    unsigned long long limit = (1ULL << (target + 1)) - 1ULL;  // 목표 이하의 비트 범위
    for (int i = 0; i < n; ++i) {  // 각 물건을 한 번만 반영
        int weight;  // 현재 물건의 양의 무게
        scanf("%d", &weight);  // 무게 입력
        if (weight <= target) bits = (bits | (bits << weight)) & limit;  // 선택과 미선택을 합치고 상한 적용
    }  // 모든 물건 반영 끝
    int possible = (int)((bits >> target) & 1ULL);  // 목표 위치의 비트 확인
    printf("%s\n", possible ? "YES" : "NO");  // 가능 여부 출력
    return 0;  // 정상 종료
}  // 프로그램 끝
```

#include <iostream>  // C++ 스트림 입력과 출력

int main() {  // 비트집합 부분합 계산 시작

### Python 예제

[실행 가능한 Python 파일](<예제_examples/18-비트마스크와비트집합_bitmask-bitset/example.py>)

```python
import sys  # 정수 토큰 읽기
tokens = iter(map(int, sys.stdin.read().split()))  # 표준 입력 순회
n, target = next(tokens), next(tokens)  # 물건 수와 목표
bits = 1  # 합 0만 가능한 초기 비트
limit = (1 << (target + 1)) - 1  # 목표 이하 마스크
for _ in range(n):  # 물건 한 개씩 처리
    weight = next(tokens)  # 현재 무게
    if weight <= target:  # 양수이므로 목표 초과 물건 제외
        bits = (bits | (bits << weight)) & limit  # 이전 상태에서 한 번만 이동
print("YES" if (bits >> target) & 1 else "NO")  # 목표 합의 비트 출력
```

### 예제의 비용과 실행 파일

- 시간: 고정 상한에서 O(n); 일반 비트집합은 O(n⌈(T+1)/w⌉) 워드 연산
- 보조 공간: 고정 상한에서 O(1)

한 정수의 시프트로 모든 가능한 합을 동시에 이동하며 목표 이하 비트만 유지합니다.
