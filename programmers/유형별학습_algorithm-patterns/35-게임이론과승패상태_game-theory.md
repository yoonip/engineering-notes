# 승패 상태와 스프라그–그런디 값

[학습목차](README.md) · [연습문제](연습문제_problem-index.md)

## 규칙과 관점의 고정

게임 알고리즘에서는 두 사람이 가능한 최선의 수를 둔다고 가정합니다.
여기서는 공개된 상태, 번갈아 하는 결정적 수, 움직일 수 없는 사람이 지는 정상 규칙을 중심으로 다룹니다.
승리·패배는 항상 “현재 차례인 사람”의 관점으로 정의합니다.
상대 차례로 이동하면 관점이 바뀌므로 한 번의 전이에서 승패 의미도 뒤집힙니다.
무승부·숨은 정보·확률적 사건이 있으면 같은 두 값만으로 충분하지 않습니다.

## 알아보는 단서와 승패 전이

상태 s에서 갈 수 있는 다음 상태 집합을 move(s)라고 정합니다.
다음 상태 중 상대가 지는 상태가 하나라도 있으면 s는 승리 상태입니다.
다음 상태가 모두 상대의 승리 상태이면 s는 패배 상태입니다.
아무 수가 없는 상태는 정상 규칙에서 패배 상태로 시작합니다.
상태 전이가 DAG이거나 돌 수처럼 엄격히 줄어드는 양이 있으면 역순 DP로 계산합니다.
이 분류는 유한 공평 게임의 기본 분석입니다. [Ferguson 원저자 조합 게임 교재](https://www.cs.cmu.edu/afs/cs/academic/class/15859-f01/www/notes/comb.pdf)

## 직접 구성한 돌 가져가기 추적

돌 한 무더기에서 매번 1개 또는 3개를 가져가며 마지막 수를 두는 사람이 이긴다고 정합니다.
남은 돌 수가 상태이며 큰 수에서 작은 수로만 이동합니다.

| 돌 수 | 갈 수 있는 돌 수 | 현재 상태 | 이유 |
| ---: | --- | --- | --- |
| 0 | 없음 | 패배 | 둘 수 없음 |
| 1 | 0 | 승리 | 패배 상태로 이동 가능 |
| 2 | 1 | 패배 | 상대 승리 상태만 존재 |
| 3 | 2,0 | 승리 | 패배 상태로 이동 가능 |
| 4 | 3,1 | 패배 | 둘 다 상대 승리 |
| 5 | 4,2 | 승리 | 둘 다 상대 패배 |

이 규칙에서는 홀수면 승리, 짝수면 패배라는 패턴을 관찰할 수 있습니다.
모든 허용 이동이 홀짝을 바꾸고 양의 홀수에서는 1개를 뺄 수 있다는 귀납으로 일반화합니다.
몇 항의 패턴을 본 것과 모든 수에 대해 증명한 것은 구분합니다.

## 짧은 승패 DP

```python
def winning_states(limit, moves):  # moves는 양의 정수 이동량 목록
    win = [False] * (limit + 1)  # 돌 0은 패배이며 나머지는 계산 전 상태
    for stones in range(1, limit + 1):  # 더 작은 상태의 승패를 먼저 계산
        win[stones] = any(step <= stones and not win[stones - step] for step in moves)  # 상대 패배로 보낼 수 있는 수 탐색
    return win  # 각 돌 수에서 현재 차례의 승리 여부 반환
```

상태 수 N+1, 허용 이동 종류 K이면 O(NK) 시간, O(N) 공간입니다.
일반적인 명시적 DAG 상태 그래프에서는 상태와 전이 수 V,E에 대해 O(V+E)입니다.
값을 구한 뒤 패배 상태로 가는 이동을 하나 저장하면 실제 승리 수를 복원할 수 있습니다.

## 독립 게임의 합과 그런디 값

한 번에 여러 게임 중 정확히 하나에서만 수를 둘 수 있는 합성 게임을 생각합니다.
각 부분 게임의 승패만 알면 합의 승패는 바로 결정되지 않습니다.
정상 규칙의 유한 공평 게임에는 G(s)=mex{G(t):t∈move(s)}를 부여합니다.
mex는 집합에 없는 가장 작은 음이 아닌 정수입니다.
예를 들어 mex{0,2}=1이고 mex{}=0입니다.
G=0은 패배, G>0은 승리이며 독립 게임의 합은 각 G의 XOR로 표현합니다. [Ferguson 교재의 합과 Sprague–Grundy 정리](https://www.cs.cmu.edu/afs/cs/academic/class/15859-f01/www/notes/comb.pdf)

돌 1개 또는 2개를 가져가는 다른 직접 구성 예제에서는 G(0…5)=[0,1,2,0,1,2]입니다.
G(2)=mex{G(1),G(0)}=mex{1,0}=2입니다.
무더기 (1,2)의 합은 1 XOR 2=3이므로 승리 상태입니다.
두 번째 무더기를 2에서 1로 바꾸면 1 XOR 1=0을 상대에게 줍니다.
무더기마다 따로 승리라고 해서 합도 승리라고 단정할 수 없습니다.

## XOR 규칙이 성립하는 이유

XOR가 0인 상태에서 한 부분 게임만 바꾸면 그 값은 기존 값과 달라집니다.
G의 정의상 같은 G값을 가진 바로 다음 상태가 없으므로 전체 XOR는 0이 아니게 됩니다.
전체 XOR가 0이 아니면 가장 높은 1비트를 가진 부분 게임을 골라 더 작은 목표 그런디 값으로 바꿀 수 있습니다.
mex 성질로 현재 G보다 작은 모든 값은 다음 상태 중에 존재합니다.
따라서 0이 아닌 합에서는 XOR 0으로, XOR 0에서는 0이 아닌 합으로만 이동한다는 승패 조건을 얻습니다.
단순 무더기 크기 자체가 G인 Nim과, 이동 제한으로 다른 G를 계산해야 하는 게임을 구분합니다.

## 순환·미제르·비공평 게임의 한계

상태가 다시 반복될 수 있으면 모든 상태를 승리·패배로만 표시할 수 없을 수 있습니다.
명시적 그래프에서는 종료 패배 상태부터 역간선을 따라 승패를 확정하고, 미확정 상태의 무승부 의미를 규칙에 맞춰 검토합니다.
마지막 수를 둔 사람이 지는 미제르 규칙은 종료 상태가 달라 일반적인 XOR 정리를 그대로 적용하지 않습니다.
두 플레이어의 허용 수가 다르면 공평 게임 조건이 깨지므로 같은 그런디 합성도 보장되지 않습니다.
여러 무더기에서 한 번에 동시에 돌을 빼는 수가 있으면 독립 게임의 합이 아닙니다.

## 구현·활용·연계 유형

mex는 한 상태의 다음 값 수보다 큰 값까지 무한히 찾을 필요가 없습니다.
차수가 d인 상태에서는 mex≤d이므로 범위를 제한한 방문 표나 시각 표시를 사용할 수 있습니다.
C·C++에서는 시프트와 XOR 자료형 폭을, Python에서는 상태 재귀의 순환과 호출 깊이를 확인합니다.
게임 규칙 검증과 작은 전략 공간의 자동 분석에 유용하지만, 확률·정보·이해관계가 있는 현실 의사결정을 같은 정상 게임으로 단정하지 않습니다.
[동적 계획법](16-동적계획법의상태와전이_dynamic-programming.md)과 [비트 XOR](18-비트마스크와비트집합_bitmask-bitset.md)을 연결해 복습합니다.

## 복습 질문과 답

- 질문: 이길 수 있는 다음 상태가 하나 있으면 승리입니까? 답: 다음 상태는 상대 관점이므로 상대가 지는 상태로 갈 수 있어야 합니다.
- 질문: 두 게임이 각각 승리면 합도 승리입니까? 답: 그런디 값이 같으면 XOR가 0이 되어 합은 패배일 수 있습니다.
- 질문: 반복이 있는 게임도 mex를 재귀 호출하면 됩니까? 답: 순환과 무승부를 먼저 처리해야 하며 유한 DAG용 재귀를 그대로 적용하면 안 됩니다.
