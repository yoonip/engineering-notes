# 배낭·수열·구간·자릿수·확률 DP

[학습목차](README.md) · [연습문제](연습문제_problem-index.md)

## 같은 원리와 다른 상태

DP의 이름은 입력 모양과 남겨야 하는 정보에 따라 달라집니다.
배낭에서는 사용량, 수열에서는 마지막 위치, 구간에서는 양끝, 자릿수에서는 상한과의 관계를 보관합니다.
아래 계산 예제는 상태 차이를 설명하기 위해 직접 구성한 예제입니다.
전이식을 외우기 전에 [상태와 전이](16-동적계획법의상태와전이_dynamic-programming.md)의 설계 순서를 적용합니다.

## 0-1 배낭과 무제한 배낭

0-1 배낭은 각 물건을 최대 한 번만 선택하는 문제입니다.
dp[w]를 용량 w 이하에서 얻는 최대 가치로 정하면, 물건 (무게 a, 가치 v)의 전이는 dp[w]=max(dp[w],dp[w-a]+v)입니다.
한 배열을 사용할 때에는 w를 큰 값부터 내려가며 계산해야 같은 물건을 다시 읽지 않습니다.
무게 2·가치 3인 물건 하나와 용량 4에서 오름차순 갱신을 하면 dp[2]=3을 다시 사용해 dp[4]=6이 되는 반례입니다.
무제한 배낭은 무게 a가 양의 정수이고 재사용이 허용될 때 같은 물건에서 w를 오름차순으로 갱신합니다.
무게 0·양의 가치인 물건을 무제한 선택하면 최댓값이 무한대이므로 이 유한 전이로 처리하지 않습니다.
물건 수 n, 정수 용량 W에서 두 방법 모두 O(nW) 시간, 가치만 구하면 O(W) 공간입니다.
W가 매우 큰 이진수 입력이면 다항 시간이라고 할 수 없는 의사다항 시간입니다. [MIT 배낭 복잡도 강의](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/7232b0ff982f501556118a8552654762_MIT6_006S20_r19.pdf)

가중치가 음수이거나 물건 간 선택 의존성이 있으면 이 단순 상태와 갱신 순서를 다시 설계합니다.
정확히 무게 W를 채워야 한다면 dp[0]=0 외의 상태를 불가능으로 시작합니다.

## 최장 증가 부분 수열: LIS

부분 수열은 중간 원소를 건너뛸 수 있지만 원래 순서를 보존합니다.
dp[i]=1+max(dp[j])에서 j<i, a[j]<a[i]를 만족하는 j를 확인하면 O(n²) 시간입니다.
직접 구성한 [3,1,2,5,4]의 끝 위치별 길이는 [1,1,2,3,3]이며 답은 3입니다.
길이별 최소 끝값 tails를 유지하면 더 큰 끝값은 같은 길이의 미래 확장에서 필요하지 않습니다.
이 배열은 [3]→[1]→[1,2]→[1,2,5]→[1,2,4]로 바뀝니다.
각 값 이상인 첫 자리를 이분 탐색으로 바꾸면 엄격 증가 LIS 길이를 O(n log n) 시간, O(n) 공간에 구합니다.
tails 자체는 일반적으로 원래 입력의 유효한 부분 수열이 아니므로 복원에는 이전 위치를 따로 저장합니다.
동일 값도 허용하는 비감소 수열은 첫 “초과” 위치를 찾아야 합니다. [MIT LIS·LCS 강의](https://www.ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/resources/lecture-16-dynamic-programming-part-2-lcs-lis-coins/)

## 최장 공통 부분 수열: LCS

두 문자열 A,B의 앞 i개와 앞 j개의 LCS 길이를 dp[i][j]로 정합니다.
A[i-1]=B[j-1]이면 dp[i-1][j-1]+1, 다르면 max(dp[i-1][j],dp[i][j-1])입니다.
같지 않은 두 마지막 문자를 모두 같은 공통 부분 수열의 마지막으로 쓸 수 없으므로 적어도 하나를 제외합니다.
직접 구성한 A=ABC, B=AC의 표는 다음과 같습니다.

| A의 접두사 / B의 접두사 | 빈 문자열 | A | AC |
| --- | ---: | ---: | ---: |
| 빈 문자열 | 0 | 0 | 0 |
| A | 0 | 1 | 1 |
| AB | 0 | 1 | 1 |
| ABC | 0 | 1 | 2 |

시간 O(|A||B|), 전체 표 공간 O(|A||B|)이며 길이만 필요하면 O(min(|A|,|B|)) 공간으로 줄입니다.
문자열의 연속 구간을 찾는 “공통 부분 문자열”과 다른 문제입니다. [MIT LCS 전이와 복원](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/28461a74f81101874a13d9679a40584d_MIT6_006S20_lec16.pdf)

## 구간 DP

구간 DP는 연속한 [l,r]의 답을 저장하고 마지막 분할점 k로 양쪽을 나눕니다.
인접한 파일만 합칠 수 있을 때 dp[l][r]=min(dp[l][k]+dp[k+1][r])+sum(l,r)입니다.
직접 구성한 크기 [2,3,4]에서 (2+3)+4의 비용은 5+9=14입니다.
2+(3+4)는 7+9=16이므로 dp[0][2]=14입니다.
마지막 합치기 직전에는 반드시 두 연속 구간이 남으므로 모든 k를 보면 최적해를 포함합니다.
구간 길이 1의 비용을 0으로 두고 짧은 길이부터 계산합니다.
누적합으로 구간 합을 O(1)에 구하면 기본 구현은 O(n³) 시간, O(n²) 공간입니다.
분할점의 단조성을 별도로 증명하면 [Knuth 최적화](37-DP최적화와볼록껍질트릭_dp-optimization.md)를 검토합니다.

## 자릿수 DP

상한 N 이하의 정수 중 자릿수 조건을 만족하는 개수를 자리별로 셉니다.
상태는 위치 pos, 지금까지 상한과 같은지 tight, 필요한 나머지·사용 숫자 정보입니다.
숫자 0의 처리와 맨 앞의 0을 구분해야 하면 started도 추가합니다.
직접 구성한 0≤x≤25, 자릿수 합이 3의 배수인 수의 개수는 9개입니다.
십의 자리가 0인 가지는 00,03,06,09로 4개, 1인 가지는 12,15,18로 3개입니다.
2인 가지는 tight를 유지해 일의 자리가 5 이하이며 21,24로 2개입니다.
자릿수 합의 나머지를 r이라 하면 다음 숫자 d에서 r'=(r+d) mod 3입니다.
고정 자릿수로 앞의 0을 허용해도 이 조건은 변하지 않으며, 숫자 0은 한 번 셉니다.
자릿수 D, 추가 상태 수 S, 진법 B에서 시간 O(DSB), 전체 표 O(DS) 또는 두 층 O(S) 공간입니다.
구간 [L,R]은 count(R)-count(L-1)로 계산하며, 상한이 음수이면 0을 반환합니다.
상한과 자릿수 합 나머지를 결합하는 문제 형태는 [AtCoder 공식 자릿수 문제](https://atcoder.jp/contests/dp/tasks/dp_s)에서 확인합니다.

## 확률 분포와 기댓값 DP

확률 DP에서는 가능한 마지막 사건을 서로 겹치지 않게 나누고 확률을 더합니다.
독립인 두 동전의 앞면 확률을 1/2, 1/3으로 직접 구성합니다.
앞면 개수 분포는 처음 [1], 첫 동전 뒤 [1/2,1/2]입니다.
둘째 동전 뒤에는 [1/3,1/2,1/6]이며, 정확히 하나의 앞면은 1/2입니다.
전이는 `new[j]=old[j](1-p)+old[j-1]p`이며 양끝의 없는 상태는 0입니다.
n개 동전의 분포는 O(n²) 시간, 두 층으로 O(n) 공간입니다.
모든 결과의 확률 합이 약 1인지 확인하면 경계와 중복 합산 오류를 찾는 데 도움이 됩니다.
독립성이 없으면 단순히 p를 곱할 수 없으며 조건부 확률에 필요한 정보를 상태에 더합니다.

기댓값은 보통 E[s]=1+Σp(s,t)E[t]처럼 첫 한 단계의 비용을 분리합니다.
예를 들어 매번 확률 1/4로 끝나는 실험은 E=1+(3/4)E이므로 E=4입니다.
자기 자신을 부르는 항을 그대로 재귀 호출하면 끝나지 않으므로 식을 먼저 풉니다.
여러 상태가 순환하면 연립방정식이나 별도 구조가 필요하며, 종료 확률과 기대 종료 시간의 유한성도 확인합니다.
정확한 소수 출력과 모듈러 확률은 다른 요구이며, 모듈러 분모의 역원이 있을 때만 나눗셈을 옮깁니다.

## 구현·활용·연계 유형

Python의 중첩 리스트는 [[0]*m]*n처럼 만들면 행을 공유하므로 각 행을 따로 생성합니다.
C·C++에서는 불가능한 INF에 비용을 더하는 연산과 큰 경우의 수의 오버플로를 확인합니다.
배낭은 제한된 예산 배분, LCS는 순서 기반 비교, 확률 DP는 독립 사건 모델의 분포 계산과 연결합니다.
현실의 업무 의존성·문자 정규화·사건 상관관계가 추가되면 현재 상태 정의를 그대로 적용하지 않습니다.
[비트집합](18-비트마스크와비트집합_bitmask-bitset.md)은 가능 여부 배낭을 여러 상태씩 처리하며, [생성함수](31-조합론과생성함수_combinatorics-generating-functions.md)는 분포 전이를 계수 곱으로 표현합니다.

## 복습 질문과 답

- 질문: 0-1 배낭을 내림차순으로 갱신하는 이유는 무엇입니까? 답: 현재 물건을 반영하기 전 상태만 읽어 한 번 사용 조건을 지키기 위함입니다.
- 질문: LIS와 LCS는 무엇이 다릅니까? 답: LIS는 한 수열의 크기 관계를, LCS는 두 수열에서 같은 값의 순서를 비교합니다.
- 질문: 구간 DP는 어떤 순서로 채웁니까? 답: 전이가 참조하는 두 구간이 더 짧으므로 길이가 짧은 구간부터 채웁니다.
- 질문: 확률 DP에 자기 전이가 있으면 DP가 불가능합니까? 답: 순차 표 채우기만으로는 부족할 수 있으며, 자기 항 정리나 연립방정식으로 해결할 수 있습니다.

## C·C++·Python으로 같은 예제 실행

물건을 한 번만 고르는 배낭과 끝 위치별 LIS를 한 프로그램에서 계산합니다.

이 예제에서 직접 구현하는 기법은 0-1 배낭 내림차순 갱신 · 끝 위치별 O(m²) LIS입니다. 같은 표준 입력에서 세 언어가 같은 결과를 출력합니다.

### 입력과 출력

n,W(0≤n≤20,0≤W≤100), 다음 n쌍의 무게·가치(1≤무게≤100,0≤가치≤1000), 수열 길이 m(0≤m≤30), 다음 m개 정수(-1000..1000)입니다.

```text
3 5
2 3
3 4
4 5
5
3 1 2 5 4
```

첫 줄 KNAPSACK 최대가치, 둘째 줄 LIS 엄격증가길이를 출력합니다.

```text
KNAPSACK 7
LIS 3
```

### 입력부터 결과까지

| 단계 | 중간 상태 | 수행 이유 |
| --- | --- | --- |
| 1 | 배낭 W=5, 물건 (2,3),(3,4),(4,5) | 각 물건을 최대 한 번 사용하는 상태를 만듭니다. |
| 2 | 첫 물건 뒤 용량 2..5의 값은 3 | 용량을 내림차순으로 갱신하여 같은 물건의 재사용을 막습니다. |
| 3 | 둘째 물건 뒤 dp[5]=3+4=7, 셋째 뒤도 7 | 무게 2와 3의 조합이 최적입니다. |
| 4 | 수열 [3,1,2,5,4]의 끝별 길이 [1,1,2,3,3] | 이전의 더 작은 값 뒤에 현재 값을 붙여 LIS 길이 3을 구합니다. |

### C 예제

[실행 가능한 C 파일](<예제_examples/17-배낭수열구간확률DP_dp-variants/example.c>)

```c
#include <stdio.h>  // 표준 입력과 출력 함수

int main(void) {  // 두 DP 변형의 독립 실행
    int n, capacity, dp[101] = {0};  // 용량 이하의 최대 가치
    scanf("%d %d", &n, &capacity);  // 물건 수와 배낭 용량
    for (int i = 0; i < n; ++i) {  // 현재 물건을 한 번씩 반영
        int weight, value;  // 현재 물건의 정보
        scanf("%d %d", &weight, &value);  // 양의 무게와 가치
        for (int w = capacity; w >= weight; --w) {  // 현재 물건의 재사용을 막는 내림차순
            int candidate = dp[w - weight] + value;  // 현재 물건을 고른 가치
            if (candidate > dp[w]) dp[w] = candidate;  // 더 좋은 선택 유지
        }  // 한 물건의 용량 갱신 끝
    }  // 배낭 계산 끝
    int m, sequence[30], length[30], best = 0;  // LIS의 값과 끝 위치 상태
    scanf("%d", &m);  // 수열 길이
    for (int i = 0; i < m; ++i) {  // 앞에서부터 LIS 상태 계산
        scanf("%d", &sequence[i]);  // 현재 수열 원소
        length[i] = 1;  // 현재 원소만 고른 길이
        for (int j = 0; j < i; ++j) {  // 앞선 끝 위치 후보
            if (sequence[j] < sequence[i] && length[j] + 1 > length[i]) length[i] = length[j] + 1;  // 엄격 증가 전이
        }  // 이전 위치 확인 끝
        if (length[i] > best) best = length[i];  // 전체 LIS 길이 유지
    }  // 수열 계산 끝
    printf("KNAPSACK %d\nLIS %d\n", dp[capacity], best);  // 두 DP 결과를 구분해 출력
    return 0;  // 정상 종료
}  // 프로그램 끝
```

### Python 예제

[실행 가능한 Python 파일](<예제_examples/17-배낭수열구간확률DP_dp-variants/example.py>)

```python
import sys  # 두 입력 묶음의 정수 읽기
tokens = iter(map(int, sys.stdin.read().split()))  # 공백 토큰 순회
n, capacity = next(tokens), next(tokens)  # 배낭 조건
dp = [0] * (capacity + 1)  # 용량 이하의 최대 가치
for _ in range(n):  # 각 물건을 한 번씩 반영
    weight, value = next(tokens), next(tokens)  # 현재 물건 정보
    for w in range(capacity, weight - 1, -1):  # 내림차순으로 이전 물건 상태만 읽기
        dp[w] = max(dp[w], dp[w - weight] + value)  # 선택과 미선택 비교
m = next(tokens)  # 증가 부분 수열 입력 길이
sequence = [next(tokens) for _ in range(m)]  # 수열 원소 저장
length = [1] * m  # 각 위치에서 끝나는 LIS의 최소 길이
for i in range(m):  # 현재 끝 위치 확정
    for j in range(i):  # 그 앞에 붙일 끝 위치 확인
        if sequence[j] < sequence[i]:  # 같은 값은 엄격 증가에 포함하지 않기
            length[i] = max(length[i], length[j] + 1)  # 현재 원소를 이어 붙인 길이
print("KNAPSACK", dp[capacity])  # 배낭 결과
print("LIS", max(length, default=0))  # 빈 수열도 길이 0으로 처리
```

### 언어별 차이

| 비교할 점 | C | C++ | Python |
| --- | --- | --- | --- |
| 표준 입출력 | scanf와 printf의 서식 지정자를 자료형에 맞춥니다. | std::cin과 std::cout으로 같은 토큰과 결과를 처리합니다. | sys.stdin.read().split()으로 읽은 토큰을 필요한 자료형으로 바꿉니다. |
| 배열과 허용 범위 | 무게 상태 101개와 수열·LIS 상태 30개의 고정 배열을 사용합니다. | 같은 상한의 고정 배열을 사용하며 입력 범위를 지킵니다. | 상태 길이에 맞춰 리스트를 만들지만 입력의 허용 범위는 같습니다. |
| 정수 연산 | 이 예제의 입력 상한에서 int 또는 long long의 연산 범위를 지킵니다. | C와 같은 정수 상한을 사용하며 중간 계산의 자료형을 확인합니다. | 정수는 임의 정밀도이지만 같은 입력 상한에서 같은 계산을 수행합니다. |

### 예제의 비용과 실행 파일

- 시간: O(nW+m²)
- 보조 공간: O(W+m)
