# 동적 계획법의 상태와 전이

[학습목차](README.md) · [연습문제](연습문제_problem-index.md)

## 핵심 원리와 중요성

동적 계획법(DP)은 같은 하위 문제의 답을 저장하고 더 큰 문제에 재사용하는 방법입니다.
상태는 지금까지의 모든 선택이 아니라, 앞으로의 선택과 비용을 판단하는 데 필요한 정보입니다.
서로 다른 과거라도 같은 상태에서 허용되는 미래와 추가 비용이 같다면 하나로 합칠 수 있습니다.
이 구분을 통해 지수 개수의 선택 이력을 다항 개수의 하위 문제로 줄이는 경우가 많습니다.
단순히 배열을 채우는 문법보다 상태가 정보를 충분히 담는지가 중요합니다. [MIT DP 하위 문제 강의](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/28461a74f81101874a13d9679a40584d_MIT6_006S20_lec16.pdf)

## 알아보는 단서와 사용할 수 없는 상태

- 최솟값·최댓값·경우의 수를 묻고, 마지막 선택에 따라 답을 작은 문제로 나눌 수 있습니다.
- 재귀를 그렸을 때 같은 인덱스·남은 용량·구간이 여러 번 등장합니다.
- 방문한 집합이나 직전 색이 미래에 영향을 주면 그 정보도 상태에 포함합니다.
- 상태 수와 상태별 선택 수를 곱해 제한 안에 들어오는지 먼저 계산합니다.

같은 위치라도 남은 연료가 다르면 갈 수 있는 경로가 다르므로 위치만으로 합치면 안 됩니다.
반대로 과거에 방문한 순서가 미래 제약에 영향을 주지 않는다면 그 순서를 전부 저장할 필요는 없습니다.
순환 의존성이 있는 식을 평범한 한 번의 표 채우기로 계산할 수도 없습니다.
시간 단계 추가, 그래프 최단 경로, 연립방정식 등 문제에 맞는 다른 처리가 필요합니다.

## 설계 순서

1. 상태의 의미를 “정확히 …한 경우의 …”처럼 한 문장으로 정합니다.
2. 마지막 행동을 나누어 전이를 작성합니다.
3. 빈 입력과 불가능한 상태의 초기값을 구분합니다.
4. 의존하는 상태가 먼저 계산되는 순서를 찾습니다.
5. 답이 놓이는 상태와 경로 복원 방법을 정합니다.
6. 작은 완전 탐색과 비교한 뒤 공간을 줄입니다.

최소화에서 불가능한 값은 충분히 큰 INF, 경우의 수에서 불가능한 값은 0으로 시작합니다.
빈 선택 한 가지를 세는 상태의 경우의 수는 1이므로, 모든 초기값을 0으로 통일하지 않습니다.

## 직접 구성한 동전 예제

동전 {1,3,4}를 제한 없이 사용해 금액 6을 만드는 최소 동전 수를 구합니다.
dp[s]는 정확히 금액 s를 만드는 최소 동전 수입니다.
dp[0]=0이고, s>0에서는 dp[s]=min(dp[s-c]+1)로 계산합니다.
여기서 c는 s 이하의 동전이며, 불가능한 이전 상태는 후보에서 제외합니다.

| 금액 s | 후보 동전 | 이전 상태에 1을 더한 값 | dp[s] |
| ---: | --- | --- | ---: |
| 0 | 빈 선택 | 0 | 0 |
| 1 | 1 | dp[0]+1=1 | 1 |
| 2 | 1 | dp[1]+1=2 | 2 |
| 3 | 1,3 | 3,1 | 1 |
| 4 | 1,3,4 | 2,2,1 | 1 |
| 5 | 1,3,4 | 2,3,2 | 2 |
| 6 | 1,3,4 | 3,2,3 | 2 |

dp[6]의 마지막 동전은 3이며 dp[3]도 동전 3이므로 답은 3+3입니다.

## 왜 맞는지: 마지막 선택과 귀납

금액 s를 만드는 최적해의 마지막 동전을 c라고 정합니다.
나머지 동전들이 s-c의 최적해가 아니면 더 적은 동전으로 바꾸어 전체 해도 줄일 수 있습니다.
따라서 최적해는 반드시 어떤 dp[s-c]+1 후보에 포함됩니다.
반대로 각 후보는 실제로 만들 수 있는 해이므로 그 최솟값도 가능한 해입니다.
양의 동전에서는 s-c<s이므로 작은 금액부터 계산하는 귀납이 성립합니다.
이처럼 상태 사이의 의존 방향과 계산 순서를 함께 제시해야 합니다. [MIT DP와 의존 관계 강의](https://courses.csail.mit.edu/6.006/fall09/lecture_notes/lecture19.pdf)

## 짧은 구현

```python
def minimum_coins(coins, target):  # 모든 동전은 양의 정수라는 조건
    inf = target + 1  # 가능한 해의 동전 수보다 큰 불가능 표시
    dp = [inf] * (target + 1)  # 정확한 금액별 최소 동전 수
    dp[0] = 0  # 금액 0은 아무것도 고르지 않아 구성
    for amount in range(1, target + 1):  # 의존 금액이 작은 순서로 계산
        for coin in coins:  # 최적해의 마지막 동전을 모두 후보로 확인
            if coin <= amount:  # 음수 금액 상태를 읽지 않도록 제한
                dp[amount] = min(dp[amount], dp[amount - coin] + 1)  # 최선의 전이 선택
    return None if dp[target] == inf else dp[target]  # 불가능과 실제 최솟값 구분
```

동전 종류 k, 목표 금액 S에 대해 시간 O(kS), 공간 O(S)입니다.
이것은 숫자 S에 비례하며 S를 이진수로 적는 길이 log S에 비례하는 알고리즘은 아닙니다.

## 메모이제이션과 표 채우기

메모이제이션은 재귀로 요청한 상태만 계산하고 저장하는 방식입니다.
표 채우기는 의존 순서로 상태를 반복문에서 계산하는 방식입니다.
상태와 전이가 같다면 둘의 본질적인 중복 제거 원리는 같습니다.
Python에서는 긴 재귀의 호출 깊이와 딕셔너리 비용, C·C++에서는 큰 지역 배열의 스택 사용량을 확인합니다.
이전 행만 쓰는 DP는 두 행으로 줄일 수 있지만, 실제 선택 복원에는 별도 정보나 재계산이 필요합니다.

## 실수·현업 연결·연계 유형

음수 동전을 허용하면 위의 작은 금액 순서가 성립하지 않으므로 같은 코드를 적용하지 않습니다.
최소 비용만 저장한 상태에서 경로 개수를 복원하려면 동률 처리와 중복 경로 정의도 추가합니다.
편집 거리와 자원 배분처럼 상태를 명확히 적을 수 있는 모델에 활용하지만, 제약이 늘면 상태 수가 급증합니다.
구체적인 상태 설계는 [DP 변형](17-배낭수열구간확률DP_dp-variants.md), 전이 비용 감소는 [DP 최적화](37-DP최적화와볼록껍질트릭_dp-optimization.md)와 연결합니다.

## 복습 질문과 답

- 질문: DP의 시간은 상태 수와 같습니까? 답: 상태별 전이를 계산하는 비용까지 합해야 하며, 상태가 n개여도 각각 n개 후보를 보면 O(n²)입니다.
- 질문: 가장 좋은 과거 하나만 남겨도 됩니까? 답: 같은 미래 가능성을 가진 상태끼리만 비교해야 하며, 남은 자원이 다른 해를 비용만 보고 제거하면 안 됩니다.
- 질문: dp[0]은 항상 0입니까? 답: 최소 동전 수에서는 0이고, 빈 방법의 개수를 세는 DP에서는 1일 수 있습니다.

## C·C++·Python으로 같은 예제 실행

정확한 금액을 만드는 최소 동전 수를 작은 금액부터 계산합니다.

이 예제에서 직접 구현하는 기법은 정확한 금액 상태 · 무제한 동전 DP · 불가능 상태 표시입니다. 같은 표준 입력에서 세 언어가 같은 결과를 출력합니다.

### 입력과 출력

첫 줄 n,S는 동전 종류 수와 목표 금액(0≤n≤20,0≤S≤1000)입니다. 다음에는 n개의 양의 정수 동전 값(1..1000)입니다. 각 동전은 무제한으로 사용합니다.

```text
3 6
1 3 4
```

최소 동전 수를 출력하며 불가능하면 -1을 출력합니다.

```text
2
```

### 입력부터 결과까지

| 단계 | 중간 상태 | 수행 이유 |
| --- | --- | --- |
| 1 | dp[0]=0, 나머지는 7 | 목표 6의 가능한 동전 수보다 큰 값으로 불가능을 표시합니다. |
| 2 | dp[1]=1, dp[2]=2, dp[3]=1 | 작은 금액의 최적값으로 다음 상태를 만듭니다. |
| 3 | dp[4]=1, dp[5]=2 | 동전 4 하나와 4+1이 각각 최적입니다. |
| 4 | dp[6]=min(3,2,3)=2 | 마지막 동전 3을 고르면 3+3으로 구성합니다. |

### C 예제

[실행 가능한 C 파일](<예제_examples/16-동적계획법의상태와전이_dynamic-programming/example.c>)

```c
#include <stdio.h>  // 표준 입력과 출력 함수

int main(void) {  // 최소 동전 수 계산 시작
    int n, target, coins[20], dp[1001];  // 동전과 금액 상태의 고정 상한
    scanf("%d %d", &n, &target);  // 종류 수와 목표 금액
    for (int i = 0; i < n; ++i) scanf("%d", &coins[i]);  // 양의 동전 값 읽기
    for (int s = 0; s <= target; ++s) dp[s] = target + 1;  // 불가능 상태로 초기화
    dp[0] = 0;  // 빈 선택으로 금액 0 구성
    for (int s = 1; s <= target; ++s) {  // 더 작은 금액이 먼저 정해지는 순서
        for (int i = 0; i < n; ++i) {  // 마지막 동전의 모든 후보
            if (coins[i] <= s && dp[s - coins[i]] + 1 < dp[s]) {  // 유효하고 더 좋은 전이
                dp[s] = dp[s - coins[i]] + 1;  // 동전 하나를 추가한 최솟값
            }  // 전이 갱신 끝
        }  // 동전 후보 순회 끝
    }  // 금액 상태 계산 끝
    int answer = dp[target] == target + 1 ? -1 : dp[target];  // 불가능을 출력 규약으로 변환
    printf("%d\n", answer);  // 최소 개수 또는 -1 출력
    return 0;  // 정상 종료
}  // 프로그램 끝
```

### C++ 예제

[실행 가능한 C++ 파일](<예제_examples/16-동적계획법의상태와전이_dynamic-programming/example.cpp>)

```cpp
#include <iostream>  // C++ 스트림 입력과 출력

int main() {  // 최소 동전 수 계산 시작
    int n, target, coins[20], dp[1001];  // 동전과 금액 상태의 고정 상한
    std::cin >> n >> target;  // 종류 수와 목표 금액

    for (int s = 1; s <= target; ++s) {  // 더 작은 금액이 먼저 정해지는 순서
        for (int i = 0; i < n; ++i) {  // 마지막 동전의 모든 후보
            if (coins[i] <= s && dp[s - coins[i]] + 1 < dp[s]) {  // 유효하고 더 좋은 전이
                dp[s] = dp[s - coins[i]] + 1;  // 동전 하나를 추가한 최솟값
            }  // 전이 갱신 끝
        }  // 동전 후보 순회 끝
    }  // 금액 상태 계산 끝
    int answer = dp[target] == target + 1 ? -1 : dp[target];  // 불가능을 출력 규약으로 변환
    std::cout << answer << "\n";  // 최소 개수 또는 -1 출력
    return 0;  // 정상 종료
}  // 프로그램 끝
```

### Python 예제

[실행 가능한 Python 파일](<예제_examples/16-동적계획법의상태와전이_dynamic-programming/example.py>)

```python
import sys  # 정수 입력 읽기
tokens = iter(map(int, sys.stdin.read().split()))  # 공백 토큰 순회
n, target = next(tokens), next(tokens)  # 동전 종류와 목표
coins = [next(tokens) for _ in range(n)]  # 사용할 양의 동전
dp = [target + 1] * (target + 1)  # 불가능 상태 표시
dp[0] = 0  # 빈 선택의 동전 수
for amount in range(1, target + 1):  # 의존 상태가 먼저 계산되는 순서
    for coin in coins:  # 마지막 동전 후보
        if coin <= amount:  # 음수 금액 제외
            dp[amount] = min(dp[amount], dp[amount - coin] + 1)  # 최선의 전이 선택
print(-1 if dp[target] == target + 1 else dp[target])  # 불가능과 최솟값 구분
```
