# 투 포인터와 슬라이딩 윈도

[학습목차](README.md) · [연습문제](연습문제_problem-index.md)

## 두 위치를 움직이며 후보를 줄이는 방법

투 포인터는 두 위치의 의미를 정하고 그 위치를 움직여 불필요한 후보를 제외하는 설계입니다.
정렬된 두 배열을 병합하는 두 손가락 방식도 각 배열의 앞부분을 한 번씩 처리하는 예입니다. [MIT 강의 3, Merge Sort의 Two Finger Algorithm](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/6d1ae5278d02bbecb5c4428928b24194_MIT6_006S20_lec3.pdf)
슬라이딩 윈도는 두 위치가 연속 구간의 양 끝을 나타내며 구간 요약을 유지하는 형태입니다.
중요한 것은 포인터가 두 개라는 모양이 아니라 어떤 후보를 안전하게 버리는지에 대한 근거입니다.

양 끝이 뒤로 돌아가지 않으면 각각 최대 N번 움직여 총 이동 횟수를 O(N)으로 제한할 수 있습니다.
그러나 매 이동마다 구간 전체를 다시 합산하면 전체 시간은 다시 O(N²)이 될 수 있습니다.

## 서로 다른 적용 조건

정렬된 배열의 두 수 합에서는 작은 합이면 왼쪽을, 큰 합이면 오른쪽을 움직이는 배제 논증을 사용합니다.
고정 길이 창의 합은 새 값 하나를 더하고 빠진 값 하나를 빼면 됩니다.
양수의 가변 길이 창에서는 오른쪽 확장이 합을 늘리고 왼쪽 축소가 합을 줄이는 단조성을 이용합니다.
서로 다른 문자의 수를 제한하는 창에서는 합의 부호가 아니라 빈도와 다른 값 개수의 단조성이 근거입니다.

따라서 “음수가 있으면 모든 슬라이딩 윈도가 불가능”이라는 설명도 틀립니다.
음수 때문에 깨지는 것은 합을 기준으로 구간을 버리는 특정 단조 논증입니다.
고정 길이 합이나 문자 중복 조건은 별도로 판단해야 합니다.

## 직접 구성한 예제: 합이 6 이상인 가장 짧은 구간

모든 값이 양수인 `[2,1,3,2,4]`를 사용합니다.
오른쪽을 확장해 합을 더하고, 합이 6 이상이면 답을 기록하면서 왼쪽을 줄입니다.

| 오른쪽에 추가한 값 | 확장 직후 창 합 | 왼쪽 축소와 후보 길이 | 처리 후 창 |
|---:|---:|---|---|
| 2 | 2 | 아직 부족 | [2] |
| 1 | 3 | 아직 부족 | [2,1] |
| 3 | 6 | 길이 3 기록 후 2 제거 | [1,3] |
| 2 | 6 | 길이 3 기록 후 1 제거 | [3,2] |
| 4 | 9 | 길이 3 기록, 3 제거 후 길이 2 기록, 2 제거 | [4] |

최종 답은 `[2,4]`의 길이 2입니다.
표의 창은 각 단계에서 아직 합이 목표 미만인 가장 뒤쪽 구간을 남기는 과정을 보여 줍니다.

```python
values, target = [2, 1, 3, 2, 4], 6  # 양수 배열과 목표 합 지정
left, total, best = 0, 0, len(values) + 1  # 왼쪽 경계·현재 합·미발견 길이 초기화
for right, value in enumerate(values):  # 오른쪽 경계를 한 칸씩 확장
    total += value  # 새 원소를 현재 구간 합에 포함
    while total >= target:  # 목표를 만족하는 동안 더 짧은 같은 끝점 구간 검사
        best = min(best, right - left + 1)  # 현재 유효 구간 길이로 최솟값 갱신
        total -= values[left]  # 현재 맨 앞 원소를 구간 합에서 제외
        left += 1  # 왼쪽 경계를 한 칸 전진
answer = 0 if best == len(values) + 1 else best  # 한 번도 찾지 못했으면 0으로 구분
```

목표가 양수이고 모든 원소가 양수인 조건에서 작성한 코드입니다.
빈 구간을 허용하거나 목표가 0 이하인 변형은 경계와 종료 조건을 다시 정해야 합니다.

## 정당성: 버린 시작점의 의미

`total`은 항상 현재 `[left,right]` 구간의 합입니다.
목표를 만족한 창은 길이를 기록한 뒤에만 시작점을 버립니다.
같은 시작점에서 오른쪽 끝을 더 늘리면 길이가 더 길어지므로 이미 기록한 구간보다 유리하지 않습니다.
합이 목표 미만이면 양수를 왼쪽에서 더 빼도 조건을 만족할 수 없으므로 오른쪽 확장이 필요합니다.
각 오른쪽 끝에서 검사할 필요가 있는 시작점들을 이 규칙으로 빠짐없이 처리합니다.

## 음수에서 깨지는 반례

배열 `[1,-1,5]`와 목표 5를 같은 코드에 넣는다고 가정합니다.
전체 창의 합 5로 길이 3을 기록한 뒤 앞의 1을 빼면 합 4가 되어 축소를 멈춥니다.
그러나 다음 -1까지 빼면 `[5]`라는 길이 1의 정답이 있습니다.
양수일 때 사용한 “더 줄이면 합은 더 작다”는 가정이 깨졌기 때문입니다.
이 변형에는 접두 합과 적절한 순서 자료구조 등 다른 논증이 필요합니다.

## 총비용과 언어 차이

예제에서 오른쪽은 N번, 왼쪽도 전체 실행 동안 N번 이하 이동합니다.
따라서 이중 반복처럼 보여도 총 O(N) 시간, 보조 공간 O(1)입니다.
정렬이 먼저 필요하면 전체 비용에 O(N log N) 정렬을 포함합니다.
빈도 기반 창에서는 서로 다른 값 수 K만큼의 해시 공간이 추가될 수 있습니다.

C·C++에서는 누적 합 자료형을 원소 자료형보다 넓게 잡아야 할 수 있습니다.
Python에서 매번 `values[left:right+1]`를 만들어 합산하면 창 요약을 유지하는 이점이 사라집니다.
양 끝 원소를 실제로 저장·삭제해야 하는 흐름이라면 덱이나 원형 버퍼를 함께 사용할 수 있습니다.

## 실전의 적용 조건

최근 K개 측정치의 합은 고정 길이 창으로 한 항목씩 갱신할 수 있습니다.
최근 10분처럼 시간 기반 창은 기록이 시각 순서로 도착한다는 조건이나 지연 도착 처리 정책이 필요합니다.
다른 종류의 사건 수를 제한하는 창은 종류별 빈도가 0이 되는 시점을 정확히 관리해야 합니다.
이 예시는 스트림 요약의 설계 조건이며 특정 감시 시스템의 구현을 단정하지 않습니다.

## 실수와 연계 유형

- `while` 대신 `if`로 한 번만 줄이면 가능한 더 짧은 창을 놓칠 수 있습니다.
- 실제 원소를 정렬하면 원래 배열의 연속 구간이라는 의미를 잃을 수 있습니다.
- 중복 값의 빈도를 지울 때 0이 되는 시점을 놓치면 종류 수가 틀어집니다.

[누적합](09-누적합과차분_prefix-difference.md)은 임의 구간 합을 재사용하는 다른 방법입니다.
[해시](06-해시와빈도집계_hashing-counting.md)는 빈도 창을, [덱](07-스택큐덱_stack-queue-deque.md)은 창의 최댓값 후보를 관리합니다.

## 복습 질문과 답

질문 1. 내부 while문 때문에 O(N²)입니까?

답. 아닙니다. 각 포인터의 전체 이동이 N번 이하이고 이동당 비용이 일정하면 총 O(N)입니다.

질문 2. 음수 반례에서 정답을 놓친 직접 원인은 무엇입니까?

답. 합이 부족해진 뒤에도 음수를 제거하면 다시 커질 수 있는데 이를 불가능하다고 가정하고 축소를 멈춘 것입니다.

## C·C++·Python으로 같은 예제 실행

모든 원소가 양수라는 조건을 이용해 오른쪽 끝을 늘리고 목표를 만족하는 동안 왼쪽 끝을 줄입니다.

이 예제에서 직접 구현하는 기법은 두 포인터 · 가변 길이 슬라이딩 윈도 · 양수 합의 단조성입니다. 같은 표준 입력에서 세 언어가 같은 결과를 출력합니다.

### 입력과 출력

N target(1≤N≤20,1≤target≤1000), N개 양수(1~100)입니다. 음수나0은 허용하지 않습니다.

```text
5 6
2 1 3 2 4
```

합이 target 이상인 연속 구간의 최소 길이입니다. 없으면0입니다.

```text
2
```

### 입력부터 결과까지

| 단계 | 중간 상태 | 수행 이유 |
| --- | --- | --- |
| 1 | right=2,left=0,total=6,best=3 | 처음 목표를 만족한 구간[2,1,3]의 길이는3입니다. |
| 2 | 왼쪽2 제거 후 left=1,total=4 | 양수를 제거하면 합이 감소하므로 더 줄일 필요가 없습니다. |
| 3 | right=4,left=2,total=9,best=3 | 오른쪽에2와4가 들어온 뒤 남아 있는 구간은[3,2,4]입니다. |
| 4 | 3 제거 후 total=6,left=3,best=2; 2 제거 후 total=4 | [2,4]로 길이2를 얻은 뒤 목표보다 작아져 축소를 끝냅니다. |

### C 예제

[실행 가능한 C 파일](<예제_examples/10-투포인터와슬라이딩윈도_two-pointers-window/example.c>)

```c
#include <stdio.h> // 양수 배열 입력과 최소 길이 출력
int main(void) { // 실행 시작점
    int n, target, a[20], left = 0, best; // 배열 크기·목표·왼쪽 경계·최소 길이
    long long sum = 0; // 현재 창의 합
    scanf("%d %d", &n, &target); // 원소 수와 목표 합 읽기
    best = n + 1; // 아직 답을 못 찾은 표식
    for (int i = 0; i < n; ++i) scanf("%d", &a[i]); // 양수 원소 입력
    for (int right = 0; right < n; ++right) { // 오른쪽 끝을 한 칸씩 확장
        sum += a[right]; // 새 원소를 현재 창에 포함
        while (sum >= target) { // 목표를 만족하는 동안 왼쪽을 줄이기
            int length = right - left + 1; // 현재 닫힌 구간의 원소 수
            if (length < best) best = length; // 더 짧은 유효 창이면 답 갱신
            sum -= a[left++]; // 왼쪽 원소를 빼고 경계 전진
        } // 이번 오른쪽 끝에서 가능한 축소 끝
    } // 모든 오른쪽 끝 확인 끝
    printf("%d\n", best == n + 1 ? 0 : best); // 유효 창이 없으면0 출력
    return 0; // 정상 종료
} // 양수 슬라이딩 윈도 예제 끝
```

### C++ 예제

[실행 가능한 C++ 파일](<예제_examples/10-투포인터와슬라이딩윈도_two-pointers-window/example.cpp>)

```cpp
#include <iostream> // 표준 입력과 출력
#include <vector> // 입력 배열 저장
using namespace std; // 표준 이름의 접두사 생략
int main() { // 실행 시작점
    int n, target; cin >> n >> target; // 배열 길이와 목표 합 읽기
    vector<int> a(n); // 원소 수에 맞춘 배열
    for (int& value : a) cin >> value; // 양수 원소 입력
    int left = 0, best = n + 1; // 왼쪽 경계와 미발견 표식
    long long sum = 0; // 현재 창의 합
    for (int right = 0; right < n; ++right) { // 오른쪽 경계를 순서대로 확장
        sum += a[right]; // 새 원소를 합에 추가
        while (sum >= target) { // 합이 충분한 동안 짧은 창 탐색
            int length = right - left + 1; // 현재 창의 길이 계산
            if (length < best) best = length; // 가장 짧은 길이 유지
            sum -= a[left++]; // 왼쪽 원소를 빼고 시작 위치 이동
        } // 이번 끝점의 축소 끝
    } // 전체 순회 끝
    cout << (best == n + 1 ? 0 : best) << '\n'; // 최소 길이 또는 미발견0 출력
    return 0; // 정상 종료
} // 양수 슬라이딩 윈도 예제 끝
```

### Python 예제

[실행 가능한 Python 파일](<예제_examples/10-투포인터와슬라이딩윈도_two-pointers-window/example.py>)

```python
import sys # 정수 토큰 입력
data = list(map(int, sys.stdin.buffer.read().split())) # 입력을 정수로 변환
n, target = data[:2] # 배열 길이와 목표 합 분리
values = data[2:] # 양수 원소 배열
left, total, best = 0, 0, n + 1 # 창의 시작·합·미발견 표식
for right, value in enumerate(values): # 오른쪽 끝을 순서대로 확장
    total += value # 새 원소를 현재 창에 포함
    while total >= target: # 목표를 만족하는 동안 창 축소
        best = min(best, right - left + 1) # 현재 유효 길이로 답 갱신
        total -= values[left] # 빠질 왼쪽 원소의 값 제거
        left += 1 # 왼쪽 경계 한 칸 전진
print(0 if best == n + 1 else best) # 최소 길이 또는 미발견0 출력
```
