# 백트래킹과 가지치기

[학습목차](README.md) · [연습문제](연습문제_problem-index.md)

## 부분 해를 만들고 되돌리는 탐색

백트래킹은 선택을 하나씩 추가하며 부분 해를 만들고, 그 선택의 탐색이 끝나면 이전 상태로 돌아가는 방법입니다.
탐색 트리의 한 경로가 지금까지 고른 선택들을 나타냅니다.
공유 상태를 바꾸는 구현에서는 선택, 재귀 탐색, 선택 취소의 대응이 중요합니다.
Stanford CS106B도 이 흐름을 choose·explore·unchoose로 설명합니다. [Stanford, Fundamental Backtracking Paradigm](https://web.stanford.edu/class/archive/cs/cs106b/cs106b.1244/lectures/11-backtracking1/)

가지치기는 현재 부분 해에서 어떤 완성도 정답이 될 수 없음을 근거로 그 아래 탐색을 생략하는 작업입니다.
이 근거가 틀리면 빨라진 대신 정답을 버리는 알고리즘이 됩니다.

## 인식 단서와 한계

“조건을 만족하는 배치”, “중복 없이 선택”, “충돌 없는 순서”, “가능한 해를 모두 찾기”가 대표 단서입니다.
선택을 추가할 때 위반을 곧바로 확인할 수 있으면 끝까지 후보를 만든 뒤 검사하는 것보다 일찍 탐색을 줄일 수 있습니다.
그러나 가지치기가 많을 것이라는 기대만으로 입력 한도를 판단하면 안 됩니다.
최악에는 대부분의 후보를 탐색할 수 있으며 해를 모두 출력하는 문제는 출력량도 고려해야 합니다.

같은 상태의 재탐색이 반복된다면 메모이제이션이 가능한지 검토합니다.
그때 상태 키에는 미래의 선택 가능성과 답을 결정하는 정보가 모두 들어가야 합니다.

## 직접 구성한 예제: 4개의 퀸 배치

4×4 체스판의 각 행에 퀸 하나를 놓되 같은 열이나 대각선에서 만나지 않도록 합니다.
행 순서를 고정하면 “지금 행에 둘 열”만 선택하면 됩니다.
열 c, 두 대각선의 식 `r-c`, `r+c`로 기존 배치와의 충돌을 확인합니다.

| 부분 선택의 열 목록 | 다음 상황 | 판단 |
|---|---|---|
| [0] | 다음 행에 2 선택 | 현재까지 충돌 없음 |
| [0,2] | 셋째 행의 모든 열이 충돌 | 이 가지를 되돌림 |
| [1] | 다음 행에 3 선택 | 현재까지 충돌 없음 |
| [1,3] | 셋째 행에 0 선택 | 현재까지 충돌 없음 |
| [1,3,0] | 마지막 행에 2 선택 | 해 [1,3,0,2] 완성 |

이 표는 탐색 일부를 발췌한 직접 구성 추적입니다.
다른 해 `[2,0,3,1]`도 있으며 전체 해 수는 2입니다.
위반된 기존 퀸 관계는 뒤에 퀸을 더 놓아도 사라지지 않으므로 충돌 순간에 가지를 버릴 수 있습니다.

## 충돌 표시와 선택 취소 코드

다음 코드는 N이 1 이상인 경우 해의 개수만 반환합니다.

```python
def count_queens(n):  # N×N 판의 유효한 행별 퀸 배치 수를 세는 함수
    columns = [False] * n  # 이미 사용한 열을 불리언 배열로 표시
    descending = [False] * (2 * n - 1)  # r-c에 n-1을 더한 대각선 번호의 사용 여부
    ascending = [False] * (2 * n - 1)  # r+c 대각선 번호의 사용 여부
    def search(row):  # 앞선 행의 선택을 유지한 채 현재 행의 열을 탐색
        if row == n:  # 모든 행에 충돌 없이 퀸을 놓았는지 확인
            return 1  # 완성된 배치 하나를 해 수에 포함
        total = 0  # 현재 부분 해에서 완성 가능한 배치 수 누적
        for column in range(n):  # 현재 행의 모든 열을 후보로 확인
            down, up = row - column + n - 1, row + column  # 두 대각선의 음수 없는 인덱스 계산
            if columns[column] or descending[down] or ascending[up]:  # 기존 퀸과 열·대각선 충돌 검사
                continue  # 이 충돌은 뒤의 선택으로 고칠 수 없으므로 가지치기
            columns[column] = descending[down] = ascending[up] = True  # 현재 선택이 사용하는 세 제약 표시
            total += search(row + 1)  # 다음 행을 탐색하고 완성된 해 수 합산
            columns[column] = descending[down] = ascending[up] = False  # 다음 후보가 같은 시작 상태를 보도록 현재 선택 취소
        return total  # 현재 행 아래에서 찾은 모든 해 수 반환
    return search(0)  # 아무 행도 고르지 않은 초기 부분 해에서 탐색 시작
```

각 대각선 표시는 현재 경로의 선택만 반영합니다.
다른 가지에서 사용한 표시가 남으면 실제로 가능한 열을 잘못 거부합니다.

## 정답성: 유효성·완전성·복원

`search(row)` 진입 시 첫 row개 행에는 서로 충돌하지 않는 퀸이 하나씩 놓여 있다는 불변식을 둡니다.
후보 검사는 새 퀸과 앞선 모든 퀸의 충돌을 열·대각선 표시로 확인하므로 유효성이 유지됩니다.
모든 유효한 완성 배치는 현재 행에서 선택해야 할 열을 하나 갖고, 반복문은 그 열을 반드시 검사합니다.
가지치기는 이미 위반된 관계만 버리므로 유효한 완성을 제거하지 않습니다.
재귀에서 돌아오면 세 표시를 되돌려 다음 형제 후보가 같은 앞선 배치를 보도록 합니다.
행별 열 목록이 다르면 다른 배치이므로 해를 중복해 세지 않습니다.

## 최적화 가지치기의 추가 조건

최소 비용 탐색에서는 현재 최선의 완성 해보다 나아질 수 없다는 하한을 사용할 수 있습니다.
그러나 현재 누적 비용 자체가 하한이 되려면 남은 비용이 음수가 아니라는 등의 조건이 필요합니다.
현재 비용이 8, 기존 최선이 6이어도 남은 선택에 -5가 가능하면 최종 3을 만들 수 있습니다.
이때 단순히 8이 크다는 이유로 버리면 최적해를 놓칩니다.

해가 하나만 필요한 탐색에서는 성공 즉시 중단할 수 있지만 개수나 모든 해를 구할 때는 같은 중단 규칙을 쓸 수 없습니다.
공유 상태를 바꾼 뒤 조기 반환할 때도 취소 단계가 필요한지 확인합니다.

## 비용과 언어 차이

열 중복을 금지하므로 완성 후보는 최대 N!개이며 위 코드는 각 부분 해에서 N개 열을 확인합니다.
충돌 검사 O(1)을 가정한 느슨한 시간 상한은 O(N·N!)이며 실제 방문 수는 대각선 가지치기에 따라 달라집니다.
표시 배열과 재귀 경로는 O(N) 공간이며 해의 배치를 전부 저장하면 별도 출력 공간이 필요합니다.

C·C++에서는 표시 배열 또는 비트 마스크로 제약을 나타낼 수 있으며 마스크의 자료형 너비를 확인해야 합니다.
Python에서도 행 깊이가 큰 일반 문제라면 재귀 한도와 스택 사용을 고려합니다.
매 선택마다 상태 전체를 복사하는 구현은 복원 오류를 줄일 수 있지만 복사 시간·공간을 추가로 계산해야 합니다.

## 실전의 적용 조건

작은 수의 작업을 충돌 없이 자원에 배정하는 모형에서는 이미 확정된 선택의 충돌을 즉시 검사할 수 있습니다.
현실의 제약이 많아질수록 후보 순서나 하한의 품질이 중요하지만 최악 지수 시간의 가능성이 사라지지는 않습니다.
제약이 변경되는 상황에서는 캐시한 상태의 유효성도 다시 확인해야 합니다.
이 사례는 제약 탐색의 모형이며 모든 일정 시스템이 완전 백트래킹을 사용한다는 뜻은 아닙니다.
