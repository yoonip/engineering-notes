# 무작위화·근사 보장·탐색 휴리스틱

[학습목차](README.md) · [연습문제](연습문제_problem-index.md)

## 서로 다른 세 가지 목표

무작위 알고리즘은 난수를 사용해 실행 경로나 답을 정하는 방법입니다.
근사 알고리즘은 최적값과 비교한 해의 품질을 수학적으로 보장하는 방법입니다.
휴리스틱은 제한된 시간에 좋은 해를 찾지만 일반적인 최적성·근사 비율을 보장하지 않을 수 있는 방법입니다.
무작위라고 항상 부정확한 것은 아니며, 근사 알고리즘이라고 반드시 무작위인 것도 아닙니다.
빠르게 나온 해의 점수와 모든 허용 입력에 대한 성능 보장을 구분하는 것이 중요합니다. [MIT 근사 알고리즘 강의](https://ocw.mit.edu/courses/6-854j-advanced-algorithms-fall-2008/837c5fca1df8315e56ab9d0e3fa760da_notes_approx.pdf)

무작위 피벗 퀵정렬은 어떤 피벗을 골라도 정렬 자체는 맞지만 실행 시간이 달라집니다.
해시만으로 문자열 일치를 선언하면 실행량은 작아도 충돌에 의한 오류가 가능합니다.
“확률이 작습니다”라고 쓰기 전에 입력 고정 여부, 난수의 선택 범위, 비교 횟수를 정합니다.

## 직접 구성한 MAX-CUT 예제

MAX-CUT은 정점을 두 집합으로 나누어 서로 다른 집합 사이 간선의 총 가중치를 최대화하는 문제입니다.
여기서는 무방향 그래프와 음이 아닌 가중치, 자기 루프가 없는 입력을 가정합니다.
각 정점을 독립적으로 확률 1/2로 양쪽 중 한 곳에 넣습니다.
간선 양끝이 다른 쪽일 확률은 1/4+1/4=1/2입니다.
간선의 잘림 여부가 서로 독립일 필요 없이 기댓값의 선형성으로 기대 절단 무게는 전체 무게 W의 절반입니다.
최적값 OPT≤W이므로 E[해의 값]≥OPT/2를 얻습니다. [MIT 무작위 MAX-CUT 분석](https://courses.csail.mit.edu/6.854/18/Scribe/s24-randApproxNP/s24-randApproxNP.html)

직접 구성한 가중치 1의 삼각형에는 배치가 2³=8개입니다.
세 정점이 같은 쪽인 2개 배치는 절단 간선 0개입니다.
나머지 6개 배치는 정점 하나가 다른 쪽이므로 절단 간선 2개입니다.
기댓값은 (2×0+6×2)/8=1.5이며 최적값은 2입니다.
이 작은 예제에서도 한 번의 실행이 0을 반환할 수 있으므로 “항상 OPT/2 이상”이라고 바꾸면 틀립니다.

## 구현과 실험 재현

```python
import random  # 실험용 의사난수 생성기 사용
def random_cut(vertex_count, edges, seed):  # edges는 (정점, 정점, 음이 아닌 가중치)
    generator = random.Random(seed)  # 실행을 재현할 수 있도록 별도 난수 상태 생성
    side = [generator.randrange(2) for _ in range(vertex_count)]  # 각 정점을 두 집합에 배치
    value = sum(weight for u, v, weight in edges if side[u] != side[v])  # 경계를 건너는 간선 무게 합산
    return value, side  # 점수와 실제 분할을 함께 반환
```

정점 V, 간선 E에서 한 실행은 O(V+E) 시간, O(V) 추가 공간입니다.
같은 입력에 R번 실행하면 O(R(V+E)) 시간이며 최고값을 따로 보관합니다.
독립 반복에서 한 번의 실패 확률이 p라고 증명한 사건은 R회 모두 실패할 확률이 p^R입니다.
MAX-CUT의 기대값 보장만으로 원하는 임계값에 대한 p를 임의로 정하지 않습니다.
최고값뿐 아니라 실행 횟수·시드·시간 예산·점수 분포를 함께 기록하면 실험 범위를 설명할 수 있습니다.
언어와 난수 라이브러리가 다르면 같은 정수 시드가 같은 수열을 만든다고 가정하지 않습니다.

## 조건부 기댓값과 결정적 선택

앞의 MAX-CUT에서 아직 배치하지 않은 정점의 기댓값을 남겨 두고 다음 한 정점의 쪽을 고릅니다.
왼쪽에 고정했을 때와 오른쪽에 고정했을 때의 조건부 기댓값 평균은 현재 기댓값입니다.
따라서 둘 중 큰 쪽을 고르면 기댓값을 낮추지 않습니다.
모든 정점을 고정한 뒤에는 조건부 기댓값이 실제 점수이므로 W/2 이상을 얻습니다.
이 그래프 모델에서는 이미 배치한 이웃과 반대편에 놓는 무게를 비교해 구현할 수 있습니다.
정점·간선을 한 번씩 정리하는 인접 리스트 구현은 O(V+E) 시간입니다.
무작위 분석이 결정적 [그리디](15-그리디와교환논증_greedy-exchange.md)의 품질 보장으로 연결되는 예입니다.

## 지역 탐색과 시뮬레이티드 어닐링

지역 탐색은 현재 해의 작은 이웃을 검사해 목적값이 좋아지는 해로 옮깁니다.
더 좋아지는 이웃이 없는 국소 최적해가 전체 최적해와 같다는 보장은 별도 증명이 필요합니다.
최소화의 시뮬레이티드 어닐링은 비용 증가 Δ>0도 exp(−Δ/T) 같은 확률로 허용해 장벽을 넘으려는 방법입니다.
온도 T가 작아질수록 나빠지는 이동이 드물어지며, 현재 해와 지금까지의 최고 해를 분리해 보관합니다.
예를 들어 현재 10→12를 허용한 뒤 8로 갈 수 있어도, 종료 시 현재 12라면 보관한 최고값 10을 반환합니다.
이것은 이동 확률을 설명하기 위한 직접 구성한 예제이며 성능 측정 결과가 아닙니다.
임의의 온도 일정과 유한 시간 예산에 전역 최적해 도달 보장을 붙이지 않습니다. 원전인 [Kirkpatrick 등의 Optimization by Simulated Annealing](https://doi.org/10.1126/science.220.4598.671)을 읽을 때도 제안한 탐색 원리와 개별 유한 실험의 결과를 구별합니다.
한 번의 이웃 평가 비용 C, 반복 횟수 I라면 탐색 비용은 O(IC)이며, 전체 점수를 매번 재계산할지 차분 갱신할지도 포함합니다.

## 실수·활용·한계

답을 정확히 요구하는 채점 문제에 근사해를 넣기 전에 부분 점수·오차·보장 요구를 확인합니다.
가중치가 음수이면 W가 OPT의 적절한 상한이라는 위의 분석을 같은 방식으로 사용하지 않습니다.
수정한 지역 해가 제약을 위반하지 않는지와 점수 차분이 정확한지를 별도로 검사합니다.
C·C++의 정수 분포에서 단순 나머지로 난수를 줄이면 편향이 생길 수 있어 분포 도구의 규약을 확인합니다.
Python의 random은 실험용이며 보안 비밀 생성 용도와 구분합니다. [Python random 공식 문서](https://docs.python.org/3/library/random.html)
큰 조합 최적화의 후보 탐색에 활용하지만, 실제 입력 분포의 측정과 최악 경우의 이론 보장은 다른 근거입니다.
[문자열 해시](29-접미사해시팰린드롬_suffix-hash-palindrome.md), [확률 DP](17-배낭수열구간확률DP_dp-variants.md), [유량 최적화](34-이분매칭과네트워크유량_matching-flow.md)와 연결합니다.

## 복습 질문과 답
