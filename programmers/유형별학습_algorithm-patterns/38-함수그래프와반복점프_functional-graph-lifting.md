# 함수 그래프의 사이클과 반복 점프

[학습목차](README.md) · [연습문제](연습문제_problem-index.md)

## 핵심 원리와 중요성

함수 그래프는 각 정점에서 다음 정점으로 향하는 간선이 정확히 하나인 방향 그래프입니다.
함수 f를 k번 적용한 f^k(v)를 묻는 문제와 같은 모델입니다.
일반 방향 그래프와 달리 다음 경로의 선택이 없으므로 반복 전이를 합성하거나 사이클을 분리할 수 있습니다.
큰 k를 매번 한 단계씩 이동하지 않는 것이 핵심입니다. [CP Initiative 함수 그래프 강의](https://usaco.guide/silver/func-graphs)
여기서 f^k는 함수 합성이며 정점 번호의 거듭제곱을 뜻하지 않습니다.

## 알아보는 단서와 조건

- 각 상태의 다음 상태가 하나로 결정되는지 확인합니다.
- 같은 전이표에 대해 많은 시작점과 큰 이동 횟수 질의가 주어지는지 확인합니다.
- 점프 중 합·최솟값처럼 함께 누적할 정보가 있는지 확인합니다.
- 질의 사이에 f가 바뀌면 이전 점프 표가 유효하지 않을 수 있으므로 정적 전이 조건을 구분합니다.

특정 행동을 고를 수 있는 문제를 임의로 다음 정점 하나로 줄이면 다른 경로를 잃습니다.
트리의 부모 점프도 같은 원리를 사용하지만, 루트 위의 이동을 자기 루프나 별도 없음 표시로 정해야 합니다.

## 사이클과 그쪽으로 들어가는 경로

유한 정점에서 같은 함수를 계속 적용하면 언젠가 이미 방문한 정점을 만납니다.
반복된 정점부터 한 바퀴가 방향 사이클이며, 그 이전은 사이클로 들어가는 경로입니다.
기저의 무방향 연결 성분마다 방향 사이클이 하나이고, 나머지 정점은 그 사이클로 들어갑니다.
자기 자신으로 가는 간선도 길이 1의 사이클입니다.
정점마다 다음 점이 유일하므로 한 경로가 서로 다른 두 사이클로 갈라질 수 없습니다.

직접 구성한 전이 f=[1,2,3,1,3]은 0→1→2→3→1과 4→3입니다.
사이클은 1→2→3→1이며 길이는 3입니다.
0에서 한 번 이동하면 사이클에 들어가므로 k≥1에서 남은 k−1만 3으로 나눈 나머지를 사용합니다.
k=11이면 1에서 10 mod 3=1번 더 가므로 답은 2입니다.
사이클 도달 전 이동량을 빼지 않고 k mod 3만 쓰면 다른 정점에서 시작한 것처럼 계산합니다.

## 이진 점프 표의 구성

jump[b][v]를 v에서 2^b번 이동한 정점으로 정의합니다.
jump[0][v]=f(v)이며 jump[b+1][v]=jump[b][jump[b][v]]입니다.
2^b번 이동 두 개를 이어 붙이면 2^(b+1)번이므로 이 점화가 성립합니다.
이는 한 단계 함수의 제곱을 미리 계산하는 방법입니다. [Laaksonen 교재의 후속 정점 질의](https://cses.fi/book/book.pdf)

| 지수 b | 이동 수 | v=0 | v=1 | v=2 | v=3 | v=4 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 0 | 1 | 1 | 2 | 3 | 1 | 3 |
| 1 | 2 | 2 | 3 | 1 | 2 | 1 |
| 2 | 4 | 1 | 2 | 3 | 1 | 3 |

위 표는 직접 구성한 같은 전이 f의 계산 결과입니다.
11=1+2+8을 낮은 비트부터 처리하면 0→1, 두 단계로 1→3, 여덟 단계로 3→2입니다.
사용하는 점프는 항상 갱신된 현재 정점에서 시작해야 합니다.

## 짧은 구현

```python
def build_jumps(successor, maximum_steps):  # 각 다음 정점은 유효한 인덱스라는 조건
    levels = max(1, maximum_steps.bit_length())  # 최대 질의의 모든 비트를 덮는 층 수
    table = [successor[:]]  # 한 단계 전이를 입력과 분리해 저장
    for _ in range(1, levels):  # 기존 이동 길이를 두 배씩 확장
        previous = table[-1]  # 직전 층의 2의 거듭제곱 점프
        table.append([previous[previous[v]] for v in range(len(successor))])  # 같은 길이 점프 두 번 합성
    return table  # 질의에서 재사용할 전이 표 반환
def advance(table, vertex, steps):  # steps는 구축 때 정한 최대 이동 수 이하
    bit = 0  # 현재 확인할 이진수 자리
    while steps:  # 아직 적용하지 않은 이동 길이 확인
        if steps & 1:  # 이번 자리의 점프가 필요하면 적용
            vertex = table[bit][vertex]  # 현재 정점에서 해당 길이만큼 이동
        steps >>= 1  # 처리한 최하위 자리 제거
        bit += 1  # 다음 층으로 진행
    return vertex  # 모든 선택한 점프를 합성한 최종 정점
```

단계 0은 while에 들어가지 않아 시작 정점을 그대로 반환합니다.
정점 n, 최대 질의 K의 비트 수 B=max(1,⌊log2 K⌋+1)에서 구축 O(nB) 시간·공간입니다.
질의는 O(B) 시간, 추가 O(1) 공간이며 q개 질의까지 O((n+q)B) 시간입니다.
K=0에서는 로그 식 대신 B=1을 사용합니다.
정점 번호를 한 워드에 저장하고 함수 조회 O(1)인 모델의 분석입니다.

## 점프 중 합과 순서 있는 요약

한 번 이동할 때 출발 정점 비용 c(v)를 더한다고 정의합니다.
sum[0][v]=c(v), sum[b+1][v]=sum[b][v]+sum[b][jump[b][v]]입니다.
질의에서는 비용을 먼저 더한 뒤 현재 정점을 jump로 바꿉니다.
도착 정점의 비용을 포함할지에 따라 초기 정의가 달라지므로 두 약속을 섞지 않습니다.
합 대신 min·max·행렬 합성처럼 결합법칙이 있는 요약도 같은 방식으로 합성할 수 있습니다.
교환법칙이 없는 연산은 앞 절반 뒤에 뒤 절반을 결합하는 순서를 지킵니다.
구축·질의의 각 결합이 O(C)라면 해당 시간 복잡도에 C를 곱합니다.

## 사이클 분해와 Floyd의 선택 기준

모든 정점을 한 번씩 분석할 때에는 진입 차수 0 정점을 지우고 남은 사이클을 순회할 수 있습니다.
제거한 정점을 역순으로 처리하면 사이클까지 거리와 도착 위치를 계산합니다.
명시적인 함수 배열에서 전체 분해는 O(n) 시간·공간입니다.
한 시작점만 필요하고 방문 표 공간을 쓰기 어렵다면 느린 포인터 한 번·빠른 포인터 두 번인 Floyd 방법을 검토합니다.
같은 정점에서 만난 뒤 시작점과 만남점에서 같은 속도로 이동하면 사이클 진입점을 찾습니다.
진입 전 길이 μ와 사이클 길이 λ를 구하는 시간은 O(μ+λ), 추가 공간은 O(1)입니다.
이는 f 평가가 O(1)일 때의 분석이며 여러 시작점 질의를 각각 반복하면 같은 경로를 다시 계산합니다.

## 실전 연결과 구현 실수

고정된 작업 라우팅·결정적 상태 전이의 장기 결과를 질의하는 모델과 연결합니다.
라우팅 정책이 바뀌거나 외부 입력에 따라 다음 상태가 달라지면 정적인 함수 모델을 다시 검토합니다.
C·C++에서는 큰 K의 자료형과 1<<b의 시프트 폭을 확인합니다.
Python에서 nB개의 표 원소는 정수 연산량뿐 아니라 리스트 메모리도 계산합니다.
인덱스 0과 “부모 없음” 0을 혼용하거나, 두 번째 반쪽의 비용을 원래 시작점에서 읽는 것이 흔한 실수입니다.
[행렬 거듭제곱](32-행렬거듭제곱과선형점화_matrix-recurrence.md)은 작은 다중 상태 선형 전이를, 이진 점프는 결정적 한 후속 정점을 합성합니다.

## 복습 질문과 답

- 질문: 점프 표는 왜 현재 정점을 두 번 조회합니까? 답: 첫 절반의 도착점에서 같은 길이의 두 번째 절반을 시작하기 때문입니다.
- 질문: 사이클 길이로 바로 나누면 됩니까? 답: 먼저 사이클 진입 전 이동량을 처리하고 남은 이동량에 주기를 적용해야 합니다.
- 질문: 전이 하나를 바꾸면 표 한 칸만 바꾸면 됩니까? 답: 그 전이를 통과하는 더 큰 점프들이 영향을 받을 수 있어 단순한 한 칸 수정으로 유지되지 않습니다.
