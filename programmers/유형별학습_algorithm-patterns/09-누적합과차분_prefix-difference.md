# 누적합과 차분

[학습목차](README.md) · [연습문제](연습문제_problem-index.md)

## 겹치는 구간 계산의 재사용

누적합은 앞에서부터 더한 결과를 저장해 구간 합을 두 접두 구간의 차이로 구하는 방법입니다.
차분은 반대로 인접 값의 변화를 저장하여 구간에 같은 값을 더하는 작업을 경계 두 곳의 변화로 표현합니다.
두 기법은 “모든 위치를 매번 다시 처리하지 않는다”는 공통점을 갖습니다.
Python의 `itertools.accumulate`도 앞선 결과에 다음 값을 결합하는 누적 연산을 제공합니다. [Python itertools.accumulate](https://docs.python.org/3/library/itertools.html#itertools.accumulate)

중요한 조건은 어떤 연산을 되돌려 공통 부분을 제거할 수 있는가입니다.
합은 뺄셈으로 제거할 수 있지만 접두 최댓값 두 개를 빼서 중간 구간의 최댓값을 얻을 수는 없습니다.

## 인식 단서와 적용 한계

값이 고정된 배열에서 많은 구간 합을 묻는다면 누적합이 유력합니다.
여러 구간에 같은 값을 더한 뒤 마지막 배열만 필요하다면 차분이 유력합니다.
구간 갱신과 구간 질의가 온라인으로 섞이면 단순한 정적 누적합·차분만으로 충분하지 않을 수 있습니다.
이때는 질의를 오프라인으로 바꿀 수 있는지 또는 갱신을 지원하는 트리 구조가 필요한지 검토합니다.

또한 구간이 포함 구간 `[l,r]`인지 반열린 구간 `[l,r)`인지 먼저 정합니다.
다음 설명은 0부터 번호를 매기고 끝을 제외하는 `[l,r)`를 사용합니다.

## 직접 구성한 예제: 음수가 있는 구간 합

배열이 `[2,-1,3,4]`라고 가정합니다.
`P[i]`를 처음 i개 값의 합으로 정의하고 빈 접두 구간 `P[0]=0`을 둡니다.

| i | 이번에 추가한 값 | P[i]의 의미 | P[i] |
|---:|---:|---|---:|
| 0 | 없음 | 빈 구간 | 0 |
| 1 | 2 | 첫 1개 합 | 2 |
| 2 | -1 | 첫 2개 합 | 1 |
| 3 | 3 | 첫 3개 합 | 4 |
| 4 | 4 | 첫 4개 합 | 8 |

`[1,4)`의 합은 `P[4]-P[1]=8-2=6`입니다.
실제 합 `-1+3+4=6`과 일치하며 음수가 있어도 누적합 공식은 변하지 않습니다.

```python
values = [2, -1, 3, 4]  # 리스트에 원래 배열 저장
prefix = [0]  # 빈 접두 구간의 합을 첫 항목으로 준비
for value in values:  # 각 원소를 순서대로 한 번씩 처리
    prefix.append(prefix[-1] + value)  # 이전 접두 합에 현재 값을 더해 다음 접두 합 생성
left, right = 1, 4  # 끝을 제외하는 질의 구간 지정
answer = prefix[right] - prefix[left]  # 공통 앞부분을 빼고 질의 구간의 합만 남기기
```

## 차분 갱신의 추적

길이 4의 0 배열에서 `[1,4)`에 5를 더한다고 가정합니다.
끝 다음 경계를 저장하기 위해 차분 배열은 길이 5로 준비합니다.
변경 전 차분은 `[0,0,0,0,0]`이며 `D[1]+=5`, `D[4]-=5`로 `[0,5,0,0,-5]`가 됩니다.
앞에서부터 누적하면 실제 네 위치의 증가량은 `[0,5,5,5]`입니다.
원래 배열에 이 증가량을 더하면 `[2,4,8,9]`가 됩니다.

구간의 시작에서 효과를 켜고 끝 다음에서 끈다고 생각하면 포함 관계가 명확해집니다.
Q개의 갱신을 경계 변화로 모두 저장한 뒤 한 번만 누적하여 각 위치에 겹친 증가량을 복원합니다.
차분·누적 관계 자체는 대학 알고리즘 과제에서도 별도 주제로 다룹니다. [NTU Algorithm Design and Analysis 2022, Difference Array & Prefix Sum](https://cool.ntu.edu.tw/courses/17712/files/2911049/download?download_frd=1)

## 정당성: 상쇄와 경계

누적합은 `P[r]=a[0]+...+a[r-1]`에서 `P[l]`의 공통 항들이 상쇄되는 식으로 증명합니다.
이는 정렬이나 원소의 부호와 무관한 항등식입니다.
차분의 구간 갱신은 시작 이전의 누적에 0, 시작부터 끝 이전까지 5, 끝부터 다시 0을 더합니다.
여러 갱신도 덧셈의 결합·교환 법칙으로 각각의 효과를 합칠 수 있습니다.

이 증명은 값을 더하는 갱신에 대한 것입니다.
구간 값을 특정 수로 대입하거나 최댓값으로 바꾸는 연산에 같은 두 경계 공식을 그대로 쓰면 안 됩니다.

## 2차원과 비용

2차원 누적합 `P[x][y]`를 앞의 x행·y열 합으로 정의하면 직사각형 합은 네 접두 직사각형의 포함·배제로 계산합니다.
`[x1,x2)×[y1,y2)`의 답은 `P[x2][y2]-P[x1][y2]-P[x2][y1]+P[x1][y1]`입니다.
두 번 뺀 공통 왼쪽 위 부분을 한 번 더하는 이유를 그림 대신 구간의 포함 횟수로 확인할 수 있습니다.

1차원 누적합은 준비 O(N), 질의 Q개 O(Q), 보조 공간 O(N)입니다.
차분은 구간 갱신 Q개와 마지막 복원에 O(N+Q), 공간 O(N)입니다.
2차원 배열 전체를 저장하면 높이 H·너비 W에 대해 O(HW) 공간이 필요합니다.

## 언어와 실전 조건

C·C++에서는 원소 각각이 작은 정수여도 전체 합은 정수 범위를 넘을 수 있으므로 합의 범위를 따로 계산합니다.
Python은 큰 정수 결과를 표현하지만 매우 큰 값의 산술을 무조건 상수 비용으로 볼 수는 없습니다.
Python에서 `prefix[1:]` 같은 슬라이스를 반복해 만들면 추가 복사 비용이 생깁니다.
센서의 시간 구간 총량이나 일별 집계에서는 데이터가 고정된 기간에 누적합을 재사용할 수 있습니다.
행사별 할인처럼 구간에 같은 증감이 붙고 마지막 결과만 필요하면 차분으로 일괄 합성할 수 있습니다.
실시간으로 과거 값이 수정되는 경우에는 이 정적 조건이 유지되는지 다시 확인합니다.

## 실수와 반례

- `[0,r)` 질의를 위해 빈 접두 합 0을 두지 않으면 첫 원소를 별도로 처리하다 경계를 틀리기 쉽습니다.
- 접두 최댓값이 `[5,5]`인 두 배열 `[5,1]`, `[5,4]`는 마지막 한 칸의 최댓값이 다릅니다. 접두 최댓값만으로는 복원할 수 없습니다.
- 차분의 끝 경계 `r`을 `r-1`로 잘못 쓰면 마지막 대상 위치부터 효과가 사라집니다.
- 모든 갱신마다 전체 차분을 복원하면 O(N+Q)의 이점을 잃습니다.

## C·C++·Python으로 같은 예제 실행

여러 반열린 구간에 값을 더하는 작업을 차분의 두 경계에 기록하고 한 번의 복원으로 최종 배열과 접두 합을 만듭니다.

이 예제에서 직접 구현하는 기법은 반열린 구간 · 차분 배열 · 누적합입니다. 같은 표준 입력에서 세 언어가 같은 결과를 출력합니다.

### 입력과 출력

N Q(1≤N≤10,0≤Q≤10), N개 값(−100~100), Q개의 l r delta(0≤l≤r≤N,−100≤delta≤100), 마지막 합 질의 L R(0≤L≤R≤N)입니다.

```text
4 1
2 -1 3 4
1 4 5
1 4
```

첫 줄은 갱신 후 배열, 둘째 줄은 [L,R)의 합입니다.

```text
2 4 8 9
21
```

### 입력부터 결과까지

| 단계 | 중간 상태 | 수행 이유 |
| --- | --- | --- |
| 1 | 갱신 전 A=[2,-1,3,4], diff=[0,0,0,0,0] | 차분은 아직 어느 위치에도 증가량이 없음을 나타냅니다. |
| 2 | 갱신[1,4)에5: diff=[0,5,0,0,-5] | 1에서 증가량을 켜고 배열 끝4에서 취소합니다. |
| 3 | 누적 증가량=[0,5,5,5], A=[2,4,8,9] | 왼쪽부터 차분을 누적해 겹친 증가량을 복원합니다. |
| 4 | P=[0,2,6,14,23], P[4]-P[1]=23-2=21 | 최종 배열의 접두 합으로 요청 구간을 계산합니다. |

### C 예제

[실행 가능한 C 파일](<예제_examples/09-누적합과차분_prefix-difference/example.c>)

```c
#include <stdio.h> // 정수 입력과 합 출력
int main(void) { // 실행 시작점
    int n, q, left, right; // 배열 크기와 갱신 수 및 최종 질의 경계
    long long a[10], diff[11] = {0}, prefix[11] = {0}, running = 0; // 값·차분·접두 합과 누적 증가량
    scanf("%d %d", &n, &q); // 원소 수와 구간 갱신 수 읽기
    for (int i = 0; i < n; ++i) scanf("%lld", &a[i]); // 원래 값 입력
    for (int i = 0; i < q; ++i) { // 모든 반열린 구간 갱신 처리
        int l, r; long long delta; // 갱신 시작·끝과 더할 값
        scanf("%d %d %lld", &l, &r, &delta); // 이번 갱신 읽기
        diff[l] += delta; // 구간 시작에서 증가량 켜기
        diff[r] -= delta; // 구간 끝에서 같은 증가량 끄기
    } // 차분 기록 끝
    scanf("%d %d", &left, &right); // 최종 합 질의 경계 읽기
    for (int i = 0; i < n; ++i) { // 차분을 복원하며 최종 값과 접두 합 생성
        running += diff[i]; // 현재 위치에 겹치는 증가량 누적
        a[i] += running; // 원래 값에 전체 증가량 반영
        prefix[i + 1] = prefix[i] + a[i]; // 최종 배열의 접두 합 누적
        printf("%s%lld", i ? " " : "", a[i]); // 복원한 값을 왼쪽부터 출력
    } // 최종 배열 복원 끝
    printf("\n%lld\n", prefix[right] - prefix[left]); // 배열 줄 다음에 최종 구간 합 출력
    return 0; // 정상 종료
} // 차분과 누적합 예제 끝
```

### C++ 예제

[실행 가능한 C++ 파일](<예제_examples/09-누적합과차분_prefix-difference/example.cpp>)

```cpp
#include <iostream> // 표준 입력과 출력
#include <vector> // 길이에 맞춘 값과 차분 배열
using namespace std; // 표준 이름의 접두사 생략
int main() { // 실행 시작점
    int n, q; cin >> n >> q; // 배열 크기와 갱신 개수 읽기
    vector<long long> a(n), diff(n + 1, 0), prefix(n + 1, 0); // 값과 끝 경계를 포함한 두 보조 배열
    for (long long& value : a) cin >> value; // 원래 값 입력
    for (int i = 0; i < q; ++i) { // 구간 갱신을 차분에만 기록
        int l, r; long long delta; cin >> l >> r >> delta; // 반열린 경계와 증가량 읽기
        diff[l] += delta; // 시작 경계에서 증가량 추가
        diff[r] -= delta; // 끝 경계에서 증가량 취소
    } // 모든 갱신 기록 끝
    int left, right; cin >> left >> right; // 최종 합 질의 경계
    long long running = 0; // 현재 위치에 적용할 누적 증가량
    for (int i = 0; i < n; ++i) { // 최종 배열과 접두 합 동시 복원
        running += diff[i]; // 새 경계의 증가·취소 반영
        a[i] += running; // 현재 원소의 최종 값 계산
        prefix[i + 1] = prefix[i] + a[i]; // 최종 배열의 접두 합 갱신
        cout << (i ? " " : "") << a[i]; // 복원한 원소 출력
    } // 한 번의 복원 순회 끝
    cout << '\n' << prefix[right] - prefix[left] << '\n'; // 구간 합을 별도 줄에 출력
    return 0; // 정상 종료
} // 차분과 누적합 예제 끝
```

### Python 예제

[실행 가능한 Python 파일](<예제_examples/09-누적합과차분_prefix-difference/example.py>)

```python
import sys # 정수 토큰 입력
tokens = iter(map(int, sys.stdin.buffer.read().split())) # 입력을 차례로 읽을 반복자
n, q = next(tokens), next(tokens) # 배열 크기와 갱신 개수
values = [next(tokens) for _ in range(n)] # 원래 값 저장
diff, prefix = [0] * (n + 1), [0] * (n + 1) # 끝 경계까지 포함한 차분과 접두 합
for _ in range(q): # 각 구간 갱신을 두 경계에 기록
    left, right, delta = next(tokens), next(tokens), next(tokens) # 반열린 구간과 증가량
    diff[left] += delta # 시작 위치부터 증가량 적용
    diff[right] -= delta # 끝 위치부터 같은 증가량 취소
left, right = next(tokens), next(tokens) # 최종 구간 합의 경계
running = 0 # 현재 위치에 겹치는 증가량
for index in range(n): # 차분 복원과 접두 합 생성
    running += diff[index] # 새 경계의 증가·취소 누적
    values[index] += running # 현재 원소의 최종 값 계산
    prefix[index + 1] = prefix[index] + values[index] # 접두 합 한 칸 확장
print(*values) # 갱신이 끝난 배열 출력
print(prefix[right] - prefix[left]) # 두 접두 합 차이로 최종 구간 합 출력
```

### 예제의 비용과 실행 파일

- 시간: O(N+Q)입니다.
