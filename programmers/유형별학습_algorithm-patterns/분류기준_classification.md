# 문제 유형의 분류 기준과 언어별 보관 상태

한 문제에는 주유형 하나와 함께 쓰는 기법을 연결합니다. 주유형은 대표 풀이에서 답을 결정하는 구조나 비용을 줄이는 핵심 기법이며, 문제의 유일한 해법이라는 뜻은 아닙니다. 예를 들어 정렬과 투포인터로 그리디를 구현했다면 여러 기법을 함께 표시할 수 있습니다.

대표 자료는 기존 Python 통과본을 우선하고, 해당 자료가 없거나 비교용·미완료이면 C++ 통과본을 사용합니다. Python 레벨 5에서 새로 통과한 풀이를 과거 보관본보다 우선 연결합니다. 이름이나 통상적인 인터넷 분류만 보고 유형을 결정하지 않으며, 풀이 요약 또는 실제 코드의 인용을 기계 판독 목록에 남깁니다.

여기서 유형은 학습 경로를 묶는 범위입니다. 매칭과 유량을 한 본문에서 다루어도 Hopcroft–Karp 구현을 유량 구현이라고 부르지 않습니다. SCC·단절점·단절선도 같은 본문에서 비교하되 서로 다른 문제와 갱신 규칙을 설명합니다. 문자열을 직접 정렬해 푼 문제는 트라이가 가능한 문제라고 해서 트라이 구현으로 분류하지 않습니다.

| 언어 링크 | 의미 |
| --- | --- |
| C·C++·Python | 해당 언어의 기존 통과 보관본입니다. 이번 유형 정리에서 새 제출한 것은 아닙니다. |
| Python 비교용 | 다른 언어 풀이와 비교하는 학습 코드이며 Python 사이트 통과 기록으로 세지 않습니다. |
| Python 미완료 | 정답에 이르지 못한 시도이며 통과 코드로 세지 않습니다. |
| — | 저장소에서 연결할 자료가 없다는 뜻입니다. 사이트의 현재 미지원 판정은 아닙니다. |

Python의 214295 미로 주행 테스트는 최대 다섯 번 제출 후 96점으로 중단한 기록을 유지합니다. C와 C++ 통과 기록을 Python 통과로 옮기지 않습니다. 389632 문자열과 알파벳과 쿼리의 과거 실패 이력은 보존하고, 문제 목록에서는 이후 Python 100점 재풀이로 연결합니다.

분류는 기존 보관 풀이를 읽어 작성한 학습용 판단이며 프로그래머스가 제공한 공식 태그가 아닙니다. 언어별 대안의 모든 구현을 같은 유형이라고 주장하지 않습니다. 모든 가능한 알고리즘과 미래의 새로운 기법을 유한한 목차에 닫아 놓는 것도 아니며, 본문에서 명시한 기초·대표·심화 기법을 실제 설명과 예제로 다룹니다.
