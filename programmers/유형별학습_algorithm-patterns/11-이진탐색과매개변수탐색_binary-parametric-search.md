# 이진 탐색과 매개변수 탐색

[학습목차](README.md) · [연습문제](연습문제_problem-index.md)

## 경계를 찾는 문제로의 전환

이진 탐색은 정렬된 값이나 단조인 판정 결과에서 경계를 반씩 줄여 찾는 방법입니다.
반드시 같은 값 하나를 찾는 검색만 의미하지는 않습니다.
“처음으로 목표 이상인 위치”처럼 존재하지 않는 값의 삽입 경계를 찾을 수도 있습니다.
Python `bisect_left`는 앞부분이 목표보다 작고 뒷부분이 목표 이상인 분할 위치를 반환합니다. [Python bisect_left](https://docs.python.org/3/library/bisect.html#bisect.bisect_left)

매개변수 탐색은 최적값을 직접 구성하는 대신 값 X를 고정한 판정 문제로 바꾸는 접근입니다.
어려운 최적화가 쉬운 판정과 단조 경계 찾기로 바뀌면 탐색 공간을 크게 줄일 수 있습니다.

## 인식 단서와 적용 불가 조건

“최대 비용을 최소화”, “최소 간격을 최대화”, “가능한 최소 용량”은 판정 문제를 생각할 단서입니다.
그러나 X가 커질 때 참·거짓이 어느 방향으로만 바뀌는지 증명하지 못하면 이진 탐색을 적용하면 안 됩니다.
값의 대소와 가능 여부가 참·거짓·참처럼 되돌아오면 중간값으로 한쪽을 버릴 수 없습니다.
판정 함수 자체가 틀리면 탐색은 그 잘못된 경계를 빠르게 찾을 뿐입니다.

연속 실수의 근삿값을 찾는 문제는 정수의 정확한 최소 경계와 종료 조건이 다릅니다.
오차 기준, 반복 횟수, 부동소수점 비교의 의미를 별도로 정합니다.

## 직접 구성한 예제: 연속 작업의 용량

순서가 고정된 작업량 `[2,3,4,2]`를 최대 두 묶음으로 나눕니다.
각 묶음은 연속해야 하며, 묶음 합의 최댓값을 최소화하려 합니다.
용량 C를 고정하면 “합이 C 이하인 연속 묶음 두 개 이하로 모두 담을 수 있는가”를 판정합니다.

| 용량 C | 왼쪽부터 가능한 만큼 담은 묶음 | 묶음 수 | 판정 |
|---:|---|---:|---|
| 5 | [2,3] / [4] / [2] | 3 | 불가능 |
| 6 | [2,3] / [4,2] | 2 | 가능 |
| 7 | [2,3] / [4,2] | 2 | 가능 |
| 11 | [2,3,4,2] | 1 | 가능 |

하한은 가장 큰 작업 4, 상한은 전체 합 11입니다.
`[4,11]`에서 7은 가능하므로 상한을 7로, 다음 5는 불가능하므로 하한을 6으로 옮깁니다.
6이 가능하여 범위가 `[6,6]`이 되면 최소 용량은 6입니다.

## 판정의 탐욕과 단조성

작업량이 음이 아니면 현재 묶음에 더 담을 수 있을 때 담는 것이 묶음 수를 늘리지 않습니다.
탐욕 분할의 첫 경계는 같은 용량의 다른 유효 분할보다 같거나 뒤이며, 이 관계를 각 묶음에 귀납적으로 적용할 수 있습니다.
따라서 탐욕으로 만든 묶음 수가 두 개를 넘으면 다른 분할도 두 개 안에 끝낼 수 없습니다.

용량 C로 가능한 분할은 더 큰 용량에서도 그대로 가능합니다.
그러므로 판정 결과는 불가능에서 가능으로 한 번만 바뀌며 첫 가능 용량을 찾을 수 있습니다.
작업량에 음수가 있으면 “다음 작업을 넣으면 초과하므로 지금 끊는다”는 탐욕 근거부터 다시 확인해야 합니다.

```python
def minimum_capacity(work, limit):  # 연속 묶음의 최소 허용 용량을 구하는 함수
    def feasible(capacity):  # 용량을 고정했을 때 묶음 수 제한을 만족하는지 판정
        groups, used = 1, 0  # 첫 묶음을 열고 현재 사용량을 0으로 시작
        for amount in work:  # 작업을 원래 순서대로 읽기
            if used + amount > capacity:  # 현재 묶음에 다음 작업을 넣으면 넘치는지 검사
                groups += 1; used = 0  # 새 묶음을 열고 그 묶음의 사용량 초기화
            used += amount  # 작업 하나를 현재 묶음에 포함
        return groups <= limit  # 필요한 묶음 수가 제한 이하인지 반환
    low, high = max(work), sum(work)  # 정답이 반드시 들어가는 포함 탐색 범위 지정
    while low < high:  # 서로 다른 후보 경계가 남아 있는 동안 반복
        middle = (low + high) // 2  # 가운데 정수 용량 선택
        if feasible(middle):  # 이 용량으로 가능한 경우
            high = middle  # 더 작은 정답이 있을 수 있으므로 가운데를 포함해 상한 축소
        else:  # 이 용량으로 불가능한 경우
            low = middle + 1  # 가운데 이하를 제외하고 하한 전진
    return low  # 범위가 한 값으로 줄었을 때 첫 가능 용량 반환
```

이 코드는 작업이 하나 이상이고 작업량이 음이 아니며 묶음 제한이 1 이상인 조건입니다.
탐색 하한이 `max(work)` 이상이므로 판정 중 작업 하나가 용량보다 큰 경우는 발생하지 않습니다.

## 탐색 불변식과 종료

반복 직전 최소 가능 용량이 항상 포함 구간 `[low,high]` 안에 있다는 불변식을 둡니다.
가능한 중간값에서는 정답이 중간값 이하이므로 상한을 중간값으로 바꿉니다.
불가능한 중간값에서는 단조성에 따라 그 이하가 모두 불가능하므로 하한을 한 칸 넘깁니다.
`low<high`이면 두 갱신 모두 구간 길이를 줄이므로 종료합니다.
마지막 한 값은 여전히 정답을 포함하는 구간이므로 정답 그 자체입니다.

## 비용과 언어 차이

작업 수 N, 탐색 값 범위의 폭 U에서 판정 한 번은 O(N), 전체는 O(N log(U+1))입니다.
별도 분할을 저장하지 않으면 판정의 보조 공간은 O(1)입니다.
정렬 배열의 위치 탐색은 O(log N)이지만 그 위치에 배열 삽입까지 하면 이동 비용이 추가됩니다. [Python bisect, Performance Notes](https://docs.python.org/3/library/bisect.html#performance-notes)

C·C++에서는 `low+high`와 전체 작업 합이 자료형 범위 안에 들어가는지 확인합니다.
필요하면 넓은 정수형과 `low+(high-low)/2` 형태를 사용합니다.
Python의 큰 정수도 연산 비용이 있으므로 불필요하게 과도한 상한을 정하지 않습니다.

## 실전의 적용 조건

연속 데이터를 여러 덩어리로 나누는 배치 크기 결정은 이 모형으로 설명할 수 있습니다.
실제 처리 시간은 데이터량 외에 작업별 고정 비용이나 자원 간섭에 의존할 수 있으므로 단순 합 모델과 구별합니다.
가능 여부가 외부 상태에 따라 변하는 실시간 시스템에서는 탐색 중 같은 X의 판정이 일관되는지도 중요합니다.
이 예제는 용량 결정의 교육용 모형이며 특정 저장 장치의 최적 설정을 제시하는 것은 아닙니다.

## 실수와 연계 유형

- 가능한 중간값에서 `high=middle-1`로 바꾸면 포함 구간 정의와 맞지 않아 정답을 버릴 수 있습니다.
- `low=middle`만 쓰면 두 값이 남은 구간에서 반복이 멈추지 않을 수 있습니다.
- 단조성을 확인하지 않고 이름에 “최소”가 있다는 이유만으로 적용하면 안 됩니다.

[정렬](05-정렬과비교함수_sorting-comparators.md)은 위치 탐색의 기반이고 [모델링](01-문제모델링과복잡도_modeling-complexity.md)은 최적화를 판정으로 바꾸는 앞단입니다.

## 삼분 탐색과 단봉 함수 최적화

이진 탐색의 단조 판정과 별도로, 최소점까지 엄격히 감소하고 이후 엄격히 증가하는 단봉 함수는 두 내부 점을 비교해 범위를 줄일 수 있습니다. 최소점 구간에서만 같은 값이 이어지는 경우도 허용합니다. 이것이 삼분 탐색이며 모든 함수가 이런 모양이라는 보장은 없습니다. [University of Washington의 Ternary Search 강의](https://courses.cs.washington.edu/courses/cse417/18wi/lectures/lec04-binary-search-3.pdf)에서 전제를 확인할 수 있습니다.

최소화를 위해 l<m1<m2<r를 택했을 때 f(m1)<f(m2)이면 m2 오른쪽을 제외합니다. 최솟값이 그 오른쪽에 있다면 감소 구간에서 앞 점의 값이 더 작다는 관찰과 모순입니다. 반대 부등호이면 m1 왼쪽을 제외하며, 두 값이 같으면 해당 전제 아래 [m1,m2]에 최소점이 있습니다.

직접 구성한 f(x)=(x-3)², [0,9]에서 m1=3,m2=6이면 값은 0과 9여서 [0,6]으로 줄입니다. 정수 구간은 길이가 작아지면 남은 점을 전부 확인해 정수 나눗셈으로 반복이 멈추지 않는 오류를 막습니다. 실수 구간은 목표 구간 오차 ε와 평가 정밀도를 정하며, 한 번 평가 비용 C에서 O(C log((r-l)/ε))의 반복 비용을 검토합니다.

전 구간에서 최솟값이 아닌 평탄 구간도 나타나는 약한 단조 조건, 여러 골짜기가 있는 함수, 평가 잡음이 있는 함수에는 같은 제거 규칙을 바로 쓰지 않습니다. 이산 볼록 함수처럼 f(x+1)-f(x)의 부호가 단조라면 그 부호 경계를 이진 탐색하는 다른 방법도 있습니다.

## C·C++·Python으로 같은 예제 실행

작업 순서를 유지해 최대 K개의 연속 그룹에 배치할 때 필요한 최소 그룹 용량을 판정 함수와 이진 탐색으로 구합니다.

이 예제에서 직접 구현하는 기법은 매개변수 탐색 · 단조 판정 함수 · 연속 그룹 탐욕 배치입니다. 같은 표준 입력에서 세 언어가 같은 결과를 출력합니다.

### 입력과 출력

N K(1≤K≤N≤20), N개 작업량(0~1000)입니다. 그룹은 비어 있지 않은 연속 구간이며 사용 그룹 수는 K 이하입니다.

```text
4 2
2 3 4 2
```

가능한 최소 그룹 용량을 정수 하나로 출력합니다.

```text
6
```

### 입력부터 결과까지

| 단계 | 중간 상태 | 수행 이유 |
| --- | --- | --- |
| 1 | 초기 low=4,high=11 | 작업 하나의 최대량4는 하한이며 전체 합11은 가능한 상한입니다. |
| 2 | middle=7: [2,3],[4,2],groups=2,high=7 | 현재 그룹을 최대한 채워도 두 그룹이면 충분하므로 상한을 낮춥니다. |
| 3 | middle=5: [2,3],[4],[2],groups=3,low=6 | 용량5는 세 그룹이 필요하므로5 이하를 버립니다. |
| 4 | middle=6: [2,3],[4,2],groups=2,low=high=6 | 용량6이 가능하고 더 작은 후보는 이미 제외되어 답이6입니다. |

### C 예제

[실행 가능한 C 파일](<예제_examples/11-이진탐색과매개변수탐색_binary-parametric-search/example.c>)

```c
#include <stdio.h> // 순서 있는 작업량 입력과 용량 출력
int n, limit, values[20]; // 작업 수·허용 그룹 수·순서대로 처리할 작업량
int feasible(long long capacity) { // 이 용량으로 제한 그룹 안에 담기는지 판정
    int groups = 1; // 첫 그룹부터 사용
    long long current = 0; // 현재 그룹의 작업량 합
    for (int i = 0; i < n; ++i) { // 작업 순서를 유지하며 하나씩 배치
        if (values[i] > capacity) return 0; // 작업 하나도 못 담는 용량 거절
        if (current + values[i] > capacity) { // 현재 그룹에 더 넣을 수 없는 경우
            ++groups; // 다음 연속 그룹 열기
            current = values[i]; // 새 그룹의 첫 작업 저장
        } else current += values[i]; // 아직 여유가 있으면 현재 그룹에 추가
    } // 모든 작업의 탐욕 배치 끝
    return groups <= limit; // 필요한 그룹 수가 제한 이내인지 반환
} // 판정 함수 끝
int main(void) { // 실행 시작점
    long long low = 0, high = 0; // 정답이 포함될 용량의 양 끝
    scanf("%d %d", &n, &limit); // 작업 수와 허용 그룹 수 읽기
    for (int i = 0; i < n; ++i) { // 각 작업량 입력과 탐색 경계 계산
        scanf("%d", &values[i]); // 이번 작업량 읽기
        if (values[i] > low) low = values[i]; // 가장 큰 작업보다 용량이 작을 수 없음
        high += values[i]; // 전부 한 그룹에 담을 용량 계산
    } // 초기 탐색 범위 완성
    while (low < high) { // 가능한 최소 용량이 하나로 좁혀질 때까지 반복
        long long middle = low + (high - low) / 2; // 넘침을 피한 중간 용량
        if (feasible(middle)) high = middle; // 가능한 용량이면 더 작은 쪽도 탐색
        else low = middle + 1; // 불가능한 용량과 그 아래를 제외
    } // 최소 가능한 용량 확정
    printf("%lld\n", low); // 최소 용량 출력
    return 0; // 정상 종료
} // 매개변수 탐색 예제 끝
```

### C++ 예제

[실행 가능한 C++ 파일](<예제_examples/11-이진탐색과매개변수탐색_binary-parametric-search/example.cpp>)

```cpp
#include <iostream> // 표준 입력과 출력
#include <vector> // 작업량 배열
using namespace std; // 표준 이름의 접두사 생략
int main() { // 실행 시작점
    int n, limit; cin >> n >> limit; // 작업 수와 허용 그룹 수 읽기
    vector<int> values(n); // 작업 순서를 보관할 배열
    long long low = 0, high = 0; // 최소 작업 용량과 전체 작업 합
    for (int& value : values) { // 각 작업량으로 탐색 범위 계산
        cin >> value; // 작업량 입력
        if (value > low) low = value; // 가장 큰 작업량을 하한으로 유지
        high += value; // 전부 합친 안전한 상한 계산
    } // 탐색 경계 완성
    auto feasible = [&](long long capacity) { // 작업 배열과 그룹 제한을 캡처한 판정 함수
        int groups = 1; long long current = 0; // 사용 그룹 수와 현재 그룹 합
        for (int value : values) { // 원래 순서대로 작업 배치
            if (value > capacity) return false; // 단일 작업도 못 담으면 거절
            if (current + value > capacity) { // 현재 그룹의 용량을 넘는 경우
                ++groups; // 새 연속 그룹 열기
                current = value; // 새 그룹을 이번 작업으로 시작
            } else current += value; // 용량 이내면 현재 그룹에 추가
        } // 탐욕 배치 끝
        return groups <= limit; // 그룹 수 제한 만족 여부
    }; // 판정 람다 정의 끝
    while (low < high) { // 최소 가능한 용량의 구간 축소
        long long middle = low + (high - low) / 2; // 중간 용량 계산
        if (feasible(middle)) high = middle; // 가능하면 이 용량을 포함해 왼쪽 탐색
        else low = middle + 1; // 불가능하면 더 큰 용량만 남기기
    } // 한 용량으로 수렴
    cout << low << '\n'; // 최소 용량 출력
    return 0; // 정상 종료
} // 매개변수 탐색 예제 끝
```

### Python 예제

[실행 가능한 Python 파일](<예제_examples/11-이진탐색과매개변수탐색_binary-parametric-search/example.py>)

```python
import sys # 정수 토큰 입력
data = list(map(int, sys.stdin.buffer.read().split())) # 입력을 정수로 변환
n, limit = data[:2] # 작업 수와 허용 그룹 수
values = data[2:] # 순서를 유지할 작업량 배열
def feasible(capacity): # 정해진 용량의 가능 여부 판정
    groups, current = 1, 0 # 첫 그룹과 현재 그룹 합
    for value in values: # 작업을 원래 순서대로 배치
        if value > capacity: # 단일 작업도 담기지 않는 경우
            return False # 이 용량은 불가능
        if current + value > capacity: # 현재 그룹에 추가하면 용량 초과
            groups += 1 # 새 연속 그룹 열기
            current = value # 새 그룹에 이번 작업 배치
        else: # 현재 그룹에 여유가 있는 경우
            current += value # 이번 작업량 누적
    return groups <= limit # 허용 그룹 수 이내인지 반환
low, high = max(values), sum(values) # 가장 큰 작업과 전체 합을 탐색 경계로 설정
while low < high: # 최소 가능한 용량이 하나 남을 때까지 반복
    middle = low + (high - low) // 2 # 정수 중간 용량
    if feasible(middle): # 해당 용량으로 작업을 나눌 수 있는 경우
        high = middle # 더 작은 정답 가능성 유지
    else: # 그룹 수 제한을 넘는 경우
        low = middle + 1 # 불가능한 용량을 제외
print(low) # 최소 가능한 용량 출력
```
