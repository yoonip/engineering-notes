# 조합 계산·포함 배제·생성함수

[학습목차](README.md) · [연습문제](연습문제_problem-index.md)

## 핵심 원리와 중요성

경우의 수 문제에서는 “같은 결과”의 정의와 중복 집계 여부를 먼저 정합니다.
순서가 있는 선택, 순서 없는 선택, 서로 구별되는 물건은 서로 다른 수를 만듭니다.
직접 나열하기 어려워지면 마지막 선택의 DP, 집합의 포함 배제, 계수 계산으로 표현을 바꿉니다.
생성함수는 수열의 각 값을 다항식·형식적 멱급수의 계수에 넣어 계산하는 도구입니다.
함수의 실제 수렴값을 구하지 않아도 유한 차수의 계수 연산은 정의할 수 있습니다. [Princeton 생성함수 교재](https://aofa.cs.princeton.edu/30gf/)

## 순열과 조합

서로 다른 n개 중 k개를 순서 있게 고르는 수는 n(n−1)…(n−k+1)입니다.
순서 없는 집합을 고르면 각 집합을 k!번 세었으므로 C(n,k)=n!/(k!(n−k)!)입니다.
직접 구성한 네 사람 A,B,C,D 중 두 사람의 순서 없는 조는 6개입니다.
AB와 BA를 서로 다른 결과로 세면 12개이므로 출력 대상의 정의를 구분합니다.
파스칼 점화 C(n,k)=C(n−1,k−1)+C(n−1,k)는 특정 한 사람을 고르는지로 나눈 결과입니다.
n≤N 전체 표는 O(N²) 시간·공간이며, 한 행만 필요하면 O(N) 공간으로 갱신합니다.

소수 p와 N<p인 조건에서 팩토리얼·역팩토리얼을 전처리하면 C(n,k)를 O(1)에 질의합니다.
전처리는 O(N+log p) 모듈러 연산과 O(N) 공간입니다.
N≥p이면 n! mod p가 0일 수 있어 같은 역원 공식을 그대로 적용하지 않습니다.
정수 답을 구한 뒤 나누는 것과 모듈러에서 역원을 곱하는 것은 조건이 다릅니다. [모듈러 역원의 공식 조건](https://atcoder.github.io/ac-library/production/document_en/math.html)

## 포함 배제와 직접 구성한 집계

조건 A 또는 B를 만족하는 개수는 |A|+|B|−|A∩B|입니다.
1부터 12 중 2 또는 3의 배수는 6+4−2=8개입니다.
6과 12는 두 조건에 들어가 두 번 더했으므로 한 번 뺍니다.
k개 조건에서는 비어 있지 않은 조건 부분집합 S마다 (−1)^(|S|+1)|∩S|를 더합니다.
어떤 원소가 정확히 t개 조건을 만족하면 그 원소의 계수는 Σ(j=1..t)(−1)^(j+1)C(t,j)=1입니다.
조건을 하나도 만족하지 않으면 항이 없으므로 0입니다.
교집합 계산이 O(C)일 때 직접 포함 배제는 O(2^k C) 시간입니다.
조건 수가 크면 이 식을 나열하는 대신 DP·변환·대칭성 등 다른 구조가 필요합니다. [MIT 포함 배제 강의](https://ocw.mit.edu/courses/18-200-principles-of-discrete-applied-mathematics-spring-2024/video_galleries/lecture-videos/)

## 보통 생성함수: 크기별 개수의 계수

A(z)=Σa_i z^i에서 a_i는 크기 i인 선택의 개수입니다.
서로 독립인 두 종류의 선택을 합치면 전체 크기는 더해지므로 계수는 합성곱이 됩니다.
[z^k]A(z)B(z)=Σ(i=0..k)a_i b_(k-i)입니다.
직접 구성한 빨간 공은 최대 2개, 파란 공은 최대 1개이며 같은 색 공은 구별하지 않습니다.
선택 다항식은 (1+z+z²)(1+z)=1+2z+2z²+z³입니다.
공 두 개를 고르는 결과는 빨강 2개 또는 빨강 1개·파랑 1개의 2가지입니다.
계수 곱은 “빨강에서 i개, 파랑에서 2−i개”라는 중복 없는 분할과 같습니다.
양의 정수 무게 w에서 물건을 한 번만 고르는 선택은 (1+z^w), 무제한 개수는 1/(1−z^w)로 표현합니다.
무게 0을 무제한으로 고르면 같은 크기의 선택이 무한히 많아지므로 이 유한 계수 표현을 적용하지 않습니다.
각 인수를 차례로 곱하는 것은 [배낭 DP](17-배낭수열구간확률DP_dp-variants.md)의 다른 표현입니다.

## 지수 생성함수: 구별되는 표지의 배분

지수 생성함수는 A(z)=Σa_i z^i/i!처럼 크기 i의 계수를 i!로 나눠 보관합니다.
두 클래스를 곱하고 k!를 곱해 계수를 복원하면 C(k,i)가 생깁니다.
이는 구별되는 k개 표지 중 어느 i개를 첫 클래스에 줄지 선택하는 수입니다.
직접 구성한 구별되는 공 2개를 빨간 상자에 최대 2개, 파란 상자에 최대 1개 넣는다고 정합니다.
각 상자 안에서는 순서를 구별하지 않으므로 EGF는 (1+z+z²/2)(1+z)입니다.
z²의 계수는 3/2이고 2!를 곱하면 3입니다.
두 공 모두 빨간 상자에 넣는 1가지와, 파란 상자에 갈 공을 고르는 2가지에 대응합니다.
보통 생성함수 예제의 같은 색 공 개수 선택과 대상의 구별 기준이 다릅니다. [Sedgewick·Flajolet의 지수 생성함수 설명](https://aofa.cs.princeton.edu/30gf/)

## 계수 계산의 절차와 복잡도

1. 객체의 크기와 같은 결과의 기준을 정합니다.
2. 선택을 중복 없이 나누거나 독립인 부분으로 곱합니다.
3. 필요한 최대 차수 K와 계수의 정수·확률·모듈러 의미를 정합니다.
4. 작은 나열과 처음 몇 계수를 비교합니다.
5. 다항식 크기에 맞춰 단순 곱셈이나 빠른 합성곱을 선택합니다.

두 길이 n,m 다항식의 직접 곱셈은 O(nm) 시간과 O(n+m) 결과 공간입니다.
FFT·NTT는 적절한 연산 모델에서 길이 L의 합성곱을 O(L log L)로 계산합니다.
NTT에는 모듈러와 변환 길이에 맞는 단위근 조건이 필요합니다.
ACL의 모듈러 합성곱은 소수 p와 필요한 2의 거듭제곱 길이가 p−1을 나누는 제약을 명시합니다. [ACL 합성곱 공식 문서](https://atcoder.github.io/ac-library/production/document_en/convolution.html)
고정된 목표 차수만 필요하면 매 곱셈 뒤 높은 차수를 버릴 수 있지만, 순환 합성곱으로 낮은 차수에 섞이지 않게 변환 길이를 정합니다.

## 실수와 현업 연결

서로 배타적이지 않은 경우를 단순히 더하면 중복을 세고, 서로 의존하는 경우를 곱하면 불가능한 조합을 포함합니다.
음수 가중치가 있으면 높은 차수가 다시 낮아질 수 있어 일반적인 양의 무게 절단 논리를 적용하지 않습니다.
C·C++에서는 계수 곱을 모듈러 전에 넓은 자료형에서 계산합니다.
Python의 정수는 커질 수 있지만 정확한 큰 계수의 곱셈 비용과 메모리는 상수가 아닙니다.
독립한 이산 확률 분포의 합은 합성곱과 연결되며, 상관된 사건에는 독립 곱을 그대로 사용하지 않습니다.
재고 선택과 자원 배분을 수식화할 수 있지만, 현실의 묶음 할인·호환 제약은 추가 인수나 상태가 필요합니다.
[정수론](30-정수론과모듈러연산_number-theory.md), [확률 DP](17-배낭수열구간확률DP_dp-variants.md), [선형 점화](32-행렬거듭제곱과선형점화_matrix-recurrence.md)와 연결합니다.

## 복습 질문과 답

- 질문: 포함 배제에서 교집합을 빼는 이유는 무엇입니까? 답: 여러 조건에 들어간 같은 객체를 최종적으로 한 번만 세기 위해 계수를 조절합니다.
- 질문: EGF 계수에 왜 k!를 다시 곱합니까? 답: 계수에 크기별 팩토리얼을 나눠 저장했으며, 곱셈에서 표지 배분의 이항계수를 만들기 위한 표현이기 때문입니다.
- 질문: 큰 소수로 나머지를 취하면 모든 N의 팩토리얼 역원이 있습니까? 답: N이 소수 이상이면 팩토리얼에 소수 인수가 들어가 역원이 없을 수 있습니다.
