직무의 범위는 제품·회로·코드·공정·검사·운영의 대상과 결과물로 설명합니다. 기술 원리와 활용은 각 본문에 연결한 표준기관·장비사·언어·프레임워크의 공식 문서에 근거합니다. 공개 직무자료는 업무 영역을 살피는 참고문헌으로 사용했으며, 자체 계산과 진단 상황은 실제 측정·운영 기록과 구분합니다.

## 4. 업무 사례의 공개 코드

[업무 사례](사례_cases/README.md)의 코드는 Tektronix·ADI의 제조사 자료와 Zephyr·cocotb·U-Boot·fio·PyEpics·SciPy·scikit-learn·PostgreSQL의 공개 원문을 사용했습니다. 고정 commit·원본 파일·구간·라이선스와 주석·발췌의 변경 범위는 [코드 출처 문서](사례_cases/코드출처와이용조건_CODE_SOURCES.md)와 각 코드 위에서 확인합니다.

업무 상황과 원인 분리 절차는 공개 기술의 입출력·관측·판정을 연결한 자체 설명입니다. NIST 공개 자료의 재계산과 scikit-learn 공식 예제의 로컬 실행은 실제 반도체 제품의 측정·수율 결과와 구분했습니다. 장비·보드·RTL 시뮬레이터·DB 서버의 실행 여부도 각 본문에 적었습니다. 초기 비트 연산 설명 코드의 자체 작성 표시는 [언어 사용 위치](10-C와Python이쓰이는위치_languages-in-the-workflow.md)에 남겼습니다.

검토 기준일은 2026-10-26입니다. 도구·표준을 사용할 때에는 적용하려는 판본의 조건을 함께 확인합니다.
