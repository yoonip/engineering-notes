## 2. 회로·하드웨어·통신의 연결

### 전원에서 시작해 신호로 갑니다

전원은 부품이 요구하는 전압·전류를 공급하는 경로입니다. 부하가 바뀌면 배선·부품·제어기의 응답 때문에 순간적인 전압 변화가 생길 수 있습니다. 정상 상태의 평균 전압, 부하 변화 때의 과도 응답, 고주파 리플은 다른 관측량입니다.

신호는 그 전원을 사용하는 소자 사이에서 정보를 전달합니다. 상승 시간이 짧아지고 배선이 길어지면 배선을 단순한 이상적 전선으로 보기 어렵습니다. 반사·손실·누화·기준면과 종단을 다루는 SI, 전원·접지망의 품질을 다루는 PI가 함께 필요합니다. 같은 파형 문제라도 제품·치구·프로브의 영향을 나눕니다.

| 공부 순서 | 핵심 개념 | 설명할 수 있어야 할 결과 |
| --- | --- | --- |
| 회로 기초 | 전압·전류·KCL/KVL·RLC·시정수·주파수 응답입니다. | 회로도에서 전류 경로와 부하 변화에 따른 예상 응답을 그립니다. |
| 전자회로 | 다이오드·MOSFET·증폭·피드백·바이어스입니다. | 스위치와 증폭기로 쓸 때 다른 동작 영역과 전력·열을 설명합니다. |
| 디지털·혼성신호 | 논리·클록·setup/hold·ADC/DAC입니다. | 샘플링·분해능·지연·노이즈가 기능에 미치는 영향을 설명합니다. |
| PCB·SI/PI | 배선·리턴 경로·임피던스·종단·PDN입니다. | 전원·신호 문제에 필요한 파형과 기준면을 정합니다. |
| RF·통신 | 변조·대역폭·SNR·EVM·BER·S파라미터입니다. | 송신 파형의 품질과 수신 오류율을 구분하고 시험 조건을 적습니다. |
| 열·기구 | 열 경로·열저항·변형·진동·조립 공차입니다. | 온도와 접촉·정렬·재료 특성이 함께 바뀌는 경로를 설명합니다. |

연결 자료는 [회로](../전자컴퓨터공학_ece/09-회로전자공학_circuits-electronics/README.md), [PCB](../전자컴퓨터공학_ece/12-PCB하드웨어설계_pcb-hardware/README.md), [전자기학·RF](../전자컴퓨터공학_ece/29-전자기학-RF_electromagnetics-rf/README.md), [통신 이론](../전자컴퓨터공학_ece/30-통신이론무선시스템_communications-wireless/README.md)입니다. 실제 검사 항목은 [제품 회로·시스템 검사](04-제품회로와시스템검사_product-circuit-system-tests.md)에서 이어집니다.

## 4. 반도체 공정·소자·메모리의 연결

도핑은 반도체의 운반자 특성을 조절하고, 게이트는 절연막을 사이에 두고 채널을 제어합니다. 공정은 이런 구조를 실제 재료와 치수로 만들며, 접촉·배선은 전류와 정보를 다음 구조로 전달합니다. 따라서 물리 원리와 제조 순서가 함께 필요합니다.

1. [소자와 공정의 기초](../반도체제조공정_semiconductor-fabrication/00-소자와공정의기초_devices-process-basics.md)에서 전자·정공·도핑·접합·MOSFET을 읽습니다.
2. [공정별 단면](../반도체제조공정_semiconductor-fabrication/11-단면으로보는공정흐름_cross-section-atlas.md)에서 늘거나 줄어드는 재료와 후속 접속을 확인합니다.
3. [제품별 공정 비교](../반도체제조공정_semiconductor-fabrication/10-로직과메모리의공정차이_logic-memory-integration.md)에서 게이트·커패시터·수직 채널·TSV가 다른 구조임을 구분합니다.
4. [공정·설비 검사](07-공정설비와패키지의검사_process-equipment-package-tests.md)에서 조절 변수와 계측·분포를 연결합니다.
5. [메모리 제품·테스트 개발](08-메모리제품과테스트개발_memory-product-test-engineering.md)에서 제품 동작·시험 프로그램·불량 분석으로 이어갑니다.

| 개념 묶음 | 업무에서 연결할 내용 |
| --- | --- |
| 재료·화학 | 표면 상태·반응·오염·확산·계면이 성장·식각·접합에 미치는 영향입니다. |
| 공정 통합 | 한 단계의 성공이 다음 단계의 노출 재료·치수·열 이력과 맞는지입니다. |
| 계측·통계 | 측정 오차와 실제 공정 변동, 상관과 원인, 관리 한계와 규격의 차이입니다. |
| 메모리 구조 | 저장과 접근, 휘발성·비휘발성, 유지·읽기·쓰기·수리·오류정정의 관계입니다. |
| 설비 | 기계·전기·제어·진공·가스·열·통신이 공정 상태를 만드는 경로입니다. |
| 패키징 | 접속·재료·휨·열·박막 다이 취급과 검사 접근의 관계입니다. |

## 5. AI·데이터·제조 IT의 연결

데이터를 많이 모았다고 바로 원인을 알 수 있는 것은 아닙니다. 어느 제품·장비·시각·공정 단계의 기록인지 맞추고, 학습 시점에 미래 결과가 섞이지 않았는지 확인해야 합니다. 설비 경보와 고장을 같은 사건으로 취급하는 것도 피해야 합니다.

| 순서 | 학습할 개념 | 결과물 |
| --- | --- | --- |
| 데이터 표현 | 타입·단위·키·시간·결측·중복입니다. | 원본 행과 집계 행의 대응표입니다. |
| 저장·전달 | SQL·트랜잭션·파이프라인·스키마·권한입니다. | 데이터 흐름과 실패·재처리 계약입니다. |
| 통계·모델 | 분할·기저율·오탐·미탐·회귀·검증입니다. | 실제 사용 기간을 분리한 평가 계획입니다. |
| AI 서비스 | 검색·모델·프롬프트·도구·지연·추적입니다. | 답변 품질과 도구 실행 성공을 나눈 평가표입니다. |
| 운영·보안 | 모니터링·접근 제어·롤백·변경 관리입니다. | 새 판본의 적용 범위와 되돌릴 조건입니다. |

기초는 [데이터 공학](../전자컴퓨터공학_ece/40-데이터베이스데이터공학_databases-data-engineering/README.md), [AI·머신러닝](../전자컴퓨터공학_ece/23-AI머신러닝_ai-machine-learning/README.md), [AI 서비스 평가](../전자컴퓨터공학_ece/46-AI응용에이전트평가_ai-agents-evaluation/README.md)이며, 실제 데이터 흐름과 업무의 연결은 [AI·데이터·제조 IT](09-AI데이터와제조IT_ai-data-manufacturing-it.md)에 있습니다.

## 6. 생산관리·구매·영업·재무·인프라도 함께 읽습니다

제품과 제조 현장에서는 설계·개발뿐 아니라 계획·조달·품질·영업·시설 운영이 함께 연결됩니다. 아래 개념은 기술 데이터가 운영 판단으로 바뀌는 접점을 설명합니다.

| 개념 | 뜻 | 제품·현장과의 연결 |
| --- | --- | --- |
| 수요·생산 계획 | 예상 수요를 생산·조달 시점과 물량으로 옮기는 일입니다. | 주문 변동·공정 리드타임·검사·설비 능력이 납기를 바꿉니다. |
| 리드타임·병목 | 작업이 끝날 때까지의 시간과 처리량을 제한하는 구간입니다. | 가장 느린 공정, 대기·셋업·재작업을 구분해야 합니다. |
| 재고·재공품 | 보유 자재·완제품과 공정 중인 제품입니다. | 부족·과잉과 체류 시간, 제품 판본·유효 기간을 함께 봅니다. |
| 공급사 품질 | 구매한 부품·재료가 필요한 특성과 일관성을 갖는지 관리하는 일입니다. | 입고 시험·공정 변화·대체품 승인과 제품 신뢰성을 연결합니다. |
| 총비용 | 구매 단가뿐 아니라 운영·유지·불량·정지·교체에 드는 비용입니다. | 싼 부품이나 장비가 전체 제품 비용도 낮춘다는 결론은 별도 계산이 필요합니다. |
| 시장·고객 요구 | 고객이 실제로 해결할 문제와 구매 조건입니다. | 규격·성능·가격·납기·서비스가 기술 사양과 연결됩니다. |
| 원가·투자 | 제품과 설비에 투입한 자원을 일정 기준으로 계산합니다. | 처리량·수율·가동·감가·에너지와 계산 범위를 함께 봅니다. |
| 인프라 계통 | 전기·물·가스·공조 등 생산을 지탱하는 공급망입니다. | 공급 품질·용량·감시·이중화·정비가 공정의 안정성과 연결됩니다. |
| 환경·안전 | 물질·설비·작업의 위험과 배출·노출을 관리합니다. | 센서·계측의 값과 실제 위험 경로, 운영·점검 기록을 함께 봅니다. |

예를 들어 장비의 처리량이 빨라도 정비 시간이 길거나 불량·재작업이 많으면 양품 출하량은 기대와 달라질 수 있습니다. 구매 담당자가 장비 단가만 보고, 생산 담당자가 평균 처리량만 보고, 품질 담당자가 출하 불량만 따로 보면 같은 문제의 연결이 끊깁니다. 제품·기간·비용 범위와 측정한 지표를 맞추는 일이 공통 기반입니다.

## 7. 학습을 설명 가능한 결과로 바꾸는 순서

1. 한 직무를 골라 담당 대상과 실패 현상 하나를 정합니다.
2. 그 현상을 설명할 블록도·단면·데이터 흐름을 그립니다.
3. 입력·관측량·단위·조건·기대 동작을 적습니다.
4. 경쟁 원인 두 가지 이상을 나눌 대조를 설계합니다.
5. 사용할 언어가 그 대조의 어느 부분을 실행하는지 설명합니다.
6. 실제 실행·문헌 검토·가정 계산을 나누어 결과를 남깁니다.

과목별 강의는 [전기·전자·통신 과목](../학습사이트와채널_learning-resources/전기전자통신과목_ece-courses.md)과 [학습 사이트 목차](../학습사이트와채널_learning-resources/README.md)에서 찾으실 수 있습니다. 각 경로에서 관측 대상·기대 동작·실패 원인·확인 방법을 구체적으로 설명하는 데 필요한 기초를 골라 공부합니다.

## English

The study paths connect mathematics, circuits, firmware, chip design, fabrication, test, AI, data and production operations to concrete work products. They are educational dependencies rather than additional hiring requirements. Each path ends with an observable quantity, a failure hypothesis, a discriminating check and a record of what was actually done.
