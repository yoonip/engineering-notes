# Web · API · Applications

[전체 목차](../../CATALOG.md) · [처음으로](../../README.md)

웹 애플리케이션은 브라우저·서버·데이터 저장소를 연결한다. 실험 결과 조회, 장치 제어, 모델 추론, 기술 문서 검색도 웹 인터페이스로 제공할 수 있다.

## 통신과 데이터

HTTP는 요청·응답 방식의 프로토콜이다. REST는 자원과 표준적인 인터페이스를 중심으로 하는 설계 스타일이고 WebSocket은 양방향 통신 연결을 제공한다. 인증·권한·입력 검증·오류 형식은 API 계약의 일부다. 오래 걸리는 작업은 요청 처리와 작업 실행을 나누기도 한다.

## 화면과 서버

FastAPI·Flask·Django·Spring·Node.js 생태계는 서버 구성에, React·Vue·Svelte·TypeScript는 웹 UI에 쓰인다. Qt·PySide·Electron은 데스크톱 애플리케이션, Streamlit·Gradio는 데이터·모델 인터페이스 구성에 자주 쓰인다. Framework 선택보다 사용자의 작업과 데이터 흐름이 구조를 정한다.

장치 제어에서는 화면에 명령을 보낸 시점과 장치가 실제 수행한 시점이 다를 수 있다. 명령 ID·진행 상태·timeout·중복 처리 방식이 필요하다. 대시보드의 시간축·단위·집계 기준은 그래프를 읽는 의미를 바꾼다.
