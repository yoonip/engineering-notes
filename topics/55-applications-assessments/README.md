# 지원 · 시험 · 면접

[전체 목차](../../CATALOG.md) · [처음으로](../../README.md)

대학·연구실·기업 지원은 관심 분야와 경험을 문서와 평가 과정으로 전달하는 일이다. 이력서·CV·자기소개서·포트폴리오는 서로 다른 길이와 형식으로 같은 경험을 설명한다. 국민대학교와 각 기업의 지원·전형 경험도 이 범위에서 다룬다.

## 문서와 기술 자료

이력서는 경력과 역량의 핵심을 요약하고, CV는 학력·연구·활동을 더 자세히 담는다. 자기소개서는 선택의 이유와 경험의 맥락을, 포트폴리오는 구현물과 결과를 보여준다. 기술 프로젝트에서는 문제·역할·설계 선택·코드·결과가 연결되어야 경험의 내용을 파악할 수 있다.

## 전형의 유형

코딩테스트는 알고리즘 구현, 직무시험은 분야 지식과 문제 해결, 과제 전형은 일정 범위의 산출물, 기술면접은 판단과 설명 과정을 다룬다. 인적성·역량검사·AI 기반 평가는 기관과 전형에 따라 방식이 다르다. 프로그래머스 등 공개 문제의 풀이는 [알고리즘](../08-problem-solving/README.md)에서 볼 수 있다.
