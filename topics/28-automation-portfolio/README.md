# 자동화와 기술 기록

[전체 목차](../../CATALOG.md) · [처음으로](../../README.md)

자동화는 반복 작업을 같은 입력과 규칙으로 실행하게 만드는 일이다. 데이터 수집·정리·실험 실행·그래프 생성·문서 빌드가 하나의 흐름으로 연결되면 결과가 만들어진 과정을 추적하기 쉽다.

## 스크립트와 CI

Python은 데이터 처리와 라이브러리 연결, Bash는 Linux 명령 조합, PowerShell은 Windows와 구조화된 시스템 작업에 쓰인다. 스크립트는 입력·출력·종료 코드·로그를 통해 다른 작업과 연결된다. GitHub Actions·GitLab CI는 저장소 변경이나 예약된 이벤트에 따라 작업을 실행한다.

## 문서 생성 도구

Quarto는 Markdown·Jupyter 기반의 글·수식·그래프를 웹 문서로 만들고, Jekyll·Hugo는 정적 사이트를 생성한다. MkDocs·Sphinx는 기술 문서, Doxygen은 코드 API 문서, Jupyter Book은 계산 문서 묶음에 사용된다.

GitHub Pages는 생성된 정적 파일을 서비스한다. Python 계산이나 모델 추론이 필요하면 로컬 또는 CI에서 실행해 결과를 만들거나 별도 서버와 연결한다. 글의 원본과 생성된 HTML, 실험 데이터·로그·환경 정보는 서로 다른 산출물이다.
