# 새로운 소자와 컴퓨팅

[전체 목차](../../CATALOG.md) · [처음으로](../../README.md)

새로운 컴퓨팅 구조는 기존 시스템의 데이터 이동·전력·연결·물리 구현 한계를 다른 방식으로 다루려는 연구와 연결된다. 서로 다른 분야의 성능 수치를 비교하려면 무엇을 계산했고 어느 범위의 비용을 포함했는지 확인해야 한다.

## Neuromorphic와 메모리 연산

Spiking neural network는 event와 시간에 따른 상태 변화를 사용한다. Event camera는 밝기 변화 사건을 비동기적으로 출력한다. Compute-in-memory는 저장 위치 가까이에서 연산해 이동 비용을 줄이려는 접근이며 memristive 소자·디지털 회로 등 여러 구현이 있다. 소자 편차·정밀도·변환 회로의 비용이 전체 시스템 결과와 연결된다.

## 빛, 양자, 생체 인터페이스

Photonic computing은 빛의 전파·간섭 등을 연산과 통신에 이용한다. Quantum computing은 qubit의 상태와 연산·측정에 기반하며 특정 알고리즘과 오류 조건에서 계산적 이점을 논의한다. Bioelectronics·웨어러블·유연 전자소자는 생체 신호·재료·구동 조건·장시간 안정성의 접점에 있다.

소자의 동작 원리, 회로의 기능, 시스템의 유효 성능은 다른 수준의 주장이다. 논문의 비교 조건과 실제 입출력·보정·주변 회로까지 연결하면 기술의 위치를 구체적으로 이해할 수 있다.
