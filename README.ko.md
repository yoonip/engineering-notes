## 무엇부터 하면 되는가
1. 이 저장소 하나를 만들고 파일과 폴더 전체를 한 번에 올립니다.
2. 관심 분야의 README를 열고 작은 실습 한 가지를 고릅니다.
3. 개념·설치·코드·검증·결과·한계를 함께 기록합니다.
4. 규모가 커진 프로젝트는 별도 저장소로 분리하고 링크합니다.
5. 대표 프로젝트와 자기소개는 영어로도 읽을 수 있게 만듭니다.
