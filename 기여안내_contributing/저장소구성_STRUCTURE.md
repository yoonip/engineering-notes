# 문서와 코드 구성 | Repository structure

학습 분야와 분석 글은 주제에 맞는 독립된 경로에 있습니다. 도구 설명, 작성자 이력, 출처, 기여자 안내는 학습 본문과 구분합니다.

| --- | --- |

| 언어이해와추리논증_reading-reasoning/ | 언어이해와 추리논증의 두 학습 축, 자료해석·학습 방법·공식 시험 자료 |
| 외국어와기술영어_foreign-languages/ | 영어·제2외국어와 기술 문서 읽기·번역 |
| 인문사회_humanities/ | 철학·경제·사회·법·역사·음악·문학·예술·미술 |

표의 경로는 저장소 루트를 기준으로 합니다. 학습을 시작하실 때에는 [첫 화면](../README.md)이나 [분야별 목차](../분야별목차_CATALOG.md)를 이용하시면 됩니다.

## English

The root navigation separates technical learning, reading and argument reasoning, foreign languages, humanities, paper studies, technology analysis and product reviews. Official model descriptions belong in `models`; constructed evaluations and calculations belong in `experiments`. Instruments and measurement methods, engineering fault cases, research, author information, tools, figure assets, references and contributor material have dedicated locations. JSON retains machine-readable paths while Markdown provides readable indexes.
