# 실제 BCI 장치: 신경 신호를 컴퓨터 명령으로 바꾸는 세 가지 접근 / BCI devices and neural control

기준일: 2026년 10월 20일. 임상시험 등록, FDA 문서와 연구 원저를 검토한 기술 리뷰입니다. 이식 장치를 사용하거나 임상 효과를 재시험하지 않았습니다. 특정인의 치료 선택이나 수술 방법을 안내하는 글이 아닙니다.

## 읽어 내는 것은 무엇입니까?

BCI는 뇌 신호를 컴퓨터와 같은 외부 장치의 입력으로 바꾸는 뇌–컴퓨터 인터페이스입니다. 사용자가 손을 움직이려 할 때 나타나는 신경 활동을 학습해 커서 이동이나 선택 명령으로 바꾸는 예가 있습니다. 기록한 전기 신호가 머릿속 모든 생각의 문장과 일대일로 대응하는 것은 아닙니다.

전극의 위치에 따라 얻는 신호와 제약이 달라집니다. 뇌 조직 안의 미세 전극은 가까운 신경 활동을 세밀하게 기록할 수 있지만 장기 조직 반응과 신호 변화 등을 고려해야 합니다. 뇌 표면 전극은 여러 신경 집단의 활동을 기록합니다. 혈관 안의 전극은 혈관을 통해 주변 뇌 활동을 기록하는 접근입니다. 어느 하나가 모든 사람과 모든 과제에서 우월하다는 결론은 임상 자료 없이 낼 수 없습니다.

두피 EEG는 수술 없이 뇌의 전기 활동을 측정하는 다른 방식입니다. 피부와 두개골을 거쳐 약해지고 섞인 신호를 읽으므로 눈·근육 움직임의 잡음도 구별해야 합니다. 이식형 장치의 커서 제어 결과를 두피 장치의 성능으로 옮기거나, 반대로 EEG 기기의 소비자 판매를 이식형 BCI의 판매 허가로 읽으면 안 됩니다.

## 현재 장치와 허가 범위

| 장치 | 확인한 상태 | 그 상태가 뜻하지 않는 것 |
| --- | --- | --- |
| Neuralink N1·R1 | PRIME의 초기 안전성과 장치 기능을 평가하는 임상시험 대상입니다. | 일반 소비자에게 판매 승인된 범용 생각 읽기 기기라는 뜻은 아닙니다. |
| Synchron Stentrode | COMMAND에서 디지털 장치 제어의 안전성과 실행 가능성을 평가합니다. | 임상시험 허가가 모든 마비 환자의 치료 효과 승인인 것은 아닙니다. |
| Precision Layer 7-T | FDA K242618의 피질 전극으로 2025년 3월 30일 510(k) 결정을 받았습니다. | 장기 무선 통신 BCI 전체의 판매 승인은 아닙니다. |

근거는 [PRIME 등록 NCT06429735](https://clinicaltrials.gov/study/NCT06429735), [COMMAND 등록 NCT05035823](https://clinicaltrials.gov/study/NCT05035823), [FDA의 Layer 7-T 허가 문서](https://www.accessdata.fda.gov/cdrh_docs/pdf24/K242618.pdf)입니다. 동적 등록 페이지는 공개 API 기록도 확인했습니다. 등록은 회사가 제출한 연구 정보를 담으며, 등록 자체가 결과의 검증은 아닙니다.

PRIME 기록의 마지막 게시 갱신은 2026년 1월 9일이며 모집 중으로 표시됩니다. COMMAND는 9월 8일 갱신에서 모집을 마친 진행 중 시험으로 표시되고 실제 등록 인원은 6명입니다. 최초 등록 뒤 시간이 지났거나 예상 종료일이 지났다는 이유만으로 연구 결과가 모두 공개됐다고 추정하지 않습니다.

Layer 7-T의 공식 용도는 30일 미만의 일시적 뇌 표면 전기 신호 기록·감시·자극입니다. 문서는 이 전극이 무선 기능과 소프트웨어를 갖지 않은 수동 장치이며 MRI 호환이 아니라고 명시합니다. 따라서 ‘FDA가 영구 이식 생각 입력 장치를 승인했습니다’라는 제목은 이 허가 범위를 넓힌 표현입니다. 510(k)는 정해진 용도에서 기존 합법 장치와의 실질적 동등성을 판단하는 절차입니다.

## 신호가 명령이 되는 과정

전극이 기록한 전압에서 잡음을 줄이고, 일정 시간 구간의 특징을 추출합니다. 특징은 발화 빈도나 주파수 대역의 세기처럼 원신호의 유용한 요약입니다. 디코더는 이 특징과 의도한 움직임 사이의 관계를 학습한 변환입니다. 이후 커서나 선택기 같은 사용자 인터페이스에 연결합니다.

사용자는 화면 피드백을 보며 신호를 조절하고, 시스템도 신호 변화를 반영할 수 있습니다. 이런 닫힌 고리를 폐루프라고 합니다. 어제 학습한 디코더가 오늘도 같은 정확도를 낸다는 보장은 없습니다. 전극 접촉과 사용자의 상태가 달라져 신호 분포가 바뀔 수 있기 때문입니다. 재교정 시간과 일상 사용 중 끊기는 시간은 최고 속도만큼 중요한 지표입니다.

자체 계산 예로 신호 특징 두 개가 2와 1이고 디코더 가중치가 0.5와 −0.2라면 출력은 0.8입니다. 이를 커서의 한 방향 속도로 연결할 수 있습니다. 실제 뇌의 뜻이 원래부터 0.8이었다는 말이 아니라, 학습한 규칙이 관측 신호를 명령으로 변환한 것입니다. 실제 장치는 훨씬 많은 신호와 시간 정보를 사용합니다.

## 교정부터 선택 완료까지 시간을 따라가 봅니다

교정은 사용자가 특정 움직임을 시도한 구간과 쉬는 구간을 기록해 신호와 목표의 관계를 맞추는 과정입니다. 전극 신호를 특징으로 줄이고, 교정 자료로 변환 규칙을 정한 뒤, 새 구간의 신호에서 명령을 추정합니다. 화면의 반응을 본 사용자가 다음 시도를 바꾸면 사람과 기계가 함께 적응하는 고리가 됩니다. 교정 때의 정답 표식과 일상에서 알아내려는 의도를 같은 입력으로 취급하지 않아야 합니다.

자체 예로 서로 겹치지 않는 200ms 구간마다 선택 여부를 판단하고 세 구간 연속 양성일 때만 클릭한다고 놓겠습니다. 첫 구간 시작부터 최소 600ms의 관측이 필요합니다. 각 구간의 잘못된 양성 확률이 10%이고 독립이라면, 정해진 세 구간 묶음이 모두 잘못 양성일 확률은 0.1³=0.1%입니다. 이는 분당 오클릭률이 아닙니다. 실제 신호의 잡음이 여러 구간에 이어지거나 창이 겹치면 독립 가정부터 깨집니다.

선택을 더 안정적으로 하려는 대기 시간이 작업 속도를 낮출 수 있습니다. 빠른 출력과 안전한 선택 사이에서 지연·누락·오클릭을 함께 정해야 합니다. 취소 버튼을 누르는 데도 같은 입력 통로가 필요하다면 잘못된 선택 하나의 복구 비용이 큽니다. 따라서 명령을 냈다는 정확도뿐 아니라 목표 작업을 끝내기까지의 오류 수정 시간을 평가합니다.

[SWITCH 원문의 그림 1과 Methods](https://jamanetwork.com/journals/jamaneurology/fullarticle/2799839)는 눈 추적으로 커서를 움직이고 BCI로 클릭하는 방식과, 항목을 차례로 강조하는 스캐너를 BCI로 선택하는 방식을 구분합니다. 전자는 눈 움직임이라는 다른 입력을 활용하고 후자는 원하는 항목의 차례를 기다려야 합니다. 동일한 뇌 신호 디코더라도 사용자 인터페이스가 달라지면 작업 속도도 달라집니다. 사용 가능한 눈·머리 움직임을 이용하는 입력기와 비교할 때에도 입력 횟수보다 준비·피로·교정·보조 인력까지 포함한 목표 작업을 맞추는 편이 좋습니다.

## 임상 원저에서 확인한 범위

[SWITCH 연구 원저, JAMA Neurology 2023](https://jamanetwork.com/journals/jamaneurology/fullarticle/2799839)는 Stentrode를 이식하고 분석에 포함된 4명을 12개월 추적했습니다. 해당 기간에 정의한 심각한 장치 관련 이상사건, 혈관 폐색, 장치 이동이 관찰되지 않았고 디지털 장치 제어가 가능했다고 보고합니다. 이는 소규모 초기 안전성·실행 가능성 근거입니다.

저자 중에는 개발 회사 관계자가 있고 제조사 지원도 공개되어 있습니다. 학술지 심사를 받았다는 점과 회사와 무관한 대규모 독립 확증 시험이라는 점은 다릅니다. 특정 예에서 눈 추적과 BCI 선택 신호를 함께 사용했다면 모든 화면 조작을 BCI 혼자 했다고 설명해서도 안 됩니다. 과제와 보조 장치가 속도에 영향을 줍니다.

[Neuralink의 2026년 참가자 보고](https://neuralink.com/updates/two-years-of-telepathy/)는 회사가 공개한 사용 사례입니다. 이를 임상시험 전체의 대조군 비교나 모든 사용자의 장기 성능으로 일반화하지 않습니다. 한 사람의 최고 기록, 여러 연구의 누적 참가자 수, 특정 등록 시험의 분모는 서로 다른 정보입니다. 제조사 블로그와 심사된 연구 결과를 표에서 구분해야 합니다.

## 신호량과 유용한 정보량

아래는 실제 제품 사양이 아닌 자체 예제입니다. 32개 채널을 초당 천 번, 표본당 16비트로 읽는다면 원자료의 전송량은 다음과 같습니다.

```math
R=32\times1000\times16=512{,}000\ \mathrm{bit/s}
```

이는 헤더·압축을 제외한 512kbps입니다. 사용자가 초당 51만 비트의 의사를 표현한다는 뜻은 아닙니다. 많은 표본이 같은 신호와 잡음을 반복해서 담기 때문입니다. 실제 유용성은 올바른 선택 수, 잘못 누른 선택을 고치는 시간, 준비 시간과 장기 사용 가능성으로 평가해야 합니다.

4명이 모두 특정 이상사건 없이 관찰됐다고 위험률이 0임을 증명할 수도 없습니다. 같은 위험률과 독립 관찰을 가정한 단순 모형에서, 4명 중 0건의 95% 단측 상한은 다음과 같습니다.

```math
(1-p)^4=0.05\quad\Rightarrow\quad
p=1-0.05^{1/4}\approx0.527
```

약 52.7%입니다. 실제 환자의 위험을 이 숫자로 추정하라는 뜻이 아닙니다. 소표본의 ‘0건’이 좁은 안전성 보증이 되지 않는다는 통계 예제입니다. 장치 종류·추적 기간·대상자가 다른 연구의 0건을 합쳐 새 위험률을 만들지 않습니다.

## 아직 남은 기술 문제

장기 신호 안정성, 충전·통신, 일상 환경의 잡음, 재교정, 감염과 기타 이상사건 감시가 필요합니다. 임상시험의 연구진 지원 시간과 집에서 혼자 쓸 때의 준비 시간을 나눠야 합니다. 복원한 목소리나 커서가 유용하더라도 원래 신체 기능이 회복됐다는 뜻과는 다릅니다. 뇌 활동을 해독한 보조 통로와 질환 자체를 치료한 결과는 구별해야 합니다.
