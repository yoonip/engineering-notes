# AI 서비스와 실제 로봇

대화형 AI, 기기 내 추론, 게임 화면 재구성, 도로 주행, 산업용 로봇, BCI와 양자컴퓨터를 다룹니다. 제품 이름보다 어떤 계산과 동작을 실제로 수행하는지, 어떤 조건에서 성능을 확인했는지를 중심으로 읽습니다.

기준일은 2026년 10월 20일입니다. 아래 10편은 공식 제품 문서와 연구·외부 시험을 읽은 문헌 리뷰입니다. 작성자가 제품을 구매하거나 직접 시승·임상·장치 성능 시험을 진행한 결과는 아닙니다. 문서에 명시한 자체 계산은 이해를 위한 예제입니다.

## 숫자와 출처를 읽는 방법

각 글은 실제 확인한 배포·시험·허가 상태를 구분합니다. 발표한 계획은 인도 실적으로 바꾸지 않고, 최고 사양은 모든 조건의 측정값으로 바꾸지 않습니다. 외부 원시험도 장치·버전·구간과 평가자의 이해관계를 함께 봅니다. 동영상 설명만 확인한 경우 영상을 직접 시청한 것으로 쓰지 않습니다.

기본 비교 원리는 [모델 평가 지표](../모델평가지표_MODEL_EVALUATION.md)에서도 이어서 읽으실 수 있습니다. 뇌 연결 지도·행동 모형·임상 BCI의 원논문은 [뇌와 신경공학 논문 해설](../../논문해설_papers/뇌와신경공학_neuroengineering/README.md)로 연결됩니다. 각 글의 세 가지 확인 문제는 본문의 구분과 작은 계산을 다시 확인하도록 구성했습니다.
