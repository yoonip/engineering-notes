# 진단과 바이오제조 기술 비교

분자를 읽는 장비, 현장진단, RNA 전달, 살아 있는 조직 모델과 의약품 생산을 원리와 실제 비교 자료로 살펴봅니다. 기준일은 2026년 10월 20일이며 글마다 확인한 제품·허가·연구 시점을 표시합니다. 미국·EU의 허가 사례를 한국의 허가로 바꾸어 해석하지 않습니다.

| 글 | 경쟁하는 방식과 중심 질문 |
| --- | --- |
| [DNA 분석기](sequencing2026.md) | 짧은 읽기·나노포어·HiFi의 정보와 데이터·운영 비용을 비교합니다. |
| [현장진단](point-of-care2026.md) | PCR·항원·CRISPR의 검출 원리와 사용자·시설 조건을 비교합니다. |
| [mRNA와 지질나노입자](mrna-lnp2026.md) | 항원 정보·자기증폭·전달·임상 비교와 공급 체계를 나눠 봅니다. |
| [장기칩과 오가노이드](organchips-organoids2026.md) | 입체 모델의 기능·재현성·처리량과 규제 단계를 비교합니다. |
| [연속 바이오제조](continuous-biomanufacturing2026.md) | 유가식·관류·다중 컬럼과 설비·개발·운영 비용을 비교합니다. |

공식 사양, 실제 표본의 학술 측정, 비용모형과 직접 만든 산술 예를 분리합니다. 제조사 자료의 조건과 연구 지원 내역을 밝히며, 장비 구매·개인별 검사·접종·치료·실험 절차를 안내하는 문서는 아닙니다. 각 글에는 확인 문제 세 개와 접힌 해설이 있습니다.
