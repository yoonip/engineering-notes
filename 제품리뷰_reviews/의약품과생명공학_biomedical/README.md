# 약물·유전자·세포치료의 원리와 임상 근거

호르몬 신호를 조절하는 약물, 혈액세포의 유전자 조절 부위를 편집하는 제품, 면역세포에 표적 인식 기능을 부여하는 제품을 비교합니다. 발견과 설계의 원리에서 시작해 임상 결과의 분모·기간·안전성과 현재 허가 범위까지 읽으실 수 있습니다.

각 글에는 공식 규제 자료·대표 원저, 자체 계산과 세 문항의 접힌 해설이 있습니다. 기준일은 2026년 10월 20일입니다. 국가·상품·제형·질환별 조건을 구분하며 개인 치료 선택이나 사용법을 안내하지 않습니다. 제조사 지원 임상을 독립 재현시험으로 표시하지 않으며 동물 실험·초기 연구와 허가 제품도 나누어 설명합니다.

비만 약물의 대표 원저를 자세히 읽으시려면 [STEP 1·SURMOUNT-1 논문 해설](../../논문해설_papers/의약품과대사_metabolic-medicine/README.md)로 이어가시면 됩니다.
