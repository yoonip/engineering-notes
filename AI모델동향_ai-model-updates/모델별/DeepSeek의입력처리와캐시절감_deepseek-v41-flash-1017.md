## 새 판본과 구조

DeepSeek는 9월 10일 V4.1-Flash를 발표하고 10월 17일 V4.1-Flash-1017로 갱신했습니다. 현행 API 이름은 `deepseek-flash`이며, 공식 앱과 웹도 갱신됐다고 안내합니다. 모델 이름이 그대로여도 실제 제공되는 판본은 바뀔 수 있으므로 평가 날짜와 가중치 revision을 같이 남겨야 합니다. [공식 변경 기록](https://api-docs.deepseek.com/updates/) · [10월 판본 모델 카드](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017)

설계에서 눈에 띄는 부분은 입력을 읽는 단계와 답을 만드는 단계의 계산을 다르게 구성한 점입니다. 입력을 한꺼번에 읽고 중간 상태를 준비하는 단계를 prefill, 그 상태를 이용해 답을 이어 쓰는 단계를 decode라고 부릅니다. 원형 V4.1-Flash의 공식 카드는 Causal Encoder–Decoder를 20층 인코더와 20층 디코더로 설명합니다. 입력 처리 때 활성 파라미터는 8B, 답 생성 때는 16B입니다. 두 값은 서로 다른 단계의 수치이므로 더해서 24B 모델이라고 부르지 않습니다. [원형의 Introduction·Architecture](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash)

MoE는 여러 전문가 신경망 중 일부를 골라 계산하는 구조입니다. 전체 도서관을 보유하되 한 질문에 필요한 책 일부만 읽는 것과 비슷합니다. 계산에 참여하는 파라미터가 작아져도 다른 전문가의 가중치를 저장하고 옮기는 비용은 남습니다. 특히 이 카드의 552B는 backbone 표기이며, 196B의 Engram 조건부 메모리와 시각 인코더도 따로 설명합니다. 552B를 전체 배포물의 정확한 파라미터 수나 필요한 GPU 메모리로 곧바로 바꾸면 안 됩니다.

KV 캐시는 앞에서 읽은 문장의 중간 계산을 보관하는 공간입니다. 매번 처음부터 읽지 않도록 남기는 메모와 비슷합니다. 공식 카드는 전역 KV를 토큰당 890바이트로 제시합니다. 이 값을 그대로 적용한 자체 계산에서는 100만 토큰 한 시퀀스의 전역 KV가 약 0.89GB입니다. 여기에 가중치·임시 계산·다른 상태·동시 요청의 메모리가 별도로 필요합니다. 이 계산은 GPU 전체 사용량의 실측값이 아닙니다. [공식 카드의 CSA2 설명](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash)

10월 발표 표에는 Terminal-Bench 4.0이 31.2에서 42.3으로 바뀐 것으로 나옵니다. 표의 차이는 11.1퍼센트포인트입니다. 이 점수를 읽을 때에는 모델만이 아니라 실행 도구인 harness도 확인해야 합니다. 변경 기록은 해당 평가에 Claude Code를 사용했다고 명시합니다. 같은 평가 이름이어도 도구·시도 횟수·시간 제한이 다르면 순수한 모델 성능 차이로 해석하기 어렵습니다. [1017 평가와 조건](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017)

실무에서는 긴 소스코드를 많이 읽는 작업과 짧은 답을 반복 생성하는 작업을 나누어 비교할 만합니다. 성공률, 총 입력·출력량, 재시도 수, 실제 경과 시간을 함께 기록해야 저렴한 모델 이름과 저렴한 작업 비용을 구분할 수 있습니다. 이는 평가 설계 제안이며 실제 API를 실행한 결과는 아닙니다.

## 판본과 공개 범위

가중치 확인 revision은 `1bae0e1088993b9b82de08f59de5be5a34e42170`입니다. API 별칭을 평가할 때도 요청 날짜와 응답의 모델 정보를 남기는 편이 좋습니다. 같은 이름을 다시 호출하는 것과 고정된 체크포인트를 다시 평가하는 것은 다릅니다.

공식 저장소는 코드와 가중치를 MIT로 배포한다고 설명합니다. 이 조건을 다른 DeepSeek 제품이나 제3자가 재배포한 양자화본 전체의 조건으로 확대하지 않습니다. [해당 판본 카드의 License](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017#license)

서비스 종료 예정과 현재 상태도 구분해야 합니다. 9월 개별 출시 기사에 남은 V4-Pro 전환 예정과 달리, 현행 변경 기록은 9월 14일 이후에도 V4-Pro API를 유지한다고 안내합니다. 이전 발표의 계획만 읽고 현재 모든 Pro 요청이 Flash로 전환됐다고 설명하지 않습니다. [현행 변경 기록](https://api-docs.deepseek.com/updates/)
