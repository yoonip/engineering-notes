# Claude Fable 5.1의 추론과 제공 범위

| 항목 | 확인한 내용 |
| --- | --- |
| 공식 API 문서의 출시일 | 2026년 9월 1일 |
| Claude API 모델 ID | `claude-fable-5-1` |
| 관련 제한 제공 모델 | `claude-mythos-5-1` |
| 자료 확인일 | 2026년 10월 29일 |

Anthropic의 현재 모델 안내는 대부분의 업무에서 Opus 5.5를 출발점으로 삼고, 어려운 추론·장시간 에이전트 업무나 Opus의 평가 결과가 요구에 못 미칠 때 Fable 5.1을 검토하도록 구분합니다. 따라서 프론티어 모델을 살펴볼 때 Opus 5.5만으로 Anthropic의 제공 범위를 대표하면 빠지는 부분이 있습니다. 이 구분은 제공사의 제품 배치이며 모든 과제의 확정 순위는 아닙니다. [공식 모델 목록](https://platform.claude.com/docs/en/models/overview)

## Fable과 Mythos의 차이는 접근 조건에도 있습니다

공식 발표는 Fable 5.1과 Mythos 5.1을 같은 기반 모델에 서로 다른 보호 장치를 적용한 형태로 설명합니다. Fable 5.1은 일반 제공되지만 Mythos 5.1은 검증 프로그램을 통과한 조직에 제한됩니다. 이름과 성능 설명을 보았다는 이유로 두 모델을 누구나 같은 조건으로 호출할 수 있다고 설명하면 안 됩니다. [공식 발표](https://www.anthropic.com/claude-fable-and-mythos-5-1)

현재 API 문서에는 Fable 5.1의 출시일이 9월 1일로 명시되어 있습니다. Claude API에서는 `claude-fable-5-1`, Amazon Bedrock에서는 제공자 접두사를 붙인 ID를 사용합니다. 다른 플랫폼의 식별자를 그대로 복사하기보다 해당 경로의 문서를 확인해야 합니다. 이 API 제공 안내는 전체 모델 가중치를 내려받는 배포 안내와는 다릅니다. [모델 사양의 Availability·Model IDs](https://platform.claude.com/docs/en/models/fable-5-1/overview)

## 추론 기능이 항상 켜져 있다는 의미

Fable 5.1은 적응형 추론을 항상 사용하는 모델로 안내됩니다. 추론 수준은 문제를 처리하는 데 쓸 계산의 깊이를 조절합니다. 내부 계산을 전부 사용자에게 공개한다는 의미는 아닙니다. 문맥은 1M토큰, 최대 출력은 128K토큰으로 안내되며 API의 기본 추론 수준은 `high`입니다. [공식 모델 사양](https://platform.claude.com/docs/en/models/fable-5-1/overview)

자료가 길고 여러 판단이 연결된 업무에서는 앞의 결론이 뒤에서 어떤 근거로 사용됐는지 보존하는 것이 중요합니다. 모델을 중간에 바꾸거나 과거 대화 내용을 다시 구성하면 일반 메시지와 추론 관련 상태가 유지되는 범위가 달라질 수 있습니다. ‘같은 문장을 다시 보냈다’는 사실만으로 동일한 작업 상태라고 가정하지 않습니다.

공식 변경 안내에는 강제 도구 호출의 제한과 이전 대화 수정에 따른 추론 상태의 무효화가 설명되어 있습니다. 따라서 API 이름만 교체하는 방식은 충분하지 않습니다. 도구를 반드시 특정 방식으로 호출하게 한 기존 코드와 대화 기록을 재구성하는 방식도 함께 확인해야 합니다. [변경 안내: Breaking changes](https://platform.claude.com/docs/en/models/fable-5-1/whats-new-fable-5-1)

## 더 높은 단가를 지불할 근거

확인일 기준 공식 Standard 가격은 Fable 5.1의 신규 입력 $10·출력 $50, Opus 5.5의 신규 입력 $4·출력 $20/백만 토큰입니다. 캐시 없는 같은 입력·출력량만 고정하면 Fable 쪽이 2.5배입니다. 이것을 실제 업무 총비용의 고정 비율로 확대하면 안 됩니다. [공식 가격표](https://platform.claude.com/docs/en/about-claude/pricing)

직접 구성한 예로, 복잡한 결함 분석에서 검토 시간을 줄이거나 기존 모델이 해결하지 못한 문제를 해결한다면 더 높은 단가를 사용할 이유가 생길 수 있습니다. 반대로 형식이 정해진 항목 추출을 두 모델이 모두 같은 품질로 끝낸다면 단가가 높은 모델의 편익은 작을 수 있습니다. 이런 판단은 동일한 자료·시험·완료 기준으로 비교해야 합니다.

## 보호 장치와 시험 점수의 관계

출시 발표의 평가에는 보호 장치가 개입한 항목의 처리 조건이 설명되어 있습니다. 일부 작업의 중단·대체 모델 사용 여부는 최종 점수에 영향을 줄 수 있습니다. 따라서 배포된 서비스의 점수를 순수한 모델 가중치의 능력만으로 설명하면 안 됩니다. [공식 발표의 평가 각주](https://www.anthropic.com/claude-fable-and-mythos-5-1)

이 글에서는 공식 제공 범위와 API 조건을 확인했습니다. Fable 5.1·Mythos 5.1을 호출하거나 내부 구조·작업 성공률을 직접 측정하지 않았습니다. 비공개 층 수·파라미터 수를 추정하거나 제한 제공 모델을 일반 모델처럼 사용할 수 있다고 설명하지 않습니다.
