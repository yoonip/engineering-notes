## Max급 모델의 공개와 기능 차이

Qwen은 8월 3일 Qwen3.8-Max를 발표했습니다. 공개 가중치의 실제 저장소 이름은 `Qwen/Qwen3.8-2.4T-A95B`입니다. 모델 카드의 2.4T는 전체 파라미터, 95B는 토큰당 활성 파라미터를 뜻합니다. T는 1조, B는 10억 단위입니다. 활성 크기는 계산량을 이해하는 실마리이며 전체 가중치 저장 공간을 뜻하지 않습니다. [공식 발표](https://qwen.ai/blog?id=qwen3.8) · [공개 모델 카드의 Model Overview](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B)

카드는 세 층의 Gated DeltaNet 뒤에 한 층의 Gated Attention이 오는 구성을 반복한다고 설명합니다. 앞의 계열은 길어진 입력의 정보를 일정한 크기의 상태에 모으는 계산이고, 뒤의 attention은 필요한 이전 위치를 다시 참조하는 계산입니다. 서로 다른 계산 방식을 섞었다는 뜻이지 긴 문서의 모든 내용을 손실 없이 기억한다는 보장은 아닙니다. MoE에서는 512개 전문가 중 10개 routed 전문가와 1개 shared 전문가를 활성화한다고 설명합니다. [공개 카드·설정](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B/blob/main/config.json)

서비스 이름과 다운로드한 모델은 같은 사양이 아닙니다. 공식 카드는 Qwen3.8-Max 서비스에 시각 입력·non-thinking·기본 1M 문맥·내장 도구 등의 추가 기능이 있다고 구분합니다. 다운로드 배포물은 텍스트 Causal Language Model이며, 기본 문맥은 262,144이고 최대 1,010,000까지 확장할 수 있다고 설명합니다. 서비스에서 이미지를 받았다는 사실만으로 공개 체크포인트에 같은 시각 입력 경로가 있다고 결론 내리면 안 됩니다. [공식 모델 카드의 Note·Model Overview](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B)

메모리 규모를 이해하기 위한 자체 단순 계산도 가능합니다. 명목상 2.4T 가중치를 모두 2바이트로 저장한다고 가정하면 가중치만 약 4.8TB입니다. 4비트로 모두 표현한다고 가정해도 약 1.2TB이며, 실제 양자화 스케일·메타데이터·캐시·통신 버퍼는 별도입니다. 전체 모델의 실제 배포 측정치가 아니라, 활성 95B만 보고 한 장의 GPU에 들어간다고 추정하면 왜 틀리는지 보여 주는 계산입니다.

가중치가 공개됐다는 말도 이용 조건 전체가 같다는 뜻은 아닙니다. 이 배포물은 Apache 2.0이 아니라 Qwen3.8-Max License입니다. 특정 규모의 Model as a Service·AI Work Assistant 사업에 대한 별도 라이선스 조건과 대규모 서비스의 이름 표시 조건을 확인해야 합니다. [해당 배포물의 LICENSE](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B/blob/main/LICENSE)

## 공개 라이선스에서 확인할 항목

해당 라이선스 §2는 MaaS 또는 AI Work Assistant 사업을 하며 계열사 합산 매출이 연속 12개월 미화 5천만 달러를 넘는 경우, 상업 이용 전에 별도 라이선스를 받도록 합니다. 외부에 모델·출력·기능을 제공하지 않는 내부 사용은 구분합니다. §1에는 일정 규모를 넘는 상용 서비스에서 모델명을 표시하는 조건도 있습니다. [LICENSE 원문](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B/blob/main/LICENSE)

따라서 상업적 사용이 언제나 금지된다고 설명하거나, 조건 없는 Apache 2.0 배포물이라고 설명하는 것 모두 부정확합니다. 같은 시리즈의 작은 모델과 Max급 배포물도 각각의 조건을 읽어야 합니다.

## 비교할 때 남길 정보

업무에서 긴 보고서 묶음을 읽힌다면, 단순히 입력이 접수되는지와 필요한 근거를 끝까지 찾아내는지를 따로 확인할 수 있습니다. 문서 앞·중간·뒤에 같은 난이도의 질문을 배치하고 출처 위치까지 맞혔는지 평가하면, 입력 한도만 보는 비교에서 놓친 차이를 살필 수 있습니다. 이는 평가 예시이며 모델의 실제 점수를 만든 것은 아닙니다.

공개 모델 확인 revision은 `207bd685a7e3696cfaff12ded7c6a7ea0f88c996`입니다. API는 서비스 이름과 실제 모드, 가중치 실행은 체크포인트·정밀도·엔진·문맥 길이를 기록합니다. 모델의 reasoning effort를 크게 설정한 점수와 작은 지연 시간 설정의 비용을 한 줄에 합치지 않습니다.

[기존 Qwen3-0.6B 설명](../../AI모델과수치실험_ai-models/models/qwen.md)은 작은 배포물의 구조와 thinking 설정을 다룹니다. 이 글은 Max급 공개와 서비스·라이선스 차이에 초점을 둡니다.
