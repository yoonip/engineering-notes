# Kimi K3.1 Pro의 서비스 출시와 가중치 공개 예정

| 항목 | 확인한 범위 |
| --- | --- |
| 발표·확인 | 발표 2026-10-24, 확인 2026-10-29 |
| 서비스 | Kimi 앱·Work·Code·API |
| 가중치 | 2026-11-04 공개 예정입니다(2026-10-29 확인). |
| 기반 | 공식 발표가 밝힌 Kimi K3의 후속 학습 모델 |

## 긴 작업을 위한 후속 학습

Moonshot AI는 10월 24일 Kimi K3.1 Pro를 발표했습니다. 공식 글은 K3의 후속 학습 모델이며 코딩·3D 생성·금융 조사 같은 긴 작업의 결과를 다룬다고 설명합니다. Kimi 앱·Work·Code·API의 서비스 출시와 전체 가중치 공개는 별도 단계입니다. 2026년 10월 29일 확인한 발표에서 가중치 공개 예정일은 11월 4일로 안내됩니다. [공식 연구 목록](https://www.kimi.com/en/blog/) · [K3.1 Pro 발표·Availability](https://www.kimi.com/en/blog/kimi-k3-1-pro)

긴 작업 능력은 한 질문에 긴 답을 쓰는 능력과 다릅니다. 모델이 파일을 만들고, 도구의 오류를 보고, 수정하고, 다시 검증하는 여러 단계를 끝까지 이어 가는 능력입니다. 운영체제나 에이전트가 제공하는 권한·도구·검사 코드가 결과에 영향을 주므로 모델 이름만으로 수행 범위를 판단하지 않습니다.

제공사는 코딩과 금융·자료 조사 평가의 향상을 제시하지만, 내부 평가와 공개 평가를 구분해 읽어야 합니다. 예를 들어 Kimi Hallu Bench Hard의 수치는 오류가 나기 쉬운 문제를 의도적으로 모은 스트레스 시험입니다. 이 수치를 일반 사용자의 모든 질문에서 발생하는 오류율로 설명할 수 없습니다. [공식 Finance·Footnotes](https://www.kimi.com/en/blog/kimi-k3-1-pro)

평가의 반복 횟수도 다릅니다. 한 번의 성공률인 pass@1과 여러 번 시도 중 성공을 보는 pass@k는 같은 확률이 아닙니다. 공식 글의 평가 주석은 도구 사용·추론량·벤치마크 부분집합 등을 구분합니다. CAD 평가도 도구를 쓴 결과와 쓰지 않은 결과를 나누며, 전체 데이터 중 1,000개 사례의 하위집합을 사용했다고 밝힙니다. 이런 차이를 빼고 숫자 하나로 다른 모델보다 낫다고 결론 내리지 않습니다.

이전 Kimi K3의 공개 모델 카드는 총 2.8T·활성 104B와 1M 문맥을 제시합니다. 그러나 K3.1 Pro 발표가 K3 기반이라는 이유만으로 미공개 배포물의 모든 설정과 라이선스가 K3와 같다고 미리 채우지는 않습니다. [기존 K3 공식 모델 카드](https://huggingface.co/moonshotai/Kimi-K3)

## 같은 점수처럼 보여도 다른 평가

한 번 성공할 확률을 20%라고 가정하고 각 시도가 서로 독립이라면, 다섯 번 중 한 번 이상 성공할 확률은 `1 − 0.8^5 = 67.232%`입니다. 이 수치는 개념을 설명하기 위해 구성한 계산이며 Kimi를 시험한 결과가 아닙니다. 실제 재시도는 서로 비슷한 실패를 반복할 수 있어 독립 가정도 그대로 성립하지 않습니다. 핵심은 반복 기회가 다른 두 수치를 같은 한 번의 성공률로 비교하지 않는 것입니다.

공식 카드가 인용한 외부 모델 점수도 모두 동일한 조건에서 새로 측정한 값은 아닙니다. 각주에는 다른 제공사의 보고서·공개 순위·자체 재평가가 섞여 있으므로, 어느 수치의 실험 주체가 누구인지 확인해야 합니다. [공식 평가 각주](https://www.kimi.com/en/blog/kimi-k3-1-pro#footnotes)

## 배포 경로를 확인하는 방법

CAD 결과도 목적에 맞게 확인해야 합니다. 참조 그림과 입체 형상이 얼마나 겹치는지를 보는 평가는 도면의 치수·공차, 재료의 강도와 실제 제조 가능성을 모두 검사하는 절차가 아닙니다. 예를 들어 볼트 구멍이 그럴듯하게 보이는 모델이라도 구멍 지름과 체결 여유가 맞지 않으면 조립되지 않습니다. 화면 생성·형상 평가·공학 검증을 분리하면 이런 차이를 놓치지 않습니다.

발표의 API 식별자는 `kimi-k3.1-pro`와 `kimi-k3.1-pro-highspeed`입니다. Highspeed의 2~3배 속도는 제공사의 발표 범위이며 이 저장소의 동일 조건 실측값이 아닙니다. 1M 문맥도 입력 한도와 실제 긴 작업 성공률을 분리해서 읽습니다.

기존 K3의 공개 라이선스에는 특정 규모의 MaaS 사업과 서비스 표시에 관한 조건이 있습니다. 하지만 K3.1 Pro의 미공개 가중치 조건을 기존 K3 라이선스로 대신하지 않습니다. 새 배포물이 올라오면 그 저장소의 LICENSE와 revision을 다시 확인해야 합니다. [선행 K3 LICENSE](https://huggingface.co/moonshotai/Kimi-K3/blob/main/LICENSE)

[Kimi-K2-Instruct 설명](../../AI모델과수치실험_ai-models/models/moonshot.md)은 이전 모델의 구조를 다루며, K3.1 Pro의 공개 완료를 뜻하지 않습니다.
