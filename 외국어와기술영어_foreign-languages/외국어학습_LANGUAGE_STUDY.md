# 영어와 제2외국어 학습 | Studying English and another language

영어를 처음부터 배우실 때에는 [영어 기초 8단원](영어기초_english-basics/README.md)의 예문과 64개 연습문제로 시작하실 수 있습니다. 이 글은 그 자료를 읽고 복습하는 방법을 설명합니다.

목표를 ‘외국어를 잘하기’로만 두면 어떤 연습을 해야 할지 정하기 어렵습니다. 기술 문서 읽기, 회의에서 질문하기, 짧은 메일 쓰기 중 당장 필요한 일을 정하고 그 상황의 자료로 연습합니다. 영어와 제2외국어에 같은 원칙을 적용하되, 문자 체계와 발음의 어려움은 따로 다룹니다.

## 한 자료를 네 번 사용하기

짧은 설명 한 문단을 고릅니다. 처음에는 전체 뜻을 읽고, 두 번째에는 모르는 표현을 확인합니다. 세 번째에는 원문을 덮고 핵심을 말하거나 씁니다. 마지막에는 원문과 비교해 빠뜨린 조건과 잘못 사용한 표현을 고칩니다. 매번 새로운 자료로 바꾸기보다 같은 내용을 이해·회상·표현하는 데 사용합니다.

직접 만든 예시 `The cache stores recently used data`를 배웠다면 `cache = 캐시`만 적지 않습니다. `stores`가 동사이며 3인칭 단수 주어와 쓰는 현재단순형에 `-s`가 붙는다는 점, `recently used`가 `data`를 꾸민다는 점을 함께 기록합니다. 다음에는 `The buffer stores incoming bytes`처럼 일부를 바꾸어 직접 문장을 만듭니다.

| 단계 | 실제로 할 일 | 확인할 결과 |
| --- | --- | --- |
| 소리와 문자 | 신뢰할 수 있는 발음을 듣고 짧게 따라 읽습니다. | 철자만 보고 잘못 굳힌 발음을 찾습니다. |
| 어휘 | 단어·품사·문장 속 뜻·짧은 예문을 함께 적습니다. | 같은 단어의 다른 뜻을 문맥으로 구분합니다. |
| 문장 | 주절과 조건절을 나누고 한 요소씩 바꿉니다. | 암기한 문장을 새 상황에서도 사용할 수 있습니다. |
| 읽기 | 짧은 원문을 읽고 핵심과 근거를 요약합니다. | 단어를 알아도 관계를 놓친 문장을 찾습니다. |
| 쓰기와 말하기 | 원문을 덮고 설명한 뒤 피드백을 받습니다. | 직접 사용하지 못하는 표현을 다음 연습에 넣습니다. |

## 복습 기록

학습일, 자료, 원문 없이 말할 수 있었는지, 틀린 부분을 적습니다. 예를 들어 다음 날과 며칠 뒤에 다시 확인하되, 반복 간격은 기억 상태와 시험 일정에 맞춥니다. 아래 시간표는 실행 가능한 한 가지 구성입니다. 모든 학습자에게 가장 좋은 배분이라는 뜻은 아닙니다.

- 5분: 지난 표현을 보지 않고 회상합니다.
- 10분: 짧은 원문을 읽고 발음·문법을 확인합니다.
- 10분: 요약하거나 상황을 바꿔 말합니다.
- 5분: 틀린 부분과 다음 복습 대상을 남깁니다.

회상과 분산 연습의 근거 및 적용 한계는 [학습 방법 해설](../언어이해와추리논증_reading-reasoning/학습방법_STUDY_METHODS.md)에 연결했습니다. [CEFR Companion Volume](https://www.coe.int/en/web/common-european-framework-reference-languages)은 이해·표현·상호작용 등의 능력을 구분할 때 참고할 수 있습니다. 특정 점수나 짧은 학습 시간만으로 실제 업무 수행을 보장하지는 않습니다.

## 제2외국어에서 따로 확인할 부분

일본어에서는 문자와 단어 경계, 독일어에서는 명사 성·격과 어순처럼 선택한 언어의 구조를 실제 예문에서 확인합니다. 어느 언어든 영어 문장을 단어마다 바꿔 끼우는 방식만으로는 자연스러운 표현을 만들기 어렵습니다. 사전과 공식 교육 자료의 예문을 기준으로 조사·전치사·활용을 묶어서 익힙니다.

## 같은 문장으로 하는 짧은 연습

다음은 직접 만든 문장입니다. 먼저 뜻을 읽고 원문을 가린 다음, 조건을 바꾸어 말해 보시면 됩니다.

> The sensor sends data every second, but it stops when the battery is low.

주어는 `The sensor`, 첫 동사는 `sends`입니다. `every second`는 매초라는 시간 표현입니다. `but` 뒤에서는 `it`이 앞의 센서를 다시 가리키고 `stops`가 두 번째 동사입니다. `when the battery is low`는 멈추는 조건을 설명합니다. `low`는 여기서 높이가 낮다는 뜻보다 배터리 잔량이 적은 상태를 나타냅니다.

| 바꿀 요소 | 새 문장 | 달라진 내용 |
|---|---|---|
| 주어를 복수로 바꿉니다. | The sensors send data every second. | 복수 주어이므로 sends가 send가 됩니다. |
| 시간을 바꿉니다. | The sensor sends data every minute. | 매초에서 매분으로 바뀝니다. |
| 부정으로 바꿉니다. | The sensor does not send data at night. | does 뒤에는 동사 원형 send를 씁니다. |
| 질문으로 바꿉니다. | Does the sensor send data every second? | does를 앞으로 옮기고 send를 원형으로 씁니다. |

문장을 보지 않고 ‘센서 두 개가 매분 데이터를 보냅니다’를 영어로 써 보세요. 단어를 모두 기억해도 복수 주어와 동사 형태를 연결해야 완성할 수 있습니다. 다음에는 뜻을 바꾸지 않은 채 `it`이 무엇을 가리키는지 설명해 봅니다.

## 제2외국어의 첫 예문을 공부하는 방식

일본어의 직접 만든 기초 예문 `これはセンサーです。`는 ‘이것은 센서입니다’라는 뜻입니다. `これ`는 이것, `は`는 화제를 표시하는 조사, `センサー`는 센서, `です`는 정중한 문장 끝 표현입니다. 이 문장에서 조사 `は`는 ‘와’로 읽습니다. 영어의 어순과 단어를 일대일로 대응시키기보다 화제와 설명의 구조를 보시면 좋습니다.

독일어의 예문 `Der Sensor ist klein.`은 ‘그 센서는 작습니다’라는 뜻입니다. `der`는 여기서 남성 단수 주격 명사에 쓰인 정관사이고, `Sensor`는 명사라 첫 글자를 대문자로 씁니다. `ist`는 sein의 현재형이며 영어의 is와 역할을 비교할 수 있습니다. `klein`은 작다는 형용사입니다. 명사의 문법적 성은 실제 물건의 성별을 말하지 않습니다.

이 두 예문은 문자·조사·관사·어순을 어떻게 기록할지 보여 주는 시작점입니다. 일본어의 `です`와 독일어의 `ist`를 모든 문맥에서 같은 표현으로 암기하지 않습니다. 학습 언어를 정한 뒤에는 공식 교육 자료의 발음과 예문으로 같은 유형을 더 연습하셔야 합니다.

## 확인 문제

1. `The buffers store data`의 주어를 `The buffer`로 바꾸면 동사는 무엇인가요?
2. `Does the sensor sends data?`에서 고칠 부분은 무엇인가요?
3. 일본어의 `は`를 언제나 영어의 be동사라고 생각해도 되나요?

<details>
<summary>답과 풀이</summary>

1. `stores`입니다. 단수 주어의 현재형입니다.
2. `sends`를 `send`로 고칩니다. 조동사 does가 있는 의문문에서는 동사 원형을 씁니다.
3. 아닙니다. 화제를 나타내는 조사와 서술을 담당하는 표현의 역할을 구별합니다.
