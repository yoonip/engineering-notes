# 외국어와 기술 영어 | Foreign languages and technical English

외국어 자체를 배우는 과정과 외국어 기술 문서를 읽는 과정을 연결합니다. 현재 본문으로 공부하실 수 있는 첫 과정은 영어 기초 8단원입니다. 알파벳·발음에서 시작하여 문장 구성, 기본 문법, 어휘, 짧은 읽기와 쓰기를 연습합니다.

## 영어부터 시작하기

[영어 기초 8단원·64개 연습](영어기초_english-basics/README.md)에는 정의, 풀이된 예문, 직접 풀 문제와 접힌 정답·해설이 있습니다. 영어를 처음 배우시면 1단원부터, 간단한 문장을 이미 읽으시면 8단원의 누적 문제를 먼저 풀어 틀린 부분으로 돌아가시면 됩니다.

예를 들어 `She doesn't reads.`를 고칠 때에는 `She doesn't read.`를 답으로 쓰는 데서 끝내지 않습니다. does가 현재형 표시를 맡으므로 뒤 동사는 원형이라는 이유를 확인하고, 주어를 they로 바꾸어 `They don't read.`까지 직접 써보시면 됩니다. [현재문 단원](영어기초_english-basics/03-현재문_BE_AND_PRESENT_SIMPLE.md)에서 같은 방식으로 연습합니다.

## 학습 방법과 기술 영어

| 분야 | 먼저 읽을 내용 | 연습 방법 |
| --- | --- | --- |
| [기술 영어](기술영어_TECHNICAL_ENGLISH.md) | 조건, 수식의 정의, 주장 강도, 요구사항 | 한 문장을 조건·동작·결과로 나눠 다시 설명합니다. |
| [외국어 학습 방법](외국어학습_LANGUAGE_STUDY.md) | 발음, 어휘, 문장, 읽기와 쓰기의 복습 | 영어 기초의 한 예문을 덮고 다시 만든 뒤 주어·시간을 바꾸어 씁니다. |
| [영어 기술 기사와 연구 읽기](기사와연구읽기_ARTICLES_AND_RESEARCH.md) | 제목의 주장, 연구 근거와 적용 범위 | 짧은 자체 지문에서 인과·가능성·책임 주체를 찾아 연습합니다. |

기술 영어에서는 단어를 많이 아는 것만큼 관계를 잘 읽는 것이 중요합니다. `only if`를 충분조건으로 읽거나 `may`를 반드시 일어나는 일로 옮기면, 단어 뜻을 알아도 설계를 잘못 이해할 수 있습니다. 번역한 문장이 원문의 조건과 강도를 유지하는지 먼저 확인합니다.

국어 지문의 문해력과 선택지 판단은 [언어이해·추리논증](../언어이해와추리논증_reading-reasoning/README.md), 사회·경제의 개념은 [인문사회](../인문사회_humanities/README.md)에서 다룹니다. 제2외국어의 학습도 이 분류에 속하며, 현재 완료된 영어 과정과 구분합니다.

## English

The English foundation course contains eight lessons and 64 exercises, with worked examples and expandable answers. It progresses from letters and pronunciation to grammar, vocabulary, reading and writing. Study methods and technical English are separate supporting paths. Second-language study belongs here as well; the completed course currently covers English.
