## 한 글을 공부하는 방법

먼저 설명의 영어 예문을 보면서 주어와 동사를 찾아보십시오. 뜻을 확인한 다음 영어만 다시 읽고, 예문의 주어나 시간 표현 하나를 바꾸어 써보시면 됩니다. 문제를 풀 때에는 정답 상자를 닫아 두고 답을 적습니다. 답을 맞혔더라도 왜 다른 형태가 아닌지 한 문장으로 말해보시면 좋습니다.

틀린 문장은 원래 문장 전체를 한 번 고쳐 쓰고, 무엇이 달라졌는지 표시합니다. 예를 들어 `He don't read.`를 `He doesn't read.`로 고쳤다면 ‘he에는 doesn't를 쓰고 뒤 동사는 원형 read를 둡니다’라고 남깁니다. 설명을 다시 읽은 직후와 다음 날에 각각 풀어보시면 기억한 답과 다시 만들 수 있는 문장을 구분하기 쉽습니다.

영작 문항에는 여러 답이 가능합니다. 해당 문항의 필수 의미와 문법 조건을 만족하면 예시답과 단어가 달라도 인정합니다. 정해진 단어로 배열하거나 선택하라는 문제는 그 조건을 따릅니다. 축약형은 허용한다고 안내한 문항에서 같은 뜻의 완전형과 함께 인정합니다.

## 범위와 참고 자료

이 과정은 영어 전체 문법을 다루지 않습니다. 현재·과거·진행 표현, 간단한 미래 표현과 조동사, 명사·수식·연결의 기초를 완성된 문장으로 연습합니다. 완료 시제·관계절·수동태는 이 과정의 학습 범위에 포함하지 않았습니다. 시험 점수나 학습 기간을 보장하는 자료도 아닙니다.

문법은 British Council의 기초 문법·문법 참고 자료와, 발음 표기는 Oxford Learner’s Dictionaries의 안내를 확인했습니다. 확인일은 2026-10-19입니다. 영어 예문·지문·문항은 이 과정에 맞게 직접 작성했으며 외부 교재의 문제를 옮기지 않았습니다. 음성은 공식 사전의 재생 기능으로 들으실 수 있도록 연결하고 파일을 복제하지 않았습니다.
