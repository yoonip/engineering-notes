## 먼저 확인할 차이

언어이해에서는 문장을 누가 말하는지, 다른 관점과 어떤 관계인지, 선지가 원문의 강도를 유지하는지 살핍니다. 추리논증 6번에서는 서로 다른 지급·청구 관계를 분리하고, 28번에서는 비교에서 유지한 조건과 바꾼 조건을 분리합니다.

선지의 ‘옳음’은 해당 문항이 요구한 범위 안에서의 판단입니다. 소설에 관한 외부 지식, 실제 법제도, 별도의 심리학 연구 결과를 추가해 정답을 바꾸지 않습니다. 특히 6번의 제도는 문제 안의 설정이며 실제 의료분쟁에 대한 법률 안내가 아닙니다.
