# 그림 자료 | Figure assets

[개념도와 편집 원본 / Concept diagrams and editable sources](도식_diagrams/README.md)

[그림 목록](도식_diagrams/그림목록_INDEX.md)에서 그림의 주제, 연결된 해설, PNG·SVG 파일을 함께 찾으실 수 있습니다. 개념을 설명하는 그림과 실행 결과를 그린 수치 그래프는 각각 해당 본문과 생성 코드에 연결되어 있습니다.

수치 그래프는 [기초 예제의 도표 폴더](../예제_examples/공학기초_foundations/figures)에 있으며, [생성 코드](../예제_examples/공학기초_foundations/make_figures.py)와 함께 제공합니다.

Numerical plots are stored with the [foundation examples](../예제_examples/공학기초_foundations/figures), alongside their [generation code](../예제_examples/공학기초_foundations/make_figures.py).

The [figure index](도식_diagrams/그림목록_INDEX.md) connects each subject to its article and PNG/SVG files. Concept diagrams and numerical plots retain links to the relevant explanations or generation code.
