# 미래·경제 보고서 | Future and economic outlooks

기업 연구기관·국책연구소·대학·국제기관의 보고서에서 기술·경제·산업의 변화를 한국어로 읽습니다. 발표 시점과 전망 기간을 함께 적고, 원문의 주장과 전제, 설명을 위해 구성한 계산·사례를 구분합니다.

[보고서 소식](새소식_updates/README.md)에는 공개 기관의 새 자료와 한국어 소개·원문 링크를 날짜별로 모읍니다. 매시간 확인하고 새 자료가 있을 때 반영합니다. 아래 해설은 원문과 전망의 전제를 별도로 검토한 글입니다.
