‘A이면 B’에서 B가 참이라는 이유만으로 A를 결론 내릴 수는 없습니다. A가 거짓인데도 B가 참인 경우를 만들어 보면 이유가 드러납니다. 추론에서는 맞는 예를 여러 개 찾는 일과 주장을 깨뜨리는 반례 하나를 찾는 일을 구분합니다.
