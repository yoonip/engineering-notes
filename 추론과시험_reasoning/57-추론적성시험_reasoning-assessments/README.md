# 추론·독해·적성시험 | Reasoning, Reading and Aptitude Assessments

[전체 분야](../../분야별목차_CATALOG.md) · [추론과 인문·사회](../추론과판단_REASONING_AND_JUDGMENT.md) · [English](#english)

논증을 읽고 조건을 모델링하며 자료의 단위와 비율을 확인합니다. LEET·PSAT와 기업 적성시험의 공식 자료를 구분하고, 실제 기출은 확인한 출처와 문항 번호로 분석합니다.

## 무엇부터 연습하시면 좋을까요

시험 이름부터 외우기보다 틀린 이유를 구분하시면 복습할 지점이 분명해집니다. 조건을 빠뜨렸다면 표와 경우 나누기, 문장에 없는 결론을 더했다면 필요조건·충분조건과 반례, 숫자가 틀렸다면 분모·단위·기준시점부터 다시 확인하시면 됩니다.

| 막히는 지점 | 먼저 해볼 일 | 연결 글 |
| --- | --- | --- |
| “반드시 참”을 고르기 어렵습니다 | 결론이 거짓이어도 조건을 만족하는 경우를 하나 만들어 봅니다 | [형식 논리와 추론](해설_notes/명제와추론_formal-logic-and-inference.md) |
| 순서·자리 조건이 얽힙니다 | 사람·자리·시간을 표의 축으로 정하고 확정 조건을 먼저 표시합니다 | [조건·제약·판단](해설_notes/조건을표로바꾸고반례로확인하기_constraint-and-decision-reasoning.md) |
| 비율 비교에서 실수합니다 | 비율 옆에 분자·분모와 비교 기준을 함께 적습니다 | [자료해석](해설_notes/자료를숫자로읽기_quantitative-data-reasoning.md) |
| 지문의 주장과 근거가 섞입니다 | 결론 한 문장과 이를 지지하는 문장을 따로 적습니다 | [논증 독해](해설_notes/논증독해_argument-reading-and-counterexamples.md) |

예를 들어 `A이면 B`라는 조건과 `B가 참`이라는 정보만으로 A를 확정할 수는 없습니다. `A는 거짓이고 B는 참`인 경우도 원래 조건을 만족하기 때문입니다. 이처럼 정답을 설명하는 문장과 오답을 무너뜨리는 반례를 한 쌍으로 남기시면 같은 실수를 다시 확인하기 쉽습니다. 이 예는 개념 설명을 위한 자체 예제이며 특정 기업의 실제 문항이 아닙니다.

## English

### Start with the reason for an error

A missing condition calls for a constraint table; an unsupported conclusion calls for a counterexample; a numerical error calls for checking denominators, units and reference periods. From “if A then B” and B alone, A does not follow: false A with true B still satisfies the implication. Keep both a justification for the answer and a counterexample to the mistaken inference. This is an explanatory example, not a corporate test question.

Reads arguments, models constraints, and checks units and ratios. Distinguishes official LEET, PSAT and corporate assessment sources and analyzes verified past questions by source and question identifier.
