# 로봇 손과 원격조종 설계를 공개하는 The Robot Studio

확인 기준일: 2026-11-02입니다.

## 기업과 선정 범위

| 항목 | 내용 |
| --- | --- |
| 조직 | The Robot Studio이며 생물의 움직임을 참고한 로봇 하드웨어를 설계·제작하는 전문 스튜디오입니다. |
| 핵심 인물 | 회사와 HOPEJr 저장소는 Rob Knight의 설계 작업을 설명합니다. 확인된 공개 근거 없이 대표의 나이나 현재 법인 직함을 덧붙이지 않습니다. |
| 공개 결과물 | DexHand, Robot Nano Hand, HOPEJr 등의 설계 프로젝트입니다. |
| 선정 이유 | 새로 설립된 기업은 아닙니다. 회사 자체가 오랜 개발 경험을 설명하므로 신생 스타트업과 구분하며, 대기업이 아닌 전문 설계 조직의 공개 하드웨어 사례로 읽습니다. |
| 확인 한계 | 현재 직원 수, 연간 매출, 양산 규모와 법인의 정확한 설립일은 확인하지 못했습니다. |

자료는 [회사 소개](https://www.therobotstudio.com/)와 [직접 운영하는 코드·설계 저장소](https://github.com/TheRobotStudio/HOPEJr)에 근거합니다. 오래 활동했다는 사실을 큰 기업으로 성장했다는 증거로 사용하지 않습니다.

## 어떤 문제를 다루는가

로봇을 연구하려면 알고리즘 외에도 손가락·관절·모터·배선·장착 구조가 필요합니다. 부품이 비싸거나 구조가 비공개이면 작은 팀이 수정·수리·실험하기 어렵습니다. The Robot Studio는 설계 자료를 공개하고 상용 부품과 제작 가능한 구조를 이용해 연구자가 로봇 하드웨어를 다룰 수 있게 하는 방향을 보여 줍니다.

회사 소개는 힘줄과 스프링을 사용한 유연한 움직임을 설명합니다. 힘줄 구동은 모터 힘을 케이블 등으로 손가락에 전달하는 방식입니다. 사람의 손과 비슷한 외형을 만들기 쉽지만 케이블 장력과 마모, 마찰을 관리해야 합니다. 유연한 구조도 사람 옆에서 자동으로 안전해진다는 뜻은 아닙니다.

## 공개된 HOPEJr 자료

[HOPEJr 저장소](https://github.com/TheRobotStudio/HOPEJr)는 전신 개발용 `Humanoid`와 Hugging Face 연동·원격조종을 다루는 `Arm`을 구분합니다. 원래 설계와 이후 협업자의 작업을 한 사람의 단독 성과로 합치지 않아야 합니다. 저장소는 Arm 부분의 최신 작업을 Martino Russi의 Hugging Face 작업으로 설명합니다.

2026년 9월 [참여 개발자의 LeRobot 글](https://huggingface.co/blog/nepyope/bringing-humanoids-to-lerobot)은 외골격으로 사람의 관절 움직임을 측정해 로봇에 옮기는 흐름을 설명합니다. 외골격은 사람이 착용하거나 움직이는 기계 구조입니다. 카메라로 손을 추정하는 대신 관절 움직임을 직접 읽는 접근이며, 보정·제어·학습 연결이 별도로 필요합니다.

공개 설계 파일과 통합 설명은 재현 출발점입니다. 문서에 부품 비용이 제시되더라도 배송·가공·공구·작업 시간·수리 비용을 포함한 완제품 가격으로 읽으면 안 됩니다. 이 글에서는 조립과 실제 동작을 수행하지 않았으며, 전신 보행·장시간 자율 작업의 신뢰성을 확인하지 않았습니다. 하위 폴더와 파일마다 라이선스 적용 범위도 도입 전에 확인해야 합니다.

## 고객·수익과 사업의 난점

회사 홈페이지는 설계 지원, 맞춤 하드웨어, 통합과 제품 개발 서비스를 안내합니다. 연구자·교육기관·개발팀이 고객 후보입니다. 이 서비스의 매출 구성, 공개 프로젝트가 계약으로 전환되는 비율, 표준 키트의 판매 실적은 확인하지 못했습니다. 공개 커뮤니티의 관심과 회사의 이익은 별도 지표입니다.

대안은 다른 공개 로봇 설계, 상용 연구용 로봇과 자체 제작입니다. 공개 하드웨어 사업은 복제 가능성 외에도 지원 요청과 부품 조달의 부담을 다뤄야 합니다. 사용자가 조립할 수 있다는 목표와 다양한 사용자가 실제로 조립·유지할 수 있는 상태에는 차이가 있습니다. 자세한 문서와 고장 진단, 부품 교체가 지속 사업의 일부입니다.

## 창업자가 해볼 수 있는 작은 실험

공개 설계 전체를 복제하는 대신 한 손가락 또는 작은 그리퍼의 구동부를 만들고 반복 개폐 기록을 남기는 실험을 제안합니다. 필요한 공부는 CAD·기구학, C/C++·모터 통신, Python·로깅, 전류·온도·위치 측정입니다. 작업 공간을 고정하고 낮은 힘으로 시작하며 전원을 즉시 끊을 수 있게 구성합니다.

그다음 다른 사람이 문서만 보고 조립·보정할 수 있는지 확인하면 제품화의 어려움을 배울 수 있습니다. 반복 위치 오차, 케이블 재조정 주기, 고장 원인과 조립 시간이 유용한 지표입니다. 앞으로 확인할 지표는 유료 서비스·키트의 현황, 파일별 이용 조건, 소프트웨어 버전 호환성과 장기 유지보수입니다.
