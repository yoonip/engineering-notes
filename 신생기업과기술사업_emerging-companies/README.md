# 신생기업과 기술사업 | Emerging Companies and Technology Ventures

아직 시장 지배력이 굳어지지 않은 국내외 기업이 어떤 문제를 어떤 기술로 풀려 하는지 분석합니다. 창업자의 나이·국적보다 제품의 작동 원리, 공개 구현·실증, 고객의 비용과 남은 과제를 살펴봅니다. 큰 기업으로 성장하기 전의 전문 기술기업도 현재 단계를 밝혀 함께 다룹니다.

각 글은 공개 자료에 근거한 기술·사업 분석입니다. 회사의 설명, 연구 결과, 고객·기관의 확인과 이 글의 해석을 구분합니다. 직접 사용·실측한 리뷰나 투자 추천은 아닙니다. 확인일은 기업별 본문에 표시합니다.

## 창업 관점에서 읽는 경로

- 센서·펌웨어·계측에 관심이 있다면 OpenGraph Labs와 bitsensing에서 측정·검수·현장 적용을 비교합니다.
- 소프트웨어로 시작하려면 Diode, AIM Intelligence, Pebblous, Bifrost AI에서 설계·시험·데이터 작업의 비용을 읽습니다.
- 로봇을 만들고 싶다면 RLWRLD, mimic, AeiROBOT과 공개 설계 비교 사례에서 모델·하드웨어·수집 도구의 역할을 나눠 봅니다.
- 공정·소재에 관심이 있다면 Furno와 Sublime의 시멘트 생산 경로를 비교하고 Molg·Allonnia에서 회수·처리 공정의 고객을 살펴봅니다.
- 우주와 반도체를 연결하려면 Space Forge에서 궤도 실증과 회수·지상 확대·고객 검사의 차이를 읽습니다.

각 회사의 필요한 언어·도구와 첫 실험은 독자의 학습을 위한 제안입니다. 회사가 실제 사용하는 비공개 기술 스택으로 추정하지 않습니다. 새로운 기업과 기존 기업의 중요한 변화는 본문·목록·조사 기록에 이어서 남깁니다.
