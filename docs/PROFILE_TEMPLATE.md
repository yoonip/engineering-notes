# 윤일평 | Yoon IlPyung

저전력 AI 하드웨어와 메모리·연산 구조를 연구해 온 윤일평입니다. 국민대학교 지능형반도체 및 디스플레이 전공으로 석사 학위를 취득했으며, ISL에서 연구했습니다.

65nm SRAM 설계, DRAM-PIM의 RTL 구현, FPGA 기반 계측 자동화를 수행했습니다. AI 모델의 연산·메모리 에너지 분석부터 회로 시뮬레이션, RTL 검증과 하드웨어 제어까지 연결해 연구합니다.

[연구·프로젝트·학술 활동](https://github.com/yoonip/engineering-notes/blob/main/research/README.md) · [engineering-notes](https://github.com/yoonip/engineering-notes) · [분야별 목차](https://github.com/yoonip/engineering-notes/blob/main/CATALOG.md)

| 주제 | 수행 내용 |
