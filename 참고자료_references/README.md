# 출처와 참고 자료 | References

해설을 읽으실 때에는 글별 출처에서 해당 수식과 정의의 근거를 먼저 찾으시면 됩니다. 도구의 사용법을 찾아보실 때에는 아래 분야별 공식 문서를 이용하시면 됩니다.

외부 강의와 공부할 곳을 찾으실 때에는 [학습 사이트와 채널](../학습사이트와채널_learning-resources/README.md)을 이용하시면 됩니다. 이곳의 글별 출처 목록은 각 해설의 수식·정의·주장을 뒷받침하는 자료입니다.

[공식 정기 발간 자료](정기발간자료_periodic-publications.md)는 기술 동향·산업 보고서·보안 공지 등 이미 작성된 자료와 기존 학습 분류를 연결합니다.

## 데이터 형식

JSON에는 글의 경로와 출처 URL을 저장합니다. [출처 문서 생성기](../기여안내_contributing/tools/build_reference_pages.py)는 이 데이터를 읽어 Markdown 목록을 만들고, 연결된 글이 실제로 있는지 검사합니다. 같은 자료를 두 번 수작업으로 관리하지 않으면서 읽기용 문서를 제공하기 위한 구성입니다.

## English

The four readable indexes link article-level sources for foundations, technical topics, advanced studies, and reasoning/humanities. Official documentation is grouped below by use. JSON retains paths and URLs for generation and checks; Markdown is the reading view. Consult the citations beside each definition or equation for the actual scope of support.
