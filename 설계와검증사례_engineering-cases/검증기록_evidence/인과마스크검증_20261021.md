# 인과 마스크와 저장 추론의 CPU 검사 / CPU checks for causal masking and saved inference

실행일은 2026-10-21입니다. 공개 D2·원래 학습 checkpoint를 사용하지 않은 합성 검사입니다. 모델을 학습하지 않았고 임시 checkpoint의 선택 epoch는 0입니다. 기존 GPU 실험은 프로젝트의 `evidence/historical-run-summary.json`, 10월 19일 검사는 `evidence/publication-checks.json`에 있는 과거 기록이며 이번 결과와 구분합니다.

## 환경과 보존

| 항목 | 이번 관측 |
|---|---|
| 운영체제·Python | Windows 11 10.0.26200, Python 3.12.14입니다. |
| 연산 | PyTorch 2.10.0+cpu, CUDA unavailable, CPU thread 1개입니다. |
| 수치·표·학습 보조 | NumPy 2.5.4, pandas 3.0.6, scikit-learn 1.9.1, matplotlib 3.11.2, joblib 1.6.0입니다. |
| Excel | openpyxl 3.1.5입니다. 실제 Microsoft Excel을 실행한 검사는 아닙니다. |
| 난수 조건 | PyTorch seed 17, NumPy default_rng(17), 3×3×32 표준정규 합성 tensor입니다. |
| 저장 fixture | 무학습 모델, feature 3개, 길이 32, h=1·2·4·8, 평균 0·표준편차 1 scaler, 임계값 1.25입니다. |

새 독립 가상환경과 로그는 작업 공간의 `tmp/career-evidence-20261021/causal/`에 두었습니다. 실행 전후 프로젝트의 20개 파일에 대해 상대 경로·길이·SHA-256을 비교했고 차이는 0개였습니다. 공개 소스·기존 요약을 수정하지 않았습니다. 학습·기본 CSV CLI·공분산 실행처럼 고정 results/models 경로를 쓰는 진입점은 호출하지 않았습니다.

첫 실행은 성공했으나 Windows stdout 인코딩으로 일부 한국어 오류 메시지가 깨져 보였습니다. 첫 로그와 run-1을 보존하고 UTF-8을 지정해 별도 run-2로 재실행했습니다. 아래 값은 읽을 수 있는 두 번째 기록입니다. 두 실행을 서로 다른 데이터 실험이나 추가 성능 실적으로 세지 않습니다.

## 관측 결과

[기존 테스트](../../프로젝트_projects/st-awfd-anomaly-triage/tests/test_causal_model.py), [CSV fixture 검사](../../프로젝트_projects/st-awfd-anomaly-triage/tests/test_demo_csv.py), [export 검사](../../프로젝트_projects/st-awfd-anomaly-triage/tests/test_workbook_export.py)의 unittest 9개가 모두 통과했습니다. 임시 폴더 안에서 미래 섭동·NLL 상수·출력 모양·유한 loss·batch 분할 동등성, label-free CSV, Excel과 fallback을 확인했습니다.

| 대조, cutoff | 평균 최대 절대 차이 | logσ 최대 절대 차이 | 불변성 조건 |
|---|---:|---:|---|
| 원본, 0 | 0 | 0 | 만족합니다. |
| 원본, 8 | 0 | 0 | 만족합니다. |
| 원본, 24 | 0 | 0 | 만족합니다. |
| 메모리 복사본에서 mask 제거, 24 | 0.42551445960998535 | 0.28253430128097534 | 위반을 검출했습니다. |
| 메모리 복사본에서 대칭 패딩, 24 | 0.9613834619522095 | 1.3633123636245728 | 위반을 검출했습니다. |

후자의 위반은 의도적으로 넣은 대조 조건입니다. 추적 소스의 과거 결함을 찾아 수정한 기록이 아닙니다. 원본과 대조는 같은 모델 상태·합성 입력으로 비교하며, 함수는 cutoff 이후에만 3을 더합니다. 판정은 평균·logσ 차이가 모두 10⁻⁶ 미만인지 확인합니다.

저장 fixture의 SHA-256은 `b17458edc4101b55e1d3d247748d76bc38d4df13aa77c6bba11390331d9d5e21`이며 실행 후 같습니다. 합성 3 lot의 직접 점수와 `score_new_csv` 점수의 최대 차이는 0입니다. target·is_test 열을 추가한 결과도 정확히 같고 결과에는 두 열이 없습니다. 검토 비율 10%에서 1개를 선택하고 임계값 1.25를 유지했습니다.

입력의 feature 누락·중복 시각·NaN·Step 1 없는 lot, checkpoint의 0인 표준편차·다른 horizons를 각각 만들어 여섯 ValueError를 확인했습니다. 이 확인은 나열한 조건에 한정하며 모든 종류의 손상 파일·보안 위협을 검사한 결과가 아닙니다.

## 재현

아래 명령은 저장소 루트 기준입니다. Python 3.12를 준비하고, 아래 probe 코드를 프로젝트 밖의 `causal-probe.py`로 저장하십시오. `$probeScript`에는 그 실제 경로를 넣습니다. 실행마다 새 임시 출력 폴더 이름을 사용하며 probe가 이미 존재하는 출력 폴더는 거부합니다. 설치 환경도 기존 프로젝트의 환경과 분리합니다.

```powershell
$envDir = Join-Path $env:TEMP ('causal-env-' + [guid]::NewGuid().ToString('N'))
python -m venv $envDir
$casePython = Join-Path $envDir 'Scripts/python.exe'
& $casePython -m pip install --index-url https://download.pytorch.org/whl/cpu torch==2.10.0
& $casePython -m pip install numpy==2.5.4 pandas==3.0.6 scikit-learn==1.9.1 matplotlib==3.11.2 joblib==1.6.0 openpyxl==3.1.5
$env:PYTHONIOENCODING = 'utf-8'
$probeScript = Join-Path $env:TEMP 'causal-probe.py'
$runDir = Join-Path $env:TEMP ('causal-check-' + [guid]::NewGuid().ToString('N'))
& $casePython -B $probeScript --project './프로젝트_projects/st-awfd-anomaly-triage' --output $runDir
```

아래 코드는 이번 private probe와 같습니다. 원본 모델을 import하고 오류 조건은 메모리 복사본에만 적용합니다. `.pt`는 자체 만든 fixture만 읽습니다. 원래 프로젝트의 데이터 다운로드나 학습은 호출하지 않습니다.

"""Read source; write synthetic CPU evidence only under the chosen private output."""
from __future__ import annotations
import argparse
import copy
import csv
import hashlib
import importlib.metadata
import os
from pathlib import Path
import platform
import subprocess
import sys
import types

parser = argparse.ArgumentParser()
parser.add_argument("--project", type=Path, required=True)
parser.add_argument("--output", type=Path, required=True)
args = parser.parse_args()
project = args.project.resolve()
output = args.output.resolve()
if output == project or project in output.parents:
    raise ValueError("Probe output must stay outside the source project.")
output.mkdir(parents=True, exist_ok=False)
for name in ("temp", "mpl"):
    (output / name).mkdir()
os.environ.update(TEMP=str(output / "temp"), TMP=str(output / "temp"), MPLCONFIGDIR=str(output / "mpl"), PYTHONDONTWRITEBYTECODE="1", CUDA_VISIBLE_DEVICES="")
sys.dont_write_bytecode = True
sys.path.insert(0, str(project))

import numpy as np
import pandas as pd
import torch
from torch.nn import functional as F
from st_awfd_model import CausalMultiHorizonGPT, causal_invariance_audit, score_signals
import st_awfd_causal_gpt_multihorizon as gpt

torch.set_num_threads(1)
torch.manual_seed(17)
device = torch.device("cpu")
assert not torch.cuda.is_available(), "This probe records a CPU-only wheel."
print("python", sys.version, flush=True)
print("executable", sys.executable, flush=True)
print("platform", platform.platform(), flush=True)
print("cpu", platform.processor(), flush=True)
for package in ("torch", "numpy", "pandas", "scikit-learn", "matplotlib", "joblib", "openpyxl"):
    print(package, importlib.metadata.version(package), flush=True)
print("cuda_available", torch.cuda.is_available(), flush=True)
print("threads", torch.get_num_threads(), flush=True)

unit = subprocess.run([sys.executable, "-B", "-m", "unittest", "discover", "-s", str(project / "tests"), "-v"], cwd=project, env=os.environ.copy(), stdout=subprocess.PIPE, stderr=subprocess.STDOUT, text=True, encoding="utf-8", errors="replace")
(output / "unit-tests.log").write_text(unit.stdout, encoding="utf-8")
print("unit_exit", unit.returncode, flush=True)
if unit.returncode:
    raise RuntimeError("Existing regression suite failed; see unit-tests.log.")

model = CausalMultiHorizonGPT(feature_count=3, sequence_length=32).eval()
signals = np.random.default_rng(17).normal(size=(3, 3, 32)).astype(np.float32)
rows = []
for cutoff in (0, 8, 24):
    audit = causal_invariance_audit(model, signals[0], device, cutoff=cutoff)
    assert audit["passes_strict_causal_invariance"]
    rows.append({"variant": "unchanged_source", "cutoff": cutoff, **audit})

maskless = copy.deepcopy(model)
original_decoder = maskless.decoder.forward
def without_mask(self, src, mask=None, **kwargs):
    return original_decoder(src, mask=None, is_causal=False)
maskless.decoder.forward = types.MethodType(without_mask, maskless.decoder)

symmetric = copy.deepcopy(model)
def centered_embedding(self, values):
    projected = F.conv1d(values, self.conv.weight, self.conv.bias, padding=2).transpose(1, 2)
    return self.activation(self.norm(projected))
symmetric.embedding.forward = types.MethodType(centered_embedding, symmetric.embedding)

for name, altered_model in (("mask_removed_in_memory", maskless), ("symmetric_padding_in_memory", symmetric)):
    audit = causal_invariance_audit(altered_model, signals[0], device, cutoff=24)
    assert not audit["passes_strict_causal_invariance"], "Negative control must be rejected."
    rows.append({"variant": name, "cutoff": 24, **audit})
with (output / "causal-controls.csv").open("w", encoding="utf-8", newline="") as handle:
    writer = csv.DictWriter(handle, fieldnames=list(rows[0]))
    writer.writeheader()
    writer.writerows(rows)
for row in rows:
    print("causal", row, flush=True)

checkpoint = {"state_dict": model.state_dict(), "feature_count": 3, "sequence_length": 32, "horizons": [1, 2, 4, 8], "scaler": {"feature_mean": [0.0]*3, "feature_std": [1.0]*3}, "normal_reference_limit": 1.25, "best_epoch": 0, "causal_embedding": True}
checkpoint_path = output / "untrained_fixture.pt"
torch.save(checkpoint, checkpoint_path)
checkpoint_hash = hashlib.sha256(checkpoint_path.read_bytes()).hexdigest()
records = []
for lot_index, identifier in enumerate((101, 102, 103)):
    for step, time in enumerate(np.linspace(0.0, 1.0, 32)):
        records.append({"MaterialID": identifier, "StepID": 1, "duration_ms": time, **{f"feature_{i+1}": float(signals[lot_index, i, step]) for i in range(3)}})
incoming = pd.DataFrame(records)
clean_path = output / "synthetic-label-free.csv"
incoming.to_csv(clean_path, index=False)
result = gpt.score_new_csv(clean_path, checkpoint_path)
result.to_csv(output / "synthetic-review-queue.csv", index=False)
features = ["feature_1", "feature_2", "feature_3"]
resampled, _, ids, _ = gpt.baseline.resample_step_one(incoming, features, sequence_length=32)
direct_scores, _, _ = score_signals(model, resampled, device)
expected = pd.Series(direct_scores, index=ids)
loaded = result.set_index("MaterialID")["anomaly_score"].reindex(ids)
delta = float(np.max(np.abs(loaded.to_numpy() - expected.to_numpy())))
np.testing.assert_allclose(loaded.to_numpy(), expected.to_numpy(), rtol=1e-5, atol=1e-6)
assert set(result["normal_reference_limit"]) == {1.25}
assert int(result["review_candidate_at_capacity"].sum()) == 1
assert "target" not in result and "is_test" not in result
labelled = incoming.assign(target=np.arange(len(incoming)) % 2, is_test=1)
labelled_path = output / "synthetic-extra-labels.csv"
labelled.to_csv(labelled_path, index=False)
labelled_result = gpt.score_new_csv(labelled_path, checkpoint_path)
pd.testing.assert_frame_equal(result, labelled_result, check_exact=True)

def must_reject(name, frame=None, changed_checkpoint=None):
    selected_path = clean_path
    saved_path = checkpoint_path
    if frame is not None:
        selected_path = output / f"invalid-{name}.csv"
        frame.to_csv(selected_path, index=False)
    if changed_checkpoint is not None:
        saved_path = output / f"invalid-{name}.pt"
        torch.save(changed_checkpoint, saved_path)
    try:
        gpt.score_new_csv(selected_path, saved_path)
    except ValueError as error:
        print("expected_rejection", name, type(error).__name__, str(error), flush=True)
        return
    raise AssertionError(f"Invalid fixture was accepted: {name}")

must_reject("missing-feature", incoming.drop(columns="feature_3"))
must_reject("duplicate-time", pd.concat([incoming, incoming.iloc[[0]]], ignore_index=True))
nan_frame = incoming.copy()
nan_frame.loc[0, "feature_1"] = np.nan
must_reject("nonfinite", nan_frame)
missing_step = incoming.copy()
missing_step.loc[missing_step["MaterialID"] == 101, "StepID"] = 2
must_reject("missing-step", missing_step)
invalid_scale = copy.deepcopy(checkpoint)
invalid_scale["scaler"]["feature_std"][0] = 0.0
must_reject("nonpositive-scale", changed_checkpoint=invalid_scale)
invalid_horizon = copy.deepcopy(checkpoint)
invalid_horizon["horizons"] = [1, 2]
must_reject("wrong-horizons", changed_checkpoint=invalid_horizon)
assert hashlib.sha256(checkpoint_path.read_bytes()).hexdigest() == checkpoint_hash
print("checkpoint_sha256", checkpoint_hash, flush=True)
print("checkpoint_unchanged", True, flush=True)
print("synthetic_roundtrip_max_abs_score_delta", delta, flush=True)
print("synthetic_lots", len(result), "selected_epoch", result.attrs["selected_epoch"], flush=True)
print("extra_labels_ignored_exactly", True, flush=True)
print("rejected_invalid_fixtures", 6, flush=True)
print("all_probe_assertions_passed", True, flush=True)

## 읽은 코드와 해석 범위

[모델](../../프로젝트_projects/st-awfd-anomaly-triage/st_awfd_model.py), [전처리·CNN](../../프로젝트_projects/st-awfd-anomaly-triage/st_awfd_pipeline.py), [학습·저장 추론](../../프로젝트_projects/st-awfd-anomaly-triage/st_awfd_causal_gpt_multihorizon.py), [공분산 점수](../../프로젝트_projects/st-awfd-anomaly-triage/st_awfd_gpt_covariance_audit.py), [Excel 출력](../../프로젝트_projects/st-awfd-anomaly-triage/workbook_export.py)과 세 테스트 파일·기존 요약을 대조했습니다. 이번 실행은 전체 Streamlit 앱·GPU 재학습·공개 데이터 정확도·실설비를 검사하지 않았습니다. checkpoint round-trip의 byte hash와 수치 동등성도 이번 무학습 fixture의 결과이며 과거 모델 파일을 다시 읽은 결과가 아닙니다.

[PyTorch 2.10 Transformer](https://docs.pytorch.org/docs/2.10/generated/torch.nn.Transformer.html)의 Boolean mask 의미, [Conv1d](https://docs.pytorch.org/docs/2.10/generated/torch.nn.Conv1d.html)의 padding·출력 정의, [TransformerEncoder](https://docs.pytorch.org/docs/2.10/generated/torch.nn.TransformerEncoder.html)의 mask 전달 설명을 확인했습니다. 라이브러리 문서는 API 의미의 근거이며 모델이나 실제 제조 과제의 성능 보장은 아닙니다.
