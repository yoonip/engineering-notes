# 칩 산술과 시험 자료의 실행 기록 / Arithmetic and test-data replay, 2026-10-21

## 실행 대상과 환경

2026-10-21에 CPython 3.12.14, Windows AMD64에서 [재현 실행기](../../예제_examples/실무검증_practical-validation/chip/run_chip_cases.py)를 실행했습니다. 표준 라이브러리만 사용했으며 물리 칩·ATE·DDR PHY·계측기·RTL·CMSIS-NN은 실행하지 않았습니다. 아래 CSV와 tap은 합성 입력입니다.

기존 `practical-silicon-lab`의 `npu.py`, `correlation.py`, `training_ber.py`를 그대로 import했습니다. 기준 저장소의 검토 시작 commit은 `30af797`입니다. 실행기는 기존 파일에 결과를 저장하지 않고 지정한 새 출력 폴더에 JSON·CSV를 만듭니다.

## 명령과 판정

저장소 루트에서 실행합니다. `OUT_A`는 아직 없는 경로로 바꿉니다. 두 번째 명령은 일부러 같은 경로를 지정한 보존 확인입니다.

```shell
python -B 예제_examples/실무검증_practical-validation/chip/run_chip_cases.py --out OUT_A
python -B 예제_examples/실무검증_practical-validation/chip/run_chip_cases.py --out OUT_A
```

| 실행 | 관측 | 종료 코드 |
|---|---|---:|
| 새 출력 경로 | `status=PASS`, checks 44, failed 0, unexpected error 없음 | 0 |
| 같은 출력 경로 | 기존 경로 거부, 첫 실행 결과 hash 보존 | 2 |
| 기존 offline 시험 | 19 tests, 19 PASS, 실패·오류·skip 0 | 0 |

기존 시험은 `프로젝트_projects/practical-silicon-lab`에서 `python -B tests/test_offline.py --report OUTSIDE_PROJECT/report.json`으로 따로 실행했습니다. 보고서 상위 폴더는 미리 존재해야 합니다. 기존 19개에는 동일 NPU·CSV·tap 동작을 확인하는 항목도 있으므로 새 44개와 더해 63종 독립 기능 coverage로 표시하지 않습니다.

전체 PASS는 의도한 오류를 검출했다는 뜻입니다. 잘못된 DUT의 `dut_status=FAIL`, 잘못된 CSV의 예상 `ValueError`는 원래 판정대로 보존합니다. 예상 밖 예외는 별도 `unexpected_error`와 전체 FAIL로 기록하도록 했으며 이번 실행에는 없었습니다.

## 해석의 한계

고정 입력의 손계산은 해당 연산 계약을 확인합니다. 모든 커널 크기, 채널, scale·반올림 정책이나 실제 메모리 일관성은 포함하지 않습니다. CSV 정답은 합성 생성 규칙이므로 고객 불량·생산 수율·실제 출하 DPPM으로 읽지 않습니다. 1차원 tap 선택은 물리 eye·BER 또는 2차원 영역 탐색의 검증이 아닙니다. 시간 성능, 계측 불확실성, 칩의 PVT 분포도 측정하지 않았습니다.
