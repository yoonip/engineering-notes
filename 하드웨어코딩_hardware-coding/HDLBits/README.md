## 코드와 설명을 읽는 방법

각 폴더의 solution.v는 사이트에 제출한 회로입니다. tb.sv는 독립 기대값과 비교하는 로컬 테스트벤치이며 제출 코드에 포함하지 않습니다. README에는 포트·원리·입력에서 출력까지의 흐름과 주석을 단 소스 전체를 담았습니다. problem.json에는 출처, 소스 해시, 도구 버전, 실제 명령과 검사 범위를 기록합니다.

비트 수가 작아 전 조합을 검사한 회로와 제한된 벡터를 검사한 회로를 구분합니다. 32비트 바이트 변환과 100비트 멀티플렉서는 가능한 전체 입력을 열거한 결과가 아닙니다. 리셋이 없는 변화 검출기는 최초 상태의 X와 워밍업 이후의 검사를 구분합니다.

## 실행과 판정

[통합 실행 방법](../README.md#검증과-재실행)으로 로컬 검사를 다시 수행합니다. 실제 사이트 판정은 [채점 화면과 해시](확인기록_online-grading.md), 로컬 결과는 [실행 기록](../확인기록_validation.md)에서 확인합니다. 온라인 테스트의 통과는 모든 가능한 입력·물리 타이밍·실물 보드 동작에 대한 증명과 구분합니다.
