# 열·전력·물을 공급하는 기술 / Technologies for heat, electricity and water

좋은 재료나 장치가 실제 공급 서비스로 이어지려면 시공·운영·전력망·인허가와 계약이 맞아야 합니다. 아래 글들은 작동 원리와 경쟁 방식, 자체 계산, 실제 발표·현장 연구의 범위를 함께 다룹니다. 기준일은 2026년 10월 20일입니다.

직접 사용·계량한 리뷰가 아니라 문헌 분석입니다. 제조사·사업자의 사양과 발표, 독립 기관의 시험·검토, 공공 연구의 예측을 구분합니다. 다른 지역·제품의 현장 결과를 해당 제품의 보증치로 쓰지 않았습니다. 원시자료를 재분석하지 않은 범위도 각 글에 적었습니다.

비용을 읽을 때는 초기 투자와 운영 비용, 전력량과 출력, 정격과 실제 가동, 장치와 최종 서비스의 경계를 먼저 확인하시면 됩니다. 예를 들어 열출력과 순전력, 막 단계 전력과 최종 송수 전력은 같은 숫자가 아닙니다.
