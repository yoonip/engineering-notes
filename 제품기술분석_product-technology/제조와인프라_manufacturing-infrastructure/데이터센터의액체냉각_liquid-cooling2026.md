# 데이터센터 액체 냉각: 열을 어디까지 옮기나요 / Liquid cooling in data centres

기준일은 2026-10-20입니다. Lenovo Neptune의 직접 수랭과 Submer SmartPod EXO의 액침을 사례로, 공랭·후면 열교환기와 비교합니다. 제조사 기술 문서와 OCP 공개 설명, NREL의 현장 연구 요약을 읽었으며 직접 설치하거나 누수·전력·온도 시험을 수행하지 않았습니다.


~~~mermaid
flowchart LR
    A[CPU·GPU 발열] --> B[콜드플레이트]
    B --> C[시설수 냉각수 순환]
    C --> D[CDU 열교환기]
    D --> E[건물 냉각 설비]
    E --> F[외부로 열 방출]
    D --> C
~~~

그림 1. 직접 수랭 데이터센터에서 칩의 열을 건물 냉각 설비로 옮기는 일반 흐름입니다. 특정 서버 랙이나 Lenovo·Submer 제품의 실제 배관 배치도는 아닙니다.

## 냉각은 열을 없애지 않고 옮깁니다

CPU와 GPU가 소비한 전력의 대부분은 시설 안에서 열로 나옵니다. 냉각판을 붙였다고 열이 없어지는 것은 아닙니다. 칩에서 냉각수로, 냉각수에서 건물의 열 배출 설비로 옮긴 뒤 외부로 내보내거나 활용합니다. 부품 온도가 낮다는 사실과 건물 전체의 에너지·물 사용량이 작다는 사실은 따로 측정해야 합니다.

공기는 팬으로 부품 표면의 열을 나릅니다. 액체는 같은 부피의 흐름으로 더 많은 열을 운반할 수 있어 고밀도 장비에서 유용합니다. 하지만 물이 회로에 직접 닿아도 된다는 뜻은 아닙니다. 직접 수랭은 칩 위 냉각판 안의 통로에 유체가 흐르고, 전자부품과 유체 사이에 구조적 경계가 있습니다. 액침은 전기 절연성을 갖춘 적합한 유체에 장비를 담그는 방식입니다.

| 방식 | 열이 이동하는 경로 | 도입 때 확인할 점 |
|---|---|---|
| 공랭 | 칩 → 방열판 → 공기 | 팬 전력, 공기 흐름, 랙 밀도 |
| 후면 열교환기(RDHx) | 장비가 덥힌 공기 → 랙 뒤 열교환기 → 물 | 장비 내부의 공랭, 배관 설치, 문이 견뎌야 할 하중 |
| 직접 수랭 | 칩 → 냉각판 → 유체 | 일부 부품의 잔열, 누수 감지, 접속부와 수질 |
| 단상 액침 | 부품 → 끓지 않는 절연 유체 → 열교환기 | 재료 적합성, 장비 보증, 인양과 정비 방식 |
| 2상 액침(two-phase) | 부품 → 유체의 기화 → 응축기 | 유체 특성, 압력·밀폐·응축 설계 |

‘액체 냉각’이라는 공통 이름으로 직접 수랭과 두 액침 방식을 같은 장비로 취급하지 않습니다. 이 글의 Submer 단상 액침 사례를 2상 액침 시스템에 그대로 적용할 수는 없습니다.

## CDU와 두 개의 순환 회로

CDU는 coolant distribution unit, 냉각 유체를 분배하고 열을 교환하는 장치입니다. 흔한 구성에서는 서버 쪽 회로 TCS와 건물 쪽 회로 FWS가 열교환기로 구분됩니다. 두 물이 직접 섞이지 않아 수질과 압력 조건을 다르게 유지할 수 있습니다. 제조사별 허용 유체와 압력·온도 조건을 맞춰야 하며, 단순히 같은 지름의 호스를 연결한다고 호환되는 것은 아닙니다.

[OCP Cold Plate 프로젝트](https://www.opencompute.org/projects/cooling-environments/cold-plate/)는 직접 액체 냉각의 인터페이스와 지침, 열린 생태계를 추진합니다. 프로젝트가 있다는 사실이 모든 제조사 제품의 현장 호환 인증을 뜻하지는 않습니다. 커넥터, 씰, 금속, 유체의 화학적 적합성과 운전 관리가 함께 맞아야 합니다.

[Lenovo 기술 문서 LP2018](https://lenovopress.lenovo.com/lp2018-lenovo-neptune-direct-water-cooling-standards)은 회로 분리, 냉각 단계별 예제, 수질·재료 관리 조건을 제시합니다. 이 분석에서는 PDF 2–5·7–9·13–14쪽을 읽었습니다. 문서의 Gold·Silver·Bronze는 Lenovo가 구성한 등급이므로 전체 산업의 공통 성능 등급으로 적지 않습니다.

특히 ‘100% 열 추출’이라는 솔루션 제목을 보고 GPU 냉각판만으로 모두 회수한다고 이해하면 안 됩니다. 문서의 H200 예시는 냉각수와 공기에 나뉘는 열을 적고 후면 열교환기를 포함해 잔열까지 회수합니다. 같은 Neptune 이름 안에서도 부품 구성과 별도 공기 냉각의 필요가 다릅니다. 물의 온도를 높여 냉동기 사용을 줄일 가능성도 부품 허용 온도와 외기, 열교환기의 조건 안에서 평가합니다.

## 액침의 장점과 교환 조건

[SmartPod EXO 공개 사양](https://submer.com/smartpod/exo/)은 모델·운전 조건에 따라 최대 361kW의 방열 용량과 이중화 구성 등을 제시합니다. 이 용량을 모든 환경에서 측정한 결과로 읽거나 ‘이중화가 있으므로 실제 99.999% 가동률이 확인됐다’고 바꾸지는 않습니다. 이중화는 설계 조건이고 실제 가용성은 고장 빈도·수리 시간·공통 원인 고장과 관찰 자료가 필요합니다.

액침은 보드의 여러 발열 부위를 유체에 연결할 수 있지만, 모든 일반 서버를 그대로 담그는 방식은 아닙니다. 유체가 케이블 피복·접착제·씰과 장기간 접촉할 때의 변화, 커넥터 정비, 잔류 유체, 부품 교체와 폐유체 처리를 검토해야 합니다. 냉각 방식이 바뀌면 랙 설치와 유지보수 인력의 작업 흐름도 달라집니다.

## 열량으로 필요한 유량을 계산합니다

아래는 장비 권장 설정이 아닌 자체 기초 계산입니다. 순수 물의 비열을 4.18kJ/(kg·K)로 일정하게 놓고 100kW의 열을 받아 물의 온도가 10K 오른다고 가정합니다. 비열은 질량 1kg의 온도를 1K 높이는 데 필요한 에너지입니다.

```math
\dot Q=\dot m c_p\Delta T,\qquad
\dot m=\frac{100}{4.18\times10}\approx2.392\ \mathrm{kg/s}
```

밀도를 1kg/L로 근사하면 약 143.54L/min입니다. 같은 열량에서 온도 차를 5K로 줄이면 필요한 질량 유량은 두 배입니다. 실제 냉각액은 물과 글리콜의 혼합 여부, 온도에 따라 비열·밀도·점도가 달라집니다. 이 한 식으로 배관 압력 손실이나 칩의 최고 온도를 결정할 수는 없습니다.

펌프도 전기를 씁니다. 자체 예로 압력 차 100kPa, 체적 유량 0.002m³/s라면 유체에 전달하는 동력은 `Δp×유량=200W`입니다. 펌프 효율을 50%로 가정하면 전기 입력은 400W입니다. 팬을 줄였다는 설명에서 펌프와 건물 쪽 설비 전력을 빼면 시스템 비교가 달라집니다.

## PUE·WUE의 분모와 측정 경계를 읽습니다

PUE는 같은 측정 기간의 시설 총에너지를 IT 장비 에너지로 나눈 값입니다. 자체 예에서 그 기간의 IT 평균 전력이 1MW이고 PUE가 1.3이면 시설 평균 전력은 1.3MW입니다. 다른 기간의 IT 평균 전력이 2MW이고 PUE가 1.1이면 시설 평균 전력은 2.2MW입니다. PUE가 낮아져도 시설 평균 전력은 늘었습니다. 계산량과 서비스 품질까지 맞추지 않으면 업무당 에너지 절감을 알 수 없습니다.

WUE도 물 사용의 범위와 분모를 표시해야 합니다. 내부 냉각수가 순환한다고 건물 외부 냉각탑의 증발수까지 0이 되는 것은 아닙니다. 현장의 직접 물 사용과 전력 생산 과정의 간접 물 사용도 구별합니다. 건식 냉각은 물을 덜 쓸 수 있지만 외기와 온도 조건에 따라 필요한 전력·열교환 면적이 달라집니다.

[NREL의 2018년 24개월 현장 연구 기록](https://research-hub.nlr.gov/en/publications/thermosyphon-cooler-hybrid-system-for-water-savings-in-an-energy-/)은 따뜻한 물을 쓰는 HPC 시설에 기존 냉각탑과 thermosyphon 장치를 조합한 결과를 설명합니다. 이 분석에서 읽은 범위는 기관이 공개한 서지 정보와 초록이며, 22쪽 보고서 본문 전체가 아닙니다. 첫해 WUE 0.70L/kWh는 측정값이고, 기존 구성만 유지했다면 1.27L/kWh였으리라는 값은 추정 비교입니다. 별도 두 시설을 같은 조건에서 실측한 결과가 아닙니다. 이 연구는 Lenovo와 Submer의 동일 조건 대결 시험도 아닙니다.

## 산업적 비용과 지역의 조건

액체 냉각의 도입에는 냉각판 외에 CDU, 배관, 바닥·하중 검토, 외부 열 배출, 감지·제어, 예비품, 교육 비용이 듭니다. 새 시설은 배치를 함께 설계할 수 있지만 기존 센터는 영업을 유지하며 공사해야 할 수 있습니다. 공급자가 제공하는 검증된 묶음은 책임 소재를 줄이는 가치가 있으며, 특정 유체·커넥터·서비스 조합만 승인되면 전환 비용도 생깁니다.

수요자는 IT 장비 수명과 건물 설비 수명이 다르다는 점도 살펴야 합니다. 다음 세대 장비가 더 많은 유량이나 다른 온도를 요구할 때 기존 CDU와 배관을 활용할 수 있는지, 복수 공급자의 냉각 장비를 같은 시설 관리 시스템에서 진단할 수 있는지 확인해야 합니다. 표준화는 이런 선택권을 넓히지만 재료 검증과 실제 운영 경험을 생략해 주지는 않습니다.

지역 사회의 관점에서는 전력망·물 자원·소음·폐열 수요가 함께 중요합니다. 폐열 회수는 근처 수요처와 온도·계절·배관 비용이 맞아야 합니다. ‘회수 가능한 열’ 전체가 실제 판매된 난방 에너지는 아닙니다. 비교에는 연간 부하, 기후, 물의 제약, 서비스 중단 비용까지 포함한 자료가 필요합니다.

## 유량과 칩 온도를 같은 숫자로 보지 않습니다

열저항은 열이 흐를 때 생기는 온도 차를 열량의 속도로 나눈 값입니다. 단위 K/W는 1W의 열을 옮길 때 온도 차가 몇 K 생기는지 나타냅니다. 접합부에서 냉각액까지의 열저항을 가상으로 0.02K/W, 부품 발열을 1,000W라고 두면 온도 차는 20K입니다. 냉각액의 해당 기준 온도가 40°C라면 이 단순 모형의 접합부는 60°C입니다.

하지만 출구 물 온도, 입구 물 온도, 냉각판 내부의 대표 온도는 서로 다릅니다. 실제 열저항의 정의와 유량 조건을 맞추지 않고 아무 물 온도에 20을 더할 수는 없습니다. 접촉 재료·압력·온도 분포도 영향을 줍니다. 유량을 높이면 유체 쪽 저항을 줄일 수 있어도 패키지 내부와 접촉부의 저항까지 모두 0이 되지는 않습니다.

열용량은 과도 상태를 이해하는 다른 값입니다. 가상 열용량 10kJ/K인 부분에서 방열이 잠시 완전히 중단되고 1kW가 계속 들어오면, 다른 경로를 생략한 온도 상승률은 0.1K/s입니다. 30초에 3K가 오릅니다. 실제 시스템의 국소 칩 온도와 건물 전체 물탱크는 시간 척도가 다르므로 큰 물탱크가 있다고 모든 부품을 같은 시간 동안 보호한다고 볼 수 없습니다.

이런 구분은 경보와 유지보수 계약에도 연결됩니다. 평균 환수 온도 하나가 정상이어도 특정 채널이 막히거나 한 부품의 접촉이 나빠질 수 있습니다. 제조사가 제공하는 센서 위치·경보·정지 규칙과 고객의 시설 제어가 어떻게 연결되는지 확인해야 합니다. 효율만큼 오류를 발견하고 영향을 제한하는 능력이 산업용 냉각의 가치입니다.

2. 내부 순환 회로가 닫혀 있으면 냉각탑 증발수도 반드시 0인가요?
