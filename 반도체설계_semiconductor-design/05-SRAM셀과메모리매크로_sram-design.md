# 6T SRAM 셀의 읽기·쓰기와 메모리 매크로 설계

확인일: 2026-10-26

SRAM은 전원이 공급되는 동안 되먹임 회로로 값을 유지하는 메모리입니다. 한 비트를 저장하는 셀과, 주소·데이터·제어 핀으로 접근하는 메모리 매크로를 구분하면 설계 흐름을 이해하기 쉽습니다. 셀 하나가 안정적이어도 긴 배선과 많은 셀을 연결한 매크로가 정해진 시간에 읽고 쓰인다는 보장은 없습니다.

이 글은 일반적인 단일 포트 6T 셀을 기준으로 원리와 확인 방법을 설명합니다. 제품별 셀 구조, 소자 치수나 assist 전압을 추정하지 않습니다. 공개 문서에 근거한 설명과 직접 구성한 계산 예이며 실제 SRAM을 생성·실행·측정한 결과는 아닙니다.

## 1. 여섯 개 트랜지스터가 한 비트를 기억하는 방법

6T의 T는 transistor입니다. CMOS 인버터 두 개가 서로의 출력을 입력으로 받으며, 두 개의 접근 NMOS가 저장 노드를 비트라인에 연결합니다. 총 PMOS 두 개와 NMOS 네 개입니다. 안정된 상태에서 저장 노드 Q와 QB는 서로 반대 값입니다. MIT 6.111 강의의 6T 회로는 이 되먹임과 두 비트라인을 이용한 접근을 보여 줍니다. [MIT OCW, Memory Basics and Timing, 2006, 슬라이드 5](https://ocw.mit.edu/courses/6-111-introductory-digital-systems-laboratory-spring-2006/499fae5e27b58a4b28605923aebe210e_lec7.pdf)

| 소자·신호 | 역할 |
| --- | --- |
| Pull-up PMOS, PU | 저장 노드의 높은 전압을 유지합니다. |
| Pull-down NMOS, PD | 반대 저장 노드의 낮은 전압을 유지합니다. |
| Access NMOS, PG | 워드라인이 켜질 때 Q·QB를 각각 BL·BLB에 연결합니다. |
| Wordline, WL | 선택한 행의 접근 소자를 제어합니다. |
| Bitline pair, BL·BLB | 열 방향으로 읽기 신호를 전달하고 쓰기 값을 공급합니다. |

Q=1, QB=0인 상태에서는 QB가 연결된 인버터가 Q를 높게, Q가 연결된 인버터가 QB를 낮게 유지합니다. 외부 입력이 계속 값을 밀어 넣지 않아도 되먹임이 상태를 유지합니다. 다만 전원 차단 뒤의 상태는 보장되지 않으며 전원이 켜진 직후 어떤 값인지도 별도 초기화 없이는 정해지지 않습니다.

‘정적’이라는 이름은 주기적인 전하 복원을 요구하는 DRAM과 구분하는 말입니다. 전류가 항상 0이라는 뜻은 아닙니다. 누설 전류, 비트라인 사전 충전과 접근 시의 충·방전 전력이 있습니다. 일반적인 셀에는 클록 핀이 없지만, 이 셀을 포함한 매크로는 입력을 클록에 맞추어 받아 내부 WL·감지 신호를 생성할 수 있습니다.

## 2. Hold: 접근하지 않을 때의 상태 유지

Hold에서는 WL을 비활성으로 두어 셀을 비트라인에서 분리합니다. 두 인버터가 높은 값과 낮은 값을 유지하는지, 전원을 낮추거나 불일치를 넣어도 상태가 유지되는지 확인합니다. 전원을 낮추면 누설 전력을 줄일 수 있지만 상태를 유지하는 여유도 줄어들 수 있습니다.

시험에서는 처음에 0을 쓴 경우와 1을 쓴 경우를 모두 다룹니다. 두 저장 노드가 완전히 대칭이라는 가정은 소자 불일치와 레이아웃 이후에는 성립하지 않을 수 있습니다. 저장값이 그대로라는 판단에는 Q·QB의 전압 범위와 관찰 시간을 명시합니다. 초기값만 설정하고 아주 짧게 관찰한 결과로 장시간 저전압 유지 특성을 대신하지 않습니다.

## 3. Read: 비트라인을 움직이면서 셀은 보존하기

전형적인 차동 읽기는 BL·BLB를 높은 전압으로 사전 충전하고 두 선을 같은 전압으로 맞추는 것으로 시작합니다. 사전 충전을 해제하고 WL을 올리면, 0을 저장한 쪽에서 접근 NMOS와 PD를 거쳐 비트라인의 전하가 빠져나갑니다. 두 비트라인에 생긴 작은 차이를 감지 증폭기가 판정합니다. [MIT OCW, Memory Basics and Timing, 슬라이드 5](https://ocw.mit.edu/courses/6-111-introductory-digital-systems-laboratory-spring-2006/499fae5e27b58a4b28605923aebe210e_lec7.pdf)

이때 낮았던 저장 노드도 비트라인에서 유입되는 전류 때문에 올라갑니다. PD가 충분히 끌어내리지 못하면 인버터의 전환점을 넘어 값이 뒤집힐 수 있습니다. 이를 read upset, 즉 읽기 교란에 의한 상태 반전이라고 합니다. Berkeley 보관 학위 원고의 §5.3.3은 접근 소자와 PD의 경쟁을 설명합니다. [Berkeley 학위 원고, §5.3.3 Read Margin, 인쇄면 91–92](https://people.eecs.berkeley.edu/~tking/theses/bsriram.pdf)

초기 비트라인 변화의 크기를 이해하기 위한 단순 근사는 다음과 같습니다.

$$
\Delta V_{BL}\approx\frac{I_{read}t}{C_{BL}}
$$

직접 구성한 예로 전류가 20 µA로 일정하고 비트라인 정전용량이 100 fF이며 관찰 시간이 200 ps라면 변화량은 약 40 mV입니다. 실제로는 전류와 저장 노드 전압이 함께 변하고, 배선 저항·비트라인 결합·감지 입력 부하가 있습니다. 이 수치를 실제 셀의 읽기 전압이나 속도 규격으로 사용하지 않습니다.

감지를 너무 빨리 시작하면 신호보다 오프셋, 즉 감지기의 입력 불일치가 더 커 잘못 판정할 수 있습니다. 너무 늦게 시작하면 지연과 비트라인 방전 에너지가 늘어날 수 있습니다. 셀 전류만 보는 대신 비트라인 차이, WL 펄스, 감지 활성화 시점과 출력 유효 시점을 함께 확인해야 합니다.

## 4. Write: 원래의 되먹임을 이기기

Q에 0을 쓰려면 BL을 낮게, BLB를 높게 구동한 뒤 WL을 활성화합니다. 접근 소자가 기존의 높은 Q를 낮추고, Q가 반대 인버터의 전환점을 지나면 되먹임이 새 상태를 지지합니다. WL이 내려간 뒤에도 새 값이 유지되어야 쓰기가 끝났다고 판단합니다. 입력이 같은 값을 다시 쓴 경우만 시험하면 실제 반전 쓰기 실패를 놓칠 수 있습니다.

읽기에는 PD가 접근 소자에 비해 충분히 강한 편이 유리하지만, 쓰기에는 접근 소자가 PU를 이길 수 있어야 합니다. 접근 소자만 크게 하면 쓰기와 비트라인 전류에 도움이 될 수 있으나 읽기 교란과 입력 정전용량이 달라집니다. 이 경쟁 관계는 Carlson 등의 2010년 논문 §II에서 설명합니다. 논문에 사용한 당시 소자 구조와 수치를 현행 공정의 치수 규칙으로 옮기지는 않습니다. [Carlson et al., SRAM Read/Write Margin Enhancements Using FinFETs, IEEE TVLSI 18(6), 2010, §II](https://people.eecs.berkeley.edu/~bora/Journals/2010/TVLSI-10.pdf)

치수는 폭의 비 하나로 결정하지 않습니다. 두 소자의 길이·문턱전압·바이어스, 허용 레이아웃, 비트라인 부하와 불일치 분포가 함께 작용합니다. 교육용 장채널 모델에서 맞춘 W/L 비가 다른 소자 구조에서도 같은 읽기·쓰기 여유를 주는 것은 아닙니다.

## 5. SNM: 정적인 상태 유지 여유

Static noise margin인 SNM은 정적인 전압 교란을 견디는 여유를 나타냅니다. 서로 맞물린 두 인버터의 전달 특성을 한 그래프에 반사해 겹치면 나비 모양의 곡선이 됩니다. 각 날개에 들어가는 최대 정사각형을 구한 뒤 더 작은 쪽의 변 길이로 두 상태 중 불리한 여유를 나타낼 수 있습니다. 이 측정의 전압원 삽입 방식과 축 정의를 함께 남겨야 결과를 비교할 수 있습니다. [Berkeley 학위 원고, §5.3.2 Hold Margin, Figure 5.1](https://people.eecs.berkeley.edu/~tking/theses/bsriram.pdf)

| 지표 | 시험 조건과 의미 | 대신할 수 없는 확인 |
| --- | --- | --- |
| Hold SNM | WL이 꺼진 보존 상태의 정적 교란 여유입니다. | 읽기 때의 저장 노드 상승입니다. |
| Read SNM | WL이 켜지고 읽기 바이어스가 적용된 상태의 여유입니다. | 제한된 읽기 펄스에서의 비트라인 발달과 감지입니다. |
| Write margin | 쓰기 전압·전류 또는 전환 조건에 기반한 쓰기 여유입니다. | 지정한 시간 안에 값이 바뀌고 유지되는지입니다. |
| 동적 접근 시험 | 실제 제어 펄스와 부하에서 읽기·쓰기를 확인합니다. | 통계적 꼬리 확률과 모든 레이아웃 조건입니다. |

Read SNM에서 비트라인을 고정된 사전 충전 전압에 붙여 두는 정적 시험과, 실제 비트라인이 방전되는 시간축 시험은 조건이 다릅니다. 어떤 조건으로 곡선을 얻었는지 표기합니다. SNM이 100 mV라는 가정 값이 있다고 해도 모든 길이·모양의 100 mV 펄스를 견딘다는 뜻은 아닙니다.

쓰기 여유에는 비트라인을 얼마나 낮춰야 뒤집히는지, 저장 노드에 어떤 전류가 필요한지 등 서로 다른 정의가 있습니다. ‘write margin’이라는 이름만 같은 수치를 비교하지 않습니다. Carlson 등의 논문도 전류 기반 N-curve와 관련된 다른 쓰기 여유 정의를 구분합니다. [Carlson et al., 2010, §II](https://people.eecs.berkeley.edu/~bora/Journals/2010/TVLSI-10.pdf)

## 6. Assist와 선택되지 않은 셀

Assist는 읽기나 쓰기 동안 전압·제어 조건을 일시적으로 바꿔 여유를 확보하는 방법입니다. 예를 들어 읽을 때 WL 전압을 낮추면 저장 노드로 유입되는 전류가 줄 수 있지만 비트라인 신호가 느리게 생길 수 있습니다. 쓰는 동안 셀 전원을 낮추면 기존 상태를 유지하는 PU의 힘이 약해질 수 있지만 같은 전원망의 다른 셀에도 영향을 줄 수 있습니다.

비트라인·워드라인 바이어스와 쓰기 중 전원 조절은 SRAM 연구에서 다루는 assist의 예입니다. 다만 방식마다 셀 면적 외의 회로와 배선 부담이 생깁니다. 여기서 특정 음전압이나 승압값을 제안하지 않으며, 소자의 단자 간 허용 전압과 신뢰성 모델이 있는 범위에서만 검토합니다. [Carlson et al., 2010, §I의 assist 예](https://people.eecs.berkeley.edu/~bora/Journals/2010/TVLSI-10.pdf)

행은 선택됐지만 쓰기 열에서는 선택되지 않은 셀을 half-selected cell이라고 부르는 경우가 있습니다. 이 셀에는 WL과 비트라인의 일부 조건만 걸립니다. 배열 구조에 따라 해당 조건이 달라지므로, 선택된 셀이 잘 써지는지만 확인하면 다른 열의 값이 깨지는 문제를 놓칠 수 있습니다. 쓰기 마스크와 컬럼 멀티플렉서, 여러 포트가 있으면 그 조합도 시험해야 합니다.

읽기 포트를 분리한 8T 등의 셀은 일부 경쟁 관계를 바꿀 수 있지만, 6T 셀에 핀만 추가한 구조는 아닙니다. 셀 회로, 면적, 비트라인, 누설과 제어를 다시 검토해야 합니다. 포트 수를 설정하는 컴파일러 옵션이 있다고 해서 임의의 6T 셀이 모든 포트를 지원하는 것도 아닙니다.

## 7. 셀에서 배열과 매크로로

| 회로 | 배열에서 필요한 이유 |
| --- | --- |
| 행 디코더와 WL 구동기 | 주소를 선택 행으로 바꾸고 긴 WL을 충전합니다. |
| 비트라인 사전 충전·등화 회로 | 접근 전에 두 선을 기준 상태로 만듭니다. |
| 컬럼 멀티플렉서 | 여러 열 중 입출력으로 연결할 열을 고릅니다. |
| 감지 증폭기 | 작은 BL·BLB 차이를 논리 출력으로 바꿉니다. |
| 쓰기 구동기·마스크 회로 | 선택한 비트만 충분한 강도로 구동합니다. |
| 제어·클록 회로 | 사전 충전, WL, 감지와 쓰기의 순서를 만듭니다. |
| 전원·접지와 경계 셀 | 전류 경로와 배열 가장자리의 레이아웃 조건을 제공합니다. |

예를 들어 256워드×32비트는 논리적으로 8,192비트입니다. 이는 자체 산술 예이며 행이 반드시 256개이고 물리 열이 반드시 32개라는 뜻은 아닙니다. 컬럼 멀티플렉싱, 뱅크 분할, 여분 행·열과 주변 회로에 따라 물리 구성이 달라집니다.

레이아웃에서는 디코더에서 먼 WL 끝과 감지기에서 먼 비트라인 끝의 셀을 확인합니다. 선택하지 않은 많은 셀도 비트라인에 정전용량과 누설을 더합니다. 셀 하나에 이상적인 짧은 배선을 연결한 결과를 큰 배열의 접근 시간으로 그대로 사용하지 않습니다.

감지 제어를 만드는 복제 경로는 실제 셀·배선 지연을 따라가도록 구성하는 방법입니다. 복제 회로와 실제 배열이 모든 공정·전원·온도·배치 조건에서 같은 비율로 변한다는 보장은 없으므로 상대 여유를 확인합니다.

## 8. Characterization: 사용자가 읽을 모델 만들기

Characterization은 회로의 동작을 다음 설계 도구가 사용할 수 있는 수치 모델로 정리하는 과정입니다. 입력 변화 속도인 slew와 출력 부하를 여러 값으로 바꾸고, PVT별로 지연·전환 시간·전력과 입력 타이밍을 구합니다. SRAM에서는 동작 모드와 활성 클록 에지, 주소·데이터·쓰기 허용 신호의 조건도 필요합니다.

Setup은 기준 에지 이전에 입력이 안정되어야 하는 시간이고, hold는 그 에지 이후에 안정 상태를 유지해야 하는 시간입니다. 경계는 단순히 출력이 한 번 바뀌는지만 보지 않고, 정의한 기능·지연 기준과 함께 정합니다. 동기식 매크로의 기준 에지는 인터페이스 규격에 따르며 모든 SRAM이 상승 에지나 하강 에지 하나를 공통으로 사용하는 것은 아닙니다.

OpenRAM의 공식 Characterization 문서는 자극 생성, SPICE 계산, 결과 추출과 Liberty 생성을 설명합니다. 또한 해석식 기반 모드와 SPICE 기반 모드를 구분하며, 열람한 `stable` 문서에서는 해석식 기반이 기본값이라고 명시합니다. 따라서 `.lib`가 생성됐다는 사실만으로 트랜지스터 시뮬레이션이나 PEX 검증이 수행됐다고 판단하지 않습니다. [OpenRAM, Characterization, Overview·Options·Analytical Characterization](https://github.com/VLSIDA/OpenRAM/blob/stable/docs/source/characterization.md)

다음은 별도의 실행 없이 구성한 시험 계획 예입니다. 숫자는 특정 컴파일러·공정의 권장값이 아닙니다.

| 축 | 설명용 시험 조건 | 함께 기록할 내용 |
| --- | --- | --- |
| 동작 | 0→1 쓰기, 1→0 쓰기, 읽기, 비활성입니다. | 이전 값, 주소, 쓰기 마스크입니다. |
| 입력 전환 | 50 ps, 100 ps, 200 ps입니다. | 전압 기준점과 신호별 적용입니다. |
| 출력 부하 | 5 fF, 10 fF, 20 fF입니다. | 부하를 붙인 핀과 외부 배선 포함 여부입니다. |
| PVT | PDK가 허용한 공정·전원·온도 조합입니다. | 실제 모델과 적용 범위입니다. |
| 위치·패턴 | 가까운 셀·먼 셀, 교대 패턴, 동일값 패턴입니다. | 주변 셀과 비선택 셀의 초기 상태입니다. |

각 조합에서 읽기 데이터가 마지막으로 쓴 값과 같은지 먼저 확인하고, 그 후에 지연과 전력을 추출합니다. 출력이 틀린 파형에서 계산한 ‘빠른 지연’은 유효한 성능이 아닙니다. 전력은 읽기·쓰기·대기 모드와 측정 구간, 포함한 전원망을 구분합니다.

## 9. Liberty, LEF, Verilog, SPICE와 GDS

OpenRAM Basic Usage는 설정 파일과 함께 GDS·SPICE·Verilog·LEF·Liberty 등의 출력물을 열거합니다. 다음 표는 각 파일이 담당하는 설계 관점을 설명합니다. 파일이 모두 존재하는 것과 서로 일치하며 검증된 것은 별도입니다. [OpenRAM, Basic Usage, Configuration Files·Output Files, `stable` 열람본](https://github.com/VLSIDA/OpenRAM/blob/stable/docs/source/basic_usage.md)

| 파일 | 주로 표현하는 내용 | 표현하지 못하거나 따로 확인할 내용 |
| --- | --- | --- |
| Liberty `.lib` | PVT 조건의 핀 속성, 타이밍 관계, 지연·전환·전력 모델입니다. | 내부 셀의 SNM 분포와 실제 전체 레이아웃입니다. |
| LEF `.lef` | 배치·배선용 크기, 핀 위치와 배선 방해 영역 등의 추상 정보입니다. | 내부 모든 트랜지스터와 마스크 도형입니다. |
| Verilog `.v` | 주소·데이터·제어의 논리 동작입니다. | 기본 기능 모델만으로는 아날로그 교란이나 실제 지연이 확인되지 않습니다. |
| SPICE `.sp` | 트랜지스터와 회로 연결을 나타내는 넷리스트입니다. | 실제 배선 기생 성분은 별도 포함 여부를 확인합니다. |
| GDS `.gds` | 레이어별 물리 도형과 계층입니다. | 사용 조건과 동작 타이밍을 자체적으로 증명하지 않습니다. |
| 설정·로그 | 워드 수, 폭, 공정, 도구 설정과 생성·검사 기록입니다. | 실행하지 않은 검사의 통과를 대신하지 않습니다. |

같은 매크로의 파일은 셀 이름, 포트명, 비트 폭, 주소 폭, 핀 극성, 전원명과 판본이 맞아야 합니다. 예를 들어 논리 모델이 활성 낮음의 쓰기 허용을 기대하는데 상위 회로가 활성 높음으로 구동하면 물리 배선이 맞아도 기능이 다릅니다. LEF 핀 위치와 GDS 핀이 다르거나 `.lib`의 전압이 다른 판본이면 배치·배선이나 타이밍 분석의 전제가 어긋납니다.

모델의 단위도 확인합니다. 시간, 정전용량과 전력의 단위가 다르면 값의 크기만 보고 비교할 수 없습니다. 표의 slew·load 범위를 크게 벗어난 외삽을 실제 검증 결과로 취급하지 않습니다. 비활성 출력의 유지·고임피던스 처리, 쓰지 않은 주소의 값과 같은 동작도 논리 모델과 인터페이스 설명에서 일치해야 합니다.

## 10. OpenRAM과 교육용 PDK의 적용 범위

SRAM 컴파일러는 지원하는 셀·주변 회로·공정 자료와 설정을 바탕으로 매크로를 구성합니다. 워드 폭과 수를 바꾸는 일은 단순한 Verilog 배열 크기 변경과 다릅니다. 물리 셀, 배열 구조, 배선과 특성 추출이 함께 바뀝니다. OpenRAM의 설정에는 포트 구성과 사용 기술이 있으며 검사·추출 도구도 PDK와 맞아야 합니다. [OpenRAM, Basic Usage, Common Configuration File Options](https://github.com/VLSIDA/OpenRAM/blob/stable/docs/source/basic_usage.md)

범용 MOSFET으로 만든 6T 셀은 원리 학습에 유용하지만, 생산용 고밀도 SRAM의 셀 레이아웃·수율·제조 권한을 그대로 제공하지 않습니다. 예를 들어 SKY130 Device Details의 SRAM 절은 특정 SRAM IP 안에서만 허용되는 전용 소자·규칙의 제한을 명시합니다. 일반 소자 규칙을 만족한다는 사실과 전용 메모리 셀 사용 권한은 구분합니다. [SkyWater SKY130 PDK, Device Details, SRAM](https://skywater-pdk.readthedocs.io/en/main/rules/device-details.html)

또한 열람한 SKY130 공개 문서의 Current Status는 해당 공개 릴리스를 Experimental Preview로 설명합니다. 이는 성숙한 공정 자체의 제조 이력과 공개 PDK 패키지의 검증 상태가 같은 말이 아님을 보여 줍니다. 실제 제작에서는 사용할 패키지 판본과 제조 경로의 승인 조건을 확인해야 합니다. [SkyWater SKY130 PDK, Current Status](https://skywater-pdk.readthedocs.io/en/main/status.html)

## 11. 불일치와 배열 수율

명목 조건에서 대칭인 셀도 문턱전압·치수·배선 변화로 한쪽 읽기나 쓰기가 더 불리해질 수 있습니다. Hold·read·write 여유를 각각 통계적으로 살피고, 실패한 표본의 회로 상태를 확인합니다. 한 셀의 평균 SNM만으로 전체 배열의 성공 확률을 정하지 않습니다.

직접 구성한 단순 모형으로, 셀마다 독립적으로 같은 실패 확률 $p$를 가진 $N$개 셀을 모두 통과해야 한다면 성공 확률은 다음과 같습니다.

$$
Y=(1-p)^N\approx e^{-Np}\quad(p\ll1)
$$

가령 $p=10^{-6}$, $N=1{,}000{,}000$이면 $Y$는 약 0.368입니다. 이 수치는 상관관계, 여분 셀, ECC, 주변 회로와 시험·수리 전략을 생략한 계산입니다. 실제 SRAM의 수율 예측이나 특정 기술의 결함률이 아닙니다. 작은 셀 실패 확률과 큰 배열의 요구가 다르다는 점을 설명합니다.

## 12. 실패 진단과 다음 단계

| 증상 | 확인할 파형·자료 | 가능한 원인 |
| --- | --- | --- |
| 읽은 뒤 저장값이 바뀝니다. | Q·QB, WL과 BL·BLB입니다. | 읽기 교란, 과한 WL 또는 소자 불일치입니다. |
| 같은 값 쓰기는 되지만 반전 쓰기가 실패합니다. | 쓰기 전 상태와 WL 종료 뒤 상태입니다. | PU와 접근 소자의 경쟁, 짧은 펄스 또는 약한 쓰기 구동입니다. |
| 셀은 정상인데 출력만 틀립니다. | 감지 입력 차이와 감지 활성화입니다. | 감지 오프셋, 이른 활성화 또는 컬럼 선택 오류입니다. |
| 먼 주소에서만 실패합니다. | 위치별 WL·BL 파형과 PEX입니다. | 배선 RC, 전원 강하 또는 배열 부하입니다. |
| 일부 비선택 셀이 바뀝니다. | 마스크, 비선택 열과 전원 assist입니다. | Half-select 교란 또는 제어 순서 문제입니다. |
| 기능 시뮬레이션과 실제 넷리스트가 다릅니다. | Verilog·SPICE 핀 순서와 동작 에지입니다. | 모델 판본, 극성 또는 인터페이스 해석 차이입니다. |
| `.lib` 수치는 있는데 생성 근거가 불명확합니다. | 설정, 특성 추출 로그와 입력 넷리스트입니다. | 해석식 추정과 SPICE·PEX 결과의 혼동입니다. |

다음 단계에서는 셀·주변 회로의 시험, DRC·LVS, PEX 후 동작과 특성 모델의 일치를 연결합니다. 메모리 매크로를 상위 칩에 배치할 때에는 물리 크기와 핀 접근, 전원, 타이밍 조건을 함께 넘깁니다. RTL 합성에서 메모리를 단순히 수많은 플립플롭으로 바꾼 회로와 검증된 SRAM 매크로를 같은 면적·전력 구조로 취급하지 않습니다.

기본 해석의 의미는 [회로 설계와 Spectre](04-회로설계와Spectre_custom-circuit-simulation.md), 전하를 저장하는 메모리와의 차이는 [DRAM 셀과 주변 회로](06-DRAM셀과주변회로_dram-design.md)에서 이어집니다. 전체 설계 흐름은 [반도체 설계 목차](README.md)에서 확인합니다.
