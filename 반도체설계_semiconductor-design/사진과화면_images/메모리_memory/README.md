## 제작자와 이용 조건

Intel 사진의 크레딧은 `Credit: Intel Corporation`입니다. 공식 뉴스룸의 온라인 편집 목적 미디어 사용 조건에 따라 해당 제품과 기술을 설명하는 문맥에 사용했습니다.

삼성전자와 SK하이닉스 자료의 출처는 각각 삼성전자 뉴스룸, SK하이닉스 뉴스룸입니다. 해당 한국 뉴스룸이 직접 제작한 자료를 원본 파일 그대로 사용했습니다. SK하이닉스 자료는 비상업적 교육 문맥에서 사용하며, 워터마크나 별도 제3자 제공 표시가 있는 자료는 여기에 포함하지 않았습니다.

OpenRAM 그림과 화면의 제작자는 OpenRAM / VLSI Design and Automation Lab입니다. 원본 저장소의 [BSD 라이선스](LICENSES/LICENSE-OpenRAM-BSD-3-Clause.txt)를 보관했습니다. DRAMSys 자료는 RPTU Kaiserslautern-Landau·Fraunhofer IESE 등의 개발 프로젝트에서 제공하며, [라이선스](LICENSES/LICENSE-DRAMSys.txt)와 [의존성 고지](LICENSES/NOTICE-DRAMSys.txt)를 보관했습니다.

Micron 자료는 University of Washington의 공식 수업 배포본인 2025 검토판을 사용했습니다. 원문 PDF의 실제 2–3페이지가 전체 슬라이드·전체 페이지의 교육 목적 사용과 크레딧을 지정합니다. 슬라이드 55·80은 각각 PDF의 실제 54·79페이지 전체를 PNG로 표시했습니다. 자르기·덧씌우기 없이 원문의 화면을 유지했으며, 출처의 지정 문구를 본문에도 붙였습니다.
