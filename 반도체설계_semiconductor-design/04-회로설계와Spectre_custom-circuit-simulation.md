# 트랜지스터 회로 설계와 Spectre 시뮬레이션

확인일: 2026-10-26

회로 설계는 원하는 동작을 트랜지스터의 연결, 크기, 바이어스와 제어 신호로 구현하는 과정입니다. 논리식이 같은 두 회로도 지연, 잡음, 소비 전력, 출력 범위와 공정 변화에 대한 민감도는 다를 수 있습니다. 이 글은 CMOS 인버터와 증폭기를 출발점으로, 회로도에서 얻은 결과를 배선 기생 성분을 포함한 결과와 비교하는 방법을 설명합니다. 설명용 수치는 특정 공정의 사양이나 실제 실행 결과가 아닙니다.

## 1. 회로 설계의 입력과 출력

설계에 앞서 입력 전압 범위, 출력 부하, 전원 범위, 온도 범위, 목표 지연 또는 대역폭, 소비 전력과 허용 오차를 정합니다. 예를 들어 ‘빠른 인버터’보다 ‘정해진 입력 상승 시간과 출력 부하에서 출력이 기준 전압을 통과하는 데 걸리는 시간이 얼마 이하인 인버터’가 시험 가능한 요구입니다. 메모리에서는 여기에 읽는 동안 저장값이 바뀌지 않는지, 지정한 펄스 안에 새 값을 쓸 수 있는지도 추가합니다.

설계 결과에는 회로도만 들어가지 않습니다. 사용한 소자 모델, 시험 회로, 해석 조건, 측정식, 통과 기준과 결과도 함께 필요합니다. 레이아웃 이후에는 연결 일치 여부와 배선 영향을 확인한 자료를 더합니다. 다음 단계의 설계자는 이 자료를 통해 어떤 조건에서 사용할 수 있는 회로인지 판단합니다.

### 처음 프로젝트를 연결하는 순서

[University of Chicago Electronics Development Group, Setting Up a New Cadence Project Using the TSMC PDK, 2020-04](https://edg.uchicago.edu/software/tsmc/)

다음 표는 프로젝트 설정부터 추출 후 비교까지의 흐름을 정리한 것입니다. 시작 명령·초기화 설정과 지원되는 연결 방식은 해당 설치 환경의 안내에 따릅니다.

| 실행과 결과 | 실행 로그의 종료 상태·경고·수렴을 확인한 뒤 동작점과 파형·측정값을 읽습니다. |

라이브러리가 보인다는 사실만으로 모델 경로와 실행 권한까지 확인되는 것은 아닙니다. 반대로 모델 파일만 있어도 레이아웃 기술 정보와 검사 규칙이 없다면 제조 가능한 물리 설계 흐름이 갖춰진 것은 아닙니다.

## 3. PDK와 MOSFET 모델

PDK는 공정에 맞는 소자 정의, 모델, 레이아웃 규칙과 검증 자료를 제공하는 설계 자료 묶음입니다. MOSFET 심벌을 놓은 다음 폭과 길이만 정했다고 해서 실제 공정의 소자가 정의되는 것은 아닙니다. 해당 소자 종류, 허용 치수, 전압 한계, 몸체 연결, 모델의 유효 범위와 모델 판본을 함께 확인해야 합니다.

NMOS의 네 단자는 게이트 G, 드레인 D, 소스 S와 몸체 B입니다. 게이트와 소스의 전압 차이 $V_{GS}$가 전류 제어에 중요하지만, $V_{DS}$와 $V_{BS}$도 영향을 줍니다. 몸체를 연결하지 않으면 의도하지 않은 전압이나 부유 노드가 생길 수 있습니다. 분리된 웰, 소자 극성, 소스·드레인의 모델상 취급은 PDK 소자 설명에 따릅니다.

기초적인 장채널·강한 반전의 이상화에서는 다음 식으로 전류의 경향을 이해합니다.

$$
I_D \approx \frac{1}{2}\mu C_{ox}\frac{W}{L}(V_{GS}-V_T)^2
$$

이는 포화 영역에서 채널 길이 변조 등 여러 효과를 생략한 근사식입니다. 폭 $W$를 늘리면 구동 전류뿐 아니라 입력 정전용량과 면적도 달라집니다. 실제 단채널 소자에서는 이 식을 치수 결정의 정답으로 사용하지 않고 PDK의 컴팩트 소자 모델, 즉 소자 물리를 회로 해석용 방정식으로 요약한 모델로 확인합니다. FinFET 등에서는 폭 조절이 연속값이 아니라 핀 수와 허용된 소자 구조에 제한될 수도 있습니다.

동작점에서 사용하는 소신호 계수는 그 지점 주변에서의 변화율입니다.

$$
g_m=\left.\frac{\partial I_D}{\partial V_{GS}}\right|_{V_{DS},V_{BS}},\qquad
g_{ds}=\left.\frac{\partial I_D}{\partial V_{DS}}\right|_{V_{GS},V_{BS}},\qquad
r_o\approx\frac{1}{g_{ds}}
$$

단위는 $g_m$, $g_{ds}$가 S이고 $r_o$가 Ω입니다. 시뮬레이터가 출력하는 ‘region’ 등의 숫자 코드는 모델마다 정의가 다를 수 있으므로 숫자 하나를 보편적인 영역 이름으로 외우지 않습니다. 전압, 전류와 소신호 계수를 함께 봅니다.

## 4. 시험 회로와 보관할 파일

설계 대상 회로와 시험 회로를 구분합니다. 인버터 자체는 입력·출력·전원 핀을 제공하고, 시험 회로는 전원, 입력원과 출력 부하를 제공합니다. 이렇게 하면 동일한 인버터를 DC, 과도 응답과 부하 변화 시험에 재사용할 수 있습니다. 이러한 분리는 Columbia 실습의 별도 testbench 셀 구성과 같습니다. [Columbia EE4321, §1 Build a testbench](https://bioee.ee.columbia.edu/courses/cad/html/spectresimulation.html)

다음은 파일의 역할을 설명하기 위한 이름 예입니다. 실제 디렉터리와 확장자는 환경에 따라 달라집니다.

| 입력·출력 | 예시 | 남기는 이유 |
| --- | --- | --- |
| 설계 데이터 | 라이브러리의 `inverter/schematic`, `inverter/layout` 뷰입니다. | 핀과 소자의 연결·치수를 확인합니다. |
| 시험 설정 | 저장한 ADE 상태 또는 시험 데이터입니다. | 변수, 코너, 해석과 측정식을 복원합니다. |
| 생성된 회로 입력 | `input.scs`와 포함된 모델 파일입니다. | GUI에서 지정한 설정이 계산 입력에 반영됐는지 확인합니다. |
| 추출 회로 | 추출 뷰 또는 `inverter_pex.sp` 같은 넷리스트입니다. | 레이아웃 연결과 기생 성분의 포함 범위를 확인합니다. |
| 실행 기록 | 시뮬레이터 로그와 실행 요약입니다. | 버전, 경고, 모델 선택, 수렴 여부와 종료 상태를 확인합니다. |
| 결과 | 파형 데이터베이스, 동작점 자료, 측정값 CSV입니다. | 그림뿐 아니라 수치와 측정 조건을 다시 확인합니다. |

파일 이름만으로 내용을 판단하지 않습니다. `.sp`와 `.scs`의 문법, 모델 포함 방식, 계층 이름, 전역 전원과 접지 이름을 확인합니다. 모델 파일의 공개·반출 가능 범위도 해당 PDK 계약에 따릅니다. 보고서에는 비공개 모델의 내용을 붙이는 대신 허용되는 판본 식별 정보와 적용 조건을 남길 수 있습니다.

## 5. 동작점과 DC 해석

동작점은 일정한 입력과 전원에서 회로의 전압과 전류가 어떤 상태에 놓이는지 구한 결과입니다. 인버터 입력이 낮으면 출력이 높아지는지, 증폭기 가지 전류가 설계값에 가까운지, 전류원이 필요한 전압 여유를 확보하는지 확인합니다. AC 그래프가 보기 좋더라도 잘못된 바이어스 주위에서 계산했다면 원하는 회로의 결과가 아닙니다.

DC 스윕은 입력이나 전원을 바꿔 가며 동작점을 구합니다. 인버터에서는 $V_{in}$에 따른 $V_{out}$ 곡선인 전압 전달 특성 VTC를 얻습니다. 기울기가 큰 전환 구간, 출력의 높은 값과 낮은 값, 전원 전류를 함께 봅니다. 증폭기에서는 입력 공통 모드, 즉 두 입력에 공통으로 걸리는 전압을 바꿔 원하는 출력과 바이어스를 유지하는 범위를 확인합니다.

메모리·래치·히스테리시스 회로는 가능한 DC 상태가 여러 개입니다. 스윕 방향이나 초기 상태가 달라지면 서로 다른 가지를 따라갈 수 있습니다. Cadence는 이런 경우 계산 로그의 수렴과 초기 동작점부터 비교하도록 설명합니다. 초기값을 강제로 정해 파형을 얻은 사실과 실제 전원 인가 회로가 그 상태를 만드는 사실은 구분해야 합니다. [Cadence, Multiple DC Solutions, 2021-12-17, Introduction·Identifying Multiple DC Solutions](https://community.cadence.com/cadence_blogs_8/b/cic/posts/spectre-tech-tips-identifying-and-resolving-spectre-accuracy-issues-caused-by-multiple-dc-solutions)

## 6. AC 해석: 바이어스 주변의 작은 변화

AC 해석은 정해진 동작점 주변에서 비선형 소자를 선형화하여 주파수 응답을 계산합니다. 따라서 AC 입력의 크기를 1로 정해 전달 함수를 읽더라도 실제 회로에 큰 사인파를 넣었을 때의 왜곡이나 출력 포화가 확인되는 것은 아닙니다. 일반적인 소신호 해석과 동작점의 관계는 ngspice 공식 매뉴얼의 AC 분석 설명에서도 확인할 수 있습니다. 여기서는 해석 원리만 참고하며 ngspice 명령을 Spectre 명령으로 옮기지 않습니다. [ngspice 공식 매뉴얼, Version 47+ 개발판, 2026-09-28, §1.2.2](https://ngspice.sourceforge.io/docs/ngspice-manual.pdf)

선형화한 회로를 단순하게 쓰면 다음 형태입니다.

$$
(G+j\omega C)\,v(\omega)=i(\omega)
$$

$G$는 전도 성분, $C$는 정전용량 성분을 모은 행렬이고 $v$는 각 노드의 작은 전압 변화입니다. 한 개의 공통 소스 증폭기에서 몸체 효과와 추가 부하를 생략하면 저주파 이득은 대략 $A_v\approx-g_m(R_D\parallel r_o)$입니다. 이는 부호와 변화 경향을 점검하는 손계산이며 실제 다단 증폭기의 극점과 영점을 모두 설명하지 않습니다.

확인할 값에는 저주파 이득, 대역폭과 위상이 있습니다. 피드백 회로의 안정성은 적절하게 정의한 루프 전달 함수를 대상으로 판단합니다. 폐루프 출력의 위상 그래프를 그대로 위상 여유로 읽으면 기준이 달라집니다. 루프를 여는 위치와 시험 방법에 따라 동작점과 부하가 바뀌지 않는지도 확인해야 합니다.

클록에 따라 상태가 반복해서 변하는 회로는 일정한 DC 상태의 선형화만으로 잡음이나 주파수 변환을 설명하기 어렵습니다. Cadence는 RF Option 문서에서 주기적 동작을 기준으로 하는 별도의 소신호 해석을 설명합니다. 실제 사용할 해석 종류와 옵션은 설치 환경에서 확인하며, 일반 AC 결과와 동일하게 취급하지 않습니다. [Cadence, Spectre RF Option, periodic small-signal analyses](https://www.cadence.com/en_US/home/resources/datasheets/spectre-rf-option-ds.html)

## 7. Transient 해석: 시간에 따른 동작

Transient 해석은 전원 인가, 입력 전환, 출력 충전, 클록과 기억 상태의 변화를 시간축에서 계산합니다. 시험에는 입력의 낮은 값·높은 값, 상승·하강 시간, 펄스 폭, 반복 주기, 시작 시점과 부하를 명시합니다. 이상적인 순간 전환보다 실제 앞단이 제공할 수 있는 전환 시간을 쓰는 것이 다음 회로와의 관계를 판단하는 데 도움이 됩니다.

지연의 한 가지 정의는 입력과 출력이 각각 전원의 50%를 통과하는 시점 차이입니다. 그러나 모든 회로의 규격이 이 정의를 따르는 것은 아닙니다. 인버터의 입력 상승과 출력 하강을 짝지은 지연, 입력 하강과 출력 상승을 짝지은 지연을 나누고, 첫 전원 인가 때의 전환을 정상 동작의 전환과 구분합니다.

다음은 측정 정의를 위한 가정 예입니다. 실제 PDK의 허용 전압이나 검증 결과가 아닙니다.

| 조건 | 설명용 설정 |
| --- | --- |
| 전원 | 1.0 V입니다. |
| 입력 | 0–1.0 V, 상승·하강 시간 100 ps입니다. |
| 출력 부하 | 이상적인 정전용량 10 fF입니다. |
| 지연 기준 | 입력·출력의 0.5 V 통과 시점 차이입니다. |
| 추가 관찰 | 출력 10–90% 전환 시간, 정상 구간의 전원 전류와 적분 에너지입니다. |

전원에서 공급한 에너지는 부호를 ‘회로로 들어오는 전류’에 맞춘 뒤 $E=\int_{t_1}^{t_2}V_{DD}(t)I_{supply}(t)\,dt$로 계산할 수 있습니다. 한 번의 동작 에너지와 여러 동작을 포함한 구간 평균 전력 $P_{avg}=E/(t_2-t_1)$을 구분합니다. 유휴 전류까지 포함했는지와 전원 수가 여러 개인지도 밝혀야 비교가 가능합니다.

계산의 내부 시간 간격과 파일에 저장하는 파형 간격은 같은 개념이 아닙니다. 출력 점을 촘촘하게 저장하는 것만으로 짧은 사건의 계산 정확도가 확보되지는 않습니다. 실패가 아주 짧은 글리치나 경계 시점에 의존하면 시간 간격·허용 오차를 바꿨을 때 결론이 유지되는지 확인합니다. 반대로 수치 설정을 바꿔 동작을 억지로 통과시키기 전에 부유 노드, 이상적인 충돌 전압원과 잘못된 모델부터 점검합니다.

## 8. 잡음의 밀도와 적분값

잡음 해석에서는 무엇을 기준으로 표시하는지부터 구분합니다. 전압 잡음의 진폭 밀도는 $\mathrm{V}/\sqrt{\mathrm{Hz}}$, 전력 스펙트럼 밀도는 $\mathrm{V}^2/\mathrm{Hz}$로 표현할 수 있습니다. 대역 내 RMS 잡음은 전력 스펙트럼 밀도를 적분한 뒤 제곱근을 취합니다.

$$
v_{n,rms}=\sqrt{\int_{f_1}^{f_2}S_v(f)\,df}
$$

Analog Devices MT-047은 전압·전류 잡음 밀도와 저항의 열잡음을 설명합니다. 같은 자료는 회로 자체 잡음과 외부 전자기 유입도 구분합니다. 회로의 잡음 모델만 계산한 결과에 외부 간섭이 자동으로 포함되는 것은 아닙니다. [Analog Devices, MT-047, pp. 1–3](https://www.analog.com/media/en/training-seminars/tutorials/MT-047.pdf)

직접 구성한 계산 예로, 출력 잡음 밀도가 관심 대역 전체에서 $5\,\mathrm{nV}/\sqrt{\mathrm{Hz}}$로 일정하고 유효 대역폭이 10 kHz라고 가정하면 $v_{n,rms}=5\sqrt{10{,}000}=500\,\mathrm{nV}$입니다. 이는 백색 잡음만 있는 가정이며 저주파의 $1/f$ 성분, 필터 형상과 실제 잡음 전달 함수를 생략합니다.

입력 환산 잡음은 출력 잡음을 입력 기준으로 환산한 값입니다. 출력 잡음과 수치가 다르다고 오류는 아니며, 사용한 신호 이득과 주파수 기준을 확인합니다. 정상 동작점에서의 소신호 잡음, 시간축에 잡음을 포함한 계산, 주기 회로의 잡음은 각각 목적이 다릅니다. 잡음 옵션을 켜지 않은 결정론적 transient 파형이 조용하다는 이유로 실제 잡음이 없다고 판단하지 않습니다.

## 9. PVT와 Monte Carlo의 질문

PVT는 공정 Process, 전압 Voltage와 온도 Temperature의 변화입니다. 코너 시험은 PDK가 정의한 모델 조합과 전원·온도 조건에서 요구가 유지되는지 확인합니다. TT·SS·FF 같은 이름의 뜻, 서로 다른 NMOS·PMOS 조합, 저항·정전용량 코너는 PDK 문서에 따릅니다. 이름만 보고 모든 지연·잡음·전력의 최악 조건을 하나로 정하지 않습니다.

Monte Carlo는 모델이 정한 통계 변수를 표본마다 바꾸어 결과의 분포를 살핍니다. 회로 전체에 함께 적용되는 공정 변화와 소자 사이의 불일치인 mismatch를 구분합니다. 분포, 상관관계, 치수 의존성과 복수 소자·배수 소자의 통계 처리는 모델의 정의에 달려 있습니다. Cadence의 공식 전문가 답변도 모델에서 변수가 어떻게 사용되는지를 먼저 확인하도록 설명합니다. [Cadence Community, Understanding underlying statistical assumptions in Monte Carlo simulations, 전문가 답변](https://community.cadence.com/cadence_technology_forums/f/custom-ic-design/62906/understanding-underlying-statistical-assumptions-in-monte-carlo-simulations)

통계 시험 기록에는 모델 판본, process·mismatch의 선택, 표본 수, 난수 초기값과 실패한 표본의 조건을 남깁니다. 수렴 실패를 성능 실패와 같은 값으로 처리하거나 조용히 버리면 분포가 왜곡될 수 있습니다. 각 범주를 나누어 원인을 확인합니다.

‘100회에서 실패가 없었다’는 관찰만으로 매우 낮은 실패 확률을 입증할 수는 없습니다. 독립적인 동일 조건의 시행을 가정하면 실패 확률 $p$인 회로에서 $n$회 모두 통과할 확률은 $(1-p)^n$입니다. 이 식은 표본 수의 의미를 보여 주는 자체 통계 모형이며, 실제 모델의 꼬리 분포와 생산 수율을 보장하지 않습니다. 특히 큰 메모리는 한 셀의 작은 실패 확률도 많은 셀에 누적되므로 별도의 수율 방법론이 필요합니다.

## 10. 회로도와 PEX 이후 결과의 비교

PEX는 parasitic extraction의 약자로, 레이아웃에서 저항·정전용량 같은 기생 성분을 추출하는 과정입니다. 배선 저항은 전압 강하와 충전 시간을 바꾸고, 정전용량은 부하와 신호 간 결합을 만듭니다. 실제 레이아웃의 소자 배치에 따른 모델 변화가 지원된다면 그것이 포함되는지도 확인합니다.

비교에는 같은 시험 회로, 입력, 전원, 온도, 소자 코너와 측정식을 사용합니다. 추출 전에는 이상화한 배선으로, 추출 후에는 선택한 추출 뷰 또는 넷리스트로 계산했다는 것을 기록합니다. ADE 문서는 이런 추출 전후 비교를 지원하는 환경으로 설명하지만, 추출된 회로가 자동으로 옳다는 뜻은 아닙니다. [Cadence, Virtuoso ADE Suite, Overview](https://www.cadence.com/en_US/home/resources/datasheets/virtuoso-ade-suite-ds.html)

| 비교할 항목 | 결과가 달라졌을 때의 확인 |
| --- | --- |
| DC 전압과 가지 전류 | 전원 배선 저항, 접촉, 소자 인식과 몸체 연결을 확인합니다. |
| 지연·상승·하강 시간 | 출력 부하와 내부 배선 RC, 입력 전환 시간을 확인합니다. |
| 이득·위상·정착 시간 | 추가 극점, 결합 경로와 피드백 배선의 영향을 확인합니다. |
| 메모리 읽기·쓰기 | 먼 셀의 WL·BL 도달 시간과 감지·쓰기 제어의 순서를 확인합니다. |
| 파형이 완전히 동일한 경우 | 실제로 추출 뷰를 선택했는지와 기생 소자가 넷리스트에 존재하는지 확인합니다. |

비교 전에는 레이아웃과 회로도의 연결을 대조하는 LVS 결과, 추출 범위와 전원·접지 처리를 확인합니다. 이미 추출한 부하를 시험 회로에 다시 더하면 이중 계산이 생길 수 있습니다. 반대로 외부 연결의 부하는 추출 경계 밖에 있어 따로 필요할 수 있습니다. 전체 정전용량 합계만 같아도 결합 위치와 분포가 다르면 동작이 달라질 수 있습니다.

## 11. 실패를 좁히는 순서

| 증상 | 먼저 확인할 자료 | 판단할 내용 |
| --- | --- | --- |
| 실행이 시작되지 않습니다. | 도구·라이선스·파일 접근 오류 로그입니다. | 회로 성능을 계산하기 전의 실행 환경 문제인지 확인합니다. |
| 모델이나 소자를 찾지 못합니다. | 실제 넷리스트의 include와 모델 이름입니다. | 심벌과 모델 종류, 경로와 문법이 맞는지 확인합니다. |
| DC가 수렴하지 않습니다. | 부유 노드, 전원 연결과 수렴 경고입니다. | 회로의 정의 문제인지, 복수 상태인지 구분합니다. |
| 출력이 전원 한쪽에 붙습니다. | 입력 공통 모드, 전류 방향과 각 소자 동작점입니다. | 바이어스와 헤드룸이 맞는지 확인합니다. |
| 시뮬레이터별 결과가 다릅니다. | 모델·초기 상태·기생 성분·허용 오차입니다. | 서로 다른 문제를 계산하고 있지 않은지 먼저 확인합니다. |
| 한 코너나 표본만 실패합니다. | 실패한 조건의 동작점과 파형입니다. | 평균값이 가린 한계와 수렴 오류를 구분합니다. |
| 추출 후에만 실패합니다. | LVS, 추출 넷리스트와 내부 노드 파형입니다. | 연결 오류와 실제 배선 부담을 나누어 확인합니다. |

실패를 분석할 때는 한 번에 한 조건을 바꿔 원인을 좁힙니다. 부하를 없애 통과시킨 결과는 해당 부하를 구동한다는 증거가 아니며, 초기 상태를 고정해 통과시킨 결과는 전원 인가 동작의 증거가 아닙니다.

## 회로 해석에서 레이아웃과 상위 연결로

회로도에서 확인한 성능을 실제 배치·배선으로 이어 가는 방법은 [풀커스텀 레이아웃](14-아날로그풀커스텀레이아웃_full-custom-layout.md)에서 설명합니다. 추출 후 동작을 확인한 블록은 [혼합신호 통합](15-아날로그와RTL의혼합신호통합_analog-digital-integration.md)에서 모델·핀·전원·제어 조건을 갖춘 매크로로 상위 RTL에 연결합니다.

## 12. 다음 설계 단계로 넘길 자료

회로도, 시험 회로, 모델 식별 정보, 시험 조건 표, 측정식과 통과·실패 기록을 하나의 설계 판본에 묶습니다. 레이아웃이 있으면 DRC·LVS의 결과와 적용한 검사 규칙, PEX 조건과 추출 전후 비교를 연결합니다. DRC는 기하 규칙, LVS는 연결 대응, 회로 시뮬레이션은 선택한 모델과 자극에서의 동작을 각각 다룹니다. 어느 하나의 통과를 다른 검사의 통과로 대신하지 않습니다.

메모리에서는 이 과정이 셀의 안정성과 매크로의 인터페이스 특성으로 이어집니다. [SRAM 셀과 메모리 매크로](05-SRAM셀과메모리매크로_sram-design.md)에서는 읽기·쓰기의 충돌과 타이밍 모델을, [DRAM 셀과 주변 회로](06-DRAM셀과주변회로_dram-design.md)에서는 작은 저장 전하의 감지·복원과 유지 시간을 설명합니다. 전체 설계 흐름은 [반도체 설계 목차](README.md)에서 연결합니다.

이 글은 공개 문서와 기본 회로 원리에 근거한 설명입니다. 특정 PDK·도구를 설치하거나 회로를 실행·측정한 기록은 포함하지 않습니다. 실제 적용에서는 사용 가능한 모델과 도구 판본에 맞춘 시험 결과를 별도로 확보해야 합니다.
