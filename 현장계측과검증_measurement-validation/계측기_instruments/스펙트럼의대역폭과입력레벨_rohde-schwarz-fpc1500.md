# 스펙트럼의 대역폭과 입력 레벨 / RBW, attenuation, and noise with the R&S FPC1500

스펙트럼에서 작은 봉우리가 보였다고 곧바로 시편의 불필요한 신호라고 결론 내릴 수는 없습니다. 입력 과부하가 분석기 안에서 만든 성분일 수도 있고, RBW를 바꿔 보이기 시작한 신호일 수도 있습니다. FPC1500의 수신 스펙트럼 기능을 대상으로 주파수 분해능과 레벨 조건을 연결합니다. 공식 문서에 근거한 절차와 자체 계산이며 실제 RF 신호·제품의 측정 결과는 없습니다. 예제는 동축으로 제공되는 알려진 저전력 시험 신호에 한정합니다.

## 시간 파형 대신 주파수별 성분을 봅니다

오실로스코프의 기본 질문은 “시간에 따라 전압이 어떻게 변하는가”입니다. 스펙트럼 분석기는 “어떤 주파수에 어느 정도의 성분이 있는가”를 묻습니다. 비슷한 사인파 두 개를 합치면 시간 파형이 주기적으로 커졌다 작아질 수 있고, 주파수 화면에서는 두 봉우리로 나뉠 수 있습니다. 두 화면은 같은 신호를 다른 축으로 표현합니다.

FPC1500 기본 주파수 범위는 5 kHz~1 GHz이고, FPC-B2와 B3로 각각 2·3 GHz까지 확장합니다. B22 전치증폭기는 별도 옵션입니다. 제품 목록의 “1/2/3 GHz”나 증폭기 사용 시의 작은 잡음 숫자를 모든 장비의 기본 상태로 읽지 않습니다. FPC1000과 FPC1500의 발생기·네트워크 분석 기능도 동일하지 않습니다. 이 글에서는 발생기 출력이나 VNA 기능을 사용하지 않습니다. [공식 모델·옵션 목록](https://www.rohde-schwarz.com/us/products/test-and-measurement/benchtop-analyzers/rs-fpc-spectrum-analyzer_63493-542324.html)

## RBW는 주파수의 작은 창입니다

RBW(Resolution Bandwidth)는 분석기의 분해능 필터 대역폭입니다. 카메라의 초점을 맞추듯, 넓은 창에 두 신호가 함께 들어오면 한 덩어리로 보일 수 있습니다. 100.000 MHz와 100.020 MHz라는 자체 예제의 간격은 20 kHz입니다. RBW 100 kHz에서는 두 성분을 나누기 어렵고, 10 kHz로 좁히면 분리할 가능성이 커집니다. 크기가 크게 다른 두 신호는 필터 모양·위상 잡음 등까지 영향을 받으므로 간격만으로 검출을 보장하지 않습니다.

RBW를 좁히면 필터 안에 들어오는 광대역 잡음 전력도 줄지만 측정 시간이 늘 수 있습니다. 좁은 필터가 안정되기 전에 빠르게 훑으면 봉우리 레벨이 실제보다 낮아질 수 있습니다. 처음에는 자동 sweep time을 유지하고, 수동 시간을 쓸 때는 미정착 표시와 반복 결과를 확인합니다. [FPC 매뉴얼, 15.5.1 Resolution filter·15.6 Sweep configuration](https://scdn.rohde-schwarz.com/ur/pws/dl_downloads/pdm/cl_manuals/user_manual/1178_4130_01/FPC_UserManual_en_13.pdf)

VBW(Video Bandwidth)는 검파 뒤 신호를 평활하게 만드는 필터의 대역폭입니다. 화면의 흔들림을 줄이는 데 쓰지만, 가까운 두 RF 신호를 나누는 RBW를 대신하지 않습니다. VBW를 지나치게 좁히면 관심 있는 진폭 변화도 줄일 수 있습니다. 연속파의 안정된 레벨을 읽는 조건과 짧은 사건을 관측하는 조건은 다릅니다. 같은 그림처럼 보여도 RBW·VBW·검파기·평균 방식이 다르면 수치 비교가 달라집니다.

## 자체 계산: 잡음바닥이 낮아졌다고 시편이 조용해진 것은 아닙니다

전력의 데시벨 단위 dBm은 1 mW를 기준으로 `10 log10(P/1 mW)`입니다. -30 dBm은 1 µW입니다. 50 Ω 정합 상태에서 Vrms=√(PR)이므로 약 7.071 mVrms에 해당합니다. 오실로스코프의 고임피던스 입력에서 읽은 전압에 이 식을 그대로 적용하지 않습니다.

자체 이상 모형의 평탄한 잡음 밀도를 -145 dBm/Hz로 가정하면, 유효 잡음 대역폭 B에 들어오는 전력은 다음과 같습니다.

```math
P_n\,[\mathrm{dBm}]=-145+10\log_{10}B
```

| 가정한 유효 대역폭 | 적분 잡음 전력 |
| --- | --- |
| 30 kHz | 약 -100.229 dBm |
| 1 kHz | -115.000 dBm |

두 설정의 차이는 약 14.771 dB입니다. 시편과 분석기의 잡음 발생량을 바꾸지 않아도 관측 대역을 줄이면 이 차이가 생깁니다. 실제 RBW의 3 dB 폭과 유효 잡음 대역폭은 필터 모양 때문에 같지 않을 수 있고, 로그 평균과 검파 방식의 보정도 필요합니다. 위 계산은 FPC1500의 DANL 사양이나 noise marker를 재현한 값이 아닙니다. DANL은 정해진 종단·감쇠·전치증폭·검파·정규화 조건에서 표시 평균 잡음을 나타내는 사양입니다.

```python
from math import log10, sqrt       # math에서 로그와 제곱근 함수를 가져옵니다.
power_w = 1e-3 * 10 ** (-30 / 10)  # dBm을 W로 변환하며 **는 거듭제곱입니다.
vrms = sqrt(power_w * 50)         # 50 Ω에 전달되는 전력으로 실효전압을 구합니다.
noise_dbm = -145 + 10 * log10(1000)  # 가정한 1 kHz 대역의 잡음 전력을 계산합니다.
print(vrms * 1000, noise_dbm)      # 전압을 mV로 바꾸어 계산값을 출력합니다.
```

위 코드는 약 7.071 mV와 -115 dBm을 출력합니다. 장비 연결이나 SCPI 제어를 수행하지 않습니다.

## 입력 감쇠는 숫자 이동보다 앞단의 동작을 바꿉니다

입력 감쇠기는 분석기 내부로 들어가는 신호를 줄여 과부하와 왜곡을 피하게 합니다. 내부 감쇠를 늘려도 장비는 그 값을 보정해 입력 기준으로 레벨을 표시합니다. 정상적인 선형 범위의 단일 성분이라면 내부 감쇠 10 dB 증가가 화면의 실제 입력 레벨 10 dB 감소와 같지는 않습니다. 반면 잡음바닥이 높아져 작은 성분을 보기 어려워질 수 있습니다.

reference level은 화면과 내부 레벨 설정에 쓰는 기준입니다. 화면 위쪽이 잘리지 않았다는 사실만으로 과부하가 없다고 판단할 수 없습니다. 여러 성분이 동시에 들어올 때는 총 입력 전력과 피크도 고려해야 합니다. 전치증폭기 역시 약한 신호에 도움이 될 수 있지만 강한 신호가 함께 있으면 동작 여유를 줄입니다. [FPC 매뉴얼, 15.4 Amplitude configuration, 108~113쪽](https://scdn.rohde-schwarz.com/ur/pws/dl_downloads/pdm/cl_manuals/user_manual/1178_4130_01/FPC_UserManual_en_13.pdf)

외부 감쇠기는 분석기 내부 감쇠와 다릅니다. 자체 예제에서 외부 10 dB 감쇠기 뒤에 -40 dBm이 읽혔다면, 정합·손실 조건을 이상적으로 가정한 시편 경계 값은 -30 dBm입니다. 케이블 손실과 외부 보정표를 이미 적용했다면 다시 더해 중복 보정하지 않습니다. 실제 입력 정격과 DC 허용 조건은 연결 전에 해당 포트의 사양으로 확인하고, 시편의 전원선을 RF 입력에 직접 연결하지 않습니다.

## 연결 → 설정 → 관측 → 판정 → 기록

1. 준비·연결: 알려진 주파수·최대 레벨·DC 유무의 저전력 동축 신호를 사용합니다. 분석기 RF 입력의 50 Ω 경계, 케이블·필요한 감쇠기·DC 차단기의 주파수와 정격을 확인합니다. 무선 방사 시험이나 전원 회로의 직접 연결로 확장하지 않습니다.
2. 탐색 설정: spectrum 모드에서 관심 대역을 넓게 잡고 전치증폭기는 끕니다. 입력 레벨에 맞는 감쇠와 reference level을 정합니다. 신호의 상한을 확인하기 전에 약한 신호 설정으로 바꾸지 않습니다.
3. 상세 설정: 100 MHz 부근의 자체 예제에서는 먼저 성분을 찾고, 좁은 span에서 RBW를 100 kHz·10 kHz로 비교합니다. 정적인 CW라면 VBW와 평균 조건을 고정하고, 자동 sweep이 끝난 트레이스를 저장합니다.
4. 관측·분리: 내부 감쇠를 10 dB 늘린 결과와 원래 결과를 비교합니다. 기본파·의심 성분·잡음바닥을 함께 적고, 해당 성분이 잡음 속으로 사라진 경우를 “없음”과 구분합니다.
5. 판정·기록: 요구 대역과 검출 한계, 레벨 불확실성, 케이블 보정 경계를 정합니다. 화면만 저장하지 않고 주파수·RBW·VBW·검파기·trace mode·sweep time·감쇠·전치증폭·외부 보정을 묶어 보관합니다.

## 고조파의 출처를 가릅니다

고조파는 기본 주파수의 정수배 성분입니다. 기본파가 -30 dBm이고 2차 성분이 -70 dBm이라는 자체 예제라면 상대 레벨은 -40 dBc입니다. dBc는 기준 반송파에 대한 상대 전력비이며, 절대 전력 dBm과 다릅니다.

분석기 자체가 비선형 동작하면 내부에서도 고조파가 생길 수 있습니다. 입력 신호가 그대로인데 내부 감쇠를 늘렸을 때 의심 성분이 기본파에 비해 낮아지면 분석기 내부 기여를 의심합니다. 그러나 신호와 내부 왜곡이 함께 섞인 경우, 잡음바닥·정합·위상도 작용하므로 한 번의 변화로 시편 원인을 확정하지 않습니다. R&S의 고조파 자료가 설명한 일반적인 분리 방법을 적용한 것이며, 그 자료의 FSW 전용 필터 옵션을 FPC1500 기능으로 옮기지 않습니다. [Harmonic Measurements on Modern Spectrum Analyzers, 1EF78_2E, 8~9쪽](https://scdn.rohde-schwarz.com/ur/pws/dl_downloads/dl_application/application_notes/1ef78/1EF78_2E.pdf)

| 가정한 관측 | 먼저 구분할 사항 | 다음 비교 |
| --- | --- | --- |
| RBW를 줄이자 봉우리가 보임 | 이전 잡음 대역에 가려졌는지 여부 | 같은 입력에서 대역폭만 바꿉니다. |
| 내부 감쇠 증가 후 의심 고조파만 낮아짐 | 분석기 내부 왜곡의 기여 | 충분한 잡음 여유에서 반복합니다. |
| 케이블을 교체하자 모든 레벨이 이동 | 경로 손실·정합·외부 보정 | 기준 신호와 경계별 보정을 확인합니다. |
| sweep을 빠르게 하자 레벨이 낮아짐 | 필터 정착 시간 부족 | 자동 시간과 비교하고 경고를 남깁니다. |

## English summary

RBW changes frequency discrimination and integrated noise; VBW smooths detected variation. Input attenuation, reference level, and preamplification affect overload and sensitivity. The examples calculate noise-bandwidth shifts and distinguish dBm from dBc, with a procedure for checking analyzer-generated harmonics. No physical RF measurements are claimed.
