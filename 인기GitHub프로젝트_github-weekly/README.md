# 인기 GitHub 프로젝트 | Popular GitHub projects

최근 관심을 받는 GitHub 프로젝트의 기능, 유용한 사용자, 설치 방법과 사용 예시를 한국어로 소개합니다. 필요한 운영체제·실행 환경과 명령을 입력할 위치를 설명하고, 공식 문서·원문 예시와 수집 당시의 주간 별 증가량을 연결합니다.

매주 월요일 오전 9시 23분(한국 표준시)에 GitHub 주간 Trending을 확인합니다. 발행한 글은 `주간기록/연도/월/날짜.md`에 남으며, 다음 달과 다음 해에도 같은 일정으로 이어집니다. 실행 시각은 GitHub 작업 대기 상황에 따라 늦어질 수 있습니다.

주간 목록은 [GitHub Trending의 This week](https://github.com/trending?since=weekly)에 표시된 순서를 사용합니다. 누적 별이 많은 순서나 한 달 전체의 별 증가량 순서는 아닙니다. 같은 프로젝트가 다음 주에도 선정되면 그 주의 수치를 새로 기록하고, 같은 주 재실행은 기존 글을 유지합니다.

각 소개는 ‘어떤 일을 하나요 → 누구에게 유용한가요 → 설치 방법 → 사용 예시 → 출처’ 순서로 읽으실 수 있습니다. 설치 명령과 API 예시는 공식 문서에서 가져왔으며, 설명용 시나리오와 직접 실행한 결과를 구분합니다.

새 주간 글도 같은 형식을 사용합니다. 공식 README를 커밋에 고정해 읽고, 필요한 경우 같은 저장소에 연결된 설치·사용 문서도 확인합니다. 영어 설명은 공개 번역 모델로 한국어를 병기하고, 코드·명령은 번역하지 않습니다. 문서에 없는 명령은 만들어 넣지 않고 공식 문서 링크를 남깁니다. GitHub 서버에서 수집과 CPU 번역이 실행되므로 GPT API나 ChatGPT 사용량은 쓰지 않습니다.
