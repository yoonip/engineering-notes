# 패키지 구성

Python 소스, 출력 없는 Jupyter 노트북, 재현 설정, 집계 지표, 합성 자료 테스트와 파일 해시 목록을 포함합니다.

말뭉치·문장별 예측·학습 가중치·모델 cache·실행 파일은 별도로 관리합니다. 테스트의 짧은 합성 문자열은 원자료에서 가져온 문장이 아닙니다.

## English

The package contains Python source, Jupyter notebooks with cleared outputs, reproducible configuration, aggregate metrics, synthetic-data tests and file hashes.

Corpora, sentence-level predictions, trained weights, model caches and executables are managed separately. The short synthetic test strings are not copied from the source corpus.
