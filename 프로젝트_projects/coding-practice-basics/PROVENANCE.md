# 출처 및 공개 범위

`c`, `cpp`, `python`에 주제별 소스 18개를 정리했습니다. 예제의 입출력 조건은 README에, 파일별 해시는 `SHA256SUMS`에 기록했습니다.

소스, 연습용 입력·기대 출력, 검증 도구와 문서를 함께 관리합니다. 검증 도구는 임시 폴더에서 C/C++를 빌드하고 세 언어의 출력을 비교하며, 실행 결과는 `VALIDATION.json`에 저장했습니다.

## English

The `c`, `cpp` and `python` directories contain eighteen sources organized by topic. README records the input/output contract; `SHA256SUMS` records file hashes.

Sources, input/expected-output fixtures, verification tools and documentation are maintained together. The verifier builds C/C++ in a temporary directory and compares outputs across the three languages. Recorded results are in `VALIDATION.json`.
