# 신경보철과 재활 / Neuroprosthetics and rehabilitation

신경 신호를 읽는 일, 신경계를 자극하는 일, 실제 행동과 생활 기능을 돕는 일을 연결합니다. 해독기의 점수와 환자가 수행한 과제는 다른 평가이므로 참여자 수·보조 조건·훈련 기간을 함께 읽습니다.

| 논문 해설 | 연결하는 공학과 임상 질문 |
|---|---|
| [뇌와 척수를 잇는 보행 제어](뇌와척수를잇는보행제어_lorach2023-brain-spine.md) | 뇌의 운동 의도를 해독해 척수 자극으로 전달하는 인터페이스를 다룹니다. 신호의 일치도, 지연 시간, 실제 보행의 보조 조건을 구분합니다. |
| [활동에 맞춘 척수 자극](활동에맞춘척수자극_rowald2022-spinal-stimulation.md) | 활동별 자극과 재활을 연결합니다. 자극 직후 가능한 움직임과 여러 달 훈련한 결과를 비교합니다. |
| [중심 시야를 돕는 광전 망막보철](중심시야를돕는광전망막보철_palanker2020-prima.md) | 빛을 전기 신호로 바꾸는 망막 장치와 영상 투사기를 다룹니다. 빛 감지·시력표 판독·일상 시각을 같은 결과로 놓지 않습니다. |
| [증상 신호에 반응하는 뇌 자극](증상신호에반응하는뇌자극_scangos2021-closed-loop.md) | 개인에게서 찾은 신호로 자극 여부를 결정하는 폐회로를 다룹니다. 한 사람의 기전 탐색과 집단 치료 효과의 차이를 읽습니다. |

## English

These four studies connect neural recording, stimulation and functional assistance. Each article separates decoding measures from patient tasks, training duration and assistance conditions. The brain–spine interface, activity-specific spinal stimulation, photovoltaic retinal prosthesis and personalized closed-loop stimulation address different impairments and evidence levels.
