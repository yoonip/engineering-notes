# 상태 추정과 안전 제어 / State estimation and safety constraints

관측에서 현재 상태를 추정하는 일과 입력으로 움직임을 제어하는 일을 구분합니다. 칼만 필터의 오차 공분산, 제어 장벽 함수의 안전 집합과 이차계획을 작은 예제로 살펴봅니다.

| 논문 | 핵심 내용 |
|---|---|
| [Kalman, 1960](예측과관측의불확실성결합_kalman-1960.md) | 선형 상태 추정, 예측·관측의 결합과 오차 공분산 |
| [제어 장벽 함수, Ames 외, 2017](안전집합과제어장벽함수_control-barrier-functions2017.md) | 안전 집합, 허용 입력·입력 한계와 이차계획 |

각 해설에는 원제·저자·발표처, 읽은 범위와 확인 문제가 있습니다. 원문의 결과와 직접 구성한 계산을 구분합니다.
