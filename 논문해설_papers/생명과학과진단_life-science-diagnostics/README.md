# 생명과학·진단과 실험 모델

DNA를 읽고 늘리는 방법, RNA에 대한 세포 반응, 살아 있는 조직 모델의 작동과 평가를 다룹니다. 원문을 한국어로 해설하며 분자 수준의 관측, 실험 모델의 결과, 임상·제품 허가를 구분합니다. 실제 실험을 따라 하는 배합·배양 안내나 개인별 검사·치료 지침은 제공하지 않습니다.

| 글 | 중심 질문 |
| --- | --- |
| [생어 서열 분석](sanger1977.md) | 멈춘 조각의 길이에서 어떻게 DNA 순서를 읽을까요? |
| [내열성 효소 PCR](pcr1988.md) | 반복 복제와 자동화의 병목은 무엇일까요? |
| [RNA 변형과 면역 인식](rna-modification2005.md) | 정보 배열 외에 어떤 분자 특징이 반응을 바꿀까요? |
| [나노포어 신호 해석](nanopore2014.md) | 전류 기록을 서열에 대응시키는 것과 새 서열을 읽는 것은 어떻게 다를까요? |
| [장 오가노이드](organoid2009.md) | 세포 증식·분화·공간 구조는 각각 어떻게 확인할까요? |
| [간 칩의 독성 예측 평가](liverchip2022.md) | 칩 수·공여자 수·약물 수와 예측 성능의 분모를 어떻게 나눌까요? |

각 글은 논문 정보와 읽은 범위, 기초 개념, 자체 예제·계산, 한계, 확인 문제와 접힌 해설을 포함합니다. 본문 수치와 직접 만든 장난감 예를 분리하여 표시합니다. 표본 조건을 벗어나 현재 모든 장비·환자에게 같은 성능이 적용된다고 해석하지 않습니다.
