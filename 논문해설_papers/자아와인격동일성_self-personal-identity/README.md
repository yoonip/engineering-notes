# 자아와 인격 동일성 / Self and personal identity

성격과 기억이 닮았다는 질적 유사성과 바로 그 하나의 존재라는 수적 동일성을 구분합니다. 기억이 달라져도 같은 사람일 수 있는지, 심리적 관계가 둘로 이어지면 무엇이 남는지, 인간 유기체의 생명이 계속되는 것이 어떤 의미인지 관련 논문에서 읽습니다.

|---|---|---|

## 판단 기준을 확인하는 방법

한 조건이 있으면 충분하다는 주장과 그 조건이 반드시 있어야 한다는 주장을 구분합니다. 심리적 연속성의 충분조건을 제안한 글을, 심리적 연속성을 모든 지속의 필요조건으로 삼는 이론과 바로 같게 놓지 않습니다. 생각하는 존재의 조건, 시간이 지나도 같은 존재인 조건, 도덕적 보호의 근거도 각각 다른 문제입니다.

뇌 이식과 기억 이전은 논증을 비교하는 사고실험이며 해당 기술이 실제로 구현되었다는 보고가 아닙니다. AI의 복사·기억·몸과 호르몬에 따른 상태 변화도 [입장별 비교 글](../../인문사회_humanities/58-철학비판적사고_philosophy-critical-thinking/해설_notes/자유의지와인격동일성_free-will-and-personal-identity.md)에서 이런 구분을 유지하며 다룹니다.
