# 태양전지·전해질·물·탄소를 다룬 논문 / Energy and environmental engineering papers

빛을 전기로 바꾸는 한계, 전해질과 계면, 물과 탄소를 분리·저장하는 공정을 읽습니다. 아래 6편은 원문 본문을 직접 읽은 해설입니다. 원문의 번역본이 아니라 용어, 가정, 증거와 한계를 자체 계산으로 연결한 글입니다. 별도 보충자료를 읽지 않은 경우 각 글에 범위를 적었습니다.

| 순서 | 논문 | 읽을 질문 |
|---|---|---|
| 1 | [Shockley·Queisser, 1961](shockley-queisser1961.md) | 태양전지 효율의 이론 한계는 어떤 가정에서 나오나요? |
| 2 | [Kim 외, 2012](perovskite-solid2012.md) | 페로브스카이트 소자에서 전하 전달 경로를 어떻게 바꾸었나요? |
| 3 | [Suo 외, 2015](water-in-salt2015.md) | 고농도 수계 전해질과 전극 계면은 어떻게 연결되나요? |
| 4 | [Elimelech·Phillip, 2011](desalination2011.md) | 좋은 막만으로 담수화 전력을 계속 줄일 수 있나요? |
| 5 | [Keith 외, 2018](direct-air-capture2018.md) | 공기 포집의 물질수지·에너지·비용에서 분모는 무엇인가요? |
| 6 | [Matter 외, 2025](peridotite-mineralisation2025.md) | 지하 탄소의 광물화를 어떻게 추적하고 추정하나요? |

처음에는 1·2편을 묶어 이론과 소자의 차이를 읽고, 4·5편을 묶어 분리 공정의 경계를 비교하시면 좋습니다. 3편의 전압 안정 창과 6편의 추적자 실험은 각각 계면과 현장 관측에서 추론이 어떻게 이루어지는지 보여 줍니다.

학습용 계산은 보고된 값을 재계산한 경우와 별도로 만든 가정인 경우를 구분합니다. 작은 시료의 효율, 전극 질량 기준 에너지 밀도, 설계 공장의 비용, 소규모 주입의 반응 비율을 완제품이나 대규모 현장의 실측 성과로 바꾸어 쓰지 않습니다.
