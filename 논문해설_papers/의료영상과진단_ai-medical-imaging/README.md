# 의료영상 복원과 AI 진단 / Medical image reconstruction and AI diagnosis

장비의 측정으로 영상을 만드는 계산, 영상에서 질환 후보를 찾는 계산, 실제 검진에서 사람과 함께 사용하는 평가를 나누어 읽습니다. MRI의 빠른 촬영, 망막 OCT, 유방촬영과 희귀질환의 얼굴 표현형을 다룹니다. 서로 다른 입력·목표·비교 설계의 수치를 한 정확도 순위로 합치지 않습니다.

| 논문 | 공학이 맡은 일 | 핵심 내용 |
|---|---|---|
| [Antun 외, 2020](의료영상복원의작은입력변화_antun2020-instability.md) | 측정에서 영상을 복원하는 학습기의 안정성을 시험합니다. | 작은 영상 구조와 작은 입력 교란의 구분 |
| [Johnson 외, 2023](빠른MRI의촬영과판독_johnson2023-knee-mri.md) | 적은 촬영 자료로 무릎 MRI를 복원하고 판독을 비교합니다. | MRI 영상 품질과 질환 판독의 일치 |
| [De Fauw 외, 2018](망막단층영상의분할과의뢰_defauw2018-oct.md) | OCT의 구조 분할을 질환 분류·의뢰 판단에 연결합니다. | OCT 장비 간 차이와 구조 분할의 중간 표현 |
| [MASAI 검진 분석, 2025](AI유방촬영의발견과판독량_masai2025.md) | AI가 포함된 유방촬영 판독 경로를 무작위 비교합니다. | 유방 검진의 발견률·재검·판독량·추적 결과 |
| [Hsieh 외, 2022](얼굴표현형으로희귀질환찾기_gestaltmatcher2022.md) | 영상의 특징을 비슷한 사례를 찾는 공간으로 옮깁니다. | 얼굴 표현형의 유사 사례 검색과 확정 진단 |
