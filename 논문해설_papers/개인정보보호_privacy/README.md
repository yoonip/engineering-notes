# 개인의 정보와 통계의 공개 / Privacy and statistical release

정확한 통계를 공개하는 일과 개인 한 명의 참여 여부를 드러내지 않는 일은 어떻게 함께 설계할 수 있는지 읽습니다. 차등정보보호의 인접 자료·민감도·잡음 척도·누적 비용을 계산하며, 이름을 지우는 익명화와의 차이를 살핍니다.

[논문 해설과 계산 예제](개인별영향과차등정보보호_noise-sensitivity2006.md)에는 원제·저자·발표처, 읽은 범위와 확인 문제가 있습니다. 원문의 결과와 직접 구성한 계산을 구분합니다.
