# AlphaZero: 자기 대국과 탐색으로 정책의 정답을 만드는 과정

David Silver, Thomas Hubert, Julian Schrittwieser 등 13명의 「A general reinforcement learning algorithm that masters chess, shogi, and Go through self-play」는 Science 362, 1140–1144쪽에 2018년 발표되었습니다. 저자 소속은 DeepMind와 University College London입니다. [공식 공개 저자 원고](https://storage.googleapis.com/deepmind-media/DeepMind.com/Blog/alphazero-shedding-new-light-on-chess-shogi-and-go/alphazero_preprint.pdf)는 보충 자료를 합쳐 32쪽입니다. [학술지 서지](https://doi.org/10.1126/science.aar6404)와 [UCL 저장 기록](https://discovery.ucl.ac.uk/id/eprint/10069050/)을 함께 확인합니다.

## 원문의 질문과 범위

2017년 선행 공개문과 2018년의 전체 평가는 제목과 대국 조건이 다릅니다. 여기서는 2018년 저자 원고를 기준으로 읽습니다. 본문 PDF 1–7쪽은 알고리즘과 평가, 보충 Methods는 입력 표현·학습·탐색·비교 조건, 뒤의 그림과 표는 추가 대국과 설정을 다룹니다. [원문 및 공식 발표 설명](https://deepmind.google/blog/alphazero-shedding-new-light-on-chess-shogi-and-go/)

동일한 학습 틀을 여러 게임에 적용하지만, 세 게임을 동시에 아는 하나의 가중치를 학습한 것은 아닙니다. 게임별 인스턴스를 따로 학습합니다. 또한 규칙·합법 수·종료 판정은 제공됩니다. “인간 기보 없이 학습했다”를 “아무런 사전 설계나 규칙 없이 시작했다”로 바꾸면 정확하지 않습니다.

## 정책과 가치에 붙이는 학습 신호

신경망은 국면에서 행동 분포와 결과 기대값을 함께 냅니다. 탐색은 그 추정을 사용해 여러 수를 살피고, 방문 횟수로 더 나은 행동 분포를 만듭니다. 자기 대국이 끝나면 실제 결과도 얻게 됩니다. 다음 학습에서는 망이 탐색 분포와 실제 결과에 가까워지도록 조정합니다. [원문 PDF 2–4쪽](https://storage.googleapis.com/deepmind-media/DeepMind.com/Blog/alphazero-shedding-new-light-on-chess-shogi-and-go/alphazero_preprint.pdf)

자기 대국은 같은 프로그램 계열이 양쪽을 맡아 경험을 만드는 절차입니다. 탐색 분포는 사람이 미리 정한 정답 수 하나가 아니라, 주어진 계산 예산에서 여러 후보를 조사한 결과입니다. 따라서 탐색이 만드는 교사도 완벽한 최적 행동의 정답표는 아닙니다.

## 직접 계산하는 두 학습 목표

설명용으로 수 A와 B만 있는 국면을 만들겠습니다. 망의 정책은 (0.6, 0.4), 탐색 방문 비율은 (0.25, 0.75)라고 가정합니다. 정책 손실의 교차엔트로피는 다음과 같습니다. 자연로그를 사용한 자체 계산입니다.

```math
L_{\mathrm{policy}}
=-0.25\log0.6-0.75\log0.4\approx0.814924
```

이 값은 B의 확률을 올리고 A의 확률을 줄이는 학습 방향을 줍니다. 현재 망이 A를 더 좋아했더라도 탐색에서 B를 더 살폈다는 자료가 교사 역할을 합니다. 단, 이 예제의 탐색 방문은 직접 설정한 숫자로 실제 대국 기록이 아닙니다.

망의 결과 예측이 0.2이고 최종 승패값이 +1이라면 제곱 오차는 (1−0.2)의 제곱, 즉 0.64입니다. 정책을 맞추는 오차와 결과를 맞추는 오차는 서로 다른 정보를 학습시킵니다. 여기에 가중치의 크기를 제어하는 항을 더할 수 있습니다. 세 항의 값과 척도를 혼동하면 손실 숫자 하나의 의미를 잘못 읽게 됩니다.

| 학습에 쓰는 정보 | 어디서 얻나요 | 어떤 질문에 답하나요 |
| --- | --- | --- |
| 국면 | 자기 대국의 중간 상태 | 무엇을 보고 있나요 |
| 탐색 분포 | 후보 수의 방문 횟수 | 어느 수를 더 고려했나요 |
| 최종 결과 | 게임의 종료 규칙 | 결국 이겼나요, 비겼나요, 졌나요 |

## 무승부를 포함한 기대값

체스처럼 무승부가 가능한 게임에서는 결과값 +1, 0, −1의 기대값을 사용할 수 있습니다. 직접 만든 확률이 승리 0.4, 무승부 0.5, 패배 0.1이라면 기대 결과는 0.3입니다. 승리 확률 0.4와 같지 않습니다. 바둑의 승패만 있는 예에서 쓰는 확률 변환을 그대로 적용하면 오류가 납니다.

```math
E[z]=1\times0.4+0\times0.5-1\times0.1=0.3
```

또한 같은 국면의 결과도 누구의 차례를 기준으로 적었는지 확인해야 합니다. 양측을 번갈아 평가하는데 부호를 바꾸지 않으면 상대에게 좋은 결과를 자신의 좋은 결과로 학습할 수 있습니다. 부호 규칙은 구현의 작은 표기 문제가 아니라 목적의 의미를 결정합니다.

## 대국 결과를 비교할 때

원문은 상대 프로그램, 하드웨어, 시간 제한, 추가 시작 국면을 구체적으로 적습니다. 이 조건은 결과를 읽는 데 필요합니다. 초당 탐색 위치가 적다는 이유만으로 전체 계산 자원도 같은 비율로 적다고 결론 내릴 수는 없습니다. 한 위치를 평가하는 신경망 계산과 전통적 탐색의 비용은 다릅니다.

마찬가지로 “일반 알고리즘”은 여기서 여러 완전 정보 보드게임에 공통 틀을 적용했다는 범위를 갖습니다. 숨겨진 카드, 변화하는 규칙, 사람의 말을 오해하는 상황까지 같은 결과가 확인되었다는 의미는 아닙니다. 훈련에 필요한 자기 대국량과 평가 시 사용하는 장치도 나누어 보셔야 합니다.

후속 [MuZero 논문](https://arxiv.org/abs/1911.08265)은 실제 전이 규칙을 탐색에 직접 제공하는 조건을 달리하여 학습된 모델로 계획합니다. 이는 AlphaZero가 이미 게임 규칙을 스스로 발견했다는 뜻이 아니라, 후속 연구가 어떤 가정을 바꾸었는지 보여 주는 연결입니다.

## 방문 횟수와 행동 선택의 관계

세 수의 탐색 방문이 10, 30, 60이라고 직접 정하면 총 방문은 100입니다. 방문 비율을 그대로 사용한 선택 분포는 0.1, 0.3, 0.6입니다. 가장 많이 방문한 수만 항상 고르는 규칙과는 다릅니다. 전자는 때로 다른 수를 시도하고 후자는 해당 국면에서 늘 세 번째 수를 고릅니다.

탐색 중에 후보를 조사하는 규칙과, 탐색이 끝난 뒤 실제 한 수를 고르는 규칙도 구분해야 합니다. 학습을 위한 자기 대국에서는 경험의 다양성이 필요할 수 있고, 평가 대국에서는 다른 설정을 사용할 수 있습니다. 방문 분포가 있다는 사실만으로 실제 행동이 항상 무작위라고 결론 내리지 않습니다.

또한 100회 방문을 100번의 실제 독립 대국 승패와 같게 세면 안 됩니다. 트리의 공통 구간과 현재 가치망의 추정이 공유될 수 있습니다. 이 연습은 탐색 결과가 어떻게 학습 자료와 행동으로 이어지는지 보여 주며, 실제 논문의 방문 설정이나 대국 결과를 재현한 것이 아닙니다.
