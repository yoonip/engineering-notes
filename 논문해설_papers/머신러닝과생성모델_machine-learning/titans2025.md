# Titans: 추론 중에도 갱신하는 신경망 기억과 짧은 어텐션

Ali Behrouz, Peilin Zhong, Vahab Mirrokni의 「Titans: Learning to Memorize at Test Time」를 읽습니다. 세 저자의 소속은 Google Research입니다. [arXiv 기록](https://arxiv.org/abs/2501.00663)의 식별자는 2501.00663이지만 v1 제출 시각은 2024년 12월 31일 UTC입니다. 따라서 식별자의 월과 실제 제출 연도를 구분합니다. 여기서는 학술지 발표를 추정하지 않고 이 공개 원고를 대상으로 합니다.

## 원문의 구조와 질문

1–2절은 배경, 3절은 장기 기억과 병렬 학습·지속 기억, 4절은 기억 결합 방식 세 가지, 5절은 언어·회상·시계열·DNA·효율·구성 요소 실험, 6절은 결론입니다. 부록은 관련 연구와 과제, 기억 모듈의 연결을 다룹니다. 짧은 범위를 보는 어텐션과, 입력에 맞춰 자체 가중치를 바꾸는 기억을 결합합니다. MAC·MAG·MAL은 기억을 합치는 방식이 다릅니다. [원문 3–5절](https://arxiv.org/pdf/2501.00663)

긴 문맥에서 특정 정보를 찾은 결과를 무제한의 정확한 기억이나 사람과 같은 장기 기억의 입증으로 확대하지 않습니다. 신경심리학에서 가져온 이름은 설계의 관점이며 동일한 생물학적 기제라는 실험 근거가 아닙니다.

## 추론 중 학습과 고정된 기억

일반적인 추론에서는 학습이 끝난 가중치를 그대로 두고 입력에 대한 출력을 계산합니다. 여기의 신경 기억은 처리 중인 입력에서 키와 값의 관계를 배우도록 내부 가중치를 갱신합니다. 바깥 학습은 무엇을 어떻게 기억할지를 학습하고, 안쪽 갱신은 현재 열의 관계를 기록하는 식으로 구분할 수 있습니다.

지속 기억은 입력과 무관한 학습 가능한 매개변수이며, 현재 문맥으로 갱신하는 장기 기억과 다릅니다. ‘persistent’라는 이름만으로 모든 사용자 대화가 영구 저장된다는 뜻은 아닙니다. 사용 범위와 초기화·저장 정책은 실제 배포 구현의 별도 조건입니다.

놀라움은 여기서 연상 기억 손실의 기울기에 연결된 수치입니다. 사람이 놀랐는지 직접 측정한 감정 값은 아닙니다. 기울기의 부호와 크기는 현재 기억이 입력 관계를 얼마나 수정해야 하는지에 대한 학습 신호로 읽는 편이 정확합니다.

## 직접 계산하는 작은 연상 기억

설명용으로 기억 함수를 M(k)=wk라고 두겠습니다. 키 k=1, 값 v=3, 현재 가중치 w=1이면 예측은 1입니다. 손실을 (wk−v)의 제곱으로 정의하면 손실은 4, w에 대한 기울기는 −4입니다.

```math
\ell=(wk-v)^2,
\qquad\frac{\partial\ell}{\partial w}=2(wk-v)k=-4
```

학습률을 0.1로 직접 정하면 새 w는 1−0.1×(−4)=1.4입니다. 같은 키를 다시 읽으면 예측은 1.4가 됩니다. 처음보다 값 3에 가까워졌지만 한 번에 정확히 외운 것은 아닙니다. 이 계산은 논문의 다층 신경 기억과 모멘텀 전체를 재현하는 실행이 아닙니다.

이번에는 같은 키에 다른 값 −3이 들어온다고 해 보겠습니다. 한 숫자 w만으로 두 값을 동시에 완벽하게 저장할 수는 없습니다. 어떤 정보를 덮어쓰고 남길지, 키를 어떻게 구분할지가 중요해집니다. 기억을 갱신한다는 사실과 모든 정보를 충돌 없이 보존한다는 결론은 다릅니다.

## 모멘텀과 잊기의 의미

이전 수정 방향을 일부 남기는 모멘텀은 한 번의 큰 신호 뒤에 관련 정보가 이어지는 상황을 고려하는 장치입니다. 감쇠는 기존 기억을 줄이는 역할을 합니다. 이런 계수를 데이터에 맞게 조절하면 고정된 누적과 다른 동작을 만들 수 있습니다.

직접 만든 단순 예로 이전 기억이 10이고 감쇠 계수를 0.9로 두면 새 기록 전에는 9가 남습니다. 이것이 정보의 90%를 의미적으로 정확히 보존했다는 뜻은 아닙니다. 숫자 크기와 사실 기억의 비율은 같은 척도가 아닙니다. 감쇠로 지운 정보가 무엇인지도 표현에 따라 달라집니다.

## 장기 기억을 어떻게 결합하나요

MAC는 기억에서 읽어 온 내용을 현재 문맥과 함께 어텐션에 넣습니다. MAG는 기억과 주 계산 경로를 게이트로 결합하고, MAL은 기억을 층으로 통합하는 방식입니다. 세 방법의 이름만 외우기보다 어디서 읽고, 어디서 쓰며, 어떤 정보가 다음 구간에 넘어가는지 화살표로 그려 보시면 좋습니다.

설명용 열에 “민수의 사물함 번호는 17”을 먼저 넣고 긴 방해 문장 뒤에 번호를 묻는 과제를 만들 수 있습니다. 단순 회상과 “민수의 사물함이 옮겨져 지금은 23”이라는 수정 반영을 따로 평가하면 저장과 갱신의 차이가 보입니다. 이 글에서는 모델을 실행하지 않았으며 두 과제의 성공률을 제시하지 않습니다.

## 결과와 남는 질문

원문은 특정 규모·학습 토큰 수에서 여러 기억 모델과 비교하고, 매우 긴 방해 문맥의 정보 찾기와 다른 모달리티를 나누어 평가합니다. 정보 찾기를 잘했다는 사실이 긴 문서 전체의 정확한 요약·다단계 추론을 모두 보장하지는 않습니다. 문맥 길이와 유효하게 이용하는 능력도 같은 수치가 아닙니다. [원문 5절](https://arxiv.org/pdf/2501.00663)

확인한 범위에서 후속 독립 연구의 성능이나 제품 적용을 단정하지 않습니다. 이 연구가 연결하는 선행 방법은 [Mamba-2](mamba2_2024.md), 선형 연상 기억, 추론 시 학습입니다. 실제 배포에서 사용자별 기억 분리와 초기화, 잘못된 입력으로 인한 기억 오염을 어떻게 처리할지는 추가 검증 문제로 남습니다.

## 수정된 사실과 방해 정보를 나누기

앞에서 번호를 17로 알렸고 나중에 23으로 정정했다고 하겠습니다. 정답은 가장 자주 나온 숫자가 아니라, 현재 유효한 조건에 맞는 숫자일 수 있습니다. 기억의 크기를 늘리는 것만으로 최신성이나 출처 신뢰도가 자동으로 결정되지는 않습니다.

반대로 방해 문장에 ‘누군가 번호가 99라고 추측했습니다’가 있으면, 단순히 나중에 나온 숫자를 저장하는 규칙도 틀릴 수 있습니다. 직접 평가 입력에는 확정 공지, 정정, 인용, 추측을 구분해 넣을 수 있습니다. 이는 기억이 남았는지와 어떤 정보를 정답 근거로 선택했는지를 분리하는 문제입니다.

원문의 길이 회상 결과를 이런 모든 자연어 갱신 상황의 해결로 확대하지 않습니다. 실제로 어느 조건에 성공하는지는 독립된 평가가 필요합니다. 이 글의 번호 사례들은 모델 출력이 아닌 자체 시험 설계이며, 사람의 장기 기억과 같은 능력을 입증했다고 해석하지 않습니다.
