# U-Net: 위치 정보를 되살려 픽셀마다 이름을 붙이는 방법

Olaf Ronneberger, Philipp Fischer, Thomas Brox의 「U-Net: Convolutional Networks for Biomedical Image Segmentation」은 MICCAI 2015 논문입니다. 저자 소속은 University of Freiburg입니다. [원문](https://arxiv.org/abs/1505.04597)과 [저자 공식 프로젝트](https://lmb.informatik.uni-freiburg.de/people/ronneber/u-net/)를 기준으로 읽습니다. 원문은 8쪽이며, 1절 배경, 2절 구조와 학습, 3절 실험, 4절 결론 순서입니다.

## 사진 분류와 다른 질문

분류가 “이 사진에 세포가 있나요”를 묻는다면, 분할은 “어느 픽셀이 세포에 속하나요”를 묻습니다. U-Net은 축소 경로와 확대 경로를 연결하고, 대응하는 해상도의 특징을 이어 붙여 위치 정보를 이용합니다. 논문은 생의학 영상과 제한된 주석 자료를 대상으로 증강과 경계 가중치를 사용합니다. 원래 구조는 유효 합성곱을 사용하므로 입력과 출력 크기도 다릅니다. [원문 2절, 그림 1](https://arxiv.org/pdf/1505.04597)

오늘날 같은 크기를 유지하도록 패딩한 구현까지 모두 원래 그림의 572→388 설정이라고 부르면 안 됩니다. U-Net이라는 큰 구조와 특정 논문의 커널·경계 처리를 구분해야 합니다.

## 용어를 그림의 움직임으로 읽기

합성곱은 작은 창을 움직이며 주변 픽셀의 정보를 일정한 계산 규칙으로 모으는 연산입니다. 특징 채널은 위치마다 여러 종류의 계산 결과를 저장한 칸입니다. 다운샘플링은 공간 크기를 줄이는 과정이며, 업샘플링은 공간 격자를 늘리는 과정입니다. 격자를 늘렸다는 이유만으로 사라진 정보를 정확하게 복원했다는 뜻은 아닙니다.

스킵 연결은 앞선 계산에서 얻은 정보를 뒤쪽으로 직접 보내는 통로입니다. U-Net의 대응 특징 결합은 채널 방향의 이어 붙이기입니다. 숫자를 더하는 잔차 연결과 같은 연산이 아닙니다. 크롭은 가장자리 일부를 잘라 두 특징의 공간 크기를 맞추는 동작입니다.

## 직접 계산하는 출력 크기

패딩 없이 3×3 합성곱을 한 번 적용하면 가로와 세로가 각각 2씩 줄어듭니다. 설명용으로 10×10 입력에서 시작해 보겠습니다.

| 계산 | 공간 크기 | 줄어든 이유 |
| --- | --- | --- |
| 시작 | 10×10 | 직접 정한 입력입니다 |
| 3×3 합성곱 한 번 | 8×8 | 창이 영상 밖으로 나가지 않습니다 |
| 다시 3×3 합성곱 | 6×6 | 각 축에서 2가 더 줄어듭니다 |
| 2×2, 보폭 2 풀링 | 3×3 | 겹치지 않는 작은 블록으로 묶습니다 |

이 예는 원문의 전체 크기 추적을 대신하지 않는 작은 계산입니다. 출력 크기가 다른 특징을 무작정 이어 붙이면 배열 차원이 맞지 않습니다. 구현에서 크롭이나 패딩이 단순한 화면 장식이 아닌 이유입니다.

두 특징이 공간 크기 8×8이고 채널이 각각 16과 32라면 이어 붙인 결과는 8×8×48입니다. 같은 위치끼리 더하려면 채널 수까지 맞아야 하지만, 이어 붙이기에서는 16과 32를 합쳐 48개의 특징을 보존합니다. 이 차이를 외워 두시면 U자형 그림의 화살표를 실제 배열 동작으로 읽기 쉽습니다.

## 픽셀 오차와 세포 경계

픽셀마다 정답 이름을 맞히게 하면 배경이 매우 많은 사진에서는 배경만 예측해도 높은 정확도가 나올 수 있습니다. 직접 만든 100픽셀 영상에서 세포가 5픽셀뿐이라면 전부 배경으로 예측하는 방법의 정확도는 95%입니다. 세포를 하나도 찾지 못했으므로 이것을 유용한 결과라고 보기 어렵습니다.

정답 세포가 5픽셀이고 예측 세포가 6픽셀이며 겹치는 부분이 4픽셀이라고 가정하겠습니다. 정밀도는 4/6, 재현율은 4/5입니다. IoU는 교집합을 합집합으로 나누므로 4/(5+6−4)=4/7, 약 0.5714입니다. 서로 다른 질문에 답하는 지표이므로 단순 정확도와 같은 값일 필요가 없습니다.

```math
\operatorname{IoU}=\frac{|P\cap G|}{|P\cup G|}
=\frac4{6+5-4}=\frac47
```

닿아 있는 두 세포를 나누려면 세포와 배경만 구별하는 것보다 경계를 세밀하게 다뤄야 합니다. 논문의 경계 가중치는 이 문제를 학습 손실에 반영하는 장치입니다. 다만 모든 분할 문제에서 같은 가중치를 써야 한다는 뜻은 아닙니다. 한 덩어리의 영역을 찾는 목표와 개체 수를 구분하는 목표가 다를 수 있습니다.

## 증강과 검증의 한계

영상 증강은 기존 자료에 회전·변형 등을 가해 학습 사례를 만드는 방법입니다. 변형한 영상에서도 정답 마스크가 같은 방식으로 움직여야 합니다. 입력만 회전하고 정답을 그대로 두면 학습 자료가 틀어집니다. 또한 의료 영상에서 물리적으로 불가능한 변형을 허용하면 실제 분포와 멀어질 수 있습니다.

같은 환자나 같은 원본 영상에서 잘라 낸 조각이 훈련과 시험에 동시에 들어가면 점수가 높아질 수 있습니다. 데이터 조각의 개수와 독립된 환자의 수는 같지 않습니다. 이 글의 계산 예제는 지표와 배열을 이해하는 연습이며 의료적 유효성을 평가한 실험이 아닙니다.

후속 [nnU-Net](https://www.nature.com/articles/s41592-020-01008-z)은 데이터 특성에 맞춘 전처리·구조·학습 설정의 중요성을 체계적으로 다룹니다. U자형 그림 하나를 그렸다는 이유만으로 모든 의료 영상 분할의 성능이 확보되는 것은 아니라는 점을 연결해서 읽을 수 있습니다.

## 겹침 지표를 하나 더 비교하기

앞의 자체 예제에서 정답 영역은 5픽셀, 예측 영역은 6픽셀, 교집합은 4픽셀이었습니다. Dice 계수는 교집합의 두 배를 두 영역 크기의 합으로 나누므로 8/11, 약 0.7273입니다. IoU의 약 0.5714와 숫자가 다르지만 같은 두 영역을 평가한 것입니다. 지표 정의가 다르기 때문입니다.

두 방법을 비교할 때 한쪽에는 Dice, 다른 쪽에는 IoU를 적어 어느 쪽이 더 높다고 판단하면 공정하지 않습니다. 범주별 평균인지 전체 픽셀을 합친 계산인지도 맞춰야 합니다. 작은 세포와 큰 배경을 합치는 방식에 따라 어떤 오류가 강조되는지가 달라집니다.

또한 조각 영상의 가장자리에서 잘린 세포를 어떻게 정답 처리했는지도 중요합니다. 패치의 경계에서 생긴 오차와 실제 물체의 경계 오류를 나누어 살피면 크롭과 겹침 타일 방식의 필요성을 이해하기 좋습니다. 이 추가 수치는 지표의 계산 연습이며 실제 의료 영상 결과나 진단 정확도를 뜻하지 않습니다.

## 스스로 확인하기

1. 10×10에 패딩 없는 3×3 합성곱을 두 번 하면 얼마인가요?
2. 채널 16과 32를 이어 붙이면 32가 되나요?
3. 배경만 예측한 정확도 95%는 세포를 잘 찾았다는 뜻인가요?

<details>
<summary>답과 이유</summary>

1. 6×6입니다. 각 합성곱에서 각 축이 2씩 줄어듭니다.
2. 48입니다. 대응 공간 위치의 채널들을 이어 붙입니다.
3. 아닙니다. 예제에서는 세포 재현율이 0입니다.
