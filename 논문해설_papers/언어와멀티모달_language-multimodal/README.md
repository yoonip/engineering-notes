# 문맥 학습과 이미지·언어 표현 | Context, language and images

모델이 새 과제를 받아들이는 방법과 서로 다른 자료를 연결하는 방법을 살펴봅니다. ‘학습’이라는 말이 쓰여도 가중치를 갱신하는 단계와 입력 문맥으로 과제를 지정하는 단계는 구분합니다.

| 논문 | 핵심 내용 | 직접 따라갈 예 |
| --- | --- | --- |
| [GPT-3](문맥의예시로수행하는언어과제_gpt3.md), 2020 | 문맥의 예시 입력과 가중치 미세조정의 차이 | 두 토큰의 조건부 확률, 시범 두 개가 있는 입력 |
| [CLIP](이미지와설명의공동표현_clip.md), 2021 | 이미지·설명의 유사도와 공동 표현 | 이미지 2개·설명 2개의 유사도와 양방향 비교 |
| [LoRA](작은행렬의모델적응_lora.md), 2021/2022 | 저차원 행렬로 표현하는 가중치 변화량 | 작은 행렬의 두 계산 경로, 학습 변수 수 비교 |

먼저 [Transformer](../Transformer의계산_ATTENTION.md)와 [논문의 용어](../논문을읽는용어_PAPER_TERMS.md)를 읽으시면 Q·K·V, embedding, gradient와 inference를 연결하기 쉽습니다. 문장 표현을 사전학습하는 [BERT](../딥러닝_deep-learning/양쪽문맥의가린토큰예측_bert.md)와 잡음에서 샘플을 만드는 [DDPM](../딥러닝_deep-learning/잡음예측과확산생성_ddpm.md)은 각각의 학습 목표를 비교하는 데 도움이 됩니다.
