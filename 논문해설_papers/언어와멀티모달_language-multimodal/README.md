# 문맥 학습과 이미지·언어 표현 | Context, language and images

모델이 새 과제를 받아들이는 방법과 서로 다른 자료를 연결하는 방법을 살펴봅니다. ‘학습’이라는 말이 쓰여도 가중치를 갱신하는 단계와 입력 문맥으로 과제를 지정하는 단계는 구분합니다.

| 논문 | 읽을 질문 | 직접 따라갈 예 |
| --- | --- | --- |
| [GPT-3](gpt3.md), 2020 | 풀이 예시를 입력하는 것과 fine-tuning은 어떻게 다릅니까? | 두 토큰의 조건부 확률, 시범 두 개가 있는 입력 |
| [CLIP](clip.md), 2021 | 이미지와 설명을 어떤 값으로 비교합니까? | 이미지 2개·설명 2개의 유사도와 양방향 비교 |
| [LoRA](lora.md), 2021/2022 | 전체 가중치를 갱신하지 않고 변화량을 어떻게 학습합니까? | 작은 행렬의 두 계산 경로, 학습 변수 수 비교 |

먼저 [Transformer](../Transformer의계산_ATTENTION.md)와 [논문의 용어](../논문을읽는용어_PAPER_TERMS.md)를 읽으시면 Q·K·V, embedding, gradient와 inference를 연결하기 쉽습니다. 문장 표현을 사전학습하는 [BERT](../딥러닝_deep-learning/bert.md)와 잡음에서 샘플을 만드는 [DDPM](../딥러닝_deep-learning/ddpm.md)은 각각의 학습 목표를 비교하는 데 도움이 됩니다.
