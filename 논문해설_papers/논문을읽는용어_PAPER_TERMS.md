# 논문에서 자주 만나는 말 | Terms for reading papers

같은 영어 단어도 연구 문맥에 따라 뜻이 달라집니다. 번역어를 외우는 데서 그치지 않고, 무엇을 입력받아 어떤 관계를 계산하는지 확인하시면 수식을 따라가기 쉽습니다. 아래 숫자 예는 설명을 위해 직접 정한 값입니다.

## 수식의 출발점: 수 하나와 수의 묶음

| 표현 | 쉬운 뜻 | 직접 계산한 예 |
| --- | --- | --- |
| Scalar / 스칼라 | 크기를 나타내는 수 하나입니다. | 온도 20이나 배율 0.5처럼 한 값으로 나타냅니다. |
| Vector / 벡터 | 순서가 있는 수의 묶음입니다. | `(2,3)`에서 첫째 성분과 둘째 성분을 바꾸면 다른 벡터입니다. |
| Matrix / 행렬 | 수를 행과 열로 놓은 표입니다. | 두 행이 `(1,2)`, `(3,4)`인 행렬은 2×2 모양입니다. |
| Dot product / 내적 | 대응하는 성분끼리 곱한 뒤 더하는 계산입니다. | `(2,3)·(4,1)=2×4+3×1=11`입니다. 이 값만으로 유사도가 항상 0~1인 것은 아닙니다. |
| Transpose / 전치 | 행과 열의 역할을 바꾸는 연산입니다. 위첨자 T로 자주 씁니다. | 위 행렬을 전치하면 두 행은 `(1,3)`, `(2,4)`가 됩니다. |

행렬과 벡터의 곱은 각 행과 벡터를 내적해서 만듭니다. 위 행렬에 세로 벡터 `(2,1)`을 곱하면 첫 결과는 `1×2+2×1=4`, 둘째는 `3×2+4×1=10`입니다. 행렬의 열 수와 벡터의 성분 수가 맞아야 합니다. 논문에서 `QKᵀ`처럼 적으면 먼저 K의 행과 열을 바꾼 다음 행렬 곱을 하라는 뜻입니다. 대응 위치만 곱하는 원소별 곱과 구분합니다.

## Attention: 무엇을 얼마나 참고할지 정하는 계산

일상 영어의 attention에는 ‘주의를 기울임’이라는 느낌이 있습니다. 신경망에서는 현재 위치의 표현을 만들 때 다른 위치의 내용을 얼마씩 섞을지 계산한다는 뜻으로 읽으시면 됩니다. 사람이 의식적으로 집중한다는 의미까지 수식에 들어 있지는 않습니다.

예를 들어 두 자료의 값이 10과 20이고 참고 비율이 0.75와 0.25라면 결과는 `0.75×10 + 0.25×20 = 12.5`입니다. 첫 자료를 더 많이 참고했지만 두 번째 자료도 결과에 들어갑니다. 비율 0.75는 이 자료가 정답일 확률이나 설명의 신뢰도 75%를 뜻하지 않습니다. 실제 계산은 [Transformer의 attention](Transformer의계산_ATTENTION.md)에서 이어집니다.

| 용어 | 이 문맥에서의 뜻 | 오해하기 쉬운 점 |
| --- | --- | --- |
| Query | 지금 찾는 정보의 기준을 나타내는 벡터입니다. | 반드시 사람이 쓴 질문 문장은 아닙니다. |
| Key | 다른 위치와 비교할 때 쓰는 특징 벡터입니다. | 암호화 열쇠와는 다른 용법입니다. |
| Value | 계산한 비율로 섞을 내용 벡터입니다. | ‘중요도 점수’ 자체가 아닙니다. |
| Head | 별도의 학습된 변환으로 attention을 계산하는 한 갈래입니다. | 각 갈래의 의미가 미리 문법·주제 등으로 지정되어 있지는 않습니다. |
| GQA | 여러 query 헤드가 더 적은 key·value 헤드를 그룹별로 공유하는 방식입니다. | 캐시의 K·V 저장량을 줄이는 구조이며 전체 실행 메모리가 같은 비율로 줄어든다는 뜻은 아닙니다. |
| Mask | 허용하지 않는 연결을 계산에서 제외하는 규칙입니다. | 금지한 점수를 0으로 바꾸기만 하면 softmax 뒤 비율이 남을 수 있습니다. |

## Normalization: 기준을 정해 값의 크기나 분포를 맞추기

Normalization은 보통 ‘정규화’라고 번역합니다. 이 말만으로 구체적인 계산이 정해지지는 않습니다. ‘무엇을 기준으로, 어느 값들을 묶어서, 어떻게 바꿉니까?’라는 세 질문이 필요합니다.

| 계산 | 직접 만든 예 | 무엇이 달라집니까? |
| --- | --- | --- |
| 범위 맞추기 | 10, 20, 30에 `(x−10)/(30−10)`을 적용하면 0, 0.5, 1입니다. | 정한 최솟값과 최댓값을 기준으로 눈금을 바꿉니다. 새 입력이 범위를 벗어나면 결과도 0~1 밖일 수 있습니다. |
| 평균·분산 맞추기 | 2, 4의 평균은 3, 두 값 전체에 대한 분산은 1입니다. 평균을 빼고 표준편차 1로 나누면 −1, 1입니다. | 기준 집합의 중심과 퍼진 정도를 맞춥니다. 모든 분포를 정규분포로 만드는 과정은 아닙니다. |
| 벡터 길이 맞추기 | 벡터 `(3,4)`의 길이는 5이므로 나누면 `(0.6,0.8)`입니다. | 방향을 유지하면서 길이를 1로 만듭니다. 영벡터에는 그대로 적용할 수 없습니다. |
| 확률 비율 만들기 | 두 점수가 같으면 softmax 결과는 0.5, 0.5입니다. | 지수함수로 바꾼 값을 합으로 나눕니다. 음수 점수도 입력할 수 있습니다. |

표준편차는 평균에서 얼마나 퍼져 있는지 나타내는 양이며 분산의 제곱근입니다. 신경망의 BatchNorm과 LayerNorm은 보통 분산에 작은 양수 epsilon을 더한 뒤 제곱근으로 나눕니다. 이때 분모가 0이 되는 일을 피할 수 있지만 결과 분산이 수학적으로 정확히 1이라고 말할 수는 없습니다. 뒤에 학습하는 배율 gamma와 이동량 beta도 붙을 수 있습니다.

Batch와 layer는 통계를 모으는 축을 가리킵니다. 예를 들어 표의 행이 표본이고 열이 특징일 때, 특징별로 여러 표본을 모으는 방식과 한 표본 안에서 여러 특징을 모으는 방식은 결과가 다릅니다. 실제 영상에서는 채널·가로·세로 축도 있으므로 라이브러리의 입력 모양과 축 정의까지 확인합니다. [BatchNorm](딥러닝_deep-learning/배치정규화_batch-normalization.md)과 [LayerNorm](딥러닝_deep-learning/층정규화_layer-normalization.md)에서 숫자로 비교합니다.

## Regularization: 학습이 특정 자료에 지나치게 맞춰지는 일을 제한하기

Regularization도 한국어로 ‘정규화’라고 부르는 경우가 있어 normalization과 헷갈리기 쉽습니다. 논문에서는 영어를 함께 확인하시는 편이 좋습니다. 정규화된 입력을 만드는 일과 모델이 학습하는 해에 제약을 주는 일은 목적이 다릅니다.

데이터베이스의 정규형과 정규화는 또 다른 문맥입니다. 사실을 어떤 관계로 나누어 표현할지와 종속·중복의 문제를 다룹니다. [Codd의 관계 모형](컴퓨팅과시스템_computing-systems/Codd_관계모형_RELATIONAL_MODEL.md)의 예는 입력 벡터를 길이 1로 바꾸거나 가중치에 벌점을 더하는 계산과 다릅니다.

예를 들어 학습 오차에 `λw²`를 더하면 오차가 같을 때 너무 큰 가중치에 비용을 더 줍니다. 직접 정한 `λ=0.1`에서는 `w=1`의 추가 비용이 0.1, `w=3`에서는 0.9입니다. 이 식이 가중치를 평균 0·분산 1로 바꾸지는 않습니다. Dropout처럼 학습 중 일부 연결의 영향을 무작위로 없애는 방법도 이 목적에 사용됩니다. 실제 일반화 효과는 자료와 설정에 따라 확인해야 합니다.

## 모델과 학습을 설명하는 말

| 용어 | 쉬운 뜻과 문맥 | 짧은 예 |
| --- | --- | --- |
| Parameter / weight | 학습 과정에서 조정하는 수입니다. weight는 입력을 얼마나 반영할지 정하는 계수로 자주 쓰입니다. | `y=wx+b`의 w와 b를 오차에 따라 바꿉니다. |
| Hyperparameter | 학습 방법이나 모델 구성을 정하는 설정입니다. | 학습률과 층 수를 정합니다. 데이터로 선택할 수 있어도 평가용 정답을 보고 고르면 안 됩니다. |
| Gradient | 각 값을 조금 바꿀 때 목적함수가 어느 방향으로 얼마나 변하는지 나타내는 미분들의 묶음입니다. | 오차를 줄이려고 기울기의 반대 방향으로 조금 이동합니다. |
| Representation / embedding | 자료를 계산 가능한 특징, 흔히 벡터로 표현한 것입니다. embedding은 어떤 공간에 대응시키는 느낌이 있습니다. | 단어 번호 자체와 단어를 나타내는 학습 벡터는 다릅니다. |
| Latent | 바로 관측한 입력과 구별되는 내부 변수라는 뜻입니다. ‘잠재’는 반드시 숨은 진실을 발견했다는 의미는 아닙니다. | 생성 모델에서 내부 벡터 z로 출력의 변화를 표현합니다. |
| Residual | 기준값과의 차이 또는 추가분입니다. 신경망에서는 지름길 입력에 더할 수정분으로 읽을 수 있습니다. | 목표가 12이고 입력이 10이면 수정분 2를 더합니다. |
| Autoregressive | 앞에서 주어진 값들을 조건으로 다음 값을 차례로 모델링한다는 뜻입니다. | `P(a,b)=P(a)P(b\|a)`로 나눕니다. |
| Inference | 학습된 모델과 주어진 입력으로 출력을 계산하는 단계입니다. | 문맥으로 뜻을 추론한다는 일반 영어 용법과 모델 실행이라는 용법을 구분합니다. |
| Generalization | 학습에 사용하지 않은 사례에도 성립하는 정도입니다. | 연습 문제 점수와 새 문제 점수를 나누어 확인합니다. |

‘학습한다’는 말도 구분해야 합니다. [GPT-3](언어와멀티모달_language-multimodal/문맥의예시로수행하는언어과제_gpt3.md)의 문맥 내 예시는 입력을 바꾸지만 그 평가 중 가중치를 갱신하지 않습니다. [LoRA](언어와멀티모달_language-multimodal/작은행렬의모델적응_lora.md)는 일부 추가 행렬을 실제로 학습합니다. 두 방법 모두 새 과제에 적응한다는 표현을 쓸 수 있어도 계산 과정은 다릅니다.

## 결과 표와 주장에 붙는 말

Baseline은 비교할 기준 방법입니다. 일부러 약한 기준만 고르면 새 방법의 장점이 커 보일 수 있습니다. Ablation은 구성 요소를 빼거나 바꿔 어떤 차이가 생기는지 살피는 실험입니다. 한 요소를 뺐을 때 점수가 낮아졌다고 해서 모든 데이터와 모든 설정에서 그 요소가 필수라고 결론 내리지는 않습니다.

Benchmark는 비교에 쓰는 과제·자료·평가 절차의 묶음입니다. ‘정확도 90’만 적힌 표보다 어떤 자료에서 어떤 기준으로 90이 나왔는지 적힌 표를 읽어야 합니다. Throughput은 시간당 처리량, latency는 요청 한 건이 끝날 때까지의 시간입니다. 처리량이 늘어도 기다리는 시간은 길어질 수 있습니다. [모델 평가의 계산 예](../분야_topics/46-AI응용에이전트평가_ai-agents-evaluation/해설_notes/모델평가지표_MODEL_EVALUATION.md)에서 확인하실 수 있습니다.
