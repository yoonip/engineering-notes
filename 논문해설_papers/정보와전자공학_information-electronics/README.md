# 정보와 전자공학의 논문 / Papers on information and electronics

정보를 얼마나 줄여 보낼 수 있는지, 반도체를 작게 만들면 무엇이 달라지는지, 계산을 어떻게 나누어야 빨라지는지를 다룬 논문 7편을 읽습니다. 각 글은 원문에서 확인한 주장과 이 문서에서 직접 만든 계산을 구분합니다.

## 연결해서 읽기

Shannon은 확률과 통신의 제약, FFT는 계산 순서, Amdahl은 전체 시간의 병목을 다룹니다. 서로 다른 문제이므로 한 논문의 식으로 다른 논문의 결론을 바로 증명할 수는 없습니다.

반도체 쪽에서는 점접촉 트랜지스터의 동작을 먼저 살펴본 뒤, Moore의 경제적 추세와 Dennard의 물리적 축소 조건을 나누어 읽으시면 좋습니다. RISC 글은 주어진 기술 자원을 명령어·제어 회로·컴파일러 사이에 어떻게 배분할지 묻습니다.

## 원문과 계산을 확인하는 방법

각 글 첫 표의 쪽 번호는 원문 인쇄 쪽 또는 링크한 PDF의 순서를 따르며, 두 번호가 다르면 따로 표시합니다. 수치 예는 별도 표시가 없는 한 이 해설에서 만든 가정입니다. 원문의 장비 성능이나 오늘날 제품의 측정 결과로 읽으시면 안 됩니다. 원문 전체나 원문 그림을 옮기지 않고, 짧은 핵심 설명과 직접 계산한 예제로 정리했습니다.
