# 통신과 정밀 측정을 읽는 논문

안테나·오류정정·광섬유가 정보를 전달하는 방법과, 원자의 신호로 시간·중력을 비교하는 방법을 다룹니다. 각 글에는 원문 위치, 읽은 판본, 용어 설명, 자체 계산과 정답 해설을 넣었습니다. 실제 장치의 결과와 이해를 위한 작은 계산을 구분합니다.

## 통신

| 논문 | 읽을 질문 | 한국어 해설 |
|---|---|---|
| Telatar, 1999 | 여러 안테나의 용량은 총 전력·채널 지식에 따라 어떻게 달라지나요? | [MIMO 채널 용량](telatar1999-mimo.md) |
| Gallager, 1962 | 적은 검사식과 신뢰도 정보로 오류를 어떻게 다루나요? | [LDPC 부호](gallager1962-ldpc.md) |
| Alamouti, 1998 | 두 송신 안테나로 오류를 줄이는 방법은 전송률 두 배와 어떻게 다른가요? | [송신 다이버시티](alamouti1998-diversity.md) |
| Kao·Hockham, 1966 | 유리섬유의 재료 손실과 파동 구조를 왜 함께 살펴야 하나요? | [광섬유 통신의 조건](kao-hockham1966-fibre.md) |

## 읽는 순서와 근거의 범위

통신이 처음이라면 광섬유 글의 손실·지연 계산과 Alamouti 글의 두 심벌 계산부터 읽으셔도 좋습니다. 그 뒤 Gallager의 패리티와 Telatar의 행렬식으로 넘어갑니다. 원자시계는 주파수·안정도·정확도, 중력계는 가속도·기울기·역문제의 차이를 먼저 확인합니다.

원문은 2026년 10월 20일에 확인했습니다. Telatar는 MIT 공개 28쪽 저자 원고, Kao·Hockham은 1999년 재입력 전문을 읽었으며 최종 조판본을 읽은 것으로 적지 않았습니다. 나머지는 각 글에 연결한 공개 출판본과 Methods를 읽었습니다. 자체 예는 원저의 데이터 재분석이나 논문 실험 재현이 아닙니다.
