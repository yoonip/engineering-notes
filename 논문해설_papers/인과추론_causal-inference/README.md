# 관측 자료와 인과 효과 / Causal inference

두 집단의 결과가 다르다는 관찰에서 출발해, 원인을 바꿨을 때의 결과를 말하려면 어떤 가정이 필요한지 읽습니다. 표본을 많이 모으는 문제와 관측 자료만으로 효과가 정해지는 문제를 구별합니다.

| 논문 | 해설 | 직접 따라갈 예제 |
|---|---|---|
| Pearl, 1995, Causal diagrams for empirical research | [관측과 개입을 구별하는 인과 그림](관측과개입을구별하는인과그림_pearl1995.md) | 실력 구성이 다른 두 집단의 비율을 같은 인구로 환산하고, 공통 결과를 조건으로 삼을 때 생기는 관련을 계산합니다. |

화살표를 그렸다는 사실이 인과 가정을 입증하지는 않습니다. 본문은 원문의 이론·토론, 자체 자료의 계산, 현실에서 더 확인해야 할 조건을 구별합니다. 실제 개입 연구의 설계와 결과는 [사회과학의 현장 자료와 실험](../사회과학의실험_social-science-experiments/README.md)에서도 비교하실 수 있습니다.
