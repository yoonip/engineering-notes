# 호르몬과 행동 / Hormones and behaviour

식욕·에너지 상태·스트레스·사회적 행동을 관련 논문에서 읽습니다. 무엇이 분비되거나 발현되는지, 어떤 개입 뒤 무슨 과제가 달라지는지, 어디까지 인과적으로 해석할 수 있는지를 따로 확인합니다. 확인일은 2026-10-20입니다. 연구 결과를 개인별 투여·치료 방법이나 인간의 가치에 관한 순위로 바꾸지 않습니다.

| 논문 | 핵심 내용 | 해석할 때 확인할 점 |
|---|---|---|
| [Considine 등, 1995: 인간 ob 유전자 발현](사람의렙틴유전자발현_considine1995-leptin.md) | 렙틴 유전자 발현과 비만의 관계 | mRNA·단백질·수용체 반응을 구분합니다. |
| [Wren 등, 2001: 그렐린과 식사](그렐린투여와식사섭취량_wren2001-ghrelin.md) | 그렐린 투여에 따른 섭취량과 허기 측정 | 작은 교차시험의 조건과 일상의 판단을 구분합니다. |
| [von Dawans 등, 2011: 집단 스트레스 시험](집단사회적스트레스실험_von-dawans2011-tsstg.md) | 사회적 평가 스트레스의 주관·호르몬·심박 측정 | 주관적 보고·호르몬·심박과 과제 구성의 차이를 봅니다. |
| [Arnsten, 2009: 스트레스와 전전두피질](스트레스와전전두엽작업기억_arnsten2009-stress-pfc.md) | 스트레스 신호와 전전두피질의 기억·주의 조절 | 급성·만성, 신호 물질과 수용체, 종과 과제를 나눕니다. |
| [Kosfeld 등, 2005: 옥시토신과 신뢰 게임](옥시토신의신뢰게임과재현_kosfeld2005-oxytocin.md) | 신뢰 게임의 금전 이전과 사회적 위험 | 사회적 위험·다른 위험, 원 연구와 후속 재현을 비교합니다. |
| [De Dreu 등, 2011: 옥시토신과 집단 구분](옥시토신과집단간편향_de-dreu2011-ingroup.md) | 옥시토신 효과와 행동 대상의 집단 구분 | 내집단 선호와 외집단 적대가 같은 결과인지 확인합니다. |

최초 발견 논문의 서지만 읽고 전문을 분석했다고 적지 않습니다. 예를 들어 이 목록의 렙틴·그렐린 글은 실제 전문을 읽은 인간 연구를 중심에 두며, 역사적 발견의 역할과 그 연구가 직접 확인한 범위를 개별 본문에서 구분합니다. 원문 그림·표·전문 번역을 재게시하지 않고 한국어 해설과 자체 예제를 제공합니다.

## 물질의 이름과 행동의 이름 사이

호르몬은 몸의 다른 곳에 신호를 전달하는 물질입니다. 농도만으로 효과가 결정되는 간단한 스위치처럼 생각하기보다 어떤 수용체가 어느 조직에서 반응하는지, 이전 상태와 시간이 무엇인지 살펴보아야 합니다. 같은 물질을 연구해도 혈액 농도를 관찰한 연구와 투여한 연구는 다른 질문에 답합니다.

원 논문의 관측 단위도 확인합니다. 세포의 mRNA가 많다는 결과는 해당 단백질의 분비량·뇌의 반응·최종 행동을 모두 직접 측정했다는 뜻이 아닙니다. 스트레스 과제가 코르티솔과 다른 여러 변화를 함께 일으켰다면 과제의 효과 전부를 코르티솔 하나의 효과로 배분할 수 없습니다. 경로를 구체적으로 묻는 연구가 필요한 이유입니다.

‘식사량 증가’와 ‘판단력 상실’, ‘신뢰 게임 송금 증가’와 ‘모든 사람에 대한 도덕성 증가’도 같은 측정이 아닙니다. 결과의 과제명과 분모를 유지하면 신기한 발견을 받아들이면서도 과장된 별칭을 피할 수 있습니다. 후속 연구가 효과를 재현하지 못했을 때에도 어떤 조건과 효과 크기를 검사했는지 살펴봅니다.
