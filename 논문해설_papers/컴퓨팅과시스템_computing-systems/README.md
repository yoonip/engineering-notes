# 계산·데이터·통신·분산 시스템 논문 | Computing and systems

컴퓨터가 수행할 수 있는 일의 범위에서 출발하여 데이터를 표현하고, 서로 다른 컴퓨터가 통신하며, 장애 속에서도 저장과 계산을 이어 가는 방법을 읽습니다. 논문마다 해결하려는 문제, 작동 과정, 용어, 자체 계산 예와 한계를 함께 설명합니다.

## 읽을 글

| --- | --- | --- | --- |

앞의 다섯 글은 각 개념의 전제를 읽는 데 도움이 됩니다. 뒤의 세 글은 저장 사본, 계산 작업, 데이터 버전이라는 서로 다른 단위의 장애 처리를 비교하기 좋습니다. 파일 복제가 작업의 중복 실행까지 막아 주거나, 사건 정렬이 합의까지 해결해 주는 것은 아닙니다.

## 예제와 논문 결과의 구분

각 글의 작은 수·표·흐름도는 설명을 위해 직접 구성했습니다. 논문 저자의 측정표나 실제 서비스 시험 결과가 아닙니다. 자체 예제는 아래 관계를 계산으로 확인했습니다.

| 글 | 자체 예제에서 확인한 내용 |
| --- | --- |
| Turing | n개의 막대 뒤에 하나를 더 쓰는 전이는 n+1회입니다. |
| Codd | 전체 조인은 3개, 통계 수강만 남긴 조인은 2개이며 이름 집합은 2개입니다. |
| Cerf·Kahn | 1,000바이트 분할은 300·300·300·100이며, 4,096/0.1은 40,960바이트/초입니다. |
| Diffie·Hellman | p=23인 예의 공유값은 2이며 중간자와의 별도 공유값은 18과 7입니다. |
| Lamport | 메시지 경로의 시계는 증가하지만 서로 연결되지 않은 사건도 숫자가 다를 수 있습니다. |
| GFS | 160 MiB 내용의 세 사본은 480 MiB이며 실제 디스크 부가 비용은 제외했습니다. |
| MapReduce | 도시별 합계는 29이며, 묶음 크기가 다르면 평균의 평균과 전체 평균이 다릅니다. |
| Dynamo | 두 갈래 `(1,0)`·`(0,1)`은 비교되지 않으며, 고정된 세 사본의 2개 집합끼리는 겹칩니다. |

서지는 출판사·학회·저자 공개 원문을 기준으로 확인했습니다. 각 글 첫 문단에는 발표처와 연도, 본문에는 읽을 절이나 쪽을 적었습니다. 같은 논문의 공개 PDF와 학회 인쇄본은 쪽 구성이 다를 수 있어 PDF 쪽과 인쇄 쪽을 구분합니다. 이 자료는 논문 전체의 번역본이나 현재 제품의 성능 순위가 아닙니다.
