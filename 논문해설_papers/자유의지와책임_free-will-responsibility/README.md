# 자유의지와 책임 / Free will and responsibility

자유의지가 무엇을 요구하는지, 어떤 책임을 정당화하려는지에 따라 논증을 비교합니다. 결정론은 예측 가능성·강제·숙명론과 구분하며, 비결정성도 그 자체로 통제를 주지는 않습니다. 각 글에는 원문 위치, 쉬운 용어 설명, 직접 만든 사례, 반론과 확인 문제가 있습니다.

## 비교하며 읽는 순서

Strawson 1962와 Galen Strawson 1994를 먼저 비교하면 책임이라는 말의 범위를 확인할 수 있습니다. Frankfurt 1969와 van Inwagen 1975는 대안 가능성과 능력을, Frankfurt 1971과 Kane 2009는 자신의 동기를 받아들이고 형성하는 문제를 비교하기 좋습니다. 어떤 글이 책임의 특정 필요조건을 공격했다는 사실을 자유의지의 완전한 이론이 증명되었다는 뜻으로 바꾸지 않습니다.

고전 논문과 최근 AI 적용 연구는 대표 논증의 일부이며 자유의지 논쟁 전체의 목록은 아닙니다. 고전 논문이 현대 AI나 호르몬을 직접 측정했다는 뜻으로 연결하지 않습니다. [입장별 비교와 AI·신체 상태 사례](../../인문사회_humanities/58-철학비판적사고_philosophy-critical-thinking/해설_notes/자유의지와인격동일성_free-will-and-personal-identity.md)에서 필요한 추가 전제를 나누어 읽으실 수 있습니다.
