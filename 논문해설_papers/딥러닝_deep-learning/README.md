# 딥러닝 논문 읽기 / Reading deep learning papers

신경망의 학습, 이미지 인식, 생성, 문맥 표현을 다룬 논문 11편을 읽습니다. 각 글에는 배경, 방법, 용어, 직접 계산할 수 있는 예제, 근거와 한계, 접어서 확인하는 자가점검이 있습니다. 수학 기호가 낯설다면 아래 순서에서 시작하시면 됩니다.

## 잠재변수와 생성

| 순서 | 논문과 발표 연도 | 먼저 알아볼 질문 |
|---|---|---|
| 7 | [VAE, 2013 공개·2014 발표](vae.md) | 잠재분포와 로그 가능도의 하한을 어떻게 학습하나요? |
| 8 | [GAN, 2014](gan.md) | 생성자와 판별자는 왜 다른 방향으로 갱신하나요? |

세 방법 모두 새 표본을 만들 수 있지만 학습 목표와 생성 절차가 다릅니다. VAE는 잠재변수와 디코더, GAN은 판별 신호를 받는 생성자, DDPM은 잡음에서 시작하는 역과정을 중심으로 비교합니다. 이름만으로 품질·속도·다양성의 순위를 정하지 않습니다.

## 수식을 읽는 데 필요한 최소한의 말

| 기호·말 | 이 묶음에서의 뜻 |
|---|---|
| x, y | 입력과 출력의 숫자 또는 숫자 묶음입니다. 실제 의미는 각 예제에서 정합니다. |
| w, θ | 학습으로 바꾸는 가중치나 파라미터입니다. |
| L, 손실 | 모델의 현재 출력을 평가해 줄이려는 숫자입니다. |
| Σ, 합 | 정해진 범위의 값을 모두 더합니다. |
| ∂, 편미분 | 다른 변수를 고정하고 한 변수를 조금 바꿀 때의 변화율입니다. |
| E, 기댓값 | 확률에 따라 가중한 평균입니다. 표본 하나와 구분합니다. |
| log | 여기의 계산에서는 자연로그입니다. 곱을 합으로 바꾸는 성질이 있습니다. |
| p(z), p(x\|z) | z의 분포와 z가 주어졌을 때 x의 조건부 분포입니다. |
| 배치·표본·특징 | 자료의 묶음, 자료 하나, 그 자료를 나타내는 각 성분입니다. |

같은 단어라도 쓰이는 대상이 다를 수 있습니다. 예를 들어 정규화는 normalization과 regularization을 구분하고, 잔차는 ResNet의 입력 대비 변화량이라는 문맥을 확인합니다. 문장의 뜻을 먼저 읽은 뒤 수식에서 어느 숫자에 해당하는지 찾으시면 됩니다.

## 계산과 실험을 구분하며 읽습니다

본문의 작은 행렬, 카드 분포, 토큰 수, 잡음 계산은 설명을 위해 직접 만든 예제입니다. 관련 산술을 검산했지만 원논문 모델을 학습하거나 논문 점수를 재현한 실험은 아닙니다. 디코더의 로그 가능도처럼 가정한 숫자는 해당 위치에 가정이라고 표시했습니다.

논문 결과를 읽을 때는 자료, 모델 크기, 학습 설정, 평가 지표, 단일 모델과 앙상블 여부를 함께 보셔야 합니다. 첫 공개 연도와 학회 발표 연도가 다른 경우 둘을 나눴습니다. 원문 그림·표와 긴 문장은 옮기지 않았으며, 직접 확인한 절과 쪽수는 각 글 앞에 기록했습니다. 출처 확인일은 2026-10-19입니다.

처음 읽으실 때는 각 글의 숫자 예제를 한 번 손으로 계산한 뒤 자가점검 3문항을 풀어 보시면 됩니다. 합계 33문항입니다. 정답을 맞혔더라도 “이 예제에서 확인한 것”과 “실제 자료에서 새로 측정해야 하는 것”을 한 문장씩 구별해 적어 보시면 논문의 주장 범위를 놓치지 않는 데 도움이 됩니다.
