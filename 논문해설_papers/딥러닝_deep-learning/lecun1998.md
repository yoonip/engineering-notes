# LeNet과 문서 인식: 같은 필터를 여러 위치에 쓰기 / LeNet and document recognition

Yann LeCun, Léon Bottou, Yoshua Bengio, Patrick Haffner의 「Gradient-Based Learning Applied to Document Recognition」입니다. Proceedings of the IEEE 86(11), pp.2278–2324, 1998년에 발표되었습니다. [공저자의 논문 안내](https://leon.bottou.org/papers/lecun-98h)와 [공저자가 공개한 원문](https://leon.bottou.org/publications/pdf/ieee-1998.pdf)을 2026-10-19에 확인했습니다. 공개 PDF는 46쪽의 제출 원고이므로, 아래 PDF 쪽수와 출판본 인쇄 쪽수는 같지 않습니다. 핵심은 §II.A–B, PDF 5–9쪽입니다.

## 픽셀을 전부 따로 연결하면 생기는 문제

같은 글자도 위치와 필체가 달라집니다. 모든 픽셀을 모든 중간 뉴런에 연결하면 가중치가 많아지고, 같은 획이 다른 위치에 나타나는 경우를 따로 배워야 할 수 있습니다. 논문은 지역 연결, 가중치 공유, 서브샘플링을 이용하는 합성곱 신경망과 LeNet-5를 설명합니다. 후반부는 인식·분할 등 여러 모듈을 전체 목표에 맞춰 학습하는 Graph Transformer Networks도 다룹니다.

이 논문을 숫자 분류 구조 하나로만 읽으면 실제 문서 인식 시스템에 관한 범위를 놓칩니다. 여기의 Graph Transformer는 그래프 변환 모듈이며, 2017년의 attention 기반 Transformer를 가리키지 않습니다.

## 합성곱의 말뜻부터 정리합니다

커널 또는 필터는 작은 창의 입력에 곱할 가중치 묶음입니다. 수용 영역은 출력 하나가 참조하는 입력 범위입니다. 특징 맵은 같은 필터를 여러 위치에 적용한 결과입니다. 가중치 공유란 위치마다 다른 가중치를 만드는 대신 같은 묶음을 반복해서 쓰는 것입니다. 어느 모양을 찾을지는 학습하되, 같은 모양을 공간 곳곳에서 찾는 규칙은 구조로 정합니다.

스트라이드는 창이 이동하는 간격입니다. 패딩은 가장자리에 값을 덧대는 방식입니다. 서브샘플링은 공간 해상도를 줄이는 계산입니다. LeNet-5의 학습 가능한 계수·편향과 sigmoid를 사용하는 서브샘플링을 현대의 max pooling과 완전히 같은 연산으로 외우지 않습니다.

## 길이 4인 입력으로 필터를 움직입니다

직접 만든 1차원 예제에서 입력은 `[1,3,2,5]`, 필터는 `[1,−1]`, 편향은 0입니다. 패딩 없이 한 칸씩 이동합니다. 딥러닝 구현에서 흔히 쓰는 필터를 뒤집지 않는 교차상관 방식으로 계산합니다.

| 창의 위치 | 계산 | 출력 |
|---|---|---:|
| 첫째 | `1×1+3×(−1)` | −2 |
| 둘째 | `3×1+2×(−1)` | 1 |
| 셋째 | `2×1+5×(−1)` | −3 |

이 필터는 바로 뒤 값보다 앞 값이 클 때 양수를 냅니다. 실제 사진의 의미를 이해한 결과가 아니라, 이 필터의 산술적 성질입니다. 출력 길이는 `(4−2)/1+1=3`입니다. 커널 길이와 이동 간격을 바꾸면 출력 길이도 달라집니다.

같은 입력 4개에서 출력 3개를 만드는 완전연결층은 가중치 12개와 편향 3개가 필요합니다. 위 필터는 가중치 2개와 공유 편향 1개, 총 3개면 됩니다. 계산 위치가 세 곳이라는 사실과 서로 독립적으로 학습하는 숫자가 세 개라는 사실을 구분해야 합니다.

원문 LeNet-5의 첫 합성곱층 C1은 5×5 입력 영역을 보는 특징 맵 6개입니다. 맵마다 필터와 편향을 하나씩 공유하므로 `(5×5+1)×6=156`개의 학습 변수가 됩니다. PDF 7쪽에서 구조와 이 수를 확인할 수 있습니다. 연결 개수는 위치마다 반복되므로 156보다 훨씬 많습니다.

## 위치 변화에 강하다는 말의 범위

필터 결과는 입력이 이동하면 함께 이동할 수 있습니다. 이를 등변성이라고 부릅니다. 입력이 이동해도 최종 답이 같다는 불변성과는 다릅니다. 가장자리 처리와 스트라이드에 따라서도 성질이 달라집니다. 해상도를 줄이면 작은 이동에 둔감해질 수 있지만, 서로 다른 모양을 구분하는 정보도 잃을 수 있습니다.

예를 들어 숫자 6과 9를 구분할 때 회전은 의미를 바꿀 수 있습니다. 모든 이동·회전·뒤집기에 무조건 같은 답을 내는 구조가 바람직하지는 않습니다. 어떤 변화가 정답을 보존하는지 먼저 생각해야 합니다.

## 실험의 근거와 뒤에 이어지는 내용

원문 §III는 손글씨 숫자 분류 방법들을 비교하고, 문서 시스템의 전체 학습은 뒤의 절들에서 다룹니다. 특정 자료에서 좋은 결과가 나왔다는 사실을 임의 문서의 정확도 보장으로 확대하지 않습니다. [AlexNet 원문](https://proceedings.neurips.cc/paper_files/paper/2012/file/c399862d3b9d6b76c8436e924a68c45b-Paper.pdf)은 이런 합성곱 계열을 더 큰 이미지 분류에 사용한 후속 사례입니다. 그 사이에 자료·계산 장치·활성화·학습 설정도 바뀌었습니다. 이 글의 필터 계산은 직접 검산했으며 MNIST나 수표 인식 학습을 실행한 결과는 아닙니다.
