# ResNet: 입력에 변화량을 더하는 신경망 / Residual networks

Kaiming He, Xiangyu Zhang, Shaoqing Ren, Jian Sun의 「Deep Residual Learning for Image Recognition」입니다. [2015년 12월 공개 원문](https://arxiv.org/pdf/1512.03385)과 [CVPR 2016 발표 기록](https://www.microsoft.com/en-us/research/publication/deep-residual-learning-for-image-recognition/)을 구분합니다. 2026-10-19에 확인했습니다. §3.1–3.2, PDF 3쪽이 잔차 학습과 지름길 연결, §3.4, 4쪽이 구현 설정, §4가 실험입니다.

## 층을 늘려도 훈련 오차가 커질 수 있습니다

깊은 모델은 표현력이 커질 수 있지만 실제 학습이 쉬워지는 것은 아닙니다. 논문 도입의 degradation 문제는 더 깊은 일반 신경망이 훈련 자료에서도 오차가 커지는 현상입니다. 훈련 성능은 좋은데 시험 성능만 나쁜 과적합과 구분합니다. 논문은 직접 전체 함수 H(x)를 배우는 대신 입력에 더할 잔차 F(x)를 배우게 구성합니다.

잔차는 여기서 `H(x)−x`인 변화량입니다. 통계 회귀의 관측값과 예측값 차이라는 용법과 문맥이 다릅니다. 잔차 연결이 각 층의 분류 오답을 그대로 더하는 연산이라는 뜻은 아닙니다.

## 더하기가 들어가는 위치를 읽습니다

기본 식은 `y=x+F(x)`입니다. F는 하나의 고정된 숫자가 아니라 여러 층으로 이루어진 학습 함수입니다. x가 직접 더해지는 경로를 shortcut 또는 skip connection이라고 합니다. F가 0에 가까우면 더하기 직후 출력은 x에 가깝습니다. 전체 출력을 처음부터 새로 만드는 대신 필요한 변화량을 배우는 관점입니다.

```math
y=x+F(x),\qquad \frac{dy}{dx}=1+\frac{dF}{dx}
```

행렬 입력에서는 1에 해당하는 것이 항등행렬이고, 여러 출력의 미분은 야코비 행렬입니다. 원래 ResNet 블록은 더하기 뒤의 활성화도 포함합니다. 위 식은 더하기 지점의 설명이며 모든 비선형 연산을 생략한 완전한 블록 공식으로 쓰지 않습니다.

x와 F(x)는 덧셈이 가능한 모양이어야 합니다. 공간 크기나 채널 수가 달라지면 변환이 필요합니다. 원문은 0을 덧대는 방법과 1×1 합성곱 등의 투영 shortcut을 구분합니다. 투영은 크기를 맞추는 학습 연산이므로 항등 연결처럼 무조건 추가 변수가 0개인 것은 아닙니다.

## 한 숫자로 경로를 비교합니다

직접 만든 선형 예제에서 x=2, `F(x)=wx`, w=0.1이라고 정합니다. 실제 이미지 블록의 학습을 재현한 것은 아닙니다.

| 계산 | 출력 | 입력에 대한 변화율 |
|---|---:|---:|
| F(x)만 사용합니다. | 0.2 | 0.1 |
| x+F(x)를 사용합니다. | 2.2 | 1.1 |

입력 2가 직접 전달되고 변화량 0.2가 더해집니다. 손실이 `L=y²/2`라면 잔차 예의 `∂L/∂x=2.2×1.1=2.42`입니다. 단순 경로의 존재가 미분에 어떻게 들어가는지 볼 수 있습니다.

그러나 w=−1이면 `y=x−x=0`, 변화율도 `1−1=0`입니다. 항등 경로가 있어도 다른 경로와 상쇄될 수 있습니다. 여기에 ReLU가 음수 영역에서 0을 만드는 경우도 고려해야 합니다. 따라서 “잔차 연결이면 기울기 소실이 절대로 없다”는 결론은 이 수식에서 나오지 않습니다.

또 다른 자체 예에서 x=(1,2), F(x)=(0.1,−0.2)이면 더하기는 `(1.1,1.8)`입니다. 두 벡터를 이어 붙인 `(1,2,0.1,−0.2)`가 아닙니다. 덧셈과 concatenation은 출력 크기부터 다릅니다.

## 학습이 쉬워진다는 말의 근거

§4는 ImageNet과 CIFAR-10 등에서 일반 연결과 잔차 연결을 비교합니다. 구현에서는 BN, 가중치 초기화, 자료 증강, 학습률 일정 등도 정합니다. 구조만 남기고 설정을 바꾼 실행 결과를 원논문의 재현이라고 부르려면 차이를 기록해야 합니다. 이 글은 수식 계산만 검산했으며 해당 자료를 학습하지 않았습니다.

훈련 오차가 줄어도 새로운 자료의 성능이 자동으로 좋아지는 것은 아닙니다. 깊이, 폭, 연산량, 정답 정보의 품질을 함께 비교해야 합니다. 원문 §4의 매우 깊은 CIFAR 실험도 깊이를 무한히 늘리면 좋다는 보편 법칙으로 읽지 않습니다.

## 후속 논문과 연결해서 읽습니다

같은 저자들의 [Identity Mappings in Deep Residual Networks, 2016](https://arxiv.org/abs/1603.05027)은 항등 경로와 활성화 위치를 분석하고 pre-activation 구성을 검토합니다. 이는 더하기 앞뒤의 정규화·활성화 위치도 중요하다는 후속 연구입니다. 원래 ResNet을 후속 구조와 섞어 그리면 비교하려던 조건이 바뀝니다.

Transformer 원문도 [§3.1](https://papers.neurips.cc/paper_files/paper/2017/file/3f5ee243547dee91fbd053c1c4a845aa-Paper.pdf)에서 잔차 연결을 사용합니다. 다만 합성곱 잔차 블록과 attention 블록은 F의 내부 계산이 다릅니다. 잔차 연결은 하나의 모델 이름에만 속한 연산이 아니라 다른 구조에도 쓸 수 있는 연결 방식입니다.
