# GAN: 생성자와 판별자가 서로 다른 목표로 학습하기 / Generative adversarial nets

Ian J. Goodfellow, Jean Pouget-Abadie, Mehdi Mirza, Bing Xu, David Warde-Farley, Sherjil Ozair, Aaron Courville, Yoshua Bengio의 「Generative Adversarial Nets」입니다. NIPS 2014에 발표되었습니다. [공식 기록](https://proceedings.neurips.cc/paper/2014/hash/f033ed80deb0234979a61f95710dbe25-Abstract.html)과 [원문 PDF](https://proceedings.neurips.cc/paper_files/paper/2014/file/f033ed80deb0234979a61f95710dbe25-Paper.pdf)를 2026-10-19에 확인했습니다. §3은 PDF 3쪽, Algorithm 1과 §4.1의 최적 판별자는 4쪽, 이론의 조건은 §4.2, 5쪽입니다.

## 정답 사진 하나와 짝짓지 않고 학습합니다

생성자 G는 무작위 입력 z를 자료처럼 보이는 출력으로 바꿉니다. 판별자 D는 실제 자료와 생성 자료를 구분합니다. 논문은 두 함수를 함께 학습하는 게임을 제안합니다. 실제 그림과 생성 그림을 반드시 한 장씩 대응시켜 픽셀 차이만 줄이는 방식은 아닙니다.

생성자는 분포를 배우려는 모델입니다. 분포는 가능한 결과들이 얼마나 자주 나타나는지 나타냅니다. 예를 들어 사진이 모두 선명해도 같은 한 종류만 반복하면 자료 전체의 다양성을 맞추지 못합니다. 판별자는 학습 신호를 주지만, 실제 물체인지 윤리적으로 적절한지 판단하는 보편적인 진위 검사기는 아닙니다.

## 같은 수식을 서로 반대 방향으로 봅니다

원문의 기본 목표는 다음과 같습니다.

```math
\min_G\max_D\left[
E_{x\sim p_{data}}\log D(x)
+E_{z\sim p_z}\log(1-D(G(z)))\right]
```

D는 실제 x에 큰 점수, 가짜 G(z)에 작은 점수를 주도록 식을 키웁니다. G는 자신이 만든 자료를 D가 실제처럼 보도록 같은 식을 줄입니다. min과 max는 하나의 사람이 두 목적을 동시에 최대로 만든다는 뜻이 아닙니다. 한쪽을 갱신할 때 다른 쪽의 가중치는 고정하는 교대 학습으로 생각할 수 있습니다.

초기 G가 너무 약하면 기본 생성자 목적의 기울기가 작아질 수 있습니다. 원문 §3은 `log D(G(z))`를 크게 하는 대안도 설명합니다. 같은 최적점을 겨냥한다는 것과 매 단계 기울기가 같다는 것은 다릅니다. 생성자를 갱신할 때 D의 가중치를 고정해도, D의 입력에 대한 미분은 G까지 전달해야 합니다.

## 두 종류의 카드로 최적 판별자를 계산합니다

다음은 실제 모델을 학습한 결과가 아닌 자체 이산 예제입니다. 가능한 카드는 A와 B뿐이라고 정합니다.

| 카드 | 실제 분포 p | 생성 분포 q |
|---|---:|---:|
| A | 0.8 | 0.4 |
| B | 0.2 | 0.6 |

실제/생성 출처를 같은 비율로 제시할 때, G를 고정한 이상적인 판별자는 `D*(x)=p(x)/(p(x)+q(x))`입니다. A에서는 `0.8/1.2=2/3`, B에서는 `0.2/0.8=1/4`입니다. D*(A)가 더 큰 이유는 A가 생성 자료보다 실제 자료에서 상대적으로 더 흔하기 때문입니다.

이 식은 직접 미분해 확인할 수도 있습니다. 특정 카드에서 `a log d+b log(1−d)`를 최대화하면 기울기는 `a/d−b/(1−d)`입니다. 이를 0으로 두면 `a(1−d)=bd`, 따라서 `d=a/(a+b)`가 나옵니다. 두 번 미분한 값이 음수여서 내부 최댓값입니다. a+b=0인 경우에는 해당 카드가 어느 쪽에서도 나오지 않으므로 식의 비율을 정의하지 않습니다.

q를 `(0.8,0.2)`로 고쳐 p와 같게 만들면 두 카드의 D*는 모두 0.5입니다. 이는 이상적 판별자가 출처를 구별할 정보가 없다는 뜻입니다. 학습되지 않은 D가 모든 카드에 0.5를 냈다는 사실만으로 G가 완벽하다고 결론낼 수는 없습니다. 판별자가 일을 못 하는 상황도 같은 점수를 낼 수 있기 때문입니다.

## 생성과 평가를 구별합니다

학습에는 실제 자료, G, D가 필요합니다. 학습 후 새 자료를 만들 때는 보통 z를 뽑아 G에 넣습니다. D가 매번 합격시킨 자료만 출력해야 한다는 절차가 기본 GAN의 정의는 아닙니다. 생성 품질과 다양성의 평가는 별도 표본과 평가 기준이 필요합니다.

Mode collapse는 여러 입력이 일부 결과에 몰려 다양성을 놓치는 현상입니다. 상대가 동시에 변하는 최적화에서는 학습이 흔들릴 수도 있습니다. §4의 수렴 논의는 충분한 모델 용량과 최적 판별자 등의 가정을 둡니다. 유한한 신경망의 몇 번 갱신이 언제나 그 가정을 만족하는 것은 아닙니다.

후속 [DCGAN, 2015](https://arxiv.org/abs/1511.06434)은 합성곱 구조를 사용하는 GAN과 학습된 표현을 분석합니다. GAN을 '생성자는 항상 좋아지고 판별자는 마지막에 무용해진다'는 이야기로 외우기보다, 현재 분포와 학습된 상대의 상태를 따로 살펴야 합니다. 이 글은 카드 분포 계산만 검산했으며 이미지 GAN을 학습하지 않았습니다.

3. 판별 정확도 50%만으로 생성 품질이 입증되나요?
