# VAE: 잠재변수의 분포를 배우고 새 자료를 만들기 / Variational autoencoders

Diederik P. Kingma와 Max Welling의 「Auto-Encoding Variational Bayes」입니다. [2013년 12월 첫 공개 기록](https://arxiv.org/abs/1312.6114)과 [ICLR 2014 공식 목록](https://iclr.cc/archive/2014/conference-proceedings/)을 구분합니다. 이 글은 [2014년 v10 PDF](https://arxiv.org/pdf/1312.6114v10)의 §2.2–2.4, PDF 2–5쪽, §3의 예제, 부록 B의 가우스 KL 유도, PDF 10–11쪽을 읽습니다. 출처 확인일은 2026-10-19입니다.

## 보이지 않는 원인을 확률로 나타냅니다

잠재변수 z는 관측 자료 x를 설명하려고 두는 숨은 변수입니다. 그림의 모양을 몇 개 숫자로 나타낼 수는 있어도 각 숫자가 반드시 색·각도처럼 사람이 붙인 뜻과 일치하지는 않습니다. 논문은 신경망으로 잠재변수의 근사 사후분포를 만들고, 재매개변수화로 미분 가능한 학습을 수행합니다.

사전분포 p(z)는 x를 보기 전에 정하는 분포입니다. 사후분포 p(z|x)는 x를 본 뒤의 분포입니다. 실제 사후분포 계산이 어려워 q(z|x)라는 근사를 사용합니다. 인코더는 x에서 q의 수치를 구하고, 디코더는 z에서 관측값의 분포 p(x|z)를 구합니다. 입력을 단순히 압축했다가 원상 복구하는 결정적 자동인코더와 확률적 구성을 구분해야 합니다.

## 학습 목표의 두 부분

로그는 곱셈을 덧셈으로 바꿔 주는 함수입니다. 관측 자료의 로그 가능도 `log p(x)`를 직접 높이기 어려워, 그보다 크지 않은 하한 ELBO를 높입니다.

```math
\mathcal L(x)=E_{q(z|x)}[\log p(x|z)]
-D_{KL}(q(z|x)\Vert p(z))\le\log p(x)
```

첫 항은 여러 z에서 x를 얼마나 잘 설명하는지 평균낸 값입니다. 둘째 항인 KL 발산은 두 분포의 차이를 재며, 항상 0 이상이고 방향을 바꾸면 대체로 값이 다릅니다. 하한을 높인다는 사실과 실제 로그 가능도를 정확히 계산했다는 주장은 다릅니다. 손실을 최소화하는 코드에서는 보통 ELBO의 음수를 사용합니다.

기댓값 E는 확률에 따른 평균입니다. 무작위 값 하나에서 얻은 수와 정확한 기댓값은 같지 않을 수 있습니다. 많은 값을 뽑아 평균내는 Monte Carlo 계산은 이 평균을 추정하는 방법입니다. VAE에서 확률을 쓴다는 사실이 출력의 의미나 안전성을 자동 보장하지는 않습니다.

## 재매개변수화를 직접 계산합니다

직접 만든 1차원 예에서 q는 평균 μ=1, 표준편차 σ=2인 정규분포입니다. 표준정규분포에서 ε를 뽑고 `z=μ+σε`로 계산합니다. ε=0.5이면 z=2입니다. σ²=4는 분산이며 σ=2와 바꿔 쓰면 안 됩니다.

같은 ε를 고정한 채 μ를 0.1 늘리면 z도 0.1 늘어납니다. σ를 0.1 늘리면 z는 0.05 늘어납니다. 따라서 `∂z/∂μ=1`, `∂z/∂σ=ε`입니다. 무작위 추출을 없앤 것이 아니라, 파라미터와 독립인 ε를 뽑은 뒤 미분 가능한 계산으로 옮긴 것입니다.

사전분포를 표준정규분포로 두면 이 가우스 예의 KL은 다음과 같습니다.

```math
D_{KL}=\frac12(\mu^2+\sigma^2-1-\log\sigma^2)
=\frac12(1+4-1-\log4)\approx1.306853
```

디코더의 평균 로그 가능도 항을 설명용으로 −2라고 가정하면 ELBO는 약 −3.306853, 최소화할 음의 ELBO는 3.306853입니다. −2는 실행으로 얻은 수가 아니라 이 산술 예를 위해 정한 값입니다. KL만 작게 하려고 μ=0, σ=1로 만들면 KL은 0이지만, x를 잘 설명하는지 첫 항도 함께 확인해야 합니다.

## 학습할 때와 생성할 때의 흐름

| 단계 | 시작점 | 계산 흐름 |
|---|---|---|
| 학습 | 실제 자료 x입니다. | 인코더 → z 추출 → 디코더 → 재구성 항과 KL → 기울기 갱신입니다. |
| 새 자료 생성 | 사전분포에서 뽑은 z입니다. | 디코더로 관측값 분포를 만들고 그 분포를 사용합니다. |

새 자료 생성에는 인코더에 넣을 실제 사진이 꼭 필요한 것은 아닙니다. 반면 기존 입력의 재구성이나 잠재표현 분석에는 인코더를 사용합니다. 디코더가 평균 이미지를 출력하는 방식과 그 관측분포에서 표본을 뽑는 방식도 구분해야 합니다.

## 근거와 한계, 후속 내용

원문 §5는 MNIST와 Frey Face 등의 실험을 보고합니다. 근사분포와 디코더의 선택은 표현 가능한 분포를 제한할 수 있으며, 위 한 점 계산은 그 자료의 생성 품질을 재현하지 않습니다. KL 발산이 일반적인 거리의 모든 성질을 만족하는 것도 아닙니다.

두 저자의 후속 [An Introduction to Variational Autoencoders, 2019](https://arxiv.org/abs/1906.02691)는 변분추론과 VAE를 더 넓게 설명합니다. VAE의 인코더·하한과 [GAN](gan.md)의 판별 게임, [DDPM](ddpm.md)의 잡음 역과정은 서로 다른 학습 구성이므로 생성 모델이라는 이유만으로 같은 손실로 묶지 않습니다.

1. μ=−1, σ=0.5, ε=2일 때 z는 얼마인가요?
2. q와 p가 같은 표준정규분포이면 KL은 얼마인가요?
3. 새 표본 생성 때 q(z|x)를 반드시 계산해야 하나요?

1. `−1+0.5×2=0`입니다.
2. 0입니다. 가우스 식에서도 `0+1−1−log1=0`입니다.
3. 아닙니다. 사전분포 p(z)에서 z를 뽑아 디코더에 넣을 수 있습니다. 재구성은 별도의 상황입니다.
