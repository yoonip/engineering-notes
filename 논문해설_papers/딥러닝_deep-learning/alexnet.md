# AlexNet: 큰 이미지 분류를 학습하는 구조와 계산 / AlexNet

Alex Krizhevsky, Ilya Sutskever, Geoffrey E. Hinton의 「ImageNet Classification with Deep Convolutional Neural Networks」입니다. NIPS 2012에 발표되었습니다. [공식 발표 기록](https://proceedings.neurips.cc/paper/2012/hash/c399862d3b9d6b76c8436e924a68c45b-Abstract.html)과 [공식 최종 PDF](https://proceedings.neurips.cc/paper_files/paper/2012/file/c399862d3b9d6b76c8436e924a68c45b-Paper.pdf)를 2026-10-19에 확인했습니다. 구조는 §3, PDF 2–5쪽, 과적합 대책은 §4, 5–6쪽, 결과는 §6, 7–8쪽입니다. 일부 안내 페이지 초록과 수치·층 설명이 달라 이 글은 연결된 최종 PDF를 기준으로 삼습니다.

## 이미지가 커지면 무엇이 어려워지나요

손글씨 숫자와 달리 자연 사진은 배경·조명·위치가 다양합니다. 큰 자료에 큰 신경망을 학습하려면 계산량과 과적합을 함께 다뤄야 합니다. 논문은 합성곱 5층과 완전연결 3층, ReLU, GPU 계산, 자료 증강, dropout 등을 결합합니다. 한 가지 장치만으로 전체 결과가 설명되는 논문은 아닙니다.

ReLU는 `max(0,x)`로 음수를 0으로, 양수를 그대로 보내는 활성화 함수입니다. GPU는 같은 형태의 수치 연산을 많이 병렬로 처리하는 장치입니다. 큰 구조가 메모리에 들어가는지와 한 번 학습하는 데 얼마나 걸리는지는 정확도와 별개의 제약입니다.

## 구조와 학습 대책을 구분합니다

합성곱층은 같은 지역 필터를 여러 위치에 적용합니다. 완전연결층은 각 출력이 모든 입력 특징을 받습니다. Pooling은 주변 결과를 모아 공간 크기를 줄입니다. Softmax는 여러 점수를 합이 1인 양수들로 바꾸어 분류 확률처럼 사용하게 합니다.

Dropout은 학습 중 일부 활성값을 무작위로 꺼서 특정 연결 조합에 지나치게 의존하는 것을 줄이려는 방법입니다. 필터를 학습 내내 영구히 삭제하는 뜻은 아닙니다. 자료 증강은 정답을 유지하는 변환을 이용해 입력의 변형을 보여 주는 방법입니다. 고양이 사진의 일부 자르기와 좌우 반전은 가능할 수 있지만, 좌우를 구분하는 과제에서는 같은 변환이 정답을 바꿀 수 있습니다.

## 첫 필터의 변수 수를 계산합니다

원문 구조에 나오는 11×11, 입력 채널 3개, 출력 필터 96개를 사용해 직접 셉니다. 위치별 계산량이 아니라 독립적인 학습 변수 수입니다.

```math
\text{필터 하나의 가중치}=11\times11\times3=363
```

필터마다 편향 하나를 더하면 364개이며, 필터 96개는 `364×96=34,944`개입니다. 출력 지점이 많아져도 같은 필터를 공유하므로 이 수에 출력 가로·세로를 다시 곱하지 않습니다. 실제 연산 횟수와 메모리 사용량을 구할 때는 출력 크기와 중간 활성값도 고려해야 합니다.

아주 작은 ReLU 계산으로 `[-2,0,3]`을 넣으면 `[0,0,3]`입니다. 양수 영역의 기울기는 1이지만 음수 영역에서는 0입니다. 따라서 ReLU를 쓰면 모든 뉴런의 기울기가 항상 잘 흐른다는 말도 맞지 않습니다. 이 계산은 활성화 함수의 성질이며 원논문의 학습 시간 실험이 아닙니다.

## Top-1과 Top-5를 혼동하지 않습니다

직접 만든 분류 예에서 정답이 '버스'이고 순위가 다음과 같다고 하겠습니다.

| 순위 | 예측 이름 |
|---|---|
| 1 | 트럭 |
| 2 | 승합차 |
| 3 | 버스 |
| 4 | 기차 |
| 5 | 자동차 |

가장 높은 하나가 정답이 아니므로 top-1은 오답입니다. 상위 5개 안에 버스가 있으므로 top-5는 정답입니다. 이런 사진이 10장이고 top-1 오답 4장, top-5 오답 1장이면 각각 오류율 40%, 10%입니다. top-5 오류가 낮다는 말이 최고 순위 예측의 정확도가 그만큼 높다는 뜻은 아닙니다.

최종 PDF 초록의 ILSVRC-2010 결과와 §6의 ILSVRC-2012 경연 결과는 자료 연도와 모델 구성이 다릅니다. 하나의 숫자를 'AlexNet 정확도'로 고정해 비교하면 실험 조건이 사라집니다. 단일 모델과 여러 모델을 합친 앙상블도 구분해야 합니다.

## 무엇이 이어졌고 무엇이 남았나요

원논문의 GPU와 자료 증강 결과는 당시 환경의 보고입니다. 이 글에서 동일 학습을 실행하지 않았으며, 현재 장치에서의 속도를 추정한 값도 제시하지 않습니다. 분포가 다른 사진이나 잘못된 라벨에 대한 성능은 해당 분류 실험만으로 알 수 없습니다.

후속 [ResNet 논문](https://arxiv.org/pdf/1512.03385)은 더 깊은 이미지 신경망의 최적화 문제를 다룹니다. AlexNet에서 층을 계속 늘리면 된다는 결론으로 연결하기보다, 구조가 깊어질 때 학습 자체가 어려워지는 이유를 이어 읽는 편이 정확합니다. Local response normalization을 후대의 [BN](batch-normalization.md)과 같은 연산으로 취급하지도 않습니다.

## 스스로 확인하기

1. 3×3 필터, 입력 채널 2, 출력 채널 4, 채널별 편향이면 변수는 몇 개인가요?
2. 정답 순위가 6이면 top-1과 top-5는 각각 맞나요?
3. Dropout으로 학습 때 활성값을 끄는 일은 자료 증강인가요?

<details>
<summary>정답과 짧은 해설</summary>

1. `(3×3×2+1)×4=76`개입니다.
2. 둘 다 오답입니다. 상위 5개에도 들지 않았습니다.
3. 아닙니다. Dropout은 신경망 내부의 활성값을 바꾸는 규제 방법이고 자료 증강은 입력 자료의 변형입니다.
