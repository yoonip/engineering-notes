# 우주 탐사와 정밀 관측 | Space exploration and precision measurement

센서의 불확실성, 자율 비행과 충돌 항법, 광통신, 우주망원경, 중력파 검출을 다룬 6편입니다. 천체 발견뿐 아니라 그것을 가능하게 한 제어·광학·전자회로·통계의 연결을 읽습니다.

## 연결해서 읽기

칼만 필터의 예측·관측 → 화성 헬리콥터의 항법·제어 → DART의 자율 접근 순서로 읽으시면 추정과 행동의 관계가 보입니다. 광학이 궁금하시면 LIGO → JWST → 광통신 검출기를 읽고, 변형률·파면·광자 계수라는 서로 다른 측정량을 비교해 보시면 좋습니다.

각 해설은 해당 논문이 다룬 시점의 결과입니다. 개발 당시의 계획을 실제 후속 임무 성과나 현재 운영 상태와 섞지 않았습니다. 직접 만든 숫자 예제는 원문 실험과 구분하며, 마지막 확인 문제로 단위·가정·한계를 점검하실 수 있습니다.
