# 뇌의 신호·연결지도와 신경공학 논문 읽기

신경세포의 계산, 전기 신호 측정, 공간 표현과 가소성, 연결지도, 가상 동물, 뇌–컴퓨터 인터페이스를 25편으로 살펴봅니다. 마지막 글은 생명과학의 다른 계산 문제인 DNA 조절 신호 예측을 다룹니다. 각 글에는 원문과 확인 위치, 방법과 한계, 용어, 작은 계산 예제와 자기점검 3문항이 있습니다.

연결지도를 만들었다는 결과, 그 지도에 활동 규칙을 붙인 모형, 몸과 환경을 결합한 시뮬레이션은 서로 다른 성과입니다. 원문의 실험 결과와 이 글의 설명용 계산도 구별합니다. 논문 그림·표와 전문 번역을 싣는 대신 원문 링크와 한국어 해설을 제공합니다.

## 처음 읽으실 때

1. 역치 뉴런과 막전압 글에서 입력·상태·출력의 차이를 익히시면 됩니다.
2. 측정과 감각 표현 글에서 전류·발화율·수용장·가소성을 구분하시면 좋습니다.
3. 연결지도 글은 노드·간선·시냅스·가중치의 단위를 확인하며 읽으시면 됩니다.
4. 가상 초파리 글에서는 실제 관측한 구조, 동역학 가정, 제어기 학습, 몸의 근사를 따로 적어 보시면 좋습니다.
5. BCI 글은 기록 방식, 참여자 수, 출력 종류, 실시간·오프라인 평가를 비교하며 읽으시면 됩니다.

수식에 익숙하지 않으셔도 자체 예제의 단위를 먼저 따라가실 수 있습니다. 벡터와 행렬 같은 표현은 [논문을 읽는 용어](../논문을읽는용어_PAPER_TERMS.md)와 함께 보시면 됩니다. 계산 예제는 원래 신경망 학습이나 임상시험을 재실행한 결과가 아닙니다.

피질 표면의 ECoG와 피질 안의 미세전극, 머리 바깥의 EEG는 서로 다른 기록 방식입니다. 문자·음성·얼굴·로봇 제어도 서로 다른 출력입니다. 단어 오류율, 문자 오류율, 청취자가 알아들은 비율, 제어 과제 성공률을 하나의 정확도로 합치지 않습니다.

Metzger·Littlejohn 글은 저자의 공개 학위논문에 실린 같은 연구의 본문도 이용하며 저널과 다른 절·쪽 배치를 명시했습니다. 한 연구 흐름의 후속 결과를 여러 독립 참여자에게 재현한 결과로 세지 않습니다. Wairagkar 글은 확인한 2024-09-20 사전논문 2판을 분석하며 2025-06-12 심사 후 출판본을 별도로 안내합니다. 두 판의 수치·저자를 합치지 않습니다.

## 판본과 계산의 확인 범위

이 목록에는 25개 연구의 해설이 있고 그중 2024–2026년 자료는 9개입니다. 이 9개에는 분석 판본을 분명히 표시한 Wairagkar의 2024년 사전논문 1개가 포함됩니다. 2025년판을 더해 26편으로 세지 않습니다. 2006년 BCI 논문 대신 공개 저자 원고를 확인한 2012년 로봇 팔 논문을 다룹니다.

각 글의 원문 위치는 확보한 공개 PDF·HTML·저자 원고를 기준으로 제시했습니다. 실제 실험 데이터의 새 측정이나 원논문의 대규모 훈련을 수행한 것은 아닙니다. 자체 예제의 산술과 링크·문서 형식은 따로 검사하며, 원논문의 성능 재현과 구별합니다. 공개 자료의 수치가 갱신될 수 있으므로 자료를 실제 분석에 사용할 때에는 원문의 확인일과 데이터 버전도 함께 남기시면 좋습니다.
