# 게임·생물·사회 데이터를 활용한 연구

게임 이용자의 행동, 점균의 수송망, 웹 검색, 음악 선택을 연구 자료와 방법으로 활용한 논문 여섯 편을 읽습니다. 서로 다른 분야를 연결한 발상과 함께, 실제로 무엇을 관찰하거나 시험했는지 살펴봅니다. 특이한 방법이라는 이유만으로 현실에서의 유용성까지 확인되었다고 판단하지 않습니다.

| 논문 | 연구의 성격 | 중심 질문 |
| --- | --- | --- |
| [게임 속 전염병, Lofgren·Fefferman 2007](게임속전염병과사람의행동_wow-epidemic2007.md) | 사건 해석과 연구 제안 | 가상 인물의 행동을 현실로 옮길 수 있을까요? |
| [단백질 접기 게임 Foldit, Khatib 외 2011](게임참여자의단백질구조해석_foldit2011.md) | 사람의 모형 탐색과 실험 구조 해석 | 게임 점수와 실제 구조 확인은 어떻게 연결될까요? |
| [점균과 수송망, Tero 외 2010](점균연결망의비용과우회경로_physarum-network2010.md) | 생물 실험·망 비교·수학 모형 | 짧은 길이와 우회 경로를 어떻게 함께 평가할까요? |
| [검색으로 독감 유사 증상 추정, Ginsberg 외 2009](검색어로추정한독감유사증상_google-flu2009.md) | 집계 자료로 모형 학습·시험 | 빠른 현재 추정과 미래 예측은 무엇이 다를까요? |
| [Google Flu Trends의 반복 오차, Lazer 외 2014](검색기반독감추정의실패_google-flu-lessons2014.md) | 성능 비교와 측정·플랫폼 비판 | 과거에 잘 맞던 관계가 왜 바뀔까요? |
| [온라인 음악 시장, Salganik 외 2006](음악시장의사회적영향_music-market2006.md) | 무작위 배정과 여러 시장의 비교 실험 | 인기의 집중과 승자의 불확실성은 어떻게 다를까요? |

각 본문은 한국어로 연구 배경·방법·결과를 설명하고, 입력 자료와 측정 대상, 비교 집단, 결과가 적용되는 범위를 구분합니다. 쉬운 용어 풀이, 직접 만든 계산 또는 설계 예, 확인 문제 세 개와 접힌 해설을 넣었습니다. 자체 예는 논문에서 관찰한 값과 구별했습니다.

검색 연구 두 편은 2009년 글을 먼저 읽고 2014년 글로 이어 가시면 좋습니다. 온라인 실험의 설계가 궁금하시면 음악 시장을, 후보 생성과 별도 실험 확인의 관계가 궁금하시면 Foldit을 먼저 읽으셔도 됩니다.
