# 게임·생물·사회 데이터를 활용한 연구

게임 이용자의 행동, 점균의 수송망, 웹 검색, 음악 선택을 연구 자료와 방법으로 활용한 논문을 읽습니다. 서로 다른 분야를 연결한 발상과 함께, 실제로 무엇을 관찰하거나 시험했는지 살펴봅니다. 특이한 방법이라는 이유만으로 현실에서의 유용성까지 확인되었다고 판단하지 않습니다.

| 논문 | 연구의 성격 | 핵심 내용 |
| --- | --- | --- |
| [게임 속 전염병, Lofgren·Fefferman 2007](게임속전염병과사람의행동_wow-epidemic2007.md) | 사건 해석과 연구 제안 | 가상 감염 사건의 행동 관찰과 현실 적용의 한계 |
| [단백질 접기 게임 Foldit, Khatib 외 2011](게임참여자의단백질구조해석_foldit2011.md) | 사람의 모형 탐색과 실험 구조 해석 | 게임을 통한 구조 탐색과 실험적 확인 |
| [점균과 수송망, Tero 외 2010](점균연결망의비용과우회경로_physarum-network2010.md) | 생물 실험·망 비교·수학 모형 | 연결망의 길이·비용과 우회 경로 |
| [검색으로 독감 유사 증상 추정, Ginsberg 외 2009](검색어로추정한독감유사증상_google-flu2009.md) | 집계 자료로 모형 학습·시험 | 현재 독감 수준의 추정과 미래 예측의 구분 |
| [Google Flu Trends의 반복 오차, Lazer 외 2014](검색기반독감추정의실패_google-flu-lessons2014.md) | 성능 비교와 측정·플랫폼 비판 | 검색 행동 변화와 예측 관계의 불안정성 |
| [온라인 음악 시장, Salganik 외 2006](음악시장의사회적영향_music-market2006.md) | 무작위 배정과 여러 시장의 비교 실험 | 음악 인기도의 집중과 결과의 불확실성 |

각 본문은 한국어로 연구 배경·방법·결과를 설명하고, 입력 자료와 측정 대상, 비교 집단, 결과가 적용되는 범위를 구분합니다. 쉬운 용어 풀이, 직접 만든 계산 또는 설계 예, 확인 문제 세 개와 접힌 해설을 넣었습니다. 자체 예는 논문에서 관찰한 값과 구별했습니다.

검색 연구는 2009년의 독감 유사 증상 추정에서 2014년의 반복 오차 분석으로 이어 읽으시면 좋습니다. 온라인 실험의 설계가 궁금하시면 음악 시장을, 후보 생성과 별도 실험 확인의 관계가 궁금하시면 Foldit을 먼저 읽으셔도 됩니다.
