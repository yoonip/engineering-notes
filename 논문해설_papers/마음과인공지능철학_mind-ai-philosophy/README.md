# 마음과 인공지능 철학 / Philosophy of mind and AI

기계가 사람과 구별되지 않게 행동하면 무엇을 인정할 수 있을까요? 말의 의미를 이해한다는 것, 무언가를 느낀다는 것, 도덕적으로 배려받을 존재라는 것은 서로 연결되지만 같은 질문은 아닙니다. 주요 논문 여섯 편과 최근 내부 기능 연구 세 편을 각 질문의 출발점과 반론에 따라 읽습니다. 확인일은 2026-10-20이며 특정 최신 모델의 의식 유무를 이 목록에서 판정하지 않습니다.

| 논문 | 중심 질문 | 함께 검토할 반론·범위 |
|---|---|---|
| [Turing, 1950](기계의사고와대화시험_turing1950.md) | ‘기계가 생각하는가’라는 질문을 어떤 시험으로 바꿀 수 있나요? | 대화에서의 판단과 내적 경험의 증명을 구분합니다. |
| [Searle, 1980](기호처리와의미이해_searle1980.md) | 규칙대로 기호를 다루면 의미 이해도 생기나요? | 방 안의 개인과 전체 시스템 중 누구의 이해를 묻는지 살펴봅니다. |
| [Dennett, 1971](믿음과목표로행동설명하기_dennett1971.md) | 믿음·욕구를 가정해 행동을 예측하는 설명은 언제 유용한가요? | 유용한 예측 관점과 주관적 경험의 판정을 구분합니다. |
| [Nagel, 1974](박쥐의감각과주관적경험_nagel1974.md) | 다른 존재로 살아간다는 느낌을 객관적 설명만으로 알 수 있나요? | 상상의 한계가 곧 비물질적 실체의 증명인지 검토합니다. |
| [Chalmers, 1995](기능설명과주관적경험_chalmers1995.md) | 기능과 행동을 설명한 뒤에도 어떤 질문이 남나요? | 경험에 관한 이론적 논증과 실험 결과를 나눕니다. |
| [Butlin 등, 2023](인공지능의식의구조적지표_butlin2023.md) | 의식 이론에서 AI를 평가할 지표를 만들 수 있나요? | 이론에 의존한 지표와 의식 판정·확률값을 구별합니다. |

각 글은 원문의 논증을 한국어로 풀어 쓰고 용어·자체 사고실험·반론·확인 문제를 붙입니다. 논문 전문이나 전체 번역을 재게시하지 않으며 실제 읽은 판본과 보충자료 범위는 개별 글에서 확인하실 수 있습니다. 오래된 글이 오늘의 Transformer를 시험한 것처럼 설명하지 않습니다.

Butlin 해설에는 2023년 보고서와 구분한 2025년 온라인·2026년 권호의 후속 방법론도 있습니다. 각 글은 실제로 읽은 판본과 학회판의 차이를 밝힙니다. 같은 기능의 보고·표현·개입이 경험이나 수적 동일성을 한 번에 증명하지는 않습니다.

## 같은 행동이라는 말의 세 가지 범위

한 번 같은 답을 하는 것, 많은 상황에서 구별하기 어려운 것, 가능한 모든 상황에서 같은 반응을 하는 것은 강도가 다른 주장입니다. 실제 시험은 일부 상황만 관측합니다. 시험 범위에서 차이를 찾지 못했다는 결과를 모든 상황의 동일성으로 확대하려면 추가 근거가 필요합니다.

기능주의는 마음을 입력·출력뿐 아니라 다른 내부 상태와의 인과적 역할로 이해하려는 관점입니다. ‘겉모습이 비슷하면 무엇이든 같은 마음입니다’라는 짧은 규칙보다 넓은 주장입니다. 한편 내적 경험을 강조하는 논증은 대화 능력을 부정하지 않으면서도 그것만으로 주관적 느낌이 설명되는지를 묻습니다. 두 입장이 서로 무엇에 동의하고 어느 단계에서 갈리는지 표시하며 읽으시면 됩니다.
