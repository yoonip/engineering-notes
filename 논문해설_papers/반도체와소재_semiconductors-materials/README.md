## 공부할 순서

소자가 처음이면 [기초 트랜지스터와 MOSFET 축소](../정보와전자공학_information-electronics/README.md)를 읽고 FinFET → 그래핀 → MoS₂ → 웨이퍼 공정으로 이어가시면 됩니다. 메모리가 궁금하시면 멤리스터와 강유전성을 비교해 전하 이동, 저항 상태, 분극 상태를 구분합니다.

재료 탐색은 GNoME → A-Lab → 탠덤 태양전지 순서가 좋습니다. 후보를 계산하는 일, 물질을 합성해 확인하는 일, 장치에서 성능과 수명을 검증하는 일이 어떻게 이어지는지 살펴보실 수 있습니다. A-Lab은 2026년 정정된 본문과 수치를 기준으로 설명합니다.

각 글의 작은 계산은 개념을 이해하기 위해 직접 구성한 예제이며 실험 재현 결과가 아닙니다. 원문이 공개한 측정과 시뮬레이션은 본문에서 나누어 설명합니다.
