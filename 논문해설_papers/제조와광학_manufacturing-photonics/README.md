# 제조 공정과 광학 계산

빛으로 재료를 굳히는 공정과 빛의 전파 자체로 계산하는 장치를 구별합니다. 각 해설에는 기초 용어, 원문에서 실제 확인한 결과, 직접 계산할 예제와 세 문항의 해설이 있습니다. 실험 시연·수치 모형·후속 제안을 나누어 읽습니다.
