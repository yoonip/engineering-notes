# 기술의 채택과 표준 경쟁

성능이 좋은 부품이 왜 바로 시장의 표준이 되지 않는지, 기존 도구·인력·호환성과 미래 지원이 선택을 어떻게 바꾸는지 읽습니다. 두 논문은 이론과 연구 정리이며 현재 기업의 점유율을 직접 추정한 자료는 아닙니다. 자체 예제로 선택 조건과 전환비용을 계산합니다.

| [Arthur, 1989](arthur1989.md) | 초기 채택의 순서가 다음 선택 조건을 바꾸는 이유와, 증가 효과가 포화될 때의 차이는 무엇입니까? |
| [Katz·Shapiro, 1994](systems-competition1994.md) | 보완재·간접 네트워크 효과·호환·지원 약속이 제품 선택에 어떻게 들어갑니까? |
