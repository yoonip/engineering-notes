## How this repository will grow
- Use a topic page for concepts, setup instructions and small examples.
- Add executable work under `projects/`, `model-lab/` or a topic-specific folder.
- Record the problem, assumptions, implementation, verification, results and limitations.
- Promote substantial projects to separate repositories and link them here.
- Use English for the main project README and a linked Korean version when useful.

## Start here
1. Read [the Korean setup and upload guide](docs/GETTING_STARTED.ko.md).
2. Choose one topic rather than treating the full catalog as a required sequence.
3. Copy the [note template](templates/NOTE_TEMPLATE.md), [project template](templates/PROJECT_TEMPLATE.md) or [model experiment template](templates/MODEL_EXPERIMENT_TEMPLATE.md).
4. Mark an item In progress only when work starts; link evidence before marking it Completed.
