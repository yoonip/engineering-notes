# 보안 실습 코드 | Security lab code

[분야 목차](../README.md) · [검증 기록](검증기록_validation.md) · [출처와 판본](../출처_sources.md)

이 폴더의 코드는 공식 문서의 원리를 참고해 직접 작성한 교육용 예제입니다. 외부 저장소의 구현 코드를 복사한 것이 아니며, 실제 서비스의 보안성이나 특정 공격의 성공을 증명하지 않습니다. RFC 4231의 HMAC 공개 테스트 벡터는 해당 출처를 별도로 표시했습니다.

모든 입력과 자료는 로컬 프로세스 안의 합성 데이터입니다. 인터넷 호스트, 계정, 실제 파일시스템 장치, 운영 서버를 대상으로 하지 않습니다. 예제를 실행하기 전에 각 파일의 전제와 한계를 확인하시기 바랍니다.

| 파일 | 확인하는 내용 |
| --- | --- |
| `sql_boundary.py` | 문자열 조립 쿼리가 입력을 SQL 구문으로 해석하는 사례와 매개변수 쿼리의 차이 |
| `access_control.py` | 객체 소유자·조직·작업 범위를 매 요청에서 확인하는 인가 규칙 |
| `webhook_auth.py` | 본문·식별자·시각을 HMAC으로 인증하고 제한 시간과 재전송을 검사하는 예 |
| `output_encoding.py` | HTML 텍스트 문맥에서 특수 문자를 인코딩하는 예 |
| `artifact_digest.py` | 별도로 신뢰하는 SHA-256 기준값과 받은 파일의 digest를 비교하는 예 |
| `agent_boundary.py` | 도구 이름·인수 형식·호출 주체·권한을 실행 직전에 다시 검사하는 예 |
| `login_detection.py` | 합성 로그인 기록의 시간창 집계와 경보 임계값 예 |
| `frame_bounds.c` | 길이 필드를 확인한 뒤 제한된 바이트 프레임을 처리하는 C 예 |
| `test_security.py` | 위 Python 모듈의 정상·오류·경계 조건 단위 검사 |
| `test_frame_bounds.c` | C 프레임 처리의 정상·잘림·길이 경계 검사 |

Python 검사는 표준 라이브러리만 사용합니다. C 검사는 C11 컴파일러가 필요합니다. 실행한 명령·환경·결과와 검사의 한계는 [검증 기록](검증기록_validation.md)에 적었습니다.
