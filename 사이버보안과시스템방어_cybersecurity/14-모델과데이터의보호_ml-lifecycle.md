# 모델과 데이터의 보호 | ML lifecycle security

[분야 목차](README.md) · [용어](용어_glossary.md) · [출처와 판본](출처_sources.md)

## 모델 파일도 소프트웨어 공급망의 일부입니다

학습 자료, 수집 코드, 전처리, 라이브러리, 가중치, tokenizer, 추론 서버, 검색 저장소를 나누어 봅니다. 모델 이름이 같아도 판본·양자화·변환·실행 코드가 다르면 같은 배포물은 아닙니다. 저장소 revision·파일 digest·모델 카드·라이선스·로더 설정을 함께 기록합니다. [NIST SP 800-218A의 AI 개발 생명주기 범위](https://csrc.nist.gov/pubs/sp/800/218/a/final)

역직렬화나 사용자 정의 로더가 코드를 실행하는 형식인지 확인합니다. ‘모델 가중치’라는 이름 때문에 임의의 다운로드 스크립트·설치 명령·원격 코드를 자동 승인하지 않습니다. 안전한 저장 형식을 선택해도 주변 런타임과 의존성까지 안전하다는 뜻은 아닙니다.

## 공격자의 권한과 시점으로 분류합니다

| 유형 | 바꾸거나 관측하는 대상 | 방어에서 연결할 부분 |
| --- | --- | --- |
| 데이터 poisoning | 학습·검색·평가 자료 일부를 오염시킵니다. | 수집 출처·변경 이력·표본 검토·독립 평가를 둡니다. |
| backdoor | 특정 조건에서 원치 않는 동작이 나오도록 유도합니다. | trigger 조건을 포함한 평가와 공급망 검사를 설계합니다. |
| evasion·적대적 입력 | 추론 입력을 바꾸어 판단을 흔듭니다. | 입력 조건·강건성·실패 시 안전 동작을 확인합니다. |
| 모델 추출 | 응답·노출된 파일 등으로 모델을 복제하려 합니다. | 접근 권한·출력량·질의 비용·배포 구조를 검토합니다. |
| membership inference | 특정 표본이 학습에 있었는지 추정하려 합니다. | 학습 자료 최소화·과적합·개인정보 평가를 다룹니다. |
| 민감정보 누출 | 응답·로그·도구로 정보가 노출됩니다. | 입력·출력·로그·검색의 권한과 보존 기간을 정합니다. |

이는 공격자가 무엇을 제어하고 알고 있는지에 따라 달라집니다. 공개 모델 전체를 아는 경우와 API만 호출하는 경우의 가정도 다릅니다. 용어·분류의 출처는 [NIST AI 100-2 E2025](https://csrc.nist.gov/pubs/ai/100/2/e2025/final), 사례 탐색 경로는 [MITRE ATLAS 공식 데이터](https://github.com/mitre-atlas/atlas-data)입니다. 이 표는 해당 자료의 모든 기법을 옮긴 완전 목록은 아닙니다.

## 개인정보 보호는 ‘이름 지우기’보다 넓습니다

직접 식별자를 없애도 다른 속성·외부 자료를 결합하면 개인을 추정할 수 있습니다. 어떤 정보를 학습·검색·로그에 넣을지 먼저 줄입니다. 차등정보보호는 인접한 데이터셋 사이의 출력 차이를 확률적으로 제한하는 틀입니다. `ε` 같은 파라미터와 조합·공개 횟수의 조건을 함께 읽어야 하며, 노이즈를 아무렇게나 추가하는 것과 같지 않습니다.

기존 [차등정보보호 해설](../논문해설_papers/개인정보보호_privacy/README.md)에서 정의·예제의 가정을 이어 읽습니다. 연합학습도 원시 자료가 한곳에 모이지 않는다는 성질과 업데이트로부터의 정보 유출 가능성을 나누어 봐야 합니다.

## 평가 세트는 학습·수정 루프와 분리합니다

같은 공격 예제를 보고 방어를 고친 뒤 그 예제에서 통과하면 회귀 검사의 근거입니다. 새로운 공격에도 일반화한다는 결론은 별도 입력·분포·판본으로 확인합니다. 자료와 모델을 수정할 수 있는 사람의 권한, 평가 정답의 노출, 배포·철회 이력도 모델 보안의 일부입니다.

## 원문에서 이어 읽기

- [NIST SP 800-218A](https://csrc.nist.gov/pubs/sp/800/218/a/final): 공식 초록의 AI 모델 생산자·시스템 생산자·구매자 범위입니다.
- [NIST AI 100-2 E2025](https://csrc.nist.gov/pubs/ai/100/2/e2025/final): 공식 초록의 생명주기·공격자 지식·목표에 따른 AML 분류입니다.
- [MITRE ATLAS 공개 데이터](https://github.com/mitre-atlas/atlas-data): 공식 저장소의 AI 위협·사례 데이터 안내입니다.
- [NIST SP 800-218](https://csrc.nist.gov/pubs/sp/800/218/final): 공식 초록·SDLC에 보안 개발 활동을 넣는 목적입니다.

## English

ML security spans data, dependencies, model artifacts, inference and privacy. Evaluation evidence must specify attacker control, data and deployment versions.
